## Question

ต้องเตรียมบิลด์ตรวจสอบที่ระบุ source commit ได้ และเก็บหลักฐานบน Android ของผู้ใช้ เพื่อแยกหน้าโหลดตอนเริ่มแอปออกจากชั้นหนังสือ สารบัญ และการเปิดตอน โดยเปรียบเทียบมีเน็ต ไม่มีเน็ต และเน็ตช้า รวมถึงตอนที่มีไฟล์อยู่แล้วกับตอนที่ยังไม่มี

งานนี้เป็น HITL prerequisite: agent เตรียมวิธีสร้าง/ติดตั้งและสิ่งที่ต้องบันทึกตามเครื่องมือและสิทธิ์ที่มีจริง ผู้ใช้ทำส่วนที่ต้องใช้มือถือของตน ไม่เดารุ่นอุปกรณ์ ไม่ถือว่าการ push ทำให้ APK เปลี่ยน และไม่ถอนแอปหรือล้างข้อมูลเดิมเพื่อให้การทดสอบผ่าน

ผลที่ต้องบันทึกใน resolution comment คือ build ที่ใช้ สภาพข้อมูลเดิม ช่วงที่รอ เวลาที่สังเกตได้ ขั้นตอน reproduce และภาพ/บันทึกประกอบที่มี ไม่ใช่การแก้ feature ให้เสร็จ หากยังสร้าง build หรือลองบนมือถือไม่ได้ ให้ระบุ prerequisite ที่ขาดตามจริง
