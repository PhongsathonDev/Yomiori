## Question

จะแสดงแหล่งแปลไทยและลิงก์ Nekopost รายเรื่องอย่างไร โดยคงเครดิตเดิมและรองรับข้อมูลเก่าที่ไม่มีแหล่งที่มา?

## Acceptance criteria

- นิยายทั้งสามเรื่องมีชื่อแหล่งแปลไทยและ URL หน้า novel ตามหลักฐานใน novels_source
- หน้ารายละเอียดเว็บและแอปแสดงลิงก์ใกล้เครดิตผู้แปล เปิดเว็บต้นทางได้ และแจ้งเมื่อเปิดไม่ได้ในแอป
- เรื่องที่ไม่มีข้อมูลต้นทางไม่แสดงลิงก์สมมติ แคชเก่ายังคงใช้งานได้
- ตรวจ build เว็บ, lint/typecheck แอป และ automated tests ก่อน commit/push

## Notes

- ผู้ใช้อนุญาตให้ implement โดยตรง ไม่ใช่งานวางแผนหรือ redesign ชั้นหนังสือ

## Resolution comments

### 2026-10-29 — OpenCode

- เพิ่ม optional `translationSource` (name/url) ใน Novel และ catalog เว็บ/แอปครบ 3 เรื่อง: kyudo-senpai → 17934, boyish-friend → 15877, black-cat-hangout → 17903 ตาม overview และ _source.json ใน novels_source
- แสดง “แหล่งแปลไทย: Nekopost” ใกล้เครดิตผู้แปล เว็บเปิดแท็บใหม่แบบ noopener/noreferrer; แอปมี link role, พื้นที่แตะขั้นต่ำ 44 และ Alert พร้อม URL เมื่อเปิดเบราว์เซอร์ไม่ได้
- catalog เก่าที่ไม่มีแหล่งที่มายังอ่านได้และเติมเฉพาะเครดิตที่ขาดจาก bundle ไม่ทับ metadata อื่น; validate metadata ต้นทางให้เป็น HTTPS
- หลักฐาน: mobile Jest 8 suites / 126 tests ผ่าน; mobile lint/typecheck ผ่าน; web production build ผ่านและ dist/data/novels.json มีเครดิตครบ; browser ตรวจหน้ารายละเอียด Kyudo แล้วพบลิงก์ถูกต้องและแสดงร่วมกับเครดิตเดิม; design detector ไม่พบ findings
- web lint ทั้งโปรเจกต์ยังไม่ผ่านเพราะ conditional hooks 4 จุดเดิมใน `reader-web/src/components/QuickFixModal.tsx` (อยู่นอก scope; มี ticket เดิม WF-0019) ไม่ได้แก้ไฟล์นั้น
- ทำให้ test loop ของ skippedChapters รองรับ array ว่างโดยระบุชนิด chapterNumber เพื่อให้ typecheck ผ่าน ไม่เปลี่ยนข้อมูลตอน
- ไม่แก้ chapter content ไม่บิลด์ APK และยังไม่ได้ตรวจบน Android จริง; การเปลี่ยน UI แอปต้องใช้ build ที่รวมโค้ดใหม่นี้
