## Question

หลักฐานอัตโนมัติ ภาพเปรียบเทียบ และ Android จริงยืนยันได้หรือยังว่าบุคลิกร่วมผ่านความเห็นผู้ใช้ พร้อมรักษาการอ่าน/ออฟไลน์/ข้อมูลเดิมและประสิทธิภาพ?

## Notes

- ยังไม่เริ่มและไม่ build ในรอบวางแผน; ใช้ [แผนพัฒนา ระยะ 5 และเกณฑ์สำเร็จร่วม](../assets/mobile-web-identity/plan.md)
- HITL: ผู้ใช้รับรองความสอดคล้องของภาพและทำส่วนทดสอบมือถือที่ agent เข้าถึงไม่ได้ ไม่รับรองแทนหรือสมมติรุ่นเครื่อง
- เก็บรุ่น/OS/build/source commit ธีม/ขนาดอักษร/คลัง/เครือข่ายและ before/after; ผล typecheck/lint/tests ไม่ทดแทน safe area/Thai wrapping/TalkBack/performance native
- ตรวจมีเน็ต/ไม่มีเน็ต/เน็ตช้า อ่านต่อ เปลี่ยนตอน พื้นหลัง ฟอนต์/ธีม และข้อมูลออฟไลน์ที่ยังอยู่หลังติดตั้งทับ ไม่ถอนแอป/ล้างข้อมูล
- เทียบ startup/เข้าอ่าน/scroll กับ baseline บนเครื่องและเงื่อนไขเดียวกัน ไม่อ้างตัวเลขที่ยังไม่วัด
- final APK ทำเมื่อมีคำสั่งส่งมอบและ UI พร้อมตาม `reader-mobile/VALIDATION.md`; push ไม่เปลี่ยน APK ที่ติดตั้งอยู่
- [ตรวจ APK สุดท้ายบน Android จริง](WF-0008.md) เป็นงานเก่าที่อาจใช้หลักฐานร่วม ไม่ใช่ blocker และไม่ปิดแทนกันอัตโนมัติ; ไม่มี Work with เพราะรอบส่งมอบร่วมยังไม่ได้ตกลง
