## Question

เว็บ Yomiori ที่สร้าง UI ขึ้นใหม่ด้วย AI อีกตัวหรือรุ่นที่ดีกว่า โดยคงธีมเดิม จะดูดีและใช้งานเหมาะกับผู้ใช้กว่าเว็บปัจจุบันหรือไม่?

## Notes

- ยังไม่เริ่ม; รอบเปิด ticket นี้บันทึกงานไว้ก่อน ตามขอบเขตของ [ทดลองเว็บ Yomiori v2 โดยคงธีมเดิม](WF-0033.md)
- เมื่อได้รับคำสั่งเริ่ม ให้ระบุ AI/model และเวอร์ชันที่ใช้จริงพร้อมเหตุผลก่อนสร้างต้นแบบ ไม่อ้างว่ารุ่นใหม่กว่าจะให้ผลดีกว่าโดยยังไม่มีผลเทียบ
- บันทึก commit ฐานและภาพเว็บเดิม แล้วให้ AI สร้างโครงหน้า/องค์ประกอบ UI ใหม่ทั้งชุดจาก brief เดียวกัน โดยรักษาอัตลักษณ์ Muji อบอุ่นและโหมดสว่าง/มืด/ซีเปีย
- ครอบคลุมเส้นทางหลักของเว็บเดิม: เลือกนิยาย ดูรายละเอียด/สารบัญ เข้าอ่าน และตั้งค่าการอ่าน; สำรวจความสามารถปัจจุบันก่อนกำหนดรายละเอียด เพื่อระบุสิ่งที่ต้นแบบทำได้และส่วนที่ยังไม่เชื่อมจริง
- ใช้ข้อมูลนิยายเดิมและกรณีเดียวกันในการเทียบ รวมชื่อไทยยาว เนื้อหาอ่านจริง และภาพประกอบ บนจอ desktop และเว็บมือถือ
- เก็บต้นแบบ/preview แยกที่ผู้ใช้เปิดลองได้ พร้อมวิธีรันและข้อจำกัด ไม่เปลี่ยน production entry point เพื่อทดสอบความชอบ
- HITL: ผู้ใช้เป็นผู้ตัดสินจากการลองใช้งานจริงว่าจะเลือก v2 ปรับต่อ หรือคงเว็บเดิม ผล build/test ไม่แทนคำตัดสินด้านหน้าตาและประสบการณ์ใช้งาน

## Acceptance

- มีต้นแบบ UI เว็บ v2 ที่สร้างใหม่และเปิดลองได้ พร้อมระบุ AI/model ที่ใช้จริงและ commit ฐานของเว็บเดิม
- ยังคงธีมและบุคลิกเดิมอย่างชัดเจนทั้งสามโหมด พร้อมภาพเทียบหน้า/ข้อมูล/ขนาดจอเดียวกัน
- เส้นทางหลักที่กำหนดไว้ลองใช้งานได้ แสดงขอบเขตที่ยังเป็น mock หรือยังไม่รองรับอย่างชัดเจน และไม่แก้ข้อมูลนิยายหรือข้อมูลผู้ใช้เดิมเพื่อทำตัวอย่าง
- มีผลเปรียบเทียบความสวยงาม ความอ่านง่าย ความสะดวกในการเลือกเรื่อง/เข้าอ่าน การรองรับจอเล็ก และความลื่นไหล พร้อมหลักฐานและข้อจำกัด ไม่สรุปว่าดีกว่าเพียงเพราะใช้ AI รุ่นอื่น
- ตรวจ build และ checks ที่เกี่ยวข้องกับต้นแบบ พร้อมบันทึกผลและปัญหาที่เหลือ
- บันทึกคำตัดสินและเหตุผลของผู้ใช้ก่อนปิด ticket; หากเลือกนำ v2 มาใช้ ให้เปิดงานส่งต่อสำหรับความครบของฟีเจอร์/การย้ายใช้งาน/การ deploy ตามช่องว่างที่พบ
