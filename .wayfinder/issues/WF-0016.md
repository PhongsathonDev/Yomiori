## Question

`ImageLightboxModal.tsx` จับ `Dimensions` ตอนโหลด module ทำให้การหมุนจอหรือเปลี่ยนขนาดหน้าต่างระหว่างเปิดแอปอาจไม่ถูกสะท้อนใน lightbox ยังไม่มีหลักฐานว่าเกิดจริงบน Android และยังไม่ยืนยันว่าซูมภาพทำงานได้ (การตรวจบนเครื่องจริงเป็นของ WF-0008)

ต้องหา reproduction ที่ชัดเจนก่อนแก้ และเมื่อแก้แล้วให้ขนาด lightbox ตามขนาดหน้าต่างปัจจุบัน รวมถึงยืนยันว่าการเปิด/ปิด/ซูมไม่ถอยหลัง

## Acceptance

- มีขั้นตอน reproduce ขนาดผิด (เช่น เปิดเครื่องที่จอเล็ก/ใหญ่ หรือ rotate/หน้าต่างเปลี่ยน) และระบุว่าเกิดหรือไม่เกิด
- ถ้าแก้: ใช้ขนาดหน้าต่างล่าสุดจาก API ที่เหมาะสมของ React Native โดยไม่เพิ่ม gesture library หรือเปลี่ยน navigation
- มี test หรือหลักฐานประกอบตามสิ่งที่ทำได้บน Jest/desktop และระบุส่วนที่ต้องตรวจบน Android
- ไม่เปลี่ยนพฤติกรรมซูม/ปิดภาพเมื่อไม่ได้เปลี่ยนขนาด
