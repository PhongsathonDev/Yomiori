## Question

ทำให้อ่านต่อกลับไปย่อหน้าล่าสุดและใกล้จุดเดิมภายในย่อหน้าที่ยาว โดยเนื้อหาที่อ่านอยู่บนหน้าจอ แม้คอมเมนต์ ภาพ หรือการตั้งค่าตัวอักษรเปลี่ยนความสูงหน้า

## Acceptance

- เก็บและคืนตำแหน่งที่สัมพันธ์กับเนื้อหา รวมกรณีปิดแอปและเปิดใหม่ โดยไม่ทับหรือทำข้อมูล progress เดิมเสีย
- เมื่อย่อหน้าที่บันทึกถูกลบหรือเปลี่ยน ID ให้ใช้ย่อหน้าที่ใกล้ตำแหน่งเดิมที่สุดเท่าที่ระบุได้; หากระบุไม่ได้ใช้เปอร์เซ็นต์เดิม
- progress รูปแบบเดิมยังอ่านและคืนตำแหน่งด้วยเปอร์เซ็นต์ได้
- ตรวจกรณีคอมเมนต์โหลดช้า รูปเปลี่ยนความสูง ขนาดตัวอักษรเปลี่ยน และเนื้อหาตอนถูกแก้ไข รวมการเลื่อนหลังผู้ใช้เริ่มอ่าน
- มี regression tests ที่ตรวจผลจริงและระบุข้อจำกัดที่ต้องตรวจ Android ใน WF-0008

## Evidence

- [การตัดสินใจตำแหน่งอ่านต่อ](WF-0010.md)
- [Android reliability review](../assets/android-reliability-review.md)

## Resolution

บันทึก ID ย่อหน้า ลำดับ และสัดส่วนภายในย่อหน้าควบคู่เปอร์เซ็นต์เดิม หน้าจอคืนตำแหน่งจาก layout และปรับตามการเปลี่ยนขนาดเนื้อหา โดยยกเลิกการคืนตำแหน่งเมื่อผู้ใช้เริ่มเลื่อน หาก ID หายใช้ย่อหน้าตามลำดับใกล้ที่สุด และใช้เปอร์เซ็นต์เมื่อไม่มี anchor ที่ใช้ได้ ข้อมูล progress เดิมยังอ่านได้

ชุด Jest ตรวจการบันทึก คืนตำแหน่งเมื่อ layout เปลี่ยนทั้งก่อนและหลังเริ่มอ่าน กรณี ID หาย และ progress เดิม; การตรวจ Android จริงเรื่องภาพ ตัวอักษร lifecycle และความแม่นยำยังอยู่ใน WF-0008
