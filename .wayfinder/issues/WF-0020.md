## Destination

ได้สเปกหน้าแรกชั้นหนังสือพร้อมภาพร่างที่ผู้ใช้ยอมรับสำหรับมือถือและแท็บเล็ตทั้งสองแนวจอ และเกณฑ์รองรับการหมุนทั้งแอปโดยรักษาหน้าอ่านเดิม ชัดพอให้ส่งต่อไป implement โดยไม่ต้องเดาการตัดสินใจด้าน UX หลัก

## Notes

- Planning only: ไม่ implement UI หรือเปลี่ยน config/build ใน map นี้; การ chart ไม่ resolve tickets
- ยึด [ข้อตกลงตั้งต้น: ชั้นหนังสือที่ปกเด่นและเลือกอ่านง่าย](../assets/bookshelf-responsive/brief.md) ซึ่งผู้ใช้ยืนยันแล้วสองรอบ ไม่เปิดโหวตข้อตกลงเดิมซ้ำเว้นแต่พบข้อขัดแย้งจริง
- ทุก session อ่าน `CONTEXT.md` และ consult `impeccable`, `vercel-react-native-skills`; tickets สนทนาใช้ `grilling` และ `domain-modeling`; ภาพร่างต้องทำร่วมกับผู้ใช้ ไม่อนุมัติแทนผู้ใช้
- คงโทนเดิมและ OLED black; เรื่องย่อ/ตัวละครอยู่หน้ารายละเอียด; แตะหนังสือเปิดรายละเอียด แถบอ่านต่อเข้าอ่านตำแหน่งล่าสุด
- ใช้ความกว้างจริงกำหนดจำนวนคอลัมน์ ไม่ผูกจำนวนคอลัมน์กับ orientation อย่างเดียว และไม่ถือผล Expo Go เป็นหลักฐาน standalone APK
- แยกจาก [วางรอบปรับความเสถียรและออฟไลน์ Reader Android](WF-0009.md) และ [เก็บงานคุณภาพ Reader ที่ตรวจพบแต่อยู่นอกเส้นความเสถียรและออฟไลน์](WF-0013.md); ไม่เปิด scope redesign ใน maps เดิม
- บันทึกงานที่เสร็จแล้วลง git และ push ตาม standing preference ของ repo; ไม่บิลด์ APK ระหว่างวางแผน

## Out of scope

- [เลือกภาพร่างชั้นหนังสือที่อ่านชื่อเรื่องง่ายบนมือถือและแท็บเล็ต](WF-0021.md) — ผู้ใช้ยกเลิกวันที่ 29 October 2026 เพราะพอใจกับหน้าแรกเดิม; ภาพร่างไม่ถูกอนุมัติและไม่ส่งต่อ implement งานหมุนจอและงานยืนยันสเปกยังคงสถานะเดิม ไม่ยกเลิกตามโดยอัตโนมัติ
- ลงมือปรับโค้ด UI, orientation/config, เพิ่ม dependencies, migration และ build/release; ส่งต่อเป็นงานถัดไปเมื่อแผนชัด
- ออกแบบหน้าอ่าน หน้ารายละเอียด หรือระบบธีมใหม่; การตรวจไม่ล้น/รักษาตำแหน่งเมื่อหมุนยังอยู่ใน scope
- เพิ่มระบบค้นหา สมาชิก ซิงก์ข้ามเครื่อง community หรือฟีเจอร์ค้นพบนิยายใหม่
- เปลี่ยนความหมายอ่านต่อ สถานะออฟไลน์ ข้อมูลนิยาย และกลไกแคช/ดาวน์โหลดที่แก้ไว้แล้ว
