## Question

เมื่อไฟล์ตอนในเครื่อง รายการตอนจาก manifest และข้อมูลหนังสือไม่ตรงกัน ควรใช้หลักฐานใดเป็นแหล่งอ้างอิงของคลังออฟไลน์ และตรวจคืนความสอดคล้องอย่างไรเพื่อไม่ซ่อนตอนที่มีอยู่จริง?

เทียบทางเลือก local index, validated file discovery และการใช้ร่วมกัน โดยอิงข้อมูลและรูปแบบไฟล์ของ repo ปัจจุบัน รวมถึงตอนสูงกว่า fallback เดิม หนังสือที่ไม่ได้อยู่ใน bundled catalog ไฟล์เสีย recovery backup และ metadata ที่อ่านไม่ได้ การตัดสินใจต้องรักษาไฟล์ดาวน์โหลดและ progress เดิม และอธิบายผลต่อเวลาเปิดแอปโดยไม่สรุปให้สแกนทุกไฟล์ก่อนแสดงหน้าจอ

เป็นการตัดสินใจร่วมกับผู้ใช้พร้อมข้อเสนอที่มีเหตุผลจากโค้ด ไม่ใช่ implementation ticket หากจำเป็นต้องทราบข้อเท็จจริงภายนอกเพิ่มเติม ให้เปิด research ticket เฉพาะคำถามนั้นตามขั้นตอนของ wayfinder
