## Destination

แอป Yomiori มีบุคลิกญี่ปุ่นมินิมอลอบอุ่นแบบเว็บ ใช้สี อักษร และองค์ประกอบสอดคล้องกัน แต่จัดวางเพื่อมือถือ อ่านง่าย แตะสะดวก และรักษาออฟไลน์/ความคืบหน้า/ค่าตั้งเดิม โดยผ่านภาพร่างที่ผู้ใช้รับรองและหลักฐาน Android จริงก่อนส่งมอบ

## Notes

- ผู้ใช้ขอวันที่ 29 October 2026: “อยากให้แอพมีบุคลิกเดียวกับเว็บ แต่จัดวางแบบมือถือ เขียนแผนการพัฒนาไว้ให้ก่อน”
- **Planning only ในรอบนี้:** สร้างแผนและงานอนาคต ไม่ claim/resolve decision ไม่แก้ UI/API/config/dependencies และไม่ build APK; งาน implementation ในกลุ่มนี้ต้องรอคำสั่งให้เริ่มพัฒนาจากผู้ใช้ด้วย ไม่ใช่ดู frontier อย่างเดียว
- รายละเอียดหลักและเกณฑ์รับงาน: [แผนพัฒนา: บุคลิกเดียวกับเว็บ จัดวางเพื่อมือถือ](../assets/mobile-web-identity/plan.md)
- ยึดเว็บปัจจุบันเป็น visual authority; สำรวจครั้งนี้อ่านโค้ดเท่านั้น ยังไม่มีภาพเทียบ native หรือ baseline performance
- คงโครงหน้าปัจจุบัน capsule ที่รับรอง ฟอนต์เนื้อหาที่เลือกได้ และ OLED black; การขยายขอบเขตต้องได้รับความเห็นชอบก่อน
- ไม่ฟื้นหรือใช้ภาพร่างที่ไม่อนุมัติจาก [แผนชั้นหนังสือที่ยกเลิก](WF-0020.md) และไม่ย้ายงานเสถียรภาพ/คุณภาพ/ตรวจ APK เดิมเข้ามา
- ก่อนลงมืออ่าน `CONTEXT.md`, Reader Android contract, `reader-mobile/AGENTS.md` และ skills ที่ตรงกับงาน; สเปก/ภาพร่างต้อง HITL หนึ่ง decision ticket ต่อ session
