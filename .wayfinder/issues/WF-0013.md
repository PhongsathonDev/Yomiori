## Destination

ได้รายการข้อบกพร่องคุณภาพ Reader ที่มีหลักฐานและเกณฑ์รับงานชัดเจน พร้อมลำดับทำหลังรอบความเสถียร/ออฟไลน์ โดยไม่เปลี่ยนข้อมูลเดิมหรือพฤติกรรมอ่านที่ผู้ใช้ยอมรับไปโดยไม่ได้ตกลง

## Notes

- ผู้ใช้สั่งให้สร้าง ticket สำหรับงานที่ยังไม่มีที่เก็บ วันที่ 28 October 2026 หลังปิด WF-0011
- ที่มา: [Android reliability review](../assets/android-reliability-review.md) หัวข้อ Smaller findings and deferred work
- งานใน map นี้ไม่ใช่แกนของ [วางรอบปรับความเสถียรและออฟไลน์ Reader Android](WF-0009.md); WF-0009 ยังโฟกัสการอ่านและออฟไลน์
- ทุกงานต้องรักษา storage key และข้อมูลเดิมในเครื่อง มี automated tests และไม่ขยายเป็น redesign หรือฟีเจอร์ใหม่
- ไม่รวมงาน implement ของ WF-0010/WF-0012 ซึ่งอยู่ในเส้นหลักของ WF-0009

## Decisions so far

- [แก้การเรียก React Hook แบบมีเงื่อนไขใน QuickFixModal เมื่อเปิดแก้ไขข้อความ](WF-0019.md) — ผู้ใช้อนุมัติแก้เฉพาะจุด; Hooks ถูกเรียกสม่ำเสมอแม้ปิด modal และ regression tests 7 เคส รวม build/lint เว็บผ่าน

## Not yet specified

- ลำดับความสำคัญและรอบที่จะลงมือ
- เกณฑ์รับงานบนอุปกรณ์จริงของแต่ละ ticket (บางข้อต้องดูบนจอ Android)
- จะรวมงานใดใน final APK รอบเดียวกับ WF-0008 หรือทำหลังส่งมอบ

## Out of scope

- Redesign ชั้นหนังสือหรือหน้าอ่าน ฟีเจอร์ community ใหม่ ระบบสมาชิก และซิงก์ข้ามเครื่อง
- iOS และ public release
- เปลี่ยน navigation หรือเพิ่ม virtualization
- เปลี่ยนความหมายของอ่านต่อ (WF-0010) และวิธีสแกนคลัง (WF-0012)
