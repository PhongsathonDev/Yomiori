## Question

mockup UI อีก 3 ทิศทาง (D, E, F) แบบใดที่จะต่างจาก A-C และต่างจากกันชัดเจน โดยยังทำ UX หลักได้ครบเหมือนเดิม?

## Notes

- ผู้ใช้สั่งวันที่ 29 October 2026: “ขอแบบ D E F เพิ่มสิ” ต่อจากชุด A-C โดยยังเน้นโครงก่อน ไม่ต้องเก็บรายละเอียด/บั๊กเล็ก
- ใช้ UX และข้อมูลตัวอย่างชุดเดียวกับ [สร้าง mockup UI ทางเลือก 3 แบบจาก UX เดียวกันโดยไม่ลอกหน้าตาเดิม](WF-0036.md) แต่ต้องไม่ซ้ำโครงกับ A (catalog), B (full stage), C (zine)
- ทิศทางตั้งต้น:
  - **D · โต๊ะทำงานนักอ่าน** — app shell แบบ workspace มีรางซ้าย/แผงขวา/แถบบน และมุมมองอ่านแบบ focus mode
  - **E · ห้องเดียว** — minimal gallery ทีละเล่ม มีสันหนังสือแนวตั้งและพื้นที่ว่างมาก เกือบไม่มี chrome
  - **F · มังงะ** — หน้ากระดาษการ์ตูน กรอบ panel, บอลลูนคำพูด, ฮาล์ฟโทน แต่เนื้อหายังอ่านได้
- เปิดดูแยกใน `prototype/ui-lab/`; ห้ามแก้ production entry point, ข้อมูลนิยาย หรือข้อมูลผู้ใช้เดิม
- HITL: ผู้ใช้เป็นผู้เลือกทิศทาง; รอบนี้ไม่ปิด ticket และไม่สรุปแทน
