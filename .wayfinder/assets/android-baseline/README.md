## ก่อนอัปเดต: เก็บอาการเดิมเท่าที่ทำได้

1. จดนิยาย/ตอนที่มั่นใจว่าเคยดาวน์โหลดแล้วหนึ่งตอน ถ้าเป็นตอนที่หายจากรายการ ให้จดชื่อและเลขตอน อย่าล้างหรือดาวน์โหลดทับเพื่อให้สถานะเปลี่ยนก่อนบันทึก
2. ในรุ่นเก่า ลองเปิดแอปแบบมีเน็ตและไม่มีเน็ตอย่างละหนึ่งครั้งถ้าสะดวก จดว่ารอที่หน้าสี/รูปเปิดแอป, หน้าหมุนโหลด, ชั้นหนังสือ, สารบัญ หรือหน้าอ่าน
3. ถ้าไม่ได้วัดรุ่นเก่าแล้ว ให้ใช้คำบอกเล่าเป็น qualitative baseline ไม่สร้างเวลาย้อนหลังขึ้นมา

## ติดตั้งโดยรักษาข้อมูล

1. ใช้ APK ใหม่จาก EAS build ที่ระบุในเอกสารนี้เท่านั้น และเลือกอัปเดตแอปเดิม
2. ไม่ถอนแอป ไม่กด Clear storage/Clear data และไม่ใช้คำสั่ง uninstall เพื่อแก้ปัญหาติดตั้ง
3. หาก Android แจ้ง package/signature/version ไม่เข้ากัน ให้หยุดและบันทึกข้อความ ไม่สร้าง signing key ใหม่หรือเปลี่ยน package เพื่อข้ามปัญหา
4. หลังติดตั้ง ตรวจข้อมูลแอปว่าเป็น `1.0.1` และ build `2` หากอุปกรณ์แสดง build code จากนั้นตรวจว่ารายการดาวน์โหลดเดิมและ progress ยังอยู่

การคง package และใช้ EAS credentials เดิมเป็นวิธีเตรียมการอัปเดต ไม่ใช่หลักฐานล่วงหน้าว่าลายเซ็น APK บนเครื่องตรงกันจนกว่าการอัปเดตจะสำเร็จ

## วิธีวัดรอบล่าสุด

ใช้เครื่องเดิม ขนาดตัวอักษร/ธีมเดิม และชุดดาวน์โหลดเดิม ทำซ้ำเงื่อนไขละ 3 ครั้งโดยไม่ล้างข้อมูล:

- **มีเน็ตปกติ:** Wi-Fi หรือมือถือที่ใช้งานได้
- **ไม่มีเน็ต:** ปิด Wi-Fi และข้อมูลมือถือก่อนเริ่ม
- **เน็ตช้า:** ทำเฉพาะเมื่อทำซ้ำสภาพที่เคยมีปัญหาได้จริง ระบุเครือข่ายตามจริง ไม่สมมติว่าเป็นการจำลอง latency ที่ควบคุมได้

ก่อนแต่ละครั้ง หยุดแอปจากข้อมูลแอปด้วย Force stop/บังคับหยุด แล้วเปิดใหม่จากไอคอน ไม่ใช้การล้างข้อมูล

จุดเวลา:

- **T0:** แตะไอคอนแอป
- **T1:** ชั้นหนังสือปรากฏและแตะใช้งานได้ — เวลาหลักสำหรับอาการที่ผู้ใช้แจ้ง
- **T2:** แตะนิยาย/เปิดสารบัญ แล้วรายการตอนพร้อมใช้งาน — วัดแยกจาก T1
- **T3:** แตะตอนที่มีในเครื่องจนย่อหน้าแรกปรากฏและเลื่อนได้ — วัดแยกจาก T1/T2

ถ้าจับเวลาด้วยตา ให้ระบุว่าเป็นค่าประมาณ จะบันทึกวิดีโอหน้าจอเพื่อหา T0/T1/T2/T3 ภายหลังก็ได้ ไม่บังคับติดตั้งเครื่องมือเพิ่ม

ทำเครื่องหมายว่ารอบใดเป็นการเปิดครั้งแรกหลังอัปเดต ไม่ปนกับรอบหลัง ๆ และไม่อ้างค่าจาก debug/Expo Go ว่าเป็นเวลาของ APK standalone

## บันทึกผล

ใช้ [results.md](results.md) ใส่ค่าจริง ไม่มีเกณฑ์ผ่านแบบตัวเลขที่เดาขึ้นก่อนวัด เครื่องหมาย “ยังไม่ได้วัด” ต้องคงอยู่จนมีผลจากผู้ใช้

อย่างน้อยขอผลสองเรื่อง: เวลา T0→T1 แบบมี/ไม่มีเน็ต และตอนที่เคยหายกลับมาเห็น/เปิดได้หรือไม่ หากยังหาย ให้บอกนิยาย เลขตอน และวิธีเข้าอ่านที่ลอง

Ticket ยังเปิดอยู่จนมีหลักฐานบนอุปกรณ์จริงหรือมีการตกลงปรับ prerequisite อย่างชัดเจน การ build ผ่านเพียงอย่างเดียวไม่ใช่ resolution
