ยกเลิกการพิจารณาภาพร่างแล้ว · เก็บเป็นประวัติ · ไม่ใช่สเปกส่งต่อ

คงหน้าแรกเดิมของแอป

ผู้ใช้ยกเลิกงานเลือกภาพร่างวันที่ 29 ตุลาคม 2026 เพราะพอใจกับแบบเดิม ภาพ A/B ด้านล่างไม่ได้รับอนุมัติและไม่ต้องเลือกต่อ

A — ชื่อเต็ม ไม่ตัด

อ่านแยกเรื่องได้โดยไม่ต้องเปิดรายละเอียด แต่ชื่อยาวทำให้เล่มนั้นสูงขึ้น

เปิดภาพร่างเดี่ยว

B — ไม่เกิน 3 บรรทัด

เห็นรายการได้กระชับกว่า แต่ท้ายชื่อบางเรื่องหายไป ต้องแตะรายละเอียดเพื่ออ่านครบ

เปิดภาพร่างเดี่ยว

ภาพร่างเก็บเป็นประวัติเท่านั้น: เดิมใช้เทียบความอ่านง่ายของชื่อ สัดส่วนปก ความหนาแน่น และลำดับอ่านต่อ → ตัวกรอง → หนังสือ ไม่ใช้ภาพเหล่านี้เป็นฐาน implement ภาพอาจย่อให้พอดีพื้นที่เทียบ; เลือกการดูภาพ “100%” เพื่ออ่านขนาดจริงและเลื่อนด้านข้าง หรือ “เปิดภาพร่างเดี่ยว” เพื่อดูเต็มพื้นที่หน้าต่างปัจจุบัน

ขนาดเป็น CSS px ไม่ใช่ข้อพิสูจน์ dp/sp ของ Android; ตัวอักษร 130% และพื้นที่แถบระบบเป็นการจำลอง ฟอนต์ระบบบน browser อาจต่างจากเครื่องจริง ไม่ได้ทดสอบหมุนจอ การคืนย่อหน้า lightbox ประสิทธิภาพ ออฟไลน์ หรือ standalone APK

ชื่อนิยาย/ปกจริงจาก repo; ตัวเลข 73 / 1 / 14 / 61 เป็นจำนวนไฟล์ตอนต้นทางวันที่ 29 ต.ค. 2026 ไม่ใช่จำนวนตอนบน CDN หรือในเครื่อง ประวัติอ่านและสถานะทั้งหมดเป็น fixture ไม่บันทึก storage ไม่เรียก API แตะหนังสือ/อ่านต่อแสดงคำอธิบายปลายทางเท่านั้น
