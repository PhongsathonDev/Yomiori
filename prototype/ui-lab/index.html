ลองหน้าตาใหม่หกแบบ

ทุกแบบทำเส้นทางหลักเหมือนกัน: เลือกเรื่อง → ดูรายละเอียด/สารบัญ → อ่าน → ตั้งค่า แต่เปลี่ยนโครง ภาษา และจังหวะการใช้งานคนละทาง ทั้งหมดเป็น mockup ที่ใช้ข้อมูลจริงบางส่วน

A คาตาล็อก ชั้นวางแบบดัชนีหนังสือ รายการเรียงเป็นตาราง เลือกเรื่องแล้วดูปก/เรื่องย่อในแผงข้าง ๆ ตัวหนังสือใหญ่และเส้นบาง ๆ ทำหน้าที่แทนการ์ด Editorial indexอ่านเร็ว เห็นหลายเรื่องพร้อมกัน
เริ่มที่โหมดกระดาษวาชิ เปิด mockup A → B โรงหนังสือ ชั้นวางเต็มจอแบบเดินผ่านโรงหนังสือ ปกเป็นพระเอก เลื่อนแนวนอนทีละเรื่อง มีป้ายชื่อญี่ปุ่นแนวตั้งและแผ่นกระดาษอ่านที่ลอยเหนือภาพ Immersive stageภาพนำทาง อารมณ์โรงหนังสือกลางคืน
เริ่มที่โหมดซูมิเข้ม เปิด mockup B → C สมุดตัดแปะ ชั้นวางเป็นสมุดตัดแปะ ปกเทป ตราปั๊ม และกระดาษพับ หน้ารายละเอียดเป็นหน้ากระดาษสองหน้าของสมุดเล่มหนึ่ง อ่านแล้วเหมือนเปิดสมุดส่วนตัว Tactile zineอบอุ่น มือทำ มีร่องรอยการอ่าน
เริ่มที่โหมดฮิโนกิอุ่น เปิด mockup C → D โต๊ะทำงานนักอ่าน หน้าตาเป็น workspace มีรางซ้ายสำหรับชั้นหนังสือ แผงขวาสำหรับตรวจดูเรื่อง และโหมดอ่านแบบโฟกัส ความหนาแน่นแบบเครื่องมือทำงาน Reading workspaceเห็นข้อมูลพร้อมกันหลายส่วน
เริ่มที่โหมดกระดาษวาชิ เปิด mockup D → E ห้องเดียว แสดงทีละเล่ม มีสันหนังสือแนวตั้งให้สลับเรื่อง พื้นที่ว่างจำนวนมาก แทบไม่มี chrome และปล่อยให้หน้าหนังสือเป็นพระเอก Single-book galleryเงียบ โปร่ง ทีละเรื่อง
เริ่มที่โหมดฮิโนกิอุ่น เปิด mockup E → F มังงะ หน้ากระดาษการ์ตูน กรอบ panel หนา บอลลูนคำพูด และฮาล์ฟโทน จัดชั้นวางเป็นหน้ามังงะที่เลือกเรื่องจาก panel ได้ Panel comicสนุก เป็นกันเอง เล่าเรื่องด้วยภาพ
