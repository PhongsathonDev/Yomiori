```sh
node prototype/ui-lab/serve.mjs
```

## หกทิศทาง

| | ชื่อ | แนว | เริ่มที่ธีม |
| --- | --- | --- | --- |
| **A** | คาตาล็อก | ชั้นวางเป็นดัชนีหนังสือ รายการเรียงตาราง + แผงดูตัวอย่างปก/เรื่องย่อด้านขวา ตัวอักษรใหญ่ เส้นบาง | กระดาษวาชิ |
| **B** | โรงหนังสือ | ชั้นวางเต็มจอ เลื่อนแนวนอนทีละเรื่อง ปกเป็นพระเอก ป้ายญี่ปุ่นแนวตั้ง และแผ่นอ่านลอยเหนือภาพ | ซูมิเข้ม |
| **C** | สมุดตัดแปะ | ชั้นวางเป็นสมุดตัดแปะ เทป ตราปั๊ม กระดาษพับ และหน้ารายละเอียดแบบสมุดสองหน้า | ฮิโนกิอุ่น |
| **D** | โต๊ะทำงานนักอ่าน | app shell แบบ workspace มีรางซ้าย/แผงขวา/แถบบน และโหมดอ่านแบบโฟกัส | กระดาษวาชิ |
| **E** | ห้องเดียว | gallery ทีละเล่ม มีสันหนังสือแนวตั้งและพื้นที่ว่างมาก เกือบไม่มี chrome | ฮิโนกิอุ่น |
| **F** | มังงะ | หน้าการ์ตูน กรอบ panel หนา บอลลูนคำพูด ฮาล์ฟโทน และสารบัญแบบหน้ามังงะ | กระดาษวาชิ |

ทั้งหกแบบกดเปลี่ยนธีมได้ครบ 3 โหมด และจำค่าใน `localStorage` แยกตามแบบ

## UX ที่ครอบคลุม

- ชั้นวาง: เห็นเรื่องที่อ่านค้าง + เลือกเรื่อง + สถานะตอน
- รายละเอียด: ชื่อไทยยาว เรื่องย่อ ข้อมูลผู้แต่ง/ผู้แปล ตัวละคร/ภาพ และสารบัญ
- อ่าน: เนื้อหาจริงตัวอย่าง, ตอนก่อน/ถัดไป, สารบัญ overlay, แถบความคืบหน้า
- ตั้งค่า: ธีม, ฟอนต์, ขนาดตัวอักษร, ระยะบรรทัด, รูปแบบบทสนทนา

## ข้อจำกัดของ mockup

- ใช้ข้อมูลตัวอย่างจากข้อมูลจริงบางส่วน (4 เรื่อง, 9 ตอนแรกต่อเรื่อง, เนื้อหาสูงสุด 22 บล็อกต่อบท) ไม่ได้โหลดทุกตอน
- ไม่มีคอมเมนต์ โหมดแก้ไข/Admin การซิงก์ความคืบหน้า หรือระบบหลังบ้าน
- ปุ่มและสถานะบางอย่างเป็นภาพนิ่ง/ค่าตัวอย่าง เช่น “อ่านไปแล้ว 32%”
- ตรวจเบื้องต้นบน Chrome desktop/mobile แล้ว แต่ยังไม่ทดสอบ Safari/Firefox หรืออุปกรณ์จริง
- ไม่แก้ production entry point หรือข้อมูลนิยายเดิม
