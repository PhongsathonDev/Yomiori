# Yomiori v2 prototype (read-only)

ต้นแบบหน้าตาเว็บ Yomiori รุ่น v2 สำหรับให้ผู้ใช้ลองเทียบกับเว็บปัจจุบัน โดยคงธีมญี่ปุ่นมินิมอลอบอุ่น Muji เดิมไว้ แต่จัดโครงหน้าและองค์ประกอบใหม่ทั้งชุด ต้นแบบนี้อ่านอย่างเดียว ไม่เชื่อมระบบจริง และไม่แก้ production entry point, ข้อมูลนิยาย หรือข้อมูลผู้ใช้ของเว็บเดิม

- แผนแม่: [ทดลองเว็บ Yomiori v2 โดยคงธีมเดิม](../../.wayfinder/issues/WF-0033.md)
- Ticket ตัวอย่างรอบนี้: [ทำตัวอย่างเว็บ v2 และปรับจนผู้ใช้พอใจก่อนพัฒนาจริง](../../.wayfinder/issues/WF-0035.md)
- งานพัฒนาเว็บใช้งานจริง: [สร้างเว็บ v2 ใหม่ด้วย AI อีกตัวหรือรุ่นที่ดีกว่าเพื่อเทียบกับเว็บปัจจุบัน](../../.wayfinder/issues/WF-0034.md) — ยังติด `Blocked by` ตัวอย่างนี้

## เปิดดู

ต้องมี Node.js และใช้ static server ขนาดเล็กที่แนบมา (ไม่มี dependency):

```sh
node prototype/web-v2/serve.mjs
```

เปิด http://127.0.0.1:5180/ — เปลี่ยน port ได้ด้วย `PORT=5181 node prototype/web-v2/serve.mjs`

แนะนำให้เปิดผ่าน server เพราะ `file://` บางเบราว์เซอร์จำกัด localStorage และฟอนต์ ถ้าเปิดแบบไฟล์ตรงๆ หน้าและธีมยังแสดงได้ แต่การจำค่า/ความคืบหน้าอาจไม่ทำงาน

## AI/model ที่ใช้จริง

- **DeepSeek V4.1 Flash** ผ่าน OpenCode (provider `opencode-go`, model id `deepseek-v4.1-flash`)

- commit ฐานของเว็บเดิมก่อนเริ่มต้นแบบ: `11a26c8` (HEAD ขณะเริ่ม; `c077189` เป็น commit ที่เปิดแผน)

## สิ่งที่เปลี่ยนจากเว็บปัจจุบัน

- ชั้นวางเปลี่ยนจาก card grid ขนาดใหญ่เป็น **ชั้นหนังสือ** ที่มีแนวรับใต้ปก แต่ละเรื่องเห็นปกหลายเรื่องพร้อมกัน และลดรายละเอียดซ้ำใน card
- หน้ารายละเอียดเปลี่ยนจาก card ต่อตอน เป็น **หน้าหนังสือ + สารบัญแบบตารางพิมพ์** ใช้เส้นบางและตัวเลขตอนแบบ serif แทนกรอบซ้ำๆ
- หน้าอ่านเปลี่ยนจาก banner card + กล่องบทสนทนา เป็น **หน้ากระดาษหนังสือ**: เปิดตอนด้วยเลขตอนและชื่อเรื่องแบบ serif, เนื้อหาความกว้างจำกัด, บทสนทนาเป็นแถบ색/ชื่อผู้พูดที่เบาลง
- ตั้งค่าเป็น **side sheet** พร้อมตัวอย่างการอ่าน และปรับผลแบบเห็นทันที
- ใช้ฟอนต์คู่ใหม่: `Noto Serif Thai` สำหรับหัวเรื่อง/เนื้อเรื่องเริ่มต้น และ `IBM Plex Sans Thai Looped` สำหรับ UI โดยยังคงสีถ่าน กระดาษวาชิ และดินเผาเดิม
- แก้ contrast ของข้อความรองและปุ่มในโหมดมืด/ซีเปียให้ผ่าน AA และเพิ่ม focus ring, reduced motion, `inert` ให้ dialog

## ขอบเขตและข้อจำกัด

- **อ่านอย่างเดียว**: ไม่มีคอมเมนต์, โหมดแก้ไข/Admin PIN, การบันทึกตอน, การอัปโหลดรูป
- ความคืบหน้าและค่าตั้งอยู่แค่ `localStorage` ของเบราว์เซอร์ที่เปิด ไม่ซิงก์ข้ามเครื่อง ไม่ผูกกับบัญชี
- ข้อมูลนิยายเป็น **สำเนา ณ วันที่สร้าง** (`js/data.js`) ไม่ได้อ่านสดจาก CDN; ถ้าเว็บจริงมีตอนใหม่ต้องรัน build data ใหม่
- ใช้ข้อมูลจริงครบ 5 เรื่อง 175 ตอน และภาพประกอบที่อ้างถึง แต่ยังไม่รวมข้อมูลคอมเมนต์และ manifest/CDN ของเว็บจริง
- หน้ารายละเอียดแสดงตัวละคร 8 คนแรกและภาพรวม 4 ภาพแรก; ข้อมูลเต็มยังอยู่ในเว็บเดิม
- ต้นแบบนี้ไม่แทนที่ production และไม่ควรใช้ตัดสินคุณภาพเนื้อหาหรือระบบหลังบ้าน

## ภาพเทียบและผลตรวจ

ดู [COMPARISON.md](COMPARISON.md) และโฟลเดอร์ [evidence/](evidence/)

- ภาพ before: เว็บปัจจุบันที่ `npm run dev` (port 5173)
- ภาพ after: ต้นแบบนี้ (port 5180)
- จอ desktop 1440×900 และ mobile 390×844, เรื่อง/ตอน/ธีมเดียวกัน
- Lighthouse ของต้นแบบ: Accessibility 1.0, Best Practices 1.0, SEO 1.0 ทั้งหน้าร้าน (dark) และหน้าอ่าน (light) — ดู `evidence/lighthouse-*.json`
- ข้อมูล DOM/ความสูงหน้า/เวลาโหลดอยู่ใน `evidence/metrics.json`; เวลาโหลดเป็นเพียงการเทียบในเครื่อง dev/static ไม่ใช่ benchmark production

## ตรวจสอบซ้ำ

```sh
node prototype/web-v2/tools/check.mjs       # ข้อมูล/ภาพ/ลิงก์/ฟอนต์ครบ
node --check prototype/web-v2/js/app.js     # syntax
```

ถ้าจะสร้างข้อมูลใหม่จาก `reader-web`:

```sh
node prototype/web-v2/tools/build-data.mjs
```

ถ้าจะสร้างหลักฐานภาพใหม่ (ต้องเปิด dev server ของเว็บเดิมที่ 5173 และ prototype ที่ 5180):

```sh
node prototype/web-v2/tools/capture.mjs
```

`build-fonts.mjs` ใช้เมื่อต้องการดาวน์โหลดฟอนต์ใหม่เท่านั้น (ต้องต่อเน็ต) ฟอนต์ที่ commit ไว้แล้วใช้งาน offline ได้

