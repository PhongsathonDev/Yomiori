- แยก HTML ด้วย Python `HTMLParser` อิสระจากตัวดึง แล้วเทียบข้อความเรียงย่อหน้าและตำแหน่งภาพกับ Markdown ทุกตอนตรงกัน รวม 9,556 ย่อหน้า/ตำแหน่งภาพ ไม่ใช้เพียงจำนวนตัวอักษรหรือการสุ่มตรวจ
- รักษาตัวหนาจาก `<strong>` ทั้ง 21 ตำแหน่งในตอน 56, 57, 58 และ 72 เป็น Markdown `**...**` และตรวจเทียบตำแหน่งกับ HTML แล้ว; ตัวดึงปัจจุบันยังไม่เก็บตัวหนาโดยอัตโนมัติ จึงต้องตรวจรูปแบบอีกครั้งหากดึงทับด้วย `--force`
- ตรวจชื่อเต็ม เครดิต วันที่ URL ของแต่ละตอน ทะเบียนไฟล์ สารบัญ ชื่อไฟล์ UTF-8 และ LF แล้ว
- ภาพทั้ง 6 ภาพมี SHA-256 ตรงกับไฟล์ที่ดาวน์โหลดจาก URL ต้นทาง และผ่านการตรวจโครงสร้างภาพด้วย Pillow
