# สถานะการแปลง — เรื่องราวของการพรากเพื่อนสนิทสาว...

- Slug: `boyish-friend`; Nekopost project 15877.
- ต้นฉบับ: เก็บครบ **99/99 รายการ** (Ch.1–97, Ch.84.5 และ Ch.99)
- แปลงเข้า reader ใหม่ทั้งเรื่อง: **99/99 ตอน** ด้วย pipeline `whole-novel`
- ใช้ `_source.json` เมื่อมี หรือไฟล์ `Ch_` ในโฟลเดอร์เรื่องเป็นทะเบียนต้นฉบับ
- checkpoint ครบที่ `.conversion/boyish-friend/` (`plan.json`, `maps/`, `receipts/`)
- ทุกตอนผ่าน `audit --complete`: verified 99, legacyUnverified 0, pending 0, excluded 0
- ข้อความทุกช่วงประกอบจากต้นฉบับและ mapping ที่ตรวจแล้ว ไม่มีการเขียนสำนวนใหม่
- เว็บและมือถือมี JSON ตอน ชุด index และ roster ตรงกันครบ 99 ตอน
- ตอนเก่า Ch.1–14 ถูกแปลงใหม่ทับจากต้นฉบับปัจจุบัน ไม่ใช้ผลลัพธ์ตัวแปลง heuristic เดิม
- ขยาย roster สำหรับตัวละครที่มีบทพูดจริง: ยูคาริ, คานัปเปะ, ฟุยุ, ครูเอโตะ, คาเอเดะ,
  ฮิโรโตะ, คุณแม่/คุณพ่อของอายะ, อากิจัง, ฮารุกิ, จิฮารุ, เรียวจิ, สตรีมเมอร์,
  เด็กชาย, คุณน้ามาสะ, เพื่อนร่วมชั้น และผู้คนรอบข้าง

## คำสั่งตรวจสอบ

```sh
npm --prefix reader-web run conversion -- audit --novel boyish-friend --complete
npm --prefix reader-web test
npm --prefix reader-web run build
```

## หมายเหตุ

- ต้นฉบับยังคงเป็นข้อมูลต้นทาง ไม่ได้แก้ไขข้อความเพื่อให้ตรงกับผลแปลง
- จำนวน 99 คือจำนวนรายการบนต้นทาง ซึ่งรวมตอนแจ้งข่าว Ch.84.5 และ Ch.99
- ยังไม่ได้ build APK ใหม่; แอปเดิมดึงตอน/สารบัญชุดใหม่ผ่าน CDN ได้
