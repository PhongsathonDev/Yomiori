# Boyish Friend — visual asset sources

## Selected artwork & sources

1. **Novel Cover & Banner (Nekopost / France Shoin e-Books):**
   - Source: Nekopost Novel Project 15877 (`https://www.nekopost.net/novel/15877`) / France Shoin e-Books official Volume 1 cover.
   - Original novel title: *クラスで2番目に可愛いボーイッシュ幼馴染を、二泊三日の修学旅行で寝取って種付けセックス漬けにする話*
   - Author: 月見ハク (Tsukimi Haku)
   - Artist / Cover Illustrator: あかつき聖 (Akatsuki Hijiri)
   - Retrieved: 2026-10-29.

2. **Character Portraits (Nekopost):**
   - **Minatori Aya (มินะโทริ อายะ):** Cropped from the official Nekopost Volume 1 cover illustration by あかつき聖.
   - **Boyan (โบยัน - ตัวเอก):** Cropped from Nekopost Manga Project 15409 (`https://www.nekopost.net/manga/15409`), Chapter 1, Page 6 by あおむし (Aomushi).
   - **Tokita (โทกิตะ):** Cropped from Nekopost Manga Project 15409, Chapter 1, Page 14 by あおむし (Aomushi).
