เล่ม 6 บทที่ 2-3

วันนี้ผมไม่ได้เข้าชมรม….คือว่า

ผมส่งข้อความไปยังกลุ่มแชทของชมรมวรรณกรรมก่อนจะเอนตัวจมลงไปในเบาะรถไฟ

หลังจากเหตุการณ์เมื่อวานที่เหมือนการไต่สวน ผมก็ตรงไปขึ้นรถไฟทันทีหลังเลิกเรียนโดยไม่แวะที่ห้องชมรม

อย่าเข้าใจผิดล่ะ ไม่ได้หนีปัญหาหรืออะไรเลย ผมพยายามจะพูดกับยากิชิโอะแล้ว แต่สุดท้ายก็คลาดสายตาไป

[ นึกว่าเธอขึ้นรถไฟขบวนนี้แล้วนะ… ]

ขณะที่พยายามมองหายากิชิโอะ ประตูรถไฟก็ปิดลง พร้อมกับการสั่นเบาๆ ของรถไฟที่เริ่มเคลื่อนตัว

รถไฟดูโล่งผิดปกติ ทำให้ผมสามารถนั่งตรงกลางที่นั่งยาวได้อย่างสบายๆ

[ ...เอาเถอะ ถ้าคลาดไปแล้วก็ช่วยไม่ได้ ]

เมื่อมีเวลาว่างกว่าที่คาด ผมหยิบหนังสือเล่มเล็กออกมาจากกระเป๋า

หนังสือเล่มนี้คือ <101 คนที่ย้ายโรงเรียนมาเล็งเป้ามาที่ผม> หรือชื่อย่อว่า < ZeroTen> ผมอ่านเล่มล่าสุดไปได้ครึ่งหนึ่งแล้ว

มันเป็นนิยายเลิฟคอมเมดี้เกี่ยวกับตัวเอกที่ต้องรับมือกับสาวสวยคนใหม่ที่ย้ายโรงเรียนมาเข้าหาเขาติดต่อกันถึง 101 วัน เนื้อเรื่องขึ้นชื่อเรื่องการแนะนำตัวละครที่เพิ่มมากขึ้นเรื่อยๆ ในแต่ละเล่ม

พูดถึงเล่มที่แล้ว มีนักเรียนย้ายเข้ามาใหม่ 27 คน และ 18 คนก็ออกจากโรงเรียนไปแล้ว

ตัวละครที่หมดบทบาทก็จะค่อยๆ หายไป แต่พวกเขายังคงใช้ชีวิตเหมือนคนทั่วไป เริ่มต้นวันใหม่ ไปโรงเรียน อ่านหนังสือ เล่นกับเพื่อน และบางครั้งก็ตกหลุมรัก

ผมพยายามอ่านหนังสือ แต่ก็ไม่สามารถตั้งสมาธิได้ จึงปิดหนังสือลง

ยากิชิโอะเป็นดาวรุ่งของชมรมกรีฑา ถ้าเธอลงจากเวทีนี้แล้วจะมีบทบาทอะไรต่อไปกันนะ?

ไม่ว่าจะเป็นอะไร เธอคงเผชิญหน้ามันด้วยรอยยิ้มสดใสราวกับแสงแดดฤดูร้อน...

ระหว่างที่ผมจมอยู่ในความคิด มีใครบางคนมานั่งข้างๆ

รถไฟคงเริ่มแน่นขึ้นโดยไม่ทันสังเกตเหรอ ? ผมยกกระเป๋าขึ้นวางบนตักก่อนมองไปรอบๆ แต่รถไฟก็ยังคงโล่งอยู่

…อะไรน่ะ?

ผมหันไปมองคนข้างๆ พบว่าเป็นเด็กนักเรียนจากโรงเรียนซึวะบุกิที่ไม่คุ้นหน้า เธอกอดกระเป๋าไว้แน่นพลางพึมพำอะไรบางอย่างเบาๆ ดูน่าขนลุก

ผมลุกขึ้นย้ายไปนั่งที่อีกตู้รถไฟอย่างเงียบๆ

…อะไรของเธอกัน?

ผมเคยได้ยินเรื่องคนที่ชอบนั่งที่ประจำ แล้วรู้สึกกระวนกระวายถ้ามีใครมานั่งแทน บางทีที่นั่งที่ผมเลือกอาจจะเป็นที่ประจำของเธอก็ได้ ถือว่าได้ทำความดีแล้วกัน

เมื่อคิดได้แบบนั้น ผมก็รู้สึกพอใจ แต่ไม่นานก็มีคนมานั่งข้างๆผมอีก

คราวนี้ก็เป็นผู้หญิงคนเดิมที่พึมพำอยู่ข้างๆ ผมอีกครั้ง

น่ากลัวจริงๆ หรือว่าเธอเป็นวิญญาณที่มีแต่ผมมองเห็นกันแน่?

ขณะที่กำลังตกใจ รถไฟก็เริ่มชะลอความเร็ว เรามาถึงสถานีชินโทโยฮาชิ ซึ่งเป็นปลายทางของสายอัตสึมิ

ผมลงจากรถไฟพร้อมกับผู้โดยสารคนอื่นๆ แต่ผู้หญิงคนนั้นก็ยังเดินตามมาใกล้ๆ ผมพยายามเก็บอาการอยากวิ่งหนีเอาไว้ แล้วรีบวิ่งผ่านประตูตรวจตั๋วทันทีที่ออกมา

ผมเป็นผู้ชาย เธอไม่น่าจะวิ่งตามทัน-

[ เดี๋ยวก่อน! ]

เธอตามผมทันอย่างรวดเร็ว เด็กสาวลึกลับจับแขนผมไว้ที่ลานทางใต้ใกล้สถานี

[ ต้องการอะไร!? ผมไม่มีเงินหรอกนะ! ]

เธอตะโกนลั่นในขณะที่ยังจับแขนผมอยู่

[ ชา! ไปดื่มชากันเถอะ! ]

[ …หา? ]

นี่มันเข้าข่ายการจีบแบบกลับด้านหรือเปล่า? ฉากคลาสสิกในนิยายโรแมนติกที่ผู้หญิงเข้ามาชวนผู้ชายแบบไม่ทันตั้งตัว แต่ทำไมมันถึงต่างกันแบบนี้ล่ะ?

[ ผมมีขวดน้ำอยู่แล้ว ไม่เป็นไรหรอก! ปล่อยผมไปเถอะ! ]

ผมพยายามดึงตัวออกสุดกำลัง แต่สุดท้ายกลับโดนเธอลากไปแทน

[ แค่ไปดื่มชาเอง! ฉันไม่ทำอะไรหรอก แค่อยู่เป็นเพื่อนกันสักพักก็พอ! ]

นี่มันความรู้สึกที่ตัวเอกในนิยายโรแมนติกต้องเผชิญหรือเปล่า น่ากลัวเกินไปแล้ว ต่อไปนี้ผมจะอ่านแต่แนวต่างโลกเท่านั้น

สุดท้าย ผมก็พยักหน้ารับอย่างจำนน พร้อมกับยอมรับชะตากรรมของตัวเอง...

◇

ผมถูกเด็กสาวปริศนาจากโรงเรียนซึวะบุกิจับไว้ที่ลานใต้ของสถานีโทโยฮาชิ

เรานั่งตรงข้ามกันในร้านกาแฟที่มองออกไปเห็นลานสถานี

เหตุผลที่เลือกที่นี่ก็ง่ายมาก—มีสถานีตำรวจอยู่ติดกัน

ผมจิบ "กาแฟประจำวัน" พลางลอบมองเธอด้วยหางตา

เธอก้มหน้าอยู่ ทำให้ผมมองหน้าเธอชัดๆ ไม่ได้ แต่ที่แน่ๆ คือผมไม่รู้จักเธอ

เธอมีใบหน้าที่เล็กกะทัดรัดและรูปร่างเพรียวบางคล้ายกับนักกีฬา

เธอกำลังจิบเครื่องดื่มสตรอว์เบอร์รีกับโยเกิร์ตที่จัดเป็นชั้นๆ

เครื่องดื่มนี่ดูน่ารักเกินไปสำหรับคนที่หน้าตาเหมือนโจรป่านะ...

[ เอ่อ... เราเคยเจอกันที่ไหนมาก่อนหรือเปล่าครับ? ]

เด็กสาวโจรป่าสะดุ้งเฮือก

[ น-นุคุมิซึชอบผู้หญิงแบบไหนเหรอ!? ]

คำถามช่างกะทันหัน และเธอรู้จักชื่อผมได้ยังไง?

โจรป่าสาวเงยหน้าขึ้นมาครั้งแรกขณะที่ผมยังนั่งอึ้งอยู่

ดวงตากลมโตของเธอคลอไปด้วยน้ำตา และริมฝีปากของเธอดูซีดเล็กน้อย

[ ฉันถามว่าชอบผู้หญิงแบบไหน... ]

ยังไม่พ้นเรื่องนี้อีกเหรอ ดูยังไงเธอก็ไม่ได้สนใจคำตอบของผมหรอก

[ เอ่อ... ในเมื่อรู้จักชื่อผมแล้ว มีอะไรต้องการจากผมหรือเปล่าครับ? หรือว่ามีใครส่งคุณมา? ]

ใช่เลย ถ้าเธอคิดจะกลั่นแกล้งผม ผมจะลากเธอไปสถานีตำรวจเดี๋ยวนี้

ถ้าเป็นแค่การล้อเล่น—ตรงไปสถานีตำรวจซะ จงสรรเสริญสถานีตำรวจ

เด็กสาวที่เหมือนจะชะงักไปกับคำพูดของผม จู่ๆ ก็พูดเสียงดังพลางมองไปรอบๆ

[ เห็นมั้ยล่ะ! ฉันบอกแล้วไงว่าฉันจีบเขาไม่ได้! ]

ผมกำลังโดนจีบเหรอ? แล้วเธอพูดกับใครกันเมื่อกี้? ขณะที่ผมกำลังสงสัย ผู้คนราวสิบคนที่นั่งรอบๆ ก็ลุกขึ้นพร้อมกันอย่างกระตือรือร้น

[ สู้ๆนะ กัปตัน! ] [ เขาเกือบจะติดกับแล้ว! ] [ แค่กระตุ้นอีกนิดเดียว! ]

..เกิดอะไรขึ้นวะเนี่ย ?

ขณะที่ผมยังอึ้ง เด็กสาวที่พวกเขาเรียกว่ากัปตันเกาหัวพลางส่งยิ้มแหยๆ

[ ขอโทษนะ นุคุมิซึ ทุกคนตามฉันมาด้วย ]

[ ...เอ่อ แล้วคุณคือ? ]

[ อ๋า ฉันรู้เลยว่าเธอจำฉันไม่ได้ รอแปปนะ ]

เธอรีบรวบผมขึ้นเป็นหางม้าและติดกิ๊บยึดผมหน้าม้าไว้ ทำให้เธอดูสดใสและกระฉับกระเฉงขึ้นมาทันที

[ แบบนี้จำฉันได้แล้วใช่มั้ย? ]

ใคร ? ผมยังคงงุนงง ส่วนเด็กสาวหางม้าก็ยิ้มแหยหนักขึ้น

[ เอาน่า เราเคยเจอกันในการประชุมประธานชมรม ฉันอยู่ชมรมกรีฑาหญิงชื่อคุราตะไง ]

อ๋อ กัปตันปีสองของชมรมกรีฑาหญิง เคยเข้ามาทักผมบ้างอยู่สองสามครั้ง

[ ไม่ได้เจอกันนานนะ แล้วพวกคนอื่นๆ ที่อยู่รอบๆ... ]

พวกสาวๆ พร้อมใจกันยกโทรศัพท์ขึ้นมาถ่ายรูปผม

[ อ่า นี่คือสมาชิกชมรมที่มารอจับตาคุณนอกใจน่ะ ]

[ ...นอกใจ? หมายถึงอะไร? ]

สาวๆ ชมรมกรีฑามองหน้ากัน ก่อนจะก้มโค้งพร้อมกัน

[ ช่วยเลิกกับเลม่อนทีค่ะ! ]

อะไรนะ!? เสียงของพวกเธอดังก้องไปทั่วร้าน

กลุ่มสาวๆ มาก้มให้ผมในร้านกาแฟใกล้สถานีตำรวจขนาดนี้...

[ ช่วยเงยหน้าขึ้นเถอะ ! ก่อนจะพูดเรื่องเลิกกัน ยากิชิโอะกับผมยังไม่ได้คบกันเลยด้วยซ้ำ ]

สาวๆ ค่อยๆ เงยหน้าขึ้นมาเมื่อได้ยินคำตอบของผม

ดูเหมือนจะเข้าใจแล้ว? แต่ความโล่งอกของผมอยู่ได้ไม่นาน สาวๆ ก็เริ่มกระซิบกระซาบอะไรบางอย่างที่ฟังดูไม่ดี

[ เล่นๆ เหรอ...] [ แย่ไปแล้ว] [ เหมือนแฟนเก่าของซาโตโกะเลย ] [ แต่ยังไม่ได้เป็นแฟนเก่ากันนี่? ]

แย่ล่ะ ข่าวลือที่ไม่มีมูลกำลังวนเวียน ซ้ำยังได้ยินว่าซาโตโกะมีแฟนเก่าที่แย่สุดๆ

ผมพยายามมองหาคนช่วย แต่ดันสบตากับกัปตันคุราตะที่มองผมอย่างจริงจัง

[ พวกคุณสองคน—เล่นๆ กันอยู่เหรอ? ]

[ ไม่ใช่นะ ! ความสัมพันธ์ของเราไม่ใช่แบบนั้น! เราเป็นแค่เพื่อนกันเท่านั้น ]

สาวๆ ในชมรมเงียบลง

ความตึงเครียดเพิ่มขึ้นจนเหมือนจะระเบิด แต่กัปตันคุราตะยกมือขึ้นเพื่อสงบทุกคน

[ เชื่อได้มั้ย? ]

จะเชื่อหรือไม่ก็ตาม ถึงผมกับยากิชิโอะจะเคยจับมือกัน แต่นั่นไม่ได้มีความหมายโรแมนติกเลย

ผมพยักหน้าอย่างหนักแน่น และกัปตันคุราตะก็ตอบด้วยการพยักหน้ากลับ

[ ทุกคน นั่งลงเถอะ พวกเรารบกวนลูกค้าคนอื่นแล้ว ]

แม้ว่าสาวๆ จะดูไม่ค่อยพอใจ แต่พวกเธอก็กลับไปที่ที่นั่งและเริ่มจิบเครื่องดื่มน่ารักๆ กันอีกครั้ง

กัปตันคุราตะละสายตาจากหลอดแล้วพูดต่อด้วยน้ำเสียงสงบ

[ เลม่อนจังมีโอกาสที่จะได้แข่งอินเตอร์ไฮปีนี้ ถ้าเธอยังรักษาฟอร์มไว้ได้ มันสำคัญต่อการแนะนำตัวเพื่อเข้ามหาวิทยาลัย และพวกเราทุกคนสนับสนุนเธอ ]

เธอมองเพื่อนร่วมทีมก่อนจะพูดต่อ

[ พวกเราไม่ได้ขัดขวางที่เธออยู่ทั้งในชมรมวรรณกรรมและกรีฑา เพราะนั่นคือสิ่งที่เธอต้องการ แต่ถ้าคุณพยายามจะพาเธอออกจากเส้นทางจริงๆ เราไม่สามารถนิ่งดูดายได้ ]

[ เอ๊ะ? ผมไม่ได้พาเธอออกไปไหนเลยนะ- ]

กัปตันคุราตะส่ายหน้าและพูดแทรก

[ ชมรมเรามีนโยบายให้ฝึกเดี่ยวได้เมื่อขออนุญาต และเลม่อนจังก็ขอฝึกเดี่ยวไปช่วงหนึ่งแล้ว และอีกอย่าง— ]

กัปตันคุราตะยิ้ม โดยที่มีชิ้นสตรอว์เบอร์รีติดอยู่ตรงริมฝีปาก

[ ฉันได้ยินมาว่าบรรยากาศในชั้น 1-C ของเลม่อนจังกับใครบางคนดูแปลกๆ จริงมั้ย? ]

เธอรู้เรื่องนี้ด้วย ผมมองไปรอบๆ พบว่ามีบางคนในชั้นของผมอยู่แถวนี้เหมือนกัน

ดูเหมือนจะเลี่ยงตอบคำถามไม่ได้ แต่จะพูดเรื่องนี้ในที่สาธารณะ...

ผมจิบกาแฟเย็นที่เหลือแล้ววางถ้วยลงบนจานรอง
