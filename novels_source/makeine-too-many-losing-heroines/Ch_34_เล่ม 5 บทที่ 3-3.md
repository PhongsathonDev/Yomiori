เล่ม 5 บทที่ 3-3

วันต่อมากลิ่นหอมของโกโก้ยังคงอบอวลอยู่รอบปกคอเสื้อของผม

ชั้นเรียนในวันศุกร์สิ้นสุดลงในขณะที่ความรู้สึกนี้ยังคงอยู่ ตอนนี้เป็นเวลาของชั่วโมงโฮมรูมแล้ว

เมื่อคืนเราไม่ได้พูดอะไรกันมาก โคมาริกับผมใช้เวลาสิบนาทีสุดท้ายรอรถไฟ

รู้สึกว่าเธอคงให้อภัยกับการกระทำแย่ๆของผมต่อชมรมวรรณกรรมเมื่อไม่นานมานี้แล้ว

แล้วก็เหมือนเคย อามานัตสึเซ็นเซเข้ามาในห้องเรียนด้วยท่าทีง่วงเหงาหาวนอนเล็กน้อย ขณะที่ผมยังจำรสขมๆของลูกเกดดำบนลิ้นได้

[ เอ่อ อืม ทุกคนอยู่กันครบแล้ว มีเรื่องที่ต้องเตือนเกี่ยวกับงานเปิดบ้านในวันอาทิตย์นะ ]

อามานัตสึเซ็นเซกระแอมก่อนจะพูดต่อ

[ ในวันนั้น มีเพียงผู้ที่ได้รับมอบหมายให้เป็นไกด์นำเที่ยวและผู้ที่รับผิดชอบเรื่องเยี่ยมชมชมรมเท่านั้นที่จะเข้ามาที่โรงเรียนได้ คนที่เหลืออย่าเข้าใจผิด อย่ามาโรงเรียนเชียวนะ เอาล่ะคนที่อยู่เวร แจกใบปลิวนี้ที ]

นักเรียนที่อยู่เวรเริ่มแจกใบปลิวให้พวกเรา เป็นตารางงานของวันนั้นและการเตรียมการที่ต้องทำล่วงหน้า

…อืม งานเปิดบ้านเริ่มบ่ายโมง ครึ่งแรกพวกเรานักเรียนจะพาผู้เยี่ยมชมทัวร์โรงเรียน และหลังจากนั้นก็เป็นเวลาว่าง พวกเขาสามารถตรวจสอบโรงเรียนได้ตามใจชอบ

ผมไม่รู้ว่าผู้เยี่ยมชมจะมาที่ห้องชมรมเมื่อไหร่ อีกอย่าง ผมไม่ได้สมัครเป็นไกด์นำเที่ยว เพราะงั้นคงต้องรออยู่ที่ห้องชมรม

หลังจากที่ทุกคนได้รับใบปลิวแล้ว อามานัตสึเซ็นเซก็เริ่มอธิบาย

[ ไกด์นำเที่ยวให้ไปรวมตัวกันที่หอประชุมหลังจากฉันอธิบายเสร็จ คนอื่นๆเตรียมตัวทำงานได้เลย ห้องเรียนของเรารับผิดชอบบอร์ดประกาศบนชั้นหนึ่ง ไปดูตารางการกันได้ ทำเสร็จแล้วก็กลับบ้านได้- ]

หลังจากนั้น อามานัตสึเซ็นเซก็นั่งลงบนเก้าอี้เหมือนกับทำงานเสร็จแล้ว

[ อ่า อย่างที่ทุกคนรู้ พวกนักเรียนคือดาราของงานเปิดบ้านนี้นะ งานทัวร์นี้จัดขึ้นเพราะเราอยากให้เด็กมัธยมต้นที่อยากมาเรียนที่ซึวะบุกิได้รู้ว่า ชีวิตในโรงเรียนมัธยมปลายเป็นยังไง ]

...หืม แปลกแฮะที่เห็นเซ็นเซจริงจังแบบนี้

พวกเราก็รู้สึกกังวลเหมือนกันจากโหมด "ความน่าจะเป็นสูง" ที่เกิดขึ้นเดือนละครั้งของเธอ

[ นั่นเป็นเหตุผลที่สภานักเรียนเป็นคนจัดการงานนี้ และไกด์นำเที่ยวก็เป็นอาสาสมัครด้วย ]

อามานัตสึเซ็นเซยิ้มและมองไปรอบๆ ห้องเรียน

[ และพวกครูอย่างเราๆเองก็เป็น-อาสาสมัครเหมือนกัน ]

โหมด “ความน่าจะเป็นสูง” จบลงแล้ว รัศมีดำมืดเริ่มล้อมรอบตัวอามานัตสึเซ็นเซ

[ ไม่หรอกนะ ฉันไม่ได้บ่นหรอกนะ แค่เสียวันอาทิตย์ไปเท่านั้นเอง หลังจากนั้นเราก็ไม่มีเวลาพักเลย แถมยังไม่ได้รับค่าจ้างอีก ทำไมพวกเราต้องมาคุยเรื่องนี้ในที่ประชุมครูด้วยนะ ? มีหลายเรื่องที่ฉันอยากจะพูด แต่หน้าที่ของครูก็คือการช่วยเหลือนักเรียน- ]

พูดจบ อามานัตสึเซ็นเซก็เริ่มเคาะแท่นบรรยายทันที

[ เราตกลงกันว่านี่มันไม่เวิร์ค ไม่ใช่เหรอ!? ก็แค่ปฏิบัติตามกฎสิ! ]

อา เซ็นเซคนเดิมกลับมาแล้ว

อามานัตสึเซ็นเซพิงแท่นบรรยายก่อนจะถอนหายใจ

[ เซ็นเซยังตรวจข้อสอบปลายภาคไม่เสร็จเลยนะ วันเสาร์ก็ต้องจมอยู่กับกระดาษข้อสอบ แล้ววันอาทิตย์ก็ต้องมาเป็นอาสาสมัครอีก เมื่อไหร่จะได้พักเนี่ย…? ]

ถึงแม้ว่าเราจะเข้าใจความรู้สึกของเธอ แต่ก็ไม่มีอะไรที่เราจะทำได้ มันเป็นเทอมที่สามแล้ว แต่ครูคนนี้ก็ยังไม่ชินกับมัน…

เซ็นเซดูไม่ใส่ใจเลยที่ทั้งห้องจ้องเธอเงียบๆ เธอพูดต่อไป

[ เซ็นเซยังโสดไม่ใช่เพราะไม่ฮ๊อต แต่เพราะไม่มีเวลาได้เจอใครต่างหาก เพื่อนฉันยังบอกเลยว่าทำไมไม่เลือกใครสักคนแล้วก็กินเขาซะ แต่ผู้ชายไม่ใช่ถั่วแระญี่ปุ่นนะรู้มั้ย? ]

เพื่อนคนนั้นคงจะเป็นโคนุกิเซ็นเซสินะ? ต้องใช่แน่ๆ

อามานัตสึเซ็นเซทำตัวเหมือนคนเมา เธอพิงแท่นบรรยายและพลิกดูใบปลิวไปเรื่อยๆ

[ เฮ้อ นั่นเป็นการพูดนอกเรื่องของเซ็นเซล่ะ วัสดุสำหรับทำบอร์ดประกาศอยู่ที่ห้องพิมพ์แล้ว เตรียมตัวให้พร้อม เอาล่ะ แยกย้ายได้ ]

…ตอนจบก็ธรรมดาเหมือนทุกที ผมลุกขึ้นท่ามกลางนักเรียนที่ตกตะลึง

เอ่อ ผมไม่ได้เป็นไกด์นำเที่ยว เพราะงั้นผมต้องจัดบอร์ดประกาศสินะ? มาดูตารางกัน โอเค แค่ต้องติดแผนที่นำทางแถวๆ ทางเข้า

งั้นก็ทำให้เสร็จเร็วๆ แล้วไปเตรียมตัวที่ชมรมวรรณกรรมดีกว่า-

[ นุคุมิซึก็รับผิดชอบแผนที่นำทางเหมือนกันใช่มั้ย? ไปด้วยกันเถอะ ]

คนที่พูดคือ โซสึเกะ ฮาคามาดะ เขาตบไหล่ผมพร้อมยิ้มอย่างสดใส

[ หืม ฮาคามาดะไม่ได้รับผิดชอบการต้อนรับผู้เยี่ยมชมเหรอ? ]

[ อ่า วันอาทิตย์ฉันมีธุระด้วย มีอีกหลายๆเรื่องเหมือนกัน ]

ฮาคามาดะพูดพร้อมยิ้มขมขื่น

วันอาทิตย์คือวันวาเลนไทน์นี่นะ คนที่อุตส่าห์มาเป็นเจ้าหน้าที่ต้อนรับผู้เยี่ยมชมโรงเรียนนี้คงไม่มีอะไรเกี่ยวข้องกับวันวาเลนไทน์แน่ๆ

[ โอ๊ะ นุคุมิซึคุง ฉันจะไปห้องชมรมหลังจากเสร็จธุระที่หอประชุมนะ โอเคมั้ย? ]

ยานามิตบไหล่ผม

[ อ่า โอเค หลังจากทำงานเสร็จฉันจะไปหมือนกัน ]

[ โซสึเกะ อย่าแกล้งนุคุมิซึคุงนะ โอเค๊ ? ]

เด็กผู้หญิงที่ไม่มีอะไรเกี่ยวข้องกับวันวาเลนไทน์โบกมือแล้วออกจากห้องไป

[ เฮ้ นุกคุง!]

เด็กผู้หญิงอีกคนที่ไม่มีอะไรเกี่ยวข้องกับมันเลยตบหลังผมอย่างแรง เจ็บจัง

[ หืม? อะไร? มันเจ็บนะ ]

[ ฉันจะไปชมรมกรีฑาหลังจากฟังคำอธิบายจบแล้ว ]

เข้าใจแล้ว ทำไมต้องบอกผมด้วยล่ะ?

[ อ่า ยากิชิโอะจะอยู่ที่ชมรมกรีฑาในวันนั้นสินะ? ]

[ ใช่ๆ ฉันจะใช้หนี้ทั้งหมดที่ติดนายไว้ เจอกัน! ]

ยากิชิโอะประนมมือก่อนจะกระโดดออกจากห้องไป

เธอยังร่าเริงเหมือนเดิม…

ผมอึ้งไปชั่วขณะ ฮากามาดะเอานิ้วมาจิ้มแขนผมเบาๆ

[ เห นุคุมิซึ นายเป็นที่นิยมมากเลยนะ ]

[ หืม? …อย่ามาแกล้งกันสิ ฮาคามาดะ ]

[ ขอโทษๆ แต่นายต่างจากภาคเรียนแรกมากเลยนะ? ]

ภาคเรียนแรกสินะ? ผมตอบกลับด้วยรอยยิ้มเก้อๆ ขณะที่เราเดินไปตามทางเดิน ฮากามาดะกับผมต้องไปหยิบวัสดุที่ห้องพิมพ์

รู้สึกว่ามีเด็กผู้หญิงมองมาที่ผมขณะที่เราเดินผ่านกัน นี่ไม่ใช่จินตนาการของผมแน่ๆ บางคนถึงกับกระซิบกระซาบกันพร้อมกับมองพวกเรา นี่ใช่ผลกระทบจากฮาคามาดะหรือเปล่า?

[ มีอะไรรึเปล่า นุคุมิซึคุง? ถ้านายจ้องฉันมากไปฉันจะเอาเขินนะ ]

[ ไม่หรอก ไม่มีอะไร… ผู้หญิงมองนายตลอดเวลาเลย แม้แต่ตอนที่นายแค่เดินผ่านไป คงลำบากมากแน่ๆ ]

ผมฟังมุขของหนุ่มหล่อขณะที่พูดแบบนั้น ฮาคามาดะทำหน้าตกใจเล็กน้อย

[ ไม่หรอก พวกเธอมองนายต่างหาก ]

[…หืม? ]

อะไรน่ะ? ผมโดนโพสต์ลงเน็ตหรือไง? ผมยิ้มเหมือนคนบ้าตอนที่ถือหนังสือการ์ตูนเล่มใหม่ในร้านหนังสือเซบุงกังเมื่อวานหรือเปล่า? นี่มันเกินไปมั้ย…?

ผมมองฮาคามาดะอย่างกังวล เขาตบไหล่ผม

[ นุคุมิซึ ไปยืนหน้าบอร์ดประกาศตรงนั้นสิ ]

[ หืม? อ่า ได้สิ ]

ผมทำตามคำสั่งและยืนหน้าบอร์ดประกาศที่ทางเดิน เด็กผู้หญิงที่ยืนอยู่ข้างหลังก็เริ่มกระซิบกระซาบกัน

[ หืม? ก็หล่ออยู่นะ? ] [ ไม่ใช่ๆ คนข้างๆต่างหาก ] [ อ๋อ …ก็ปกตินะ ] [ ใช่ๆ ก็ปกติ ]

…พวกเธอยังคงบอกว่าผม “ปกติ” นั่นคงหมายถึงผมแหละเพราะผมอยู่กับคนที่ไม่ปกติ

ว่าแต่ เด็กผู้หญิงคิดว่าผม “ปกติ” หรอ? ก็เป็นการประเมินที่ไม่เลว…

ฮาคามาดะยักไหล่หลังจากที่กลุ่มเด็กผู้หญิงที่กระซิบกระซาบกันเดินจากไป

[ นายกลายเป็นหัวข้อร้อนแรงหลังจากเหตุการณ์ในหอประชุมเมื่อปลายปีที่แล้วน่ะ ]

หอประชุม- เขาหมายถึงตอนที่ผมกอดชิกิยะซังตอนที่เธอกำลังจะล้มน่ะเหรอ?

แน่นอน เธอนุ่มนิ่ม เย็น และหอม…

[ นั่นมันช่วยไม่ได้นะ แต่ไม่ใช่การคุกคามทางเพศแน่นอนแหละ ]

[ นายพูดถึงอะไรน่ะ? ทุกคนพูดกันว่านายกำลังวุ่นวายกับสมาชิกสภานักเรียน บางคนถึงกับบอกว่านายกำลังจีบสองคนในเวลาเดียวกันด้วยซ้ำ ]

…อะไรนะ?

[ เดี๋ยว ไม่จริงสักหน่อย พูดตามตรงแล้ว ผมต่างหากที่โดนพวกเธอลากมาพัวพันในทุกความหมาย โอเคมั้ย? ]

[ ฉันเข้าใจดี นายไม่ใช่คนแบบนั้นหรอก ]

ฮาคามาดะพยักหน้า คิดว่าหมอนี่พูดประโยคเดียวกันนี้ในตอนท้ายของภาคเรียนที่สอง

ถ้าเป็นแบบนั้น ประโยคต่อไปของเขาคงจะเป็น-

[ ถึงฉันจะเข้าใจดี แต่นายควรหาโอกาสอธิบายทุกอย่างให้ชัดเจนนะ คนอื่นจะเข้าใจผิดได้ ถ้าพวกเธอคิดว่านายพยายามถอยห่างหรือเล่นกับความรู้สึกของพวกเธอน่ะ ]

[ แน่ใจนะว่านายเข้าใจ? ]

[ ใช่สิ ฉันเข้าใจดี ]

…หมอนี่ไม่เข้าใจอะไรเลย ความมั่นใจของผมเพิ่มขึ้นแล้วผมก็ยักไหล่ตามฮาคามาดะ

✧

งานบนบอร์ดประกาศเสร็จเรียบร้อยแล้ว

หลังจากนั้นผมก็เดินตรงไปที่ห้องชมรม เป็นการเผชิญหน้ากันระหว่างผมกับโคมาริที่นั่งอยู่ฝั่งตรงข้ามของโต๊ะ

[ อ-เอาล่ะ ส่งฉบับร่างมาให้ฉันซะ ]

โคมาริเคาะโต๊ะด้วยปลายนิ้วของเธอ แน่นอนว่าเรากำลังจะทำนิตยสารของชมรมอยู่

ผมพยักหน้าอย่างมั่นใจ

[ อืม ใช่สิ นิตยสารของชมรมต้องการฉบับร่างนี่ ]

[ ร-ร่างของนายเป็นร่างเดียวที่เหลืออยู่ ย-ยานามิส่งของเธอมาแล้วม-เหมือนกัน ]

ยานามิเขียนนิยายร้านสะดวกซื้อของเธอเสร็จแล้วเหมือนเคย ตอนนี้เหลือแค่ของผมเท่านั้น

ผมพยักหน้าอย่างมั่นใจอีกครั้ง

[ รู้อยู่ว่าเธอกังวลเกี่ยวกับร่างของผม- แต่เธอไม่รู้เลยหรอว่าผมยังทำไม่เสร็จ -? ]
