งานฉลองวันเกิดนุคุมิซึ คาจู 20xx

คืนวันหนึ่งก่อนการเลือกตั้งสภานักเรียน ผมกำลังง่วนอยู่กับการเตรียมบทเรียนสำหรับวันพรุ่งนี้ในห้องของตัวเอง

พอพลิกสมุดโน้ตวิชาคณิตศาสตร์ คาจูที่นั่งอยู่บนตักของผมและกำลังดูสมุดคำศัพท์ก็เงยหน้าขึ้น

[ ท่านพี่คะ พอขึ้นปี 2 แล้วเวลาที่ต้องใช้เตรียมบทเรียนก็เพิ่มขึ้นสินะคะ ]

[ อ่า ถ้าไม่เตรียมตัวไปให้ดี เดี๋ยวจะเรียนตามไม่ทันเอาน่ะ ]

ผมจดบันทึกลงในสมุดโน้ตไปพลาง ตรวจสอบสูตรในหนังสือเรียนไปพลาง

ทันใดนั้น ศีรษะของคาจูที่ชะโงกเข้ามาดูหนังสือเรียนก็บังวิสัยทัศน์ของผม

[ คาจู มันบังนะ ขยับมาทางนี้หน่อย ]

พอผมจับหัวของคาจูขยับไปด้านข้าง ผมก็สังเกตเห็นเรื่องบางอย่าง

ร่างกายของคาจูบนตัก ระยะห่างระหว่างฝ่าเท้ากับพื้น──

[ คาจู ตัวสูงขึ้นรึเปล่า?」

[ ค่ะ พอเข้าปีนี้ก็สูงขึ้นมา 1 เซนติเมตรแล้วค่ะ ]

คาจูยืดหลังตรงเป๊ะ

ผมวางฝ่ามือลงบนศีรษะของคาจูด้วยความรู้สึกตื้นตัน คาจูตัวเล็กมาตั้งแต่ไหนแต่ไร ค่อยๆเติบโตขึ้นทีละนิด

ช่างแตกต่างจากการเติบโตด้านข้างของยานามิ น่าดีใจจริงๆ

[ จะว่าไป ของขวัญวันเกิดเอาเป็นพจนานุกรมแน่เหรอ ]

[ ค่ะ สามารถสัมผัสถึงท่านพี่ไปพร้อมกับอ่านหนังสือเตรียมสอบได้ ไม่มีของขวัญอะไรดีไปกว่านี้แล้วค่ะ ]

คาจูยืนยันอย่างหนักแน่น

──สุดสัปดาห์นี้ เป็นวันเกิดอายุครบ 15 ปีของคาจู

ถึงจะถูกขอให้ซื้อพจนานุกรมอังกฤษ-ญี่ปุ่นเป็นของขวัญ แต่จะให้อีกสักอย่างไม่ได้เหรอเนี่ย......

ผมลูบหัวคาจู แล้วขยับดินสอกดเขียนลงบนสมุดโน้ตต่อไปด้วยใจที่ลอยไปที่อื่น

◇

เลิกเรียนวันถัดมา มีการจัดประชุมชมรมวิสามัญขึ้นที่ห้องชมรมวรรณกรรม

ผมใช้อำนาจของประธานชมรม เรียกตัวทุกคนมาอย่างกะทันหัน

[ ขอบใจที่อุตส่าห์มารวมตัวกันนะทุกคน ]

ยานามิ โคมาริ และชิราทามะซัง ทั้ง 3 คนพยักหน้าด้วยสีหน้าจริงจัง

[ ประธานมีเรื่องอะไรเหรอคะ? ]

ชิราทามะซังยกมือขึ้นอย่างน่ารัก

ผมพยักหน้าอย่างเคร่งขรึม แล้วแจ้งแก่ทั้ง 3 คน

[ อ่า สุดสัปดาห์ที่จะถึงนี้──เป็นวันเกิดของคาจูน่ะ ]

ไม่รู้ทำไมพวกนั้นถึงไม่มีปฏิกิริยาตอบรับ แต่ผมก็ตั้งสติแล้วอธิบายต่อ

[ ก็เลยจะทำเค้กเซอร์ไพรส์น่ะ แต่กำลังลังเลว่าจะทำเค้กแบบไหนดี ]

ยังคงไร้ซึ่งปฏิกิริยาตอบรับ

ผมไม่สนใจ แล้วแจกเอกสารที่เตรียมมา

[ ช็อตเค้กสตรอว์เบอร์รีหรือครีมช็อกโกแลตก็ดี แต่ทาร์ตหรือชิฟฟ่อนชาฝรั่งก็น่าสนใจ คาจูทำพวกชีสเค้กบ่อยแล้ว แต่ก็เพราะมันแช่แข็งเก็บได้ง่าย──」

[ ......เดี๋ยวก่อนนะนุคุมิซึคุง ]

คราวนี้ยานามิยกมือขึ้นด้วยสีหน้าฉงนสงสัย

[ ว่าไง ยานามิซัง ]

[ พวกเรา ถูกเรียกมาเพื่อเลือกว่าจะทำเค้กวันเกิดให้คุณน้องสาวแบบไหนเหรอ? แค่นั้น? ไม่มีเค้กให้กินเหรอ? ]

[ ก็คงจะเป็นแบบนั้นล่ะมั้ง ขอพูดต่อได้ไหม? ]

[ หะ...หัวสมองทำด้วยฟองน้ำรึไง ]

ไม่รู้ทำไมโคมาริถึงแว้งกัดเอา ให้ตายสิ สงสัยต้องอธิบายสักหน่อย

[ เอาน่าฟังก่อน ครั้งนี้เป็นวันเกิดอายุครบ 15 ปีของคาจู สมัยก่อนในญี่ปุ่นเขาว่ากันว่าผู้ชายถือเป็นผู้ใหญ่เมื่ออายุ 15 ในยุคที่ชายหญิงเท่าเทียมกันแบบนี้ จะบอกว่าปีนี้เป็นพิธีบรรลุนิติภาวะของคาจูก็ไม่เกินจริงหรอก ]

อะแฮ่ม ผมมองหน้าทุกคนไปรอบๆ

[ สรุปคือมันเป็นเรื่องน่ายินดีขนาดนั้นเชียวนะ เข้าใจใช่ไหม? ]

[ ไม่เห็นเข้าใจเลย แต่เรื่องที่นุคุมิซึคุงเห่อและเรื่องที่ไม่มีเค้กให้กินนี่เข้าใจแล้วนะ ]

ยานามิสะบัดกระดาษที่ผมทำไปมา

[ ก่อนอื่นเลยนะนุคุมิซึคุง นายอบเค้กเป็นด้วยเหรอ? ฉันไม่เห็นเคยได้กินเลย ]

[ เพราะเป็นการท้าทายครั้งแรก ก็เลยกังวลอยู่นี่ไง ]

แล้วทำไมถึงจำเป็นต้องให้ยานามิกินด้วยล่ะ

ชิราทามะซังประสานมือไว้ที่หน้าอก

[ ถ้าเป็นเค้กฉันเคยทำนะคะ ถ้าเป็นการฉลองให้คาจูซังละก็ ขอให้ฉันช่วยเถอะค่ะ ]

[ เอ๊ะ อ่า ขอบใจนะ......]

ผมรู้สึกกดดันแปลกๆ จนพูดไม่ออก

จะว่าไป เพราะครั้งนี้เป็นเรื่องของคาจู ผมเลยตั้งใจว่าจะทำโดยไม่รวมชิราทามะซังแท้ๆ

ผมเลยเลือกวันที่ชิราทามะซังติดงานสภานักเรียน แต่ไหงมาอยู่ที่นี่ได้ล่ะเนี่ย......ทำไมกันนะ...... เหมือนจะรู้สึกถึงความขัดแย้งในใจของผม ชิราทามะซังก็เอียงคออย่างน่ารัก

[ งั้น มาทำด้วยกันที่บ้านฉันไหมคะ? ถ้าเป็นสุดสัปดาห์นี้ที่บ้านไม่มีคนอยู่ด้วยค่ะ ]

[ แต่ว่าตั้งใจจะทำเค้กที่บ้านผมน่ะสิ ]

โคมาริทำหน้าสงสัย

[ ซะ เซอร์ไพรส์แท้ๆ แต่จะทำที่บ้านเหรอ ]

[ อ่า เพราะในตารางงานของคาจูมีกำหนดการออกไปข้างนอกตอนบ่าย ก็เลยกะว่าจะทำตอนนั้น ]

[ ......นุคุมิซึคุง ยังแชร์ตารางงานกับน้องสาวอยู่อีกเหรอ ]

ยานามิมองมาด้วยสายตามีเลศนัย ก็ผมไม่รู้วิธียกเลิกนี่

ทันใดนั้น ชิราทามะซังที่ลุกจากที่นั่ง ไม่รู้ทำไมถึงมานั่งลงข้างๆผม

[ ครั้งแรกอาจจะไม่ราบรื่นก็ได้ค่ะ มีเวลาเผื่อไว้จะดีกว่า ที่บ้านฉันไม่มีใครอยู่ อยู่กันแค่สองต่อสอง ไม่ต้องเกรงใจก็ได้นะคะ ]

[ ยะ อย่างนั้นเหรอ...... ]

ซังชิราทามะชะโงกตัวเข้ามาหาผมที่กำลังโดนไล่ต้อน

[ อย่างนั้นแหละค่ะ ครั้งแรกของประธาน ให้ฉันช่วยได้ไหมคะ? ]

จริงอยู่ที่ถ้าเป็นครั้งแรกอาจจะพลาดก็ได้ แต่ชิราทามะซังตัวหอมจัง

แถมที่บ้านไม่มีใครอยู่ด้วยสินะ...... ไม่เกี่ยวกับการทำเค้กสักหน่อย

[ เอ่อ......ผมเองก็เป็นผู้ชาย จะให้ไปบ้านที่ไม่มีใครอยู่มันก็ดูไม่ดีไม่ใช่เหรอ ครอบครัวเธอคงเป็นห่วงแย่ ]

ชิราทามะซังเอานิ้วชี้แตะที่คาง แล้วเอียงคออย่างน่ารัก

[ แต่พวกเราคบกันอยู่นี่คะ คงไม่มีปัญหาหรอกมั้ง? ]

[[！！！]]

หา?! พูดอะไรของเธอน่ะ

ผมสัมผัสได้ถึงรังสีอำมหิตจากยานามิและโคมาริ แล้วส่ายหน้าสุดแรงเกิด

[ เดี๋ยว! เราไม่ได้คบกันสักหน่อย?! ]

[ อ้าว ตายจริง จำผิดไปค่ะ ก็แค่แนะนำกับพวกพี่สาวไปว่าประธานเป็นแฟนกันเฉยๆ สินะคะ ]

ชิราทามะซังแลบลิ้น แฮ่ น่ารักจัง

ใช่ ก็แค่นั้นแหละ ที่ห้างอิอนมอลล์ในโทโยคาวะ แค่เป่าหูสามีภรรยาตระกูลทานากะว่าพวกเราคบกัน──

[ ยังไม่ได้บอกความจริงกับสองคนนั้นอีกเหรอ?! ]

[ ก็วันงานแต่งงาน ประธานเป็นคนพูดเองนี่คะ ว่าให้อยู่ข้างๆ── ]

ชิราทามะซังชำเลืองมองยานามิกับโคมาริ แล้วรีบเอามือปิดปากเหมือนตกใจ

[ ขอโทษค่ะ เป็นความลับแค่สองคนสินะคะ ]

[ มันจะทำให้เข้าใจผิดเอานะ ช่วยเติมหัวเรื่องให้ชัดเจนหน่อยสิ! ]

แย่แล้ว ขืนถูกมองว่าเป็นผู้ชายเลวที่แตะต้องสมาชิกชมรมใหม่คงเป็นเรื่องใหญ่

ผมสูดหายใจเข้าลึกๆ แล้วหันกลับไปหาสมาชิกเก่าทั้งสอง

[ ปะ ไปตายซะ ]

[ ตอนแผนการล้างแค้นคราวนั้น ผมโกหกอาจารย์ทานากะกับพี่สาวไปว่าคบอยู่กับชิราทามะซังน่ะ ]

อธิบายจบ เท่านี้ทั้งสองคนก็น่าจะเข้าใจ──สีหน้าดูไม่เข้าใจเลยแฮะ

[ โห......แล้วทำไมต้องโกหกแบบนั้นด้วย? ]

[ ถ้าถามว่าทำไมเนี่ย── ]

ทำไมกันนะ ผมเองก็ไม่ค่อยเข้าใจเหมือนกัน

[ พะ พูดว่า ให้อยู่ข้างๆ จริงเรอะ ]

ทั้งที่ผมไม่ได้ทำอะไรผิดแท้ๆ ทำไมถึงต้องโดนตำหนิขนาดนี้ด้วย

[ ประธานขอโทษที่ทำให้เดือดร้อนนะคะ ถ้าถูกเข้าใจผิดว่าคบกับฉัน คงจะไม่ชอบสินะคะ ]

[ เอ่อ ไม่ใช่ว่าไม่ชอบหรอก...... ]

พอได้ยินคำนั้น ชิราทามะซังก็ยิ้มแย้มราวดอกไม้บาน

[ ค่อยยังชั่ว! งั้นไปทำเค้กที่บ้านฉัน── ]

ชิราทามะซังนิ่งไปชั่วครู่ ก่อนจะยิ้มแล้วพยักหน้าเหมือนตั้งหลักได้

[ นั่นสินะคะ ถ้าแถวบ้านประธานมีสถานที่ที่พอเหมาะก็คงดีหรอกค่ะ ]

อะไรกัน ความตึงเครียดแปลกๆ นี่ โคมาริที่เมื่อกี้ยังจ้องผมอยู่ ตอนนี้กลับจ้องมือถือตัวสั่นงันงก นี่มันเกิดอะไรขึ้นกันแน่......?
