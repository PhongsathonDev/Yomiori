เล่ม 4 บทที่ 4-2

ผู้อำนวยการพูดนานตามเคย คำแนะนำเกี่ยวกับการระวังภัยในช่วงวันหยุดฤดูหนาวของเขายาวกว่าของอามานัตสึเซนเซถึง 5 เท่า

คณะกรรมการนักเรียนกำลังช่วยชมรมกระจายเสียงในพิธี ตอนนี้พวกเขายังยุ่งอยู่กับการเก็บของให้เสร็จ

เทียร่าซังกำลังตรวจสอบอุปกรณ์อยู่ พลางรับมือกับชิกิยะซังที่เกาะติดไม่ห่าง พูดอีกอย่างก็คือ ชิกิยะซังไม่ได้ทำงานเลย

บางทีทั้งสองคนนี้อาจจะเคยมีอะไรเกิดขึ้นในอดีตด้วยเหมือนกัน อย่างไรก็ตาม ตอนนี้เราก็จัดการทุกอย่างที่จำเป็นแล้ว

ผมมองฝูงชนตรงทางออกของโรงยิมด้วยความเหม่อลอย

นักเรียนปีสามค่อยๆ ทยอยออกมา แต่ดูเหมือนพวกเขายังต้องการเวลาอีกสักหน่อย

ผมอยู่ห่างจากเพื่อนร่วมชั้นเล็กน้อย ยานามิเดินเข้ามาหาผม

[ ...นุคุมิซึคุง วันนี้มาสายนะ ไม่ค่อยได้เห็นเลย ]

[ เผลอหลับไปอีกครั้งน่ะ พยายามปั่นจักรยานมาแล้วนะ แต่ก็ไม่ทันอยู่ดี ]

[ เอ๊ะ นายมาโรงเรียนด้วยรถไฟไม่ใช่เหรอ? ถ้ามันเร็วกว่า ทำไมไม่ถึงไม่ใช้จักรยานไปเลยล่ะ? ]

[ มันเหนื่อยเกิน ฤดูร้อนก็ร้อน ฤดูหนาวก็หนาว ]

เธอพึมพำเบาๆ ก่อนถามอย่างเงียบๆ

[ ว่าแต่...เมื่อวานเกิดอะไรขึ้นเหรอ นุคุมิซึคุง? ]

[ ส่งข้อความไปบอกในไลน์แล้ว ก็คงไปได้ดีล่ะมั้ง ]

[ ไม่ใช่ว่ามันกำกวมไปเหรอ? อะไรคือ ‘ก็คงไปได้ดีล่ะมั้ง’ ฉันคงไม่ลำบากตอนลดน้ำหนักขนาดนี้หรอกถ้าทุกอย่างไปได้ดี ]

เธอพูดอะไรของเธอเนี่ย?

[ ไม่รู้รายละเอียดเท่าไหร่ แต่รุ่นพี่ชิกิยะดูเหมือนจะถามอะไรมากกว่านี้ไม่ได้เมื่อวาน ]

ยานามิจ้องผมด้วยสายตาแข็งกร้าวหลังจากฟังคำตอบนั้น

[ ...เดี๋ยวนะ เมื่อวานนายแค่พาสองคนนั้นไปเจอกันใช่มั้ย? นายได้ไปเดทกับรุ่นพี่ชิกิยะรึเปล่า? ]

[ ไม่ใช่เดต เราแค่ไปกินข้าวที่คาเฟ่ ]

[ นั่นก็คือเดทไม่ใช่เหรอ? ใช้เวลาร่วมกันในคาเฟ่ในวันคริสต์มาสอีฟก็คือเดทใช่มั้ยล่ะ? แหม นุคุมิซึคุงคงจะมีความสุขดีนี่ เทียบกับฉันที่นั่งนับทศนิยมของพาย… ]

นับทศนิยมของพาย…ในวันคริสต์มาสอีฟเนี่ยนะ?

[ เธอชอบทำแบบนั้นเหรอ? ]

[ นายคิดว่าฉันอยากทำเหรอ? ]

งั้นทำไมถึงทำล่ะ? ยานามิขยับเข้าใกล้ผมพลางจ้องด้วยสายตาที่ดูโมโห

[ ฉันซื้อตารางพายที่มีทศนิยมหนึ่งล้านตำแหน่งมาไว้สำหรับวันคริสต์มาสอีฟ ทุกปัญหาของฉันก็หายไปตอนที่นับไปได้ครึ่งหนึ่ง ฉันให้ยืมได้นะถ้านายอยากใช้ ]

ผมไม่มีปัญหาเยอะขนาดนั้นหรอกนะ ให้มาเลยเถอะถ้าอยากจะให้จริงๆ

คนในโรงยิมเริ่มทยอยหายไปเกือบหมดแล้ว ยานามิเดินเข้ามาใกล้ผมอีก

[ นุคุมิซึคุง...เรื่องที่นัดไว้…หลังเลิกเรียน ]

[ อ้อ มีปาร์ตี้คริสต์มาสใช่มั้ย? ]

ยานามิพยักหน้า

[ ยังลังเลอยู่เลยว่าจะไปดีรึเปล่า เอางี้มั้ย เดี๋ยวจะไปคุยกับน้องสาวจังก่อน นายจะได้มาปาร์ตี้กับฉัน ]

[ แต่ไม่มีใครสังเกตผมในงานหรอก ไม่มีใครให้คุยด้วย ]

ยานามิเตะรองเท้าของผมอย่างไม่พอใจเมื่อได้ยินแบบนั้น

[ ....นายยังมีฉันอยู่นะ ]

ก็ไม่ผิดหรอก แต่คนอื่นๆคงจะสนุกสนานกันมาก พอเดาได้เลยว่าตัวเองจะเข้ากับบรรยากาศนั้นไม่ได้แน่

แต่ในทางกลับกัน ผมก็ไม่อยากให้คนอื่นมาคุยด้วยเพราะสงสารหรอก...

ผมพยายามหาข้ออ้างดี ๆ เพื่อปฏิเสธเธอ แต่ตอนนั้นเอง ก็เห็นชิกิยะซังกำลังยกลำโพงแล้วโซเซอยู่ตรงมุมของโรงยิม

เป็นเรื่องดีที่เธอกำลังทำงานอยู่

แต่ทำไมมันดูอันตรายจัง สายลำโพงเหมือนจะพันขาเธออยู่แล้ว

ทำไมเธอเดินไปด้านข้างน่ะ? กำลังจะชนผนังแล้ว....

ไม่ไหวๆ ทำไมยัยคนนี้ถึงทำให้คนอื่นเป็นห่วงอยู่เรื่อยเลย?

[ มีอะไรเหรอ นุคุมิซึคุง? ]

ผมเมินยานามิแล้วรีบเร่งฝีเท้าไปหาชิกิยะซังทันที

จากนั้นชิกิยะซังก็เหยียบสายลำโพงจนเสียการทรงตัว

เสียงลำโพงกระแทกพื้นดังสนั่น ทุกคนในโรงยิมหันมามองทางนี้

สิ่งที่พวกเขากำลังมองก็คือ- ผมกำลังกอดชิกิยะซังด้วยสองมือของผม

[ รุ่นพี่ เป็นอะไรหรือเปล่าครับ? ]

ขนตาที่หนายาวของชิกิยะซังกระตุกอยู่ในอ้อมกอดของผม ดูเหมือนว่าเธอจะตกใจ

[ ไม่เป็นไร…แล้วลำโพงล่ะ…? ]

[ ใครสนใจลำโพงกันเล่า- ]

ผมใจเย็นลงทันทีที่รู้สึกตัวถึงท่าทางของเราตอนนี้ มันเหมือนกับท่าเต้นบอลรูมที่เป็นเอกลักษณ์มากๆท่านึงเลย

มีนักเรียนซึวะบุกิเกือบร้อยคนจ้องมาทางเรา

[ ร-รุ่นพี่ ยืนเองได้มั้ย!? ได้ใช่มั้ยครับ? งั้นผมจะปล่อยแล้วนะ! ]

ผมรีบถอยออกมา แต่ชิกิยะซังกลับกอดคอผมแทน

[ เฮ้ย รุ่นพี่!? ]

[ ทำไมถึง…มาที่นี่? ]

[ หา? ก็เพราะรุ่นพี่โซเซอยู่ ดูเหมือนจะอันตรายก็เลย- ]

[ นาย…คอยมองฉันอยู่ตลอดเลย ? ]

กลิ่นหอมจากเมคอัพของเธอลอยเข้ามาแตะจมูกของผมดวงตาสีขาวของชิกิยะซังกำลังจ้องมองผมอย่างเหม่อลอย

[ นายอยาก…คบกับฉันเหรอ...? ]

เสียงกระซิบของเธอหวานราวกับน้ำผึ้ง เหมือนกับว่าเธอกำลังลูบไล้คอของผม

หลังจากเงียบไปชั่วครู่ เสียงฮือฮาก็ดังขึ้นจากนักเรียนที่อยู่รอบ ๆ

ผมทวนคำพูดของชิกิยะซังอย่างใจเย็น แต่หลังจากนั้นผมก็รีบส่ายหัวอย่างลนลาน

[ ม-ไม่ๆ! ผมไม่กล้าทำแบบนั้นหรอก- หมายถึงมันดูเกินตัวไปสำหรับผม ! ]

[ ...ไม่เหรอ? ]

[ ค-ครับ! ]

ผมร้องเสียงสูง ชิกิยะซังพึมพำเบา ๆ

[..งั้นเหรอ..…ฉันเข้าใจผิดเอง… ]

ชิกิยะซังเงียบไป ทุกคนกำลังมองมาที่เราจากไกลๆ พวกเขากำลังกระซิบกันอยู่

ความรู้สึกนี่มันอะไร? ผมทำอะไรพลาดไปหรือเปล่า…?

ผมยืนนิ่งอยู่กับที่ เหงื่อเย็นๆเริ่มไหลออกจากร่างกายของผม เทียร่าซังก็แทรกตัวออกมาจากฝูงชนแล้วเดินมาหาเรา

[ เดี๋ยวก่อนค่ะ รุ่นพี่ชิกิยะ ! พวกเธอสองคนทำอะไรกันในที่สาธารณะคะเนี่ย !? ]

เธอดึงชิกิยะซังออกจากอ้อมแขนของผมอย่างแรง

รอดแล้ว… เทียร่าซังจ้องเขม็งมาที่ผม

[ น-นุคุมิซึซัง! ว่าแล้ว ! พอนายเจอใครก็เข้าไปจีบเลยสินะ ! ฉันผิดหวังในตัวนายจริงๆ ! ]

[ ไม่ ๆ ผมแค่ช่วยเธอไว้เพราะเธอเกือบจะสะดุดล้มแค่นั้นเอง รุ่นพี่ช่วยอธิบายหน่อยสิ! ]

ชิกิยะซังพยักหน้าเบา ๆ แล้วเธอก็เอียงหัวไปทางเทียร่าซัง

[ งั้น…คราวนี้เป็นทีของเทียร่าจังแล้ว… ]

[ อะ!? ฉันไม่ได้มี- ]

อะไรน่ะ? มีอะไรอีกเหรอ?

ผมรู้สึกตกใจเล็กน้อย ส่วนชิกิยะซังยกนิ้วแตะคางของเทียร่าซัง

[ ให้ฉัน…ช่วยพูดมั้ย...? ]

[ ม-ไม่เป็นไร ขอบคุณค่ะ! น-นุคุมิซึซัง! ]

เทียร่าซังหน้าแดงแล้วมายืนอยู่ตรงหน้าผม

[ อ่า มีอะไรเหรอ? ]

[ วันนี้หลังเลิกเรียน ฉันมีเรื่องจะคุยกับนาย ช่วยเคลียร์ตารางเวลานายด้วย! ]

[ เอ๊ะ? ก็ได้มั้ง…]

[ อ-อย่าคาดหวังอะไรแปลกๆ ล่ะ! แล้วจะโทรหานายทีหลัง! ]

เทียร่าซังดึงมือของชิกิยะซังแล้วเดินจากไปหลังจากพูดจบ

…เอ่อ นี่มันเกิดอะไรขึ้นเนี่ย?

ผมที่ยืนนิ่งๆอยู่ ก็เลยตัดสินใจยกเอาลำโพงที่อยู่บนพื้นเพื่อพยายามหันเหความสนใจของทุกคน

ผิวเย็นๆของชิกิยะซังและความอบอุ่นจากร่างกายเธอยังติดอยู่ในฝ่ามือของผม

[ เอ่อ มีใครรู้มั้ยว่าต้องเอาลำโพงนี้ไปวางที่ไหน...? ]

เสียงรอบข้างกลบเสียงอันแผ่วเบาของผม

สองใจ ความสัมพันธ์ซับซ้อน รักสามเส้า คำพูดที่ฟังแล้วไม่สบายใจเหล่านี้ดังก้องในหูของผม

เดี๋ยวนะ ควรทำยังไงดี...? ผมมองไปรอบ ๆ เพื่อขอความช่วยเหลือและเห็นยานามิ

…อา เธอหันหน้าหนีไปแล้ว

โคนุกิเซนเซ ปรากฏตัวขึ้นในเสื้อคลุมสีขาวขณะที่ผมกำลังเผชิญหน้ากับความยากลำบาก

[ เอาล่ะ ทุกคนกลับห้องเรียนกันได้แล้วนะ โฮมรูมใกล้จะเริ่มแล้ว ]

เธอบอกให้นักเรียนแยกย้ายออกไปแล้วค่อยโบกมือเรียกผม

[ เอาลำโพงนั้นมาทางนี้หน่อย ตามฉันมา ]

[ อ่ะ ครับ! ]

รอดแล้วรู้สึกผิดจริงๆที่เคยไม่อยากให้เธอเข้ามาใกล้ตอนแรก

โคนุกิเซนเซเดินเข้ามาใกล้ผมจากข้างหลังวางลำโพงลงบนชั้นหลังเวที

[ ...นายคงเจอเรื่องลำบากสินะ ทำไมนายไม่มาคุยปัญหาความสัมพันธ์ชายหญิงบ้างล่ะ? ]

[ ไม่ครับ ไม่มีความสัมพันธ์อะไรแบบนั้นเลย ผมพูดจริง ๆ ขอร้องหยุดกระซิบข้างหูผมเถอะครับ ]

ผมไม่อยากให้เธอเข้ามาใกล้จริงๆนั่นแหละ ให้เธออยู่ห่างสักสองเมตรจะดีที่สุด

[ เซนเซใจกว้างกับเรื่องพวกนี้นะ มีแอปที่ต้องจ่ายเงินตัวนึงที่ทำให้แชทแอคเคานต์ของนายดูเหมือนมี 5 บัญชีได้ สนใจให้ฉันแนะนำมั้ย? ]

[ เอ่อ ผมทำงานตรงนี้เสร็จแล้ว งั้นผมไปก่อนนะครับ ]

ผมเมินเธอแล้วพยายามจะออกไป

[ ..เฮ้ นุคุมิซุคุง ]

เซนเซเรียกผมด้วยน้ำเสียงที่ดูเศร้ากว่าปกติ

[ มีอะไรเหรอครับ? ]

[ เซนเซก็เคยเจออะไรมามากมายตอนอายุเท่านายเหมือนกัน แน่นอนว่าฉันเคยเผชิญกับสิ่งเหล่านั้นจากมุมมองของวัยรุ่นมาแล้ว ]

รอยยิ้มอ่อนโยนปรากฏบนใบหน้าของเธอ

[ แต่ ณ จุดนี้ บางครั้งฉันก็คิดว่าถ้าฉันเผชิญหน้ากับเรื่องพวกนั้นด้วยท่าทีที่จริงใจมากกว่านี้ก็คงจะดี ]

[ เซนเซ…]

โคโนกิเซนเซมีท่าทีเหมือนจะรู้ทุกอย่าง เธอพยักหน้าให้กำลังใจผม

[ เพราะงั้น นุคุมิซึคุง ไม่ใช่แค่ร่างกาย แต่นายต้องเผชิญหน้าเธอด้วยใจและจิตวิญญาณที่เปลือยเปล่า- ]

[ โอเค อย่างแรกเลยคือ พวกเราไม่ได้สัมผัสร่างกายกัน ]

ผมพูดขัดเธอ

[ อาระ ยังไม่มีงั้นเหรอ? เซนเซเก่งเรื่องพวกนี้มากนะ นายมีแผนจะทำอะไรหรือเปล่า? ]

[ ไม่มีครับ แต่ขอบคุณนะครับเซนเซ ]
