เล่ม 7 บทที่ 1-4 บทคั่น

ช่วงพักกลางวันที่โรงเรียนมัธยมปลายซึวะบุกิ

กลุ่มเด็กผู้หญิงกลุ่มหนึ่งกำลังพูดคุยกันอย่างออกรสในห้องเรียน 1-F

ในตอนแรก การสนทนาของพวกเธอวนเวียนอยู่กับเรื่องละครและการเรียน แต่ไม่นานนัก หัวข้อก็เปลี่ยนไปเป็นเรื่องบางอย่าง

หัวข้อที่พวกเธอพูดถึงคือเพื่อนร่วมชั้นที่กำลังถูกพักการเรียน

เด็กสาวคนหนึ่งที่มีดวงตาคล้ายสุนัขจิ้งจอกมองไปที่เก้าอี้ว่างและเอ่ยขึ้น

[ โดนพักการเรียนตั้งแต่เปิดเทอมมาใหม่ๆ นี่มันแรงไปปะ? ต้องทำอะไรขนาดไหนถึงจะโดนแบบนั้น? ]

เด็กสาวอีกคนรับคำและพูดต่อ

[ เขาว่ากันว่าเป็นเรื่องความสัมพันธ์กับผู้ชาย แถมยังมีข่าวลือว่าผู้ชายคนนั้นเป็นครูด้วยนะ ]

[ จริงเหรอ? ครูเนี่ยนะ? ครูที่โรงเรียนเราก็ลุงแก่ๆ ทั้งนั้นไม่ใช่เหรอ? ]

พวกเธอหัวเราะกันเบาๆ เสียงพูดคุยดังระงมไปทั่ว

เด็กชายคนหนึ่งตะโกนแทรกมาจากที่ไกลๆ

[ เฮ้ พวกเธอแกล้งเธอจนเขาโดนพักการเรียนหรือเปล่าเนี่ย? ]

[ ผู้หญิงนี่น่ากลัวจริงๆ ]

[ หา? พวกนายพูดเหมือนตัวเองดีนักเหรอ? เธอแค่ใช้พวกนายเล่นสนุกก็เท่านั้นแหละ ]

เสียงหัวเราะของเด็กชายดังสะท้อนกลับมา ขณะที่เด็กผู้หญิงทำเสียงหงุดหงิดแบบเล่นๆ

จากนั้น ในช่วงจังหวะที่การสนทนาเงียบลง

[ -ว่าแต่ ชิราทามะซังเป็นคนแบบไหนกันแน่? ]

คำถามที่โพล่งขึ้นมาทำให้ทุกคนเงียบงันไปชั่วขณะ

คนที่ถามคือเด็กสาวตัวเล็กที่ถักผมยาวสีดำเป็นเปียอย่างเรียบร้อย

กลุ่มเด็กผู้หญิงที่จับกลุ่มกันหันมาสบตากันอย่างลังเล

[ ...พูดก็พูดเถอะ ฉันไม่เคยคุยกับเธอเลยสักครั้ง ]

[ ใช่ เธอชอบอยู่ท่ามกลางพวกผู้ชายตลอด ]

[ พวกผู้ชายคงรู้จักเธอมากกว่าเราอีกเนอะ? ]

ชิราทามะ ริโกะ  หลังจากเข้าเรียนได้ไม่นาน เธอก็ตกเป็นที่สนใจของกลุ่มผู้ชาย และก่อนที่ใครจะทันสังเกต เธอก็หายตัวไป

เพื่อนร่วมชั้นที่เอาแต่ซุบซิบกัน ไม่มีใครรู้เลยว่าเธอเป็นคนแบบไหนจริงๆ

เด็กสาวคนหนึ่งที่เพิ่งพูดเรื่องชิราทามะไป หันมองรอบๆ อย่างสงสัย

[ ...นี่ เด็กผู้หญิงน่ารักเมื่อกี้นี้คือใครเหรอ? ]

[ เอ๊ะ? ฉันนึกว่าเป็นเพื่อนเธอซะอีก เคย์จัง? ]

[ ฉันไม่รู้จักนะ หรือว่าเป็นเพื่อนของชิราทามะซัง? ]

เด็กผู้หญิงที่ไม่คุ้นหน้าได้หายตัวไปแล้ว

เด็กสาวตาจิ้งจอกที่ดูสับสนเหมือนเพิ่งตื่นจากฝัน พึมพำเบาๆ

[ ...ชิราทามะซังมีเพื่อนผู้หญิงด้วยเหรอ? ]

— เด็กสาวตัวเล็กที่กำลังแกะผมเปียของเธอ เดินออกจากโถงทางเดินอย่างรวดเร็ว

แม้รูปลักษณ์ของเธอจะโดดเด่น แต่เธอกลับเดินผ่านนักเรียนคนอื่นๆ อย่างไม่มีใครสังเกต

ขณะที่เธอเคลื่อนตัวออกจากอาคารเรียน ผมยาวที่ตอนนี้ถูกปล่อยลงมา สะบัดพลิ้วอย่างงดงาม

เธอไม่หยุดเดิน มุ่งหน้าไปยังประตูโรงเรียน และพึมพำกับตัวเองเบาๆ

[ ...เด็กคนนั้นออกจะกระตุ้นท่านพี่เกินไปหน่อย. . . ]
