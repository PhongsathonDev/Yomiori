# Ch.31 — เล่ม 5 บทที่ 2-4 บทคั่น

Ch.31 — เล่ม 5 บทที่ 2-4 บทคั่น

By Monica

Published: 2025-05-20T07:40:02Z

Source: https://www.nekopost.net/novel/14560/31

บทคั่น : คนที่ถูกทิ้งไว้ข้างหลังใช้เวลาสบาย ๆ

ห้องชมรม หลังเลิกเรียน ยานามิกับโคมาริต่างคนต่างทำของตัวเอง ไม่มีเรื่องอะไรจะคุยกันมากนัก

ยานามิกำลังอ่านนิตยสารโดยเอาแขนหนุนหมอน แล้วก็พึมพำขึ้นมา “อ๊ะ”

[  โคมาริจัง อันนี้ดูน่ากินดีนะ เป็นโมจิช็อกโกแลตน่ะ ]

[ เอ๋? ชะ…ช็อกโกแลต… ? โมจิ ? ]

จู่ๆ ก็ชวนคุยแบบไม่มีปี่มีขลุ่ย ทำให้โคมาริขมวดคิ้วก่อนจะคั่นหน้าหนังสือที่อ่านอยู่

[ ใช่ พูดง่ายๆ ก็คือโมจิรสช็อกโกแลตนั่นแหละ ]

[ อ-เอ่อ…เหรอ? ]

โคมาริงงยิ่งกว่าเดิม เพราะไม่ได้รับข้อมูลเพิ่มเติมอะไรเลย

[ ดูสิ วาเลนไทน์ก็ใกล้เข้ามาแล้วนี่ เด็กชมรมวรรณกรรมเราไม่ได้สัญญากันไว้ว่าจะให้ช็อกโกแลตตามมารยาทกันเหรอ? ]

[ อ-อืม…เหรอ? ]

โคมาริเอียงคอ ส่วนยานามิพยักหน้าอย่างมั่นใจก่อนจะส่ายหน้าอย่างช้าๆ

[ ...อา ไม่สิ พูดผิด ฉันลืมไป ]

[ ช-ใช่มั้ยล่ะ? ]

โคมาริกลับไปเปิดหนังสืออ่านต่อ ยานามิปิดนิตยสารด้วยท่าทีเบื่อหน่าย

[ วันเปิดบ้านก็สุดสัปดาห์นี้แล้วใช่มั้ย เราไม่ต้องเตรียมอะไรกันหน่อยเหรอ?]

[ ป-ประธานช่วงนี้ไม่ได้เรื่องเลยน้า… ]

[ ใช่ เรื่องคลั่งน้องสาวของนุคุมิซึก็ปวดหัวพอดู ]

จริงๆ แล้วตอนนี้พวกเธอควรจะกำลังเตรียมตัวสำหรับวันเปิดบ้าน

ดูเหมือนว่าชมรมวรรณกรรมจะมีคนมาเยี่ยมเยียนเยอะพอตัวในทุกปี

[ ไนุคุมิซึคุงหนีไปแบบนี้ในช่วงที่เรายุ่งขนาดนี้ไม่ถูกต้องเลยนะ ]

[ เขาไปกับยากิชิโอใช่มั้ยล่ะ? ]

[ ...อะไรนะ? แล้วทำไมฉันไม่รู้? ]

ยานามิทำหน้าเหี้ยมขึ้นมา เงยหน้าขึ้นทันที

[ เอ๋? ม-ไม่ได้บอกเหรอว่าเขาจะไปที่โมโมโซโนะ?]

[ โรงเรียนมัธยมต้นเหรอ? เลม่อนจังกลับไปเริ่มใหม่ตั้งแต่ม.ต้นเลยเหรอ…? ]

‘บางทีอาจจะเหมาะกับเธอก็ได้นะ’—โคมาริเกือบเผลอพูดออกมา แต่รีบกลืนคำพูดนั้นไว้

[ ม-ไม่สิ เขาไปที่โรงเรียนของน้องสาวน่ะ ไปแอบตามดูเธอ… ]

[ อ้อ จริงสิ เขาเคยเรียนที่โรงเรียนมัธยมต้นเดียวกันนี่นา ]

ยานามิยักไหล่แบบช่วยไม่ได้

[ เฮ้อ ถ้าเรื่องเกี่ยวกับน้องสาวนุคุมิซึคุงก็เป็นแบบนี้ทุกที ถ้างั้นก็มาหาของกินกันเถอะ ]

ว่าแล้วก็หยิบเค้กช็อกโกแลตราคาถูกออกมาหนึ่งห่อ เป็นพายช็อกโกแลตบาง ๆ สองชิ้น

[ ช่วงนี้ฉันติดอันนี้มากเลย โดยเฉพาะเวลามันประกบกันสองชิ้นแล้วกิน มันดีมากเลยนะ ]

ยานามิเปิดถุงหยิบพายสองชิ้นออกมา

[ โคมาริจังจะลองด้วยมั้ย? อร่อยนะ? ]

[ อ-อืม งั้นขอชิ้นนึงก็ได้… ]

โคมาริเหยียดมือออกไป แต่ยานามิกลับเอาสองชิ้นประกบกันแล้วกัดกินไปทันที

โคมาริชะงักไป ยานามิยื่นถุงใหม่ให้เธอ

[ พอกินประกบกันแล้วมันอร่อยมากนะ อยากลองดูมั้ย? ]

[ ฉ-ฉันขอแค่ชิ้นเดียวก็พอ… ]

ยานามิกินหมดสามถุงก่อนที่โคมาริจะกินของเธอหมดชิ้นเดียวเสียอีก แล้วก็ลุกขึ้นไปชงชา

[ นุคุมิซึคุงไม่น่าไว้ใจเลย ดูเหมือนว่างานเตรียมวันเปิดบ้านจะตกมาอยู่ที่พวกเราแล้ว ทั้งที่ก่อนหน้านี้คุยกันว่าจะทำวารสารชมรม แต่ต้นฉบับยังไม่มีซักชิ้น— ]

[ อ-เอ่อ ฉันทำของฉันเกือบเสร็จแล้วล่ะ… ]

โคมาริพูดพร้อมกับกัดเค้กชิ้นที่สอง

ยานามิหยุดมือจากการชงชา

[ นี่ ฟังนะ เด็กม.ต้นเขาไม่ได้ตื่นเต้นกับวารสารชมรมหรอก ]

[ ฉ-ฉันก็ไม่แน่ใจเท่าไหร่นะ… ]

โคมาริตอบกลับเบา ๆ ยานามิวางถ้วยชาลงกับโต๊ะเสียงดัง

[ โคมาริจัง เราเป็นเด็กม.ปลายแล้วนะ ต้องใช้สิ่งที่มีต่างจากเด็กม.ต้นมาต่อสู้น่ะ ]

[ ส-สิ่งที่เด็กม.ต้นไม่มี…? ]

ยานามินั่งลงบนเก้าอี้แล้วสะบัดผมอย่างเว่อร์วัง

[ —ก็คือ เสน่ห์ของสาวมัธยมปลายน่ะ ]
