เล่ม 8 บทที่ 1-2

สองวันหลังจากที่จู่ ๆ ก็ถูกชวนแบบไม่ทันตั้งตัว —

ที่ห้องคหกรรมหลังเลิกเรียน

ผมกำลังมองดูซากุไรคุงขูดโกโบด้วยฝีมืออันคล่องแคล่วอย่างน่าประทับใจ

[ นั่นไว้ทำกับข้าวกล่องให้ประธานเหรอ? ทำที่โรงเรียนเลยเหรอเนี่ย ]

[ ใช่แล้ว เตรียมกับข้าวล่วงหน้าหลังเลิกเรียน ส่วนของทอดกับย่างค่อยทำที่บ้านตอนเช้า ]

เสียงหัวเราะอย่างสนุกสนานของสมาชิกชมรมทำอาหารดังมาจากอีกฟากหนึ่งของห้องคหกรรม

แม้เขาจะไม่ได้เป็นสมาชิกชมรมทำอาหาร แต่ดูเหมือนจะได้ใช้สถานที่เป็นบางครั้ง

[ ...ได้ยินเรื่องมาบ้างแล้วล่ะ นุคุมิซึคุงก็คงลำบากเหมือนกันสินะ]

ซากุไรคุงยิ้มนิด ๆ อย่างลำบากใจ ขณะเอาโกโบที่ขูดแล้วลงแช่น้ำในชาม

[ ถ้าคิดอย่างนั้น ก็ช่วยเป็นผู้สนับสนุนให้แทนผมทีได้มั้ยล่ะ? วันนี้บาโซริก็ยังดักรอฉันอยู่ที่ทางเดินอีกแล้ว ]

[ บาโซริจังไม่อยากขอความช่วยเหลือจากสมาชิกสภานักเรียนหรอก ยูเมโกะซังเสนอตัวจะเป็นผู้สนับสนุนให้ก็โดนปฏิเสธแบบเด็ดขาดเลย ]

[ รุ่นพี่ปีสามก็เป็นผู้สนับสนุนได้นี่นะ ]

[ เพราะมันไม่มีข้อกำหนดตายตัว ผู้ผู้สนับสนุนไม่จำเป็นต้องเป็นสมาชิกสภานักเรียนก็ได้ ]

งั้นเหรอ... ที่แท้ก็แบบนั้นเอง แต่ยังไง ๆ เทียร่าซังก็คงไม่คิดจะพึ่งพาสามคนในสภานักเรียนอยู่ดี...

ผมรู้สึกไม่สะดวกจะถามต่อ จึงหันไปมองหม้อที่ส่งเสียงเดือดปุด ๆ

[ หม้อนั้นต้มอะไรอยู่น่ะ? ]

[ กำลังเคี่ยวฟูกิกับอาบุระอาเกะอยู่น่ะ เป็นของโปรดฮิบะเน่ ]

ซากุไรคุงยกขอบอะลูมิเนียมฟอยล์ที่ใช้แทนฝาครอบหม้อขึ้น

[ประธานชอบของกินแบบฝาดๆเหรอเนี่ย]

[ พื้นฐานคืออาหารญี่ปุ่นล่ะ ปล่อยไว้เฉย ๆ จะไม่แตะเนื้อกับของมัน ๆ เลย ต้องคอยระวังให้ดี ]

โห อย่างงั้นเลยสินะ... เอามาหารสองกับยานามิ—ไม่สิ หารสี่น่าจะกำลังดี

[ ได้ดูแลฮิบะเน่ก็คราวนี้เป็นครั้งสุดท้ายแล้วล่ะ พอจบงานกีฬาสีก็มีเลือกตั้งสภานักเรียนต่ออีก อย่างน้อยจะได้ทำข้าวกล่องให้น่ะนะ ]

—ได้ดูแลอีกแค่ไม่นาน

นักเรียนปีสามส่วนใหญ่จะย้ายไปเรียนต่อที่อื่น

แม้ตอนนี้ยังเรียนอยู่ตึกเดียวกัน แต่ต่างคนก็ต่างเริ่มเดินไปในทางของตัวเองแล้ว

[ ประธานเรียนจบแล้วก็คงออกจากเมืองโทโยฮาชิสินะ]

[ บอกว่าอยากไปโตเกียวเพื่ออนาคตน่ะ ผมเองก็เริ่มคิดเหมือนกัน—]

กำลังจะพูดต่อด้วยน้ำเสียงเศร้า ๆ

[ ซากุไรคุง— อ้ามมม ~! ]

นักเรียนหญิงจากชมรมทำอาหารก็แทรกเข้ามา

หญิงสาวหน้าตาสะดุดตา ยื่นช้อนไม้จ่อไปที่ปากของซากุไรคุง

เขารับมันเข้าปากอย่างไม่ลังเล แล้วก็พยักหน้าอย่างยิ้มแย้ม

[ ชะ...ชาวันมุชิเย็นสินะ ใช้น้ำซุปจากคอมบุผสมกับคัตสึโอะเหรอครับ?]

[ ใช่ๆ ลงทุนต้มน้ำซุปเองเลยนะ คราวหน้าจะสอนให้ก็ได้นะ]

[ ตั้งตารอเลยครับ ]

[ คืนนี้มาบ้านฉันมั้ยล่ะ? พ่อแม่ไม่อยู่ด้วยนะ ]

[ คงต้องขอปฏิเสธดีกว่า กลัวจะรบกวน ]

หญิงสาวหัวเราะเบา ๆ แล้วโบกมือลาออกไป

ซากุไรคุงโบกมือกลับเบา ๆ แล้วหยิบแครอทขึ้นมา—

[ เดี๋ยว เมื่อกี้มันอะไรน่ะ คบกันอยู่เหรอ ? ]

[ เปล่าน่า เธอเป็นรองหัวหน้าชมรมทำอาหารน่ะ เป็นคนที่ช่วยพูดให้เรามาใช้ห้องนี้ได้น่ะ ]

เหรอ…งั้นเธอเป็นคนจัดการให้ซากุไรคุงใช้ห้องนี้เอง…เหรอ…

[ ไม่สิ 'อ้ามมม' มันไม่เกี่ยวเลยนะ ถ้าไม่ได้คบกันใครเขาทำแบบนั้นกัน ? ]

[ ไม่ได้หมายความว่าอย่างนั้นซะหน่อย ชมรมทำอาหารไม่มีผู้ชายเลย เธอคงแค่สนุกเฉย ๆ น่ะ]

ซากุไรคุงยิ้มหัวเราะแบบเก้อ ๆ… แต่ผมเองก็เป็นผู้ชายนะ

[ พูดตรง ๆ เลยนะ ถ้านุคุมิซึคุงช่วยบาโซริจังได้ ผมจะรู้สึกสบายใจมากเลยล่ะ ดูเหมือนคนรู้จักผู้ชายของเธอก็มีแค่พวกเรานี่แหละ ]

[ ถ้าปฏิเสธไป จะเกิดอะไรขึ้นเหรอ? ]

[ อาจารย์ก็คงจะแนะนำผู้ชายที่เป็นผู้สมัครให้เธอล่ะมั้ง ]

ซากุไรคุงพูดอย่างไม่ใส่ใจพลางปิดไฟเตา

[ พวกคนในสึวะบุกิไม่ได้มีพลังขับเคลื่อนจากกิจกรรมสภานักเรียนอยู่แล้ว ทุกปีถ้าไม่มีใครลงสมัคร อาจารย์ก็จะคอยจัดการไม่ให้กลายเป็นศูนย์ ]

[ ถ้างั้นผมไม่ต้องช่วยก็ไม่เป็นไรใช่มั้ย…]

[ ถ้าเธอเข้ากับคนที่ได้อาจารยแนะนำมาได้ล่ะก็นะ แต่เท่าที่เห็นจนถึงตอนนี้ ไม่มีใครพูดถึงเธอในทางไม่ดีเลย เพราะเธอเป็นคนที่เข้าหาผู้อื่นเพื่ออีกฝ่ายอย่างจริงใจ ]

[ ดูออกเลยแฮะ… ]

[ ก็พอรู้บ้างน่ะ สภานักเรียนมีแค่ 4 คน แล้วพวกเราก็อยู่ปีเดียวกันด้วย ]

ซากุไรคุงที่กำลังปอกเปลือกแครอทหยุดมือ

[ สภานักเรียนชุดนี้ยังไง ๆ ฮิบะเน่ก็มีอิทธิพลสูงอยู่แล้ว และการที่เธอไม่ขอความช่วยเหลือจากพวกเราสามคน ก็คงมีเหตุผลของเธอเองล่ะ ผมก็เลยไม่เข้าไปยุ่ง]

ซากุไรคุงพูดชัดเจน แล้วเริ่มใช้มีดอีกครั้ง

ดูท่าเรื่องของเทียร่าซัง คงไม่ใช่เรื่องที่ควรพูดต่อ…

ผมพยายามเปลี่ยนความคิด แล้วหยิบแครอทที่ปอกแล้วขึ้นมา

[ มีอะไรให้ช่วยมั้ย? ]

[ งั้นช่วยหั่นบาง ๆ ให้ทีนะ ใช้ที่ปอกตรงนั้นได้เลย ]

[ โอเค วันนี้จะทำเมนูอะไรเหรอ? ]

[ คินปิระโกโบกับถั่วฝักยาวคลุกงาน่ะ]

ระหว่างที่เราสองคนทำงานเงียบ ๆ อยู่ ก็มีเสียงหวีดร้องจากด้านหลัง

[ รุ่นพี่ซากุไร ขอโทษที่รบกวนนะคะ~ ] [ ขอโทษค่า~ ]

คราวนี้เป็นกลุ่มเด็กหญิงปี1 สามคนที่ดูไร้เดียงสา

เพื่อนสองคนขนาบข้างเร่งให้เด็กหญิงคนกลางที่ก้มหน้ามองพื้นอยู่พูดออกมา

[ เร็วเข้า บอกไปเลยสิ ] [ บอกไปสิ~ ]

เธอโดนเพื่อนทั้งสองดันหลัง เด็กหญิงคนนั้นก็ยื่นห่อเล็ก ๆ ออกมาอย่างรวดเร็ว

[ อะ…อ๊ะ รุ่นพี่ซากุไร! หนูทำมาเองค่ะ! ช่วยลองชิมดูด้วยนะคะ!]

ในมือเธอมีมัดดาเลนที่ห่อไว้อย่างสวยงาม

[ ขอบใจนะ ไว้จะลองชิมทีหลัง ]

[ นะ…หนูจะคอยเป็นกำลังใจให้เสมอนะคะ ! ]

แล้วทั้งสามก็ร้องกรี๊ดแล้ววิ่งหนีไป

[……เมื่อกี้มันอะไรน่ะ? เกิดอีเวนต์พิเศษขึ้นงั้นเหรอ ? ]

[ เอ่อ…อาจเพราะผมไม่ค่อยดูแมน ก็เลยเข้าหาง่ายล่ะมั้ง ]

ก็จริง ผมเองก็โดนบอกว่าไม่แมนบ่อย ๆ แต่อย่างน้อยก็ไม่เคยโดนน้องปี1ฝากชิมขนมสักที

ระหว่างกำลังคิดเรื่องชนชั้นเชิงเพศอยู่ ซากุไรคุงก็พูดขึ้นมาเสียงเงียบ ๆ

[ …ผมตั้งใจว่าจะให้ความสำคัญกับปีนี้มาก ๆ เลยนะ ]

เขาหยุดมือที่ถือมีดไว้ แล้วพูดด้วยเสียงที่มีแค่ผมได้ยิน

[ สำหรับผม สภานักเรียนก็คือบาโซริจัง ยูเมโกะซัง แล้วก็ฮิบะเน่ นั่นแหละ ทั้งหมดเลย เพราะงั้นเรื่องนี้ก็ถือว่าจบแล้ว ผมจะรอดูผลเลือกตั้ง แล้วพอจบกีฬาสีก็จะมุ่งอ่านหนังสือล่ะ ]

เขาชำเลืองมองผมเล็กน้อย ก่อนพูดต่ออย่างเก้อ ๆ

[ ขอโทษนะ ที่ช่วยอะไรไม่ได้เลย ]

ผมเกือบจะพูดว่า [ ไม่เป็นไรหรอก ] แล้ว แต่กลับส่งยิ้มเจื่อน ๆ กลับไปแทน

พูดตามตรง ผมตั้งใจจะโยนปัญหาเทียร่าให้ซากุไรคุง

แต่เขากลับยิ้มแล้วยอมขอโทษผมแทน—ผมทำได้แต่ยอมแพ้หมดรูป

…ถึงว่าทำไมซากุไรคุงถึงฮอต

ผมได้แต่ยิ้มรับอย่างเข้าใจ แล้วหันกลับมาขูดแครอทเงียบๆต่อไป
