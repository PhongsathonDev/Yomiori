เล่ม 7 บทที่ 2-7 บทคั่น

เวลาผ่านไปหนึ่งสัปดาห์นับตั้งแต่ชิราทามะซังเริ่มการทดลองอยู่ในชมรม

ในห้องชมรมหลังเลิกเรียน ยานามิ โคมาริ และสมาชิกชั่วคราวอย่างชิราทามะกำลังอยู่ด้วยกัน

ยานามิกำลังเคี้ยวป๊อกกี้พลางจ้องประตูห้องชมรมอย่างเหม่อลอย

[ นี่ นุคุมิซึคุงหายไปไหนแล้วน่ะ? ]

[ ด-โดนเรียกไปที่ห้องพยาบาลน่ะ ]

โคมาริตอบโดยที่สายตายังจดจ่ออยู่กับโทรศัพท์ของตัวเอง

[ อ่า โคนุกิเซ็นเซอีกแล้วสิ นุคุมิซึคุงเป็นประธานชมรมอยู่แล้วนี่นา~ ]

กร๊อบ กร๊อบ ยานามิเคี้ยวป๊อกกี้อีกแท่งแล้วใช้ปลายนิ้วหยิบกล่องส่งให้ชิราทามะ

[ นี่ ชิราทามะจัง กินมั้ย? ]

[ โอ๊ะ ค่ะ ขอบคุณนะคะ ]

ชิราทามะที่กำลังอ่านนิตยสารชมรมเก่า ๆ พลันเปลี่ยนมาเป็นรอยยิ้มประจำตัว

เธอเปิดซองป๊อกกี้จากกล่อง พลางหัวเราะเบา ๆ อย่างอดไม่ได้

[ ขำอะไรเหรอ ชิราทามะจัง? ]

[ ก็แค่คิดว่า รุ่นพี่ยานามิกับฉันอาจจะคล้ายกันนิดหน่อยค่ะ ]

ชิราทามะกัดป๊อกกี้ช้า ๆ พลางเอียงหัวอย่างน่ารัก

[ ทำไมเหรอ? หรือเพราะเราชอบสลัดเหมือนกัน? ]

[ ก็ส่วนหนึ่งค่ะ แต่ฉันก็พกขนมติดตัวตลอดเหมือนกัน ดูสิคะ ]

ชิราทามะหยิบถุงลูกอมเนื้อนุ่มหน้าตาน่ารักออกมา

ยานามิเห็นแล้วพยักหน้ารับอย่างกระตือรือร้น

[ เธอเข้าใจสินะ ชิราทามะจัง ขนมมันเป็นสิ่งจำเป็นสำหรับผู้หญิง แต่พวกผู้ชายไม่มีทางเข้าใจหรอก พวกเขาชอบหาว่าเรากินเยอะเกินไป— ]

ขณะที่ยานามิเริ่มระบาย ชิราทามะก็เอียงหัวเล็กน้อย

[ กำลังพูดถึงประธานอยู่เหรอคะ? ]

[ ...เปล่านะ ไม่ได้พูดถึงนุคุมิซึคุง ]

ยานามิปฏิเสธด้วยสีหน้าจริงจัง ชิราทามะดูงุนงงอยู่ครู่หนึ่ง แต่สุดท้ายก็ปล่อยผ่าน เธอยิ้มพร้อมยื่นถุงลูกอมให้

[ อยากลองกินดูมั้ยคะ? ]

[ ขอบคุณนะ! ]

[ รุ่นพี่โคมาริ จะลองบ้างมั้ยคะ? ]

[ ...อุ๊? ข-ขอบคุณนะ ]

บรรยากาศอันอ่อนโยนเข้ามาเติมเต็มห้องชมรม

ยานามิเคี้ยวลูกอมเนื้อนุ่มไปพลางพยักหน้าซ้ำ ๆ

[ ขนมนี่มันเยียวยาจิตใจจริง ๆ ถ้าไม่มีมันนี่อยู่ไม่ได้เลย ]

[ ใช่ค่ะ ฉันต้องกินเยอะ ๆ ไม่งั้นน้ำหนักจะลดเอา มันเป็นเรื่องที่เหนื่อยเหมือนกัน ]

[ ...เอ๊ะ? ]

สีหน้าของยานามินิ่งค้าง

ชิราทามะยังคงพูดด้วยสีหน้าไร้เดียงสา พลางเอียงคออีกครั้ง

[ ไม่ใช่แบบนั้นเหรอคะรุ่นพี่? ถ้ากินแค่มื้ออาหาร น้ำหนักจะลดเลยต้องพกขนมติดตัวไว้ ]

[ ...ก็ใช่ ]

ยานามิพยักหน้ารับโดยไม่ลืมส่งสายตาอ้อนวอนให้โคมาริ ดูเหมือนเธอจะพูดอะไรบางอย่าง จากนั้นยานามิก็โน้มตัวมาข้างหน้าอย่างจริงจัง

[ ...นี่ ชิราทามะจัง มีเคล็ดลับอะไรมั้ย? ]

[ เคล็ดลับ? อืม หาช่วงเวลาที่จะกินทีละน้อยๆบ่อย ๆ มั้งคะ ]

[ แล้วมันช่วยลดน้ำหนักได้เหรอ? ]

[ เอ๊ะ? ไม่ใช่ค่ะ เป็นเคล็ดลับไม่ให้น้ำหนักลดต่างหาก ]

ยานามิเงียบไป

ชิราทามะที่ไม่ทันสังเกตปฏิกิริยาของยานามิยังคงพูดด้วยรอยยิ้ม

[ เมื่อคืนนี้ฉันกินเค้กก่อนนอนเลยล่ะคะ มันไม่ดีต่อผิวก็จริง แต่ฉันกินข้าวเย็นไม่เยอะ รุ่นพี่กินอะไรก่อนนอนบ้างมั้ยคะ? ]

[ ฉันกินบะหมี่ถ้วยเมื่อคืนนี้เหมือนกัน... ]

ยานามิก้มหน้าด้วยท่าทางหมดแรง

ชิราทามะปรบมืออย่างสดใสโดยไม่รู้ถึงผลกระทบของคำพูดตัวเอง

[ สุดยอดไปเลยค่ะ! ฉันกินบะหมี่ถ้วยไม่หมดแน่ ๆ มีแต่พวกผู้ชายชมรมกีฬาเท่านั้นแหละที่กินบะหมี่ถ้วยใหญ่ๆพวกนั้นได้ใช่มั้ยล่ะคะ? ]

[ อืม เธอ...พูดถูก... ]

พลังของยานามิค่อย ๆ หมดไปเหมือนธูปที่ไหม้หมดแล้ว ขณะที่ชิราทามะยังคงพูดต่อไปอย่างสบายใจ

โคมาริที่มือสั่นอยู่เงียบ ๆ หยิบหูฟังมาใส่แล้วเปิดเพลงในโทรศัพท์

[ เมื่อเร็ว ๆ นี้ฉันเริ่มกินข้าวกล่องร้านสะดวกซื้อหมดแล้วนะคะ แบบนี้อาจจะโตขึ้นนิดหน่อยก็ได้ มีเคล็ดลับการกินเยอะ ๆ บ้างมั้ยคะ รุ่นพี่ยานามิ? ]

[ บางที...แค่ใส่เครื่องปรุงทุกซองตั้งแต่เริ่มเลย... ]

หลังจากตอบเสร็จ ยานามิก็ทรุดตัวลงไม่ขยับอีก

โคมาริลุกขึ้นเงียบ ๆ เอาหน้าผากไปพิงกับผนัง

[ เอ่อ ทั้งสองคนไม่เป็นอะไรแน่นะคะ...? ]

ไม่มีคำตอบ

ชิราทามะมองรุ่นพี่ทั้งสองที่ดูไร้เรี่ยวแรงเหมือนศพ ก่อนจะกลับมาเปิดนิตยสารชมรมเก่า ๆ อีกครั้ง—
