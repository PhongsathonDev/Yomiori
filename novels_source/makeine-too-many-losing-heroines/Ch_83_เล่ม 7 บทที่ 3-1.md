เล่ม 7 บทที่ 3-1

วันถัดมาหลังจากที่เรายอมช่วยเหลือเรื่องวุ่นวายที่เกิดขึ้นอย่างไม่เต็มใจ ตอนนี้เป็นช่วงพักเที่ยง

ที่บันไดหนีไฟของอาคารเรียนเก่า ผมยืนพิงราวบันไดบริเวณชานพักพร้อมกับเสียบหลอดเข้าไปในกล่องนม

[ ขอโทษที่เรียกพวกนายมาที่นี่กะทันหันนะ ]

ที่นั่งอยู่บนขั้นบันไดฝั่งตรงข้ามผมพร้อมแกะกล่องเบนโตะของตัวเองคือ อายาโนะ มิตสึกิ และซากุไร ฮิโรโตะ

[ นุคุมิซึ นายบอกว่ามีเรื่องสำคัญจะพูด ใช่มั้ย? ว่ามาเลย ]

อายาโนะพูดขณะโยนไข่นกกระทาที่พันด้วยเบคอนเข้าปากอย่างไม่รีรอ

พ่อแม่ของเขาชอบทำอาหาร กล่องเบนโตะของเขาเลยดูมีสีสันและหลากหลายเสมอ

[ ผมก็พร้อมแล้ว ว่ามาได้เลย ]

ซากุไรคุงพูดด้วยรอยยิ้มอ่อนโยน ก่อนจะคีบฟูกิที่เคี่ยวแล้วขึ้นมากับตะเกียบ

ช่วงนี้เขาเริ่มทำเบนโตะเอง แถมยังทำให้ประธานนักเรียนทุกวันด้วย แต่งงานกันเลยเถอะ

[ ขอบคุณนะ จริง ๆ แล้ว อยากคุยกับพวกนายเกี่ยวกับเด็กปีหนึ่งคนใหม่ที่พวกเรากำลังดูแลอยู่ในชมรมวรรณกรรม ]

...ตอนนี้ก็ไม่มีเหตุผลที่จะปิดบังแล้ว

ผมสูดลมหายใจลึกก่อนจะเริ่มเล่าทุกอย่างที่เกิดขึ้นทีละขั้นตอน

หลังจากฟังจบ อายาโนะวางตะเกียบลงก่อนจะเอียงคอ

[ เล่าเรื่องทั้งหมดให้พวกเราฟังแบบนี้...ไม่เป็นไรเหรอ ? ]

[ มันไม่ใช่เรื่องที่ควรป่าวประกาศไปทั่ว แต่ผมขออนุญาตเธอแล้ว ]

ถึงผมจะไม่ได้ถามว่าเธออนุญาตมากแค่ไหน แต่น่าจะโอเคล่ะมั้ง

[ เคยได้ยินเรื่องนี้มาบ้าง แต่ก็ไม่คิดว่ามันจะซับซ้อนขนาดนี้ ]

ซากุไรคุงพูดพร้อมกับมองรากโกโบพันด้วยเนื้อที่อยู่บนตะเกียบด้วยรอยยิ้มจาง ๆ

[ เธอบอกว่าอยากทำความเข้าใจกับความรู้สึกของตัวเอง แต่คนที่เกี่ยวข้องคือพี่เขยของเธอ มันไม่ใช่เรื่องที่สารภาพแล้วจบกันได้ เราไม่รู้ว่าเธอจะทำอะไรลงไป ]

อายาโนะพยักหน้า ก่อนจะหยิบตะเกียบขึ้นมาอีกครั้ง

[ เธอเคยมีเรื่องกับตำรวจมาก่อน ถ้าเกิดอะไรแบบนั้นขึ้นอีก คราวนี้แค่โดนพักการเรียนคงไม่พอ ]

ซากุไรคุงเงยหน้าขึ้นมองฟ้าอย่างครุ่นคิดเมื่อได้รับสายตาจากอายาโนะ

[ เราไม่ใช่เซ็นเซเลยไม่รู้แน่ชัดหรอก แต่...ไม่เคยได้ยินเรื่องที่ใครจะโดนพักการเรียนสองครั้งในเวลาสั้น ๆ แบบนี้นะ ]

การที่ไม่เคยได้ยินก็คือมันไม่เคยเกิดขึ้นจริง ๆ นั่นแหละ

ผมดื่มนมจนหมดก่อนจะหันไปพูดกับทั้งสองคน

[ เพราะงั้นเลยอยากขอคำแนะนำจากพวกนาย ตอนนี้รับปากว่าจะช่วยเธอไปแล้ว แต่ก็อยากเลี่ยงไม่ให้มีอะไรผิดกฎหมายเกิดขึ้น แต่เพราะผมเป็นผู้ชาย เลยไม่เข้าใจความรู้สึกของผู้หญิงเท่าไหร่ อยากให้พวกนายช่วยคิดแผนที่เธอพอใจที ]

ความเงียบโรยตัว ทั้งสองคนมองหน้ากันด้วยสีหน้าฉงนก่อนจะพูดขึ้นมาอย่างลังเล

[ ...นุคุมิซึ พวกเราก็เป็นผู้ชายเหมือนกันนะ ]

[ ใช่ น่าจะไปถามพวกผู้หญิงในชมรมวรรณกรรมจะดีกว่ามั้ย? ]

ก็รู้อยู่แล้วว่าจะต้องพูดแบบนี้ ผมมองพวกเขาด้วยสายตาจริงจัง

[ ฟังนะ ผมได้ตระหนักบางอย่างในปีที่ผ่านมา— ผู้หญิงในชมรมวรรณกรรมไม่นับเป็นผู้หญิงเลย ]

ทั้งสองคนดูเหมือนมีบางอย่างจะพูด แต่สุดท้ายก็หุบปากไป

[ ถ้าจะให้พูดคือ พวกนายอาจจะมีมุมมองที่เข้าใจได้มากกว่าซะอีก ]

หลังจากคิดอยู่สักพัก อายาโนะก็พยักหน้าพร้อมสีหน้าที่ซับซ้อน

[ ฉันจะลองถามคนรู้จักดูแบบอ้อม ๆ แต่คงหวังอะไรมากไม่ได้หรอก ]

[ ผมจะลองถามความคิดเห็นดูเหมือนกัน แต่ไม่มั่นใจว่าจะเข้าใจความรู้สึกของผู้หญิงเท่าไหร่นะ ]

เท่านี้ก็มากพอแล้ว การอยู่ในชมรมวรรณกรรมมันทำให้ความรู้สึกปกติของเราบิดเบี้ยวไปหมด

[ นายเองก็รีบกินข้าวด้วยล่ะ นุคุมิซึคุง ใกล้จะเข้าเรียนแล้ว ]

ซากุไรคุงพูดขณะเก็บกล่องเบนโตะที่ทานเสร็จแล้ว

เอ๊ะ เวลาขนาดนี้แล้วเหรอ? ผมควรกินบ้าง ไม่งั้นเดี๋ยวพักคาบหน้าคงโดนยานามิกินข้าวกลางวันจนหมดแน่...

ขณะที่ฟังบทสนทนาของทั้งสองคนที่กินข้าวเสร็จแล้ว ผมเปิดถุงขนมปังแกงกะหรี่ขึ้นมา

พอคิดดูแล้ว ผู้หญิงที่พวกเขารู้จักก็คือ—

ใบหน้าที่คุ้นเคยแวบเข้ามาในหัวผม

ผมรีบสลัดความคิดนั้นทิ้งไปแล้วกัดขนมปังแกงกะหรี่เข้าไปหนึ่งคำ

◇

หลังเลิกเรียน ห้องชมรมเต็มไปด้วยบรรยากาศตึงเครียด

ยานามิและโคมาริจ้องซองจดหมายที่ ชิราทามะ ริโกะ วางไว้บนโต๊ะโดยไม่พูดอะไร

มีซองจดหมายขนาดใหญ่สามซองที่ใหญ่พอจะใส่สมุดหรือกระดาษ A4 ได้

บนซองแต่ละซองมีตัวอักษรขนาดใหญ่เขียนว่า <สน>, <ไผ่>, และ <บ๊วย>

[ เมื่อคืนฉันคิดแผนมาได้สามแผนค่ะ ประธาน เลือกแผนที่ชอบได้เลย ]

เธอกล่าวพร้อมกับส่งซองให้ผม

ชอบงั้นเหรอ? ผมไม่ใช่คนประเภทที่ชอบเลือกอะไรแบบนี้เลย...

[ เลือกสิคะ ประธาน ]

[ ร-รีบเลือกเลยนะ ป-ประธาน ]

ยานามิและโคมาริกดดันฉันจากทั้งสองข้าง เฮ้อ พวกนี้จะเรียกผมว่าประธานแค่ตอนแบบนี้เท่านั้นสินะ

หลังลังเลอยู่พักใหญ่ ผมหยิบซองที่เขียนว่า <ไผ่> ขึ้นมา มันเป็นการเลือกแบบญี่ปุ่นทั่วไปที่เน้นทางสายกลาง

[ เอ่อ...โฆษณาขายบ้านเหรอ...? ]

ข้างในซองคือใบปลิวโฆษณาขายบ้านในเมือง

สถานที่ตั้งอยู่บนภูเขาทางตอนเหนือของสถานีฟุตะกะวะ เป็นบ้านโดดเดี่ยว

[ ฉันเจอที่พักน่ารักๆ ที่ฟุตะกะวะค่ะ มันไม่มีบ้านหลังอื่นอยู่ใกล้ๆ และมีห้องใต้ดินด้วยนะคะ- ]

ผมใส่ใบปลิวกลับลงไปในซองก่อนที่เธอจะอธิบายจบ

[ ...ขอดูซองอื่นได้มั้ย? ]

[ ประธานคะ ไม่อยากฟังแผนหน่อยเหรอ? ]

ไม่อยาก ผมรีบหยิบซองที่เขียนว่า <สน> ขึ้นมาแบบหมดหวัง

คราวนี้เป็นโบรชัวร์การท่องเที่ยว

หน้าปกเป็นภาพใหญ่ของบ้านพักกลางน้ำสุดเก๋

[ อ่า...นี่อะไรเหรอ...? ]

[ พี่สาวฉันกับทานากะเซ็นเซจะไปฮันนีมูนที่ตาฮีติค่ะ พวกเขายุ่งกันมากเลยอยากไปพักผ่อนสักครั้ง ]

ยานามิแย่งโบรชัวร์จากชิราทามะก่อนที่เธอจะพูดจบ

[ ว้าว นี่มันดูดีสุดๆ เลย! คืนสุดโรแมนติกใต้แสงดาว- ]

ยานามิมองโบรชัวร์ด้วยแววตาเหม่อลอย ก่อนสายตาจะหม่นลงอย่างรวดเร็ว

[ ...เข้าใจแล้วล่ะ หลังแต่งงานก็ต้องมีฮันนีมูนสินะ เข้าใจเลย... ]

อ่าาาาาา มาอีกแล้ว

ผมส่งสัญญาณให้โคมาริ เธอจึงยื่นลูกอมโฮชิอุเมะให้ยานามิ

ยานามิที่ดูไร้ชีวิตค่อยๆ เคี้ยวลูกอมไปเรื่อยๆ ขณะที่ผมค่อยๆ ดึงโบรชัวร์กลับมาจากมือเธอ

[ แล้วแผนนี้คืออะไรเหรอ? ]

[ พี่สาวฉันกับฉันดูเหมือนกันเป๊ะจากข้างหลังค่ะ ถ้าฉันเช่าบ้านพักติดกันได้ ฉันก็แอบไปสลับตัวกับพี่สาวตอนกลางคืน- ]

ผมรีบใส่โบรชัวร์กลับลงไปในซอง

เหลือแค่ซองที่เขียนว่า <บ๊วย> เท่านั้น ผมภาวนาก่อนจะเปิดมัน

ข้างในมีเอกสารและแคตาล็อก

[ ...นี่คือโบรชัวร์สถานที่จัดงานแต่งงานเหรอ? ]

[ ใช่ค่ะ มันเป็นเอกสารเกี่ยวกับงานแต่งของพี่สาว ฉันถ่ายเอกสารทุกอย่างมา โบรชัวร์ ใบเสนอราคา แผนผังที่นั่งในวันงาน อะไรแบบนี้ค่ะ ]

มือของชิราทามะหยุดลงบนเอกสารกองหนา

มีภาพชุดแต่งงานสีขาวบริสุทธิ์ที่โดดเด่นด้วยชายกระโปรงยาว

[ ...ฉันอยากใส่ชุดนี้แล้วถ่ายรูปในโบสถ์ค่ะ ]

เธอส่ายหัวเบาๆ ก่อนพลิกภาพกลับ

[ พี่สาวฉันได้ทำทุกอย่างก่อน ฉันเลยอยากมีอะไรสักอย่างที่ได้ทำเป็นคนแรกบ้าง บางทีตอนนั้นฉันอาจจะเรียกทานากะเซ็นเซว่าพี่ชายได้ ]

ผมนิ่งเงียบ พยายามคิดคำพูดที่เหมาะสม ขณะที่ชิราทามะเริ่มเก็บเอกสารเกี่ยวกับงานแต่ง

[ เป็นไปไม่ได้ใช่หรอกมั้ย ? งั้นไปตามแผนสนหรือไผ่เถอะ- ]

ปัง! ผมเอนตัวไปข้างหน้าและกดมือบนเอกสาร

[ เราเอาแผนนี้แหละ! ]

[ เดี๋ยวก่อนสิ นุคุมิซึคุง!? ]

ยานามิตกใจ นี่คิดดูนะ แผนอื่นมันคือแผนสนกับไผ่นะ ?

ชิราทามะกระพริบตาและเงยหน้ามองผมด้วยสายตากลมโต

[ ชุดจะมาถึงก่อนวันแต่งงานไม่นาน เพราะงั้นการถ่ายรูปในชุดนี้คงลำบากใช่มั้ย ? ]

[ ก็ใช่ค่ะ การถ่ายรูปในชุดนั้นน่าจะยาก แต่...ถ้าเราใช้ชุดอื่นแทนล่ะ? ]

[ ในโบสถ์เหรอ? ]

[ ในโบสถ์ค่ะ ]

[ ...อีกอย่างนึงค่ะ ]

อะไรอีก? เอ่อ แค่นี้ยังไม่พอเหรอ?

ชิราทามะโน้มตัวเข้ามาใกล้ตอนที่ผมลังเล

[ ...ถ้าสมมุติว่า เราถ่ายรูปคู่กับทานากะเซ็นเซได้ล่ะ? ]

[ ในโบสถ์เหรอ? ]

[ ในโบสถ์ค่ะ ]

ชิราทามะพยักหน้าอย่างกระตือรือร้น

เป็นไปไม่ได้หรอก

การถ่ายรูปคู่ในโบสถ์โดยที่เขาไม่รู้ตัวมันชัดเจนว่าเป็นปัญหา

ชิราทามะก็น่าจะรู้ว่ามันแทบจะเป็นไปไม่ได้ แม้ว่าเธอจะเป็นคนเสนอมาก็ตาม

สายตาของเธอเหลือบไปที่ซองอีกสองซอง-

[ ...ทำกันเถอะค่ะ ]

ดวงตาของชิราทามะเปล่งประกายเมื่อได้ยินคำพูดของผม

[ งั้นเริ่มกันเลยนะคะ- ]

ก่อนที่เธอจะพูดจบ ยานามิกับโคมาริก็คว้าแขนผมแล้วลากไปที่มุมห้อง

[ นี่? พวกเธอสองคนจะทำอะไรน่ะ? ]

[ นายจะช่วยเธอจริงๆ เหรอ!? ฉันไม่อยากเป็นผู้สมรู้ร่วมคิดกับอาชญากรหรอกนะ! ]

[ ถ-ถ้านายจะต-ตายก็ไปต-ตายคนเดียวเลย! ]

ให้ตายสิ พวกเธอสองคนเว่อร์ไปแล้ว เราก็แค่พูดถึงการถ่ายรูปเอง

การแอบเข้าไปในสถานที่แต่งงานในวันงาน หลอกล่อเจ้าบ่าวเพื่อถ่ายรูปคู่-

[ ...เดี๋ยวนะ มันผิดกฎหมายเหรอ? ]

ยานามิกับโคมาริพยักหน้าแรงๆ
