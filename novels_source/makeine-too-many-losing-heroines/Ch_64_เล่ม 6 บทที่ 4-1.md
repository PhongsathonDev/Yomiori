เล่ม 6 บทที่ 4-1

ห้าวันหลังจากที่ยานามิประกาศตัวเป็นศัตรู วันนี้คือวันสุดท้ายของภาคเรียนที่สาม

ในวันที่พิเศษแบบนี้ ความรู้สึกและเวลาเหมือนลอยละล่องราวกับความฝัน

แม้จะผ่านพิธีปิดภาคเรียนและได้รับสมุดพกในห้องเรียนแล้ว ความจริงบางอย่างจมลึกเข้ามาในใจของผม

ผลการเรียนของผมลดลงตั้งแต่ภาคเรียนที่สอง ผมปิดสมุดพกลงและมองไปรอบๆ ห้องเรียน

เสียงจอแจในห้องค่อยๆ เงียบลงโดยที่ครูไม่ได้พูดอะไรเลย

อามานัตสึเซ็นเซเริ่มพูดขึ้นเมื่อทุกคนสงบและนั่งลง

[ …พรุ่งนี้ปิดเทอมฤดูใบไม้ผลิก็จะเริ่มแล้ว พอกลับมา ทุกคนก็จะขึ้นปีสองกันแล้วนะ ]

สีหน้าจริงจังของอามานัตสึเซนเซยที่ไม่ค่อยได้เห็นนัก และบรรยากาศที่แตกต่างออกไป ทำให้ผมนั่งหลังตรงโดยไม่รู้ตัว

[ ปีสอง หมายถึงการต้องเลือกสายวิทย์หรือสายศิลป์ และจะมีการเปลี่ยนห้องเรียนกันด้วย นี่จะเป็นโฮมรูมครั้งสุดท้ายกับเพื่อนๆ ห้องนี้ และกับครูด้วย ]

เซ็นเซกวาดสายตามองพวกเราทุกคนช้าๆ ราวกับพยายามจดจำภาพจากโต๊ะครู

[ แต่ทุกปี ห้องเรียนก็จะถูกยุบและจัดใหม่ในเดือนเมษายน พวกเธออาจจะรู้สึกกังวล แต่เมื่อเริ่มต้นขึ้น ทุกอย่างก็จะโอเคเอง จำไว้นะ ถ้าพวกเธอกังวล คนอื่นก็รู้สึกเหมือนกัน ถ้าพวกเธอมีเมตตาให้ผู้อื่น ความเมตตานั้นจะย้อนกลับมาหาแน่นอน ]

—ปีนี้มีอะไรเกิดขึ้นมากมาย

ช่วงเทอมแรก ผมแทบไม่ได้คุยกับใครเลย แต่ไม่ทันรู้ตัวก็มีคนอยู่รอบตัวผมแล้ว

มีเรื่องวุ่นวายมากมาย แต่ก็มีเรื่องสนุกมากมายเหมือนกัน

[ ครูจะจดจำห้อง 1-C เอาไว้เสมอ ดังนั้นพวกเธอสามารถลืมมันได้ตั้งแต่พรุ่งนี้เลย เพื่อที่ทุกคนจะได้ก้าวไปยังขั้นต่อไปโดยไม่ต้องกังวล ]

แม้แต่คนๆนี้ ที่ตอนแรกยังจำหน้าผมไม่ได้ ตอนนี้ก็เรียกชื่อผมได้อย่างคล่องแคล่ว และไม่นานมานี้ก็ยังเป็นคนพาอาจารย์ที่ปรึกษามาคุมชมรมวรรณกรรมของเราอีกด้วย

แม้ว่าการเข้ามาของโคนุกิเซ็นเซจะมีทั้งข้อดีและข้อเสีย แต่สมดุลโดยรวมก็ถือว่าอยู่ในเกณฑ์บวก

หลังจากพูดความในใจจนจบ อามานัตสึเซ็นเซก็ผ่อนคลายไหล่ลง

[ นี่เป็นครั้งที่ห้าที่ครูส่งนักเรียนไปแบบนี้ แต่ทุกครั้งก็ยังรู้สึกเหงาอยู่ดี อึก… ]

อามานัตสึเซ็นเซสูดน้ำมูกเบาๆ และใช้ผ้าเช็ดหน้าซับน้ำตา

—เธอกำลังร้องไห้อยู่เหรอ?

ปกติแล้วเซ็นเซไม่ได้เป็นคนจริงจังขนาดนี้ แต่ดูเหมือนว่าเธอจะรักพวกเรามาก

เมื่อเห็นน้ำตาของครูที่ไม่คาดคิด บรรยากาศในห้องเรียนก็เต็มไปด้วยความสงบ

[ เดี๋ยวนะ นี่ควรเป็นครั้งที่หกใช่มั้ย? หรือครั้งที่สี่? ปีที่สามนั่นตอนครูลืมเอาสมุดพกมาแล้วโดนหัวหน้าระดับดุอย่างหนัก... ]

คำบ่นพึมพำของอามานัตสึเซ็นเซทำลายบรรยากาศเงียบขรึมไป

—อามานัตสึจังก็ยังคงเป็นอามานัตสึจังเหมือนเดิม

[ เอาล่ะ บางคนอาจจะได้อยู่ห้องเดียวกันปีหน้า และเราก็ยังเจอกันในวิชาเรียนนะ ปีหน้าก็ฝากตัวด้วยนะทุกคน! ]

ด้วยพลังที่คุ้นเคย อามานัตสึเซ็นเซตบโต๊ะครูพร้อมกับสมุดรายชื่อ

[ โอเค หมดเวลาของโฮมรูมแล้ว! ห้อง 1-C เลิกเรียนได้! ]

◇

ยังไม่ทันถึง 11 โมง โฮมรูมก็จบลง

วันนี้มีงานเลี้ยงของห้องเรียน เพื่อนร่วมห้องต่างทยอยออกไปโดยไม่มีใครอ้อยอิ่ง คงเพราะไม่มีใครยึดติดกับการกล่าวลา

พูดตามตรง ผมเองก็ได้รับเชิญ แต่ปฏิเสธไปแล้ว

ในห้องเรียนที่เงียบสงบ ฉันจ้องมองกระดานดำที่ว่างเปล่า

[ มาถึงจุดนี้ได้ยังไงกันนะ ]

คำพูดนั้นหลุดออกมาโดยไม่ได้ตั้งใจ

จากคนที่ไม่มีเพื่อนแม้แต่คนเดียว ตอนนี้ผมกำลังจะไปแข่งวิ่ง 100 เมตรแบบเสียเปรียบกับดาวเด่นของทีมวิ่งหญิง

เธอเป็นคนที่ทั้งได้รับความรักและความนิยม คนอย่างเธอคงไม่มีปัญหาเรื่องเพื่อนหรือแฟน แล้วทำไมเธอถึงมอบการตัดสินใจสำคัญขนาดนั้นให้กับผมล่ะ?

คำถามนี้วนเวียนอยู่ในหัวนับสิบครั้ง หรืออาจจะนับร้อยครั้งแล้วก็ได้

แต่ไม่ว่าจะคิดยังไง ผมก็ไม่มีคำตอบ และไม่รู้ด้วยว่าคำตอบจะอยู่ที่ปลายเส้นวิ่ง 100 เมตรหรือเปล่า

ตอนนี้ สิ่งที่ผมทำได้ก็แค่ทำในสิ่งที่ผมทำได้เท่านั้น—

[ เหมือนเดิมเลยนะ นุคุมิซึคุง ]

เสียงร่าเริงที่คุ้นเคยทำให้ผมรู้สึกเหนื่อยทันที

คนที่เข้ามาในห้องคือ ยานามิ อันนะ

เธอมองไปรอบๆ ห้องเรียนก่อนจะนั่งลงข้างๆ ผม

[ นุคุมิซึคุงไม่ได้บอกว่าจะไม่เข้าประชุมห้องเพราะมีธุระเหรอ? ]

[ ใช่ มีประชุมกับประธานนักเรียนต่อจากนี้ ]

[ …ฮึ่ม พวกเธอดูสนิทกันดีจังเลยนะ ]

ยานามิมักจะไม่ค่อยพอใจเวลาพูดถึงประธานนักเรียน

ก็แน่ล่ะ ประธานเป็นคนที่ทั้งเรียนเก่งและสวย เธอเป็นที่ชื่นชมในความสามารถทั้งสองด้าน คงจะอิจฉาน่าดู

[ ยานามิซังไม่ไปประชุมห้องเหรอ? ]

[ ไปสิ แต่ยังมีเวลาเหลือ ]

ดูเหมือนเธอจะมาที่นี่เพื่อกล่าวลาในห้องเรียน ยานามินี่ก็มีมุมอ่อนไหวเหมือนกันนะ

เธอเอนหลังพิงเก้าอี้แล้วเหยียดแขนออก

[ ปีนี้ผ่านไปเร็วมากเลยเนอะ ? ]

[ ใช่ เร็วมาก ]

ถึงจะรู้สึกว่ามันยาวนาน แต่พอมองย้อนกลับไปก็เหมือนผ่านไปในพริบตา

ยานามิยกขาเก้าอี้ด้านหน้าขึ้นก่อนจะพูดด้วยน้ำเสียงเบาๆ

[ …ฉันเคยฝันไว้ว่าพอเข้าม.ปลายในโรงเรียนซึวะบุกิ ทุกอย่างจะเปลี่ยนไป แล้วฉันจะได้ใช้ชีวิตวัยรุ่นเหมือนในหนังหรือซีรีส์ ]

เสียงเอี๊ยดอ๊าดดังจากเก้าอี้ของเธอ

[ -แต่ทุกอย่างก็ไม่ได้เป็นไปตามที่คิดเสมอไปใช่มั้ยล่ะ? ]

เธอพูดพร้อมรอยยิ้มที่ดูเหมือนทั้งเย้ยตัวเองและยอมรับชะตากรรม

สงสัยว่าฉากแบบไหนที่ยานามิคิดภาพไว้สำหรับชีวิตมัธยมปลายของเธอ

คงเป็นภาพที่มีฮาคามาดะอยู่เคียงข้าง ทั้งเรียนด้วยกัน ออกเดท และบางครั้งก็ทะเลาะกัน

[ โซสึเกะกับคาเร็นจังอยู่ห้องเดียวกัน ตอนแรกมันก็ลำบาก แต่เพื่อนๆ ทุกคนก็ใจดี ส่วนนายเอง นุคุมิซึคุง— ]

[ เอ๊ะ ผมเหรอ? ]

อยู่ๆ ก็ได้ยินชื่อที่ไม่คาดคิด ผมอดถามซ้ำไม่ได้

ยานามิพูดต่อโดยไม่ตอบคำถามของผม

[ …ก็ไม่แย่เท่าไหร่หรอก ]

— ไม่แย่เท่าไหร่หรอก

ยานามิพยายามจบปีแรกในมัธยมปลายของเธอด้วยคำพูดนั้น พร้อมน้ำตาที่คลออยู่ในดวงตา

มันเป็นเรื่องของคนอื่น แต่ผมก็อดรู้สึกโล่งใจไม่ได้

บางทีน้ำตาที่ยานามิหลั่งออกมาอาจไม่ใช่เรื่องเสียเปล่า

ในขณะที่ผมคิดเรื่องนี้ ยานามิเลื่อนเก้าอี้เข้ามาใกล้ด้วยเสียงกระแทก

[ ว่าแต่ ได้ยินข่าวลือเรื่องเปลี่ยนห้องเรียนหรือเปล่า? ]

ข่าวลือเหรอ? ผมส่ายหัวตรงๆ ยานามิก็พูดต่อด้วยสีหน้าที่เหมือนรู้ข้อมูลมา

[ เขาว่ากันว่าคู่รักมักจะได้อยู่คนละห้องกัน ]

[ อ๋อ เหรอ? ]

ยานามิไม่สังเกตเลยว่าผมไม่ได้สนใจ และเธอก็พูดต่อไป

[ ถ้าเป็นแบบนั้น โซสึเกะกับคาเร็นจังอาจจะได้อยู่คนละห้องกันก็ได้นะ สองคนนั้นที่อยู่ด้วยกันมาตลอดอาจต้องแยกกัน แล้วฉันก็มีโอกาสได้อยู่ห้องเดียวกับโซสึเกะ คิดว่านั่นหมายถึงอะไรล่ะ? ]

[ …เธอไม่ได้คิดจะฉกฮาคามาดะมาใช่มั้ย? ]

หยุดเถอะ นั่นมันบ้าเกินไปแล้ว

ยานามิไม่สนใจความกังวลของผม เธอโบกมือไปมาเหมือนไล่ความคิดนั้น

[ ไม่มีทาง ฉันไม่ทำแบบนั้นหรอก ทั้งสองคนนั้นก็เป็นเพื่อนสนิทของฉันนะ ]

[ เธอคิดแบบนั้นจริงๆ เหรอ? จริงๆ นะ? ]

ยิ่งได้ยินเรื่อง "เพื่อนสนิท" ของเธอ ยิ่งรู้สึกไม่ค่อยแน่ใจเข้าไปใหญ่…

[ ฟังนะ นุคุมิซึคุง ได้ยินมาว่า 70% ของคู่รักในมัธยมปลายเลิกกันภายใน 6 เดือน ]

[ เอ๊ะ จริงเหรอ? ]

ยานามิพยักหน้าอย่างจริงจัง

[ ผมคิดว่าสองคนนั้นเหมาะสมกันดี และผมก็หวังว่ามันจะไปได้สวย แต่ตัวเลขไม่เคยโกหกใช่มั้ย? 70% เลิกกันเนี่ย ]

[ อืม… ]

[ โซสึเกะที่อกหักหลังจากเลิกกับคนรัก… มันก็ต้องเป็นหน้าที่ของเพื่อนสมัยเด็กอย่างผมที่จะคอยปลอบใจเขาใช่มั้ย? จากนั้น มันก็ไม่ใช่ว่าความรักครั้งใหม่จะไม่เกิดขึ้นนะ ]

ฟังดูเหมือนเธอพิจารณาเขาเพราะคิดว่าน่าจะเป็นเป้าหมายที่ง่ายเมื่อเขาอ่อนแอ

ยานามิดูเหมือนเป็นคนที่เลือกเป้าหมายง่ายๆ แต่ตอนนี้เธอกลับมองเพดานด้วยท่าทางฝันหวาน

[ แต่สองคนนั้นก็คบกันมาเกินครึ่งปีแล้วนิ? ความสัมพันธ์ของพวกเขาก็น่าจะมั่นคงแล้ว ]

[ …ใช่ คิดว่ามันดีที่สุดที่ทั้งสองคนจะยังเป็นแบบนี้ต่อไป ]

งั้นการเปลี่ยนห้องก็คงไม่ทำให้พวกเขาสั่นคลอนมากนัก แต่ใครจะรู้ล่ะ?

แม้ว่าสองคนนั้นจะได้อยู่คนละห้อง ก็ไม่ได้หมายความว่ายานามิจะได้อยู่ห้องเดียวกับฮาคามาดะด้วย

[ …ใช่ ผมเองก็ต้องเปลี่ยนห้องเหมือนกัน ]

[ เอ๊ะ เพิ่งรู้เหรอ? ]

[ ไม่หรอก รู้อยู่แล้ว แต่ว่าช่วงนี้ยุ่งอยู่กับเรื่องการแข่งสัปดาห์หน้า ]

มันคงไม่จบถ้าผมยังทำเหมือนมองไม่เห็นปัญหา

แต่ทุกคนรอบตัวก็ไม่ได้ใส่ใจกับมันเลย และพวกเขาก็ก้าวไปข้างหน้ากันต่อแม้แต่ความกังวลของยากิชิโอะ ถ้าปล่อยไว้ มันก็จะถูกกลืนไปกับกาลเวลา

[ …การฝึกเป็นยังไงบ้าง? ]

[ ก็ไปได้ดีนะ แน่นอนว่าเลม่อนจังท็อปฟอร์มเลยล่ะ ]

ยานามิยิ้มอย่างภาคภูมิใจราวกับว่าเป็นความสำเร็จของตัวเอง

— ออกก่อน 2.5 วินาที ถ้าผมวิ่งได้ตามค่าเฉลี่ยของนักเรียนชายปีหนึ่ง ยากิชิโอะจะชนะไม่ได้เว้นแต่เธอจะทำลายสถิติส่วนตัว

รอยยิ้มของยานามิบ่งบอกว่าเธอมั่นใจว่ายากิชิโอะจะสร้างสถิติใหม่ได้

[ ในฐานะทีมยากิชิโอะ ฉันไม่คิดจะแพ้หรอกนะ ]

ยานามิกำหมัดยื่นมาให้ผม

ผมยิ้มบางๆ ก่อนจะชนหมัดกับเธอเบาๆ

[ อืม ช่วยออมมือให้หน่อยแล้วกันนะ ]

เพิงเล็กๆ ข้างสนามกีฬา มีอุปกรณ์ฝึกซ้อมเก่าๆ ครบชุด

ปกติแล้ว ทีมกีฬาต่างๆ จะผลัดกันใช้อุปกรณ์ที่นี่ แต่ดูเหมือนวันนี้หลังพิธีปิดจะไม่มีทีมไหนจองไว้ ประธานนักเรียนจึงเรียกตัวผมมา

[ โอเค อีกห้าครั้ง อย่าหย่อนเข่านะ ]

[ ยกขาไม่ขึ้นแล้ว….. ]

[ เวลานี้แหละที่ต้องใช้ใจสู้ หลังของนายลอยขึ้นแล้วนะ งั้นเพิ่มอีกสามครั้ง ]

[ เอ๊ะ… ]

ผมนอนลงบนม้านั่ง แล้วยกขาขึ้นตรง

มันเป็นการออกกำลังกายง่ายๆ แต่ก็ท้าทายพอสมควร เพราะประธานกดต้นขาของผมไว้เพิ่มแรงต้าน

หลังจากฝึกจนเสร็จตามจำนวนที่กำหนด และเหนื่อยจนหมดแรง ประธานก็ตบหน้าท้องของผมเบาๆ

[ พักห้านาที เดี๋ยวไปต่อที่เครื่องฝึก ]

การออกกำลังกายอย่างจริงจังแบบนี้เหนื่อยกว่าการนั่งทำซิทอัพไปเรื่อยเปื่อยที่บ้านเยอะเลย…

ตามที่ประธานบอก โปรแกรมนี้ออกแบบมาสำหรับผู้ใหญ่ที่ไม่ค่อยได้ออกกำลังกาย

ผมลุกขึ้นนั่งบนม้านั่ง ใช้มือพัดหน้าตัวเองเบาๆ

[ มันเหนื่อยเหมือนตอนเริ่มต้นเลย แต่ก็รู้สึกว่ากล้ามเนื้อแข็งแรงขึ้นนะ ]

[ เราเพิ่มแรงต้านตามความเหมาะสม ไม่ต้องกังวล เป้าหมายคือการปรับสภาพร่างกายให้สมบูรณ์ ]

ประธานพูดในขณะที่เล่นโทรศัพท์ของเธอไปด้วย เธอใช้แอปบันทึกข้อมูลการออกกำลังกาย

ข้อมูลของผมก็ถูกอัปโหลดลงในแอปเดียวกัน ดังนั้นถ้าผมขี้เกียจ เธอก็รู้แน่นอน

…รู้สึกว่าโดนควบคุมแบบนี้ก็ไม่ได้แย่นะ

[ ขอบคุณที่ช่วยจัดการโปรแกรมนี้ให้ผมนะครับ ประธาน ]

[ อย่าคิดมาก ฉันทำเพราะฉันชอบน่ะ ]

ประธานเก็บโทรศัพท์แล้วนั่งลงข้างผม

— เธอบอกว่าเธอทำเพราะชอบ

เธอไม่ได้ชอบผมหรอกใช่มั้ย? ถ้าอย่างนั้นก็คงมีความเป็นไปได้เดียว

[ …ถึงจะเป็นประธานนักเรียนแต่ก็ยังเป็นห่วงยากิชิโอะอยู่เหรอ ? ]

ประธานหัวเราะเบาๆ กับคำถามตรงไปตรงมาของฉัน

[ ฉันไม่ปฏิเสธหรอก แต่อย่าคิดมากล่ะ ]

[ ก็ใช่ เธอเป็นที่รู้จักในโรงเรียน การที่เธอจะเลิกวิ่งมันก็เป็นเรื่องน่าเสียดาย ]

หลังจากเงียบไปสักพัก ประธานก็หันมาพูดต่อ

[ -นายเคยได้ยินใช่มั้ยว่าฉันเคยอยู่ชมรมวิ่งสมัยมัธยมต้น? ]

[ อืม ใช่ บาโซริซังเคยเล่าให้ฟัง ]

[ ตอนฉันอยู่ปีสอง ฉันเคยแข่งกับยากิชิโอะในการแข่งขันระดับเมือง เธอเป็นแค่เด็กปีหนึ่ง ]

[ แล้วผลเป็นยังไง? ]

[ จะถามถึงผลการแข่งขันทำไมล่ะ มันก็ชัดเจนอยู่แล้ว ฉันเทียบเธอไม่ติดเลย ]

ประธานยิ้มขื่นขมพร้อมกับไขว้ขา

[ ในทัวร์นาเมนต์นั้น เธอลงแข่งห้ารายการ และยืนบนโพเดียมที่สูงที่สุดทั้งห้ารายการ ]

…ชนะที่หนึ่งทุกรายการ ฟังแล้วก็อดนึกถึงสิ่งที่อายาโนะเคยเล่าไม่ได้

ประธานพูดต่อเหมือนกำลังค้นหาความทรงจำ

[ โดยเฉพาะในรายการ 1500 เมตร จำได้เลยว่ามันสร้างความฮือฮาอย่างมาก ]

[ ฮือฮายังไงเหรอ? ]

[ เวลาที่เธอทำลายสถิติระดับจังหวัดได้ เวลานั้นดีพอที่จะลงแข่งระดับประเทศ และทั้งหมดนี้จากเด็กปีหนึ่งที่ยังไม่มีสถิติอะไรเลย สุดท้ายมันถูกบันทึกเป็นข้อผิดพลาดทางการวัด และจัดเก็บไว้เป็นเพียงข้อมูลอ้างอิง ]

นั่นคือความสามารถของยากิชิโอะในสมัยมัธยมต้น

[ แต่ยากิชิโอะบอกว่าเธอไม่เคยแข่งระดับประเทศเลย เกิดอะไรขึ้นเหรอ? ]

[ …เธอถอนตัวจากทุกการแข่งขัน ยกเว้นวิ่ง 100 เมตร ในทัวร์นาเมนต์ระดับจังหวัด ]

ประธานลุกขึ้นเดินไปที่เครื่องฝึกข้างผนัง

[ แม้ว่าเธอจะได้ตำแหน่งในรายการ 100 เมตร แต่เธอก็ไม่ได้ขึ้นโพเดียม และมันก็จบลงแค่นั้น ฉันไม่เคยได้ยินว่าเธอไปแข่งระดับประเทศอีกเลย ]

เธอปรับน้ำหนักเครื่องฝึก ก่อนจะกวักมือเรียกผม

[ มาเถอะ คราวนี้เป็นการฝึกงอขา ]

การฝึกงอขาคือต้องนอนคว่ำ แล้วยกขาจากหัวเข่าขึ้น ซึ่งเน้นกล้ามเนื้อหลังต้นขา มันท้าทาย และบอกตรงๆ ว่าไม่ค่อยอยากทำเท่าไหร่

[ ครั้งก่อนที่ทำมันหนักมากเลยนะ ]

[ ใช่ แต่ความหนักนี่แหละที่ทำให้รู้สึกถึงผลลัพธ์จริงๆ ใช่มั้ยล่ะ? ]

ไม่ได้รู้สึกเห็นด้วยหรอก แต่ก็พอเข้าใจว่าการโดนคนสวยอย่างประธานผลักดันให้ทำอะไรหนักๆ แบบนี้มันมีเสน่ห์ยังไง

ผมครุ่นคิดเรื่องที่ได้ฟังจากประธาน ในขณะที่ทำลายกล้ามเนื้อขาของตัวเอง

กัปตันทีมวิ่งหญิงคุราตะ อายาโนะ มิตซึกิ และประธานโฮโคบารุ

เรื่องราวจากสามคนนี้เชื่อมโยงกัน และนั่นอาจเป็นที่มาของปัญหาของยากิชิโอะ

แต่การเผชิญหน้าปัญหาเหล่านี้เป็นสิ่งที่เธอต้องทำเอง…

[ -เอาล่ะ 10 ครั้ง คิดว่าจะทำต่อไหวม้ัย? ]

ดูเหมือนว่าจะทำครบจำนวนโดยไม่รู้ตัว ผมทิ้งตัวลงบนเครื่องฝึกอย่างหมดแรง

[ ไม่ไหวแล้ว จะเป็นตะคริว ]

[ งั้นพักก่อน แล้วไปต่ออีกเซ็ต ระหว่างพักก็ทำซิทอัพนะ ]

พักแบบนี้ได้ด้วยเหรอ? ผมครางออกมาเบาๆ ขณะลุกขึ้นนั่ง

จากนั้น ประธานก็เริ่มนวดข้อเท้าผมด้วยสองมือ

[ วันนี้ยังไม่ได้ถามเลย ข้อเท้าเธอเป็นยังไงบ้าง? ]

[ เอ่อ… ]

พอพูดถึง ผมเพิ่งรู้ตัวว่าอาการปวดข้อเท้าหายไปแล้ว ถ้าวันแรกให้คะแนนความเจ็บสิบล่ะก็—

[ ศูนย์เลย ]

ประธานยิ้มอย่างพอใจกับคำตอบของผม

[ ดี พรุ่งนี้เจอกันที่สนามตอนเจ็ดโมงเช้า ]
