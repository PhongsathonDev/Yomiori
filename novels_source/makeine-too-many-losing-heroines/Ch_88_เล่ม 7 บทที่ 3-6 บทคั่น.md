เล่ม 7 บทที่ 3-6 บทคั่น

ค่ำวันหนึ่ง ในอพาร์ตเมนต์เล็กๆ ที่แสนอบอุ่น ผู้หญิงสามคนล้อมรอบโต๊ะเตี้ยพร้อมเครื่องดื่มในมือ

เมื่อ อามานัตสึ โคนามิ เจ้าของบ้าน ยกแก้วขึ้น สองสาวที่เหลือ โคนุกิ ซาโยะ และ ชิราทามะ มิโนริ ก็ทำตามทันที

[ เอาล่ะ ดื่มฉลองให้กับงานแต่งงานที่กำลังจะมาของชิราทามะ มิโนริ ! ชนแก้ว! ]

[ [ ชนแก้ว ! ] ]

เสียงแก้วชนกันดังกังวาน ก่อนที่อามานัตสึจะกระดกเบียร์หมดแก้ว แล้ววางแก้วเปล่าลงบนโต๊ะ

[ นี่มันข่าวดีมากเลยนะ! ทานากะเซ็นเซเป็นที่รักของทั้งนักเรียนและเพื่อนร่วมงาน เธอนี่โชคดีจริงๆ เลยน้า โนริทามะจัง ]

[ ใช่ ฉันโชคดีมากจริงๆ ]

มิโนริตอบพร้อมรอยยิ้มสดใส ขณะรินเบียร์ลงในแก้วของอามานัตสึ

โคนุกิเงยหน้ามองเพดาน พร้อมใช้นิ้วนับอะไรบางอย่าง

[ พวกเธอคบกันมาตั้งเจ็ดปี…ตั้งแต่สมัยมหา’ลัยเลยนี่นะ ถึงจะตัดสินใจแต่งงานกัน แต่ก็ถือว่านานเหมือนกันนะ [

[ เขาอยากให้ฉันตั้งหลักเรื่องงานก่อนน่ะ เขาบอกว่าสามปีแรกสำคัญที่สุด ]

เธอพูดพลางพยายามกลั้นยิ้ม แต่ก็ไม่อาจปิดบังรอยยิ้มกว้างนั้นได้ อามานัตสึและโคนุกิหันมาสบตากันพร้อมยิ้มเหมือนรู้ทัน

[ จะว่าไป ตอนเรียนเธอไม่เคยแนะนำเขาให้พวกเรารู้จักเลย ไม่ว่าจะถามยังไงก็ไม่บอก พวกเราก็เพิ่งได้เห็นหน้ากันตอนที่เขามาสอนที่ซึวะบุกินี่แหละ ]

[ นั่นสิ ทำไมถึงต้องปิดเป็นความลับขนาดนั้น? ]

มิโนริถือแก้วไว้ในมือทั้งสองข้าง แล้วส่งยิ้มหวานๆ ออกมา

[ -เพราะสเปกของนุกิซัง มักจะเป็นแฟนคนอื่นเสมอน่ะสิ ]

ตะเกียบในมือของอามานัตสึหล่นลงทำให้หอยเชลล์ตกลงบนโต๊ะ

[ โนริทามะจัง เธอนี่พูดตรงไปนะ อีกอย่าง ช่วงนี้โคนุกิจังก็เปลี่ยนไปเยอะแล้ว ]

[ อาระ มิโนริพูดถูก เธอรู้มั้ยว่า ของของคนอื่นมันช่างน่าดึงดูดแค่ไหน ]

[ ...โคนุกิจัง อย่างน้อยก็ช่วยปฏิเสธบ้างเถอะ ]

อามานัตสึ โคนามิ อายุ 28 ปี พบว่าตัวเองกำลังรับบทเป็นคนตรงๆในวงสนทนานี้ ซึ่งแทบไม่เคยเกิดขึ้นมาก่อน

ขณะที่โคนุกิและมิโนริชนแก้วอีกครั้ง อามานัตสึก็เคี้ยวหอยเชลล์ของตัวเองพร้อมกับถอนหายใจเบาๆ

[ งานแต่งสุดสัปดาห์นี้ใช่มั้ย? เตรียมทุกอย่างเรียบร้อยหรือยัง? ]

[ ค่ะ ทุกอย่าง...เรียบร้อยแล้วค่ะ ]

น้ำเสียงของมิโนริมีอะไรบางอย่างที่ดูคลุมเครือ ทำให้โคนุกิมองเธอด้วยความเป็นห่วง

[ เรื่องริโกะจังใช่มั้ย? ]

มิโนริพยายามยิ้ม แต่ในที่สุดก็ยอมพยักหน้าแทน

[ ตั้งแต่เกิดเรื่องนั้น พวกเราแทบไม่ได้คุยกันเลย ]

[ ริโกะผูกพันกับเธอมากเลยนี่นา เธอคงรู้สึกว่าทานากะเซ็นเซกำลังแย่งเธอไป เลยยินดีกับงานแต่งของเธอได้ไม่เต็มที่ ]

อามานัตสึพูดอย่างสบายๆ ทำให้สีหน้าเคร่งเครียดของมิโนริผ่อนคลายลง

[ อาจจะใช่ แล้วเธอก็เพิ่งมีแฟนด้วยล่ะ ]

[ จริงเหรอ? เป็นใครล่ะ? ]

[ เธอบอกว่าเป็นประธานชมรมวรรณกรรม ]

แค่ก ! โคนุกิและอามานัตสึแทบสำลักด้วยความตกใจ

พวกเธอหันมามองหน้ากัน ก่อนเลือกคำพูดอย่างระมัดระวัง

[ ...เอ่อ ถึงเขาจะดูไม่ค่อยเด่น แต่เขาก็ไม่ใช่คนเลวร้ายนะ ถึงจะมีสาวๆ ล้อมรอบตัวเยอะก็เถอะ ]

[ จริงนะ การที่เขายังคงความนิ่งท่ามกลางผู้หญิงมากมายได้ก็นับว่าเป็นข้อดี เขานี่ก็เป็นตัวเลือกที่น่าสนใจเหมือนกัน ]

[ เขาเป็นเด็กแบบไหนกันนะ… ]

ใบหน้าของมิโนริเต็มไปด้วยความกังวลหลังจากฟังคำพูดของเพื่อนๆ

[ ...เอาเป็นว่าเขามีลักษณะคล้ายกับทานากะเซ็นเซนั่นแหละ ]

อามานัตสึเสริมอย่างพยายามหาเรื่องดีๆ พูด มิโนรินั่งตัวตรงทันที

[ ...งั้นริโกะก็เลือกคนที่คล้ายกับยูจิซังสินะ ]

มิโนริพูดกับตัวเองเหมือนยืนยันอะไรบางอย่าง ก่อนกลับมายิ้มตามปกติ

[ อ้อ จริงสิ อามานัตสึซัง เธอเริ่มใช้แอปหาคู่ใช่มั้ย? มีใครน่าสนใจบ้างมั้ย? ]

[ ไม่ใช่เธอบอกว่าเตรียมนัดเจอไว้แล้วเหรอ? ]

[ ...เกือบโดนหลอกซื้ออพาร์ตเมนต์น่ะ ]

[ [ ............ ] ]

อามานัตสึเปิดเบียร์กระป๋องอีกกระป๋องอย่างรวดเร็ว โดยไม่เทใส่แก้ว ก่อนกระดกดื่มรวดเดียว

โคนุกิยกกระป๋องเบียร์ขึ้น ขณะที่มิโนริยื่นแก้วให้เธอเติม

[ ดื่มเถอะโคนามิ ]

[ แน่นอน ดื่มต่อกันเถอะ ]

[ ใช่ วันนี้ต้องจัดเต็ม! ]

สายลมที่พัดเข้ามาทางหน้าต่างทำให้ผ้าม่านพลิ้วไหวเบาๆ
