บทคั่น : เหตุผลที่ไม่ได้เป็นแฟนกัน

[ เอ่อ….ขอไปเข้าห้องน้ำก่อนนะ ]

ในห้องคาราโอเกะ วันอาทิตย์

หลังจากที่นุคุมิซึวิ่งหนีจากที่นั่ง เหลือแค่ยากิชิโอะกับเทียร่าอยู่ในห้อง

ความเงียบปกคลุม ยากิชิโอะจิบชาอู่หลงแล้วนั่งข้าง ๆ เทียร่า

[ นี่ บา-จัง ]

[ บา...? เอ่อ หมายถึงฉันเหรอ? ]

ยากิชิโอะพยักหน้าอย่างเป็นธรรมชาติ แล้วส่งไมโครโฟนให้เธอ

[ ฉันมีคำถามน่ะ เธอกำลังคบกับนุกคุงอยู่หรือเปล่า? ]

[ หา!? ทะ-ทำไมถึงถามแบบนั้นล่ะ!? ]

เอี๊ยดด เสียงร้องของเทียร่าทำให้ไมโครโฟนส่งเสียงดังแสบหู

แต่ยากิชิโอะไม่สะทกสะท้าน เธอยังคงดันไมโครโฟนไปหาเทียร่าต่อ

[ ระยะห่างระหว่างพวกเธอมันทำให้ฉันคิดแบบนั้นน่ะ มันดูยังไงๆอยู่ ใกล้เกินกว่าจะเป็นแค่การเรียนธรรมดา ๆ ใช่มั้ยล่ะ? ]

[ น-นั่นก็เพราะ! ]

เทียร่ารีบคว้าไมโครโฟนไป

[ นั่นก็เพราะมีหนังสือคำถามเล่มเดียวไง! มีปัญหาอะไร!? ฉันเรียนกับผู้ชายมันแปลกตรงไหนล่ะ!? ]

พูดจบเทียร่าก็หายใจหอบก่อนจะส่งไมโครโฟนคืนให้ยากิชิโอะ

[ เอ่อ... ก็ไม่แปลกหรอก ]

ยากิชิโอะเหมือนจะถูกความดุดันของเธอทำให้ประหลาดใจ เธอพยักหน้าแล้วปิดไมโครโฟน

เทียร่าจิบชาที่เหลือจนหมดแล้วพูดออกมาด้วยน้ำเสียงสงบ

[ ฉันเคยเจอนุคุมิซึซังมาก่อน จากนั้นก็แค่เรียนด้วยกันเท่านั้นเอง ว่าแต่เธอล่ะ ยากิชิโอะซัง ความสัมพันธ์ของเธอกับเขาคืออะไร? ]

[ หืม? เราอยู่ในชมรมวรรณกรรมด้วยกัน เขาเรียกฉันมาที่นี่วันนี้เพราะ- ]

ยากิชิโอะหยุดชะงัก เธอขมวดคิ้วแล้วมองเพดาน

[ เอ๋... เขาเรียกฉันมาที่นี่จริงเหรอ...? ]

[ เอ่อ... หมายความว่าไงน่ะ? เธอมาที่นี่เองโดยที่เขาไม่ได้บอกอะไรเลยเหรอ? ]

ยากิชิโอะกอดอกแล้วเอียงหัว

[ อืม- ฉันไม่ค่อยแน่ใจนะ พอมาคิดดูแล้ว ตอนที่เขาอธิบายมันก็ไม่ได้ชัดเจนขนาดนั้น ฉันแค่คิดว่าอยากมาร้องคาราโอเกะเองตอนตื่นขึ้นมาน่ะ ]

[ ...เข้าใจแล้ว ]

เทียร่าพยักหน้าซ้ำ ๆ เหมือนเธอเข้าใจทุกอย่างหมดแล้ว

[ นี่มันเหมือนพวกต้มตุ๋นงานแต่งเลยนะเนี่ย ]

[ เอ๋? ต้มตุ๋นงานแต่ง? ]

[ ใช่เลย มันเป็นเทคนิคที่ทำให้อีกฝ่ายต้องรับผิดชอบผ่านคำพูดกำกวม สมมติว่าคนรักของเธอบอกว่า ‘ฉันแต่งงานไม่ได้เพราะมีหนี้สินมากมาย’ แทนที่จะพูดว่า ‘ได้โปรดแต่งงานกับฉันเถอะ’ เธอจะทำยังไง? ]

[ หนี้น่ากลัวมากนะ ฉันคงบอกว่าเดี๋ยวช่วยใช้หนี้ด้วยกัน พยายามกันเถอะ... ]

ยากิชิโอะเหมือนจะรู้ตัวถึงอะไรบางอย่าง เธอตบมือฉาด

[ เห็นภาพแล้วใช่มั้ย? เขาแค่ทำให้เธอคิดว่าเธอจะแต่งงานกับเขาได้เมื่อเธอใช้หนี้หมดแล้ว พูดง่าย ๆ ก็คือนุคุมิซึซังใช้กลยุทธ์แบบการต้มตุ๋นงานแต่งแม้จะยังเป็นนักเรียนมัธยมปลายอยู่ก็ตาม ]

[ ฉันติดกับดักงานแต่งไปแล้วเหรอเนี่ย? แต่ยานะจังเป็นคนที่โทรมาหาฉันนะ ]

[ ถึงฉันจะไม่รู้ว่าคนคนนั้นคือใคร แต่การเตรียมบุคคลที่สามไว้ล่วงหน้า นั่นก็เป็นกลยุทธ์คลาสสิกเหมือนกัน ]

เทียร่าจ้องไปที่ประตูห้อง ซึ่งนุคุมิซึเพิ่งเดินออกไป

[ แต่ฉันรู้สึกว่านุกคุงไม่ใช่คนแบบนั้นนะ เขาเป็นเด็กหนุ่มที่ไม่ค่อยรู้ตัวและซื่อ ๆ มากกว่า ต่างจากพวกจอมวางแผนร้ายกาจพวกนั้นเยอะเลย ]

[ อืม ก็จริง เขาไม่ใช่คนฉลาดขนาดนั้น แถมไม่มีนิสัยที่จะทำเรื่องต้มตุ๋นแบบนี้ วันนี้เขาก็ดูซื่อ ๆ เหมือนกัน... ]

เทียร่าพูดไปเรื่อย ๆ ขณะที่เธอเทชาใส่ขวดน้ำของตัวเอง

[ บา-จัง เขาเคยทำอะไรกับเธอบ้างมั้ย? ]

[ ฉันไม่ได้หมายความว่าเขาทำอะไรกับฉันนะ ฉันแค่บอกว่าผู้หญิงควรจะเตรียมพร้อมเวลาออกไปไหนมาไหนกับใครก็ตาม ]

[ เฮ้ะ...ก็ใช่ ]

ยากิชิโอะผิวปากเบา ๆ

[ มันไม่ใช่ว่าเธอต้องคอยระวังเรื่องพวกนี้เวลาเธออยากจะคบใคร แต่ว่านุคุมิซึซังดูจะไม่เข้าใจความพยายามของผู้หญิงเลย เขาซื่อเกินไป ]

[ อา เข้าใจเลย นุกคุงเป็นแบบนั้นแหละ ใครที่ตกหลุมรักเขาคงต้องลำบากน่าดู ]

[ ใช่เลย เขาคือศัตรูของสาว ๆ อย่างที่เรียกกัน ]

[ นุกคุงนี่ไม่น่าให้อภัยจริง ๆ ]

ทั้งสองคนมองตากันแล้วหัวเราะออกมาอย่างร่าเริง

ระหว่างนั้นเอง นุคุมิซึเปิดประตูเข้ามา เขาดูตกใจ

[ ...เอ่อ มีอะไรเหรอ? ทำไมพวกเธอถึงจ้องผมแบบนั้นล่ะ? ]

[ ส่วนนี่แหละที่ฉันไม่ชอบในตัวเขา ]

[ ใช่เลย ถูกต้อง ]

สองสาวหัวเราะออกมาอีกครั้ง นุคุมิซึทำได้แค่ถอนหายใจอย่างช่วยไม่ได้-
