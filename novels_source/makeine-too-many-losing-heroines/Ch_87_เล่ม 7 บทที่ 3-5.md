เล่ม 7 บทที่ 3-5

วันที่สามของวันหยุดยาวห้าวัน เหลืออีกห้าวันจนกว่าจะถึงวันแต่งงาน

อาชญากรทั้งสี่คน อาซากุโมะซัง ชิราทามะซัง ประธานนักเรียน และผม นั่งอยู่ในห้องชมรมวรรณกรรม

อาซากุโมะซังกดปุ่มจับเวลาและจ้องตัวเลขด้วยสายตาเหลือบเล็กน้อย

[ 1 นาที 15 วินาที เราพอจะขยายบทสนทนาเพิ่มได้มั้ย? ]

[ ถ้าลากบทสนทนาออกไปมากเกินไปจะดูไม่เป็นธรรมชาติ สู้เปลี่ยนหัวข้อเร็ว ๆ แล้วรักษาเวลาไว้ดีกว่า ]

ประธานนักเรียนส่ายหน้าและวางตารางเวลาลงบนโต๊ะ

วันนี้พวกเรากำลังจำลองเหตุการณ์ในวันสำคัญ

เพื่อที่จะผ่านด่านต้อนรับและพาตัวทานากะเซ็นเซออกมาได้ เราหลีกเลี่ยงการพูดคุยไม่ได้เลย ดังนั้นจึงต้องเตรียมตัวอย่างละเอียด

อาซากุโมะซังหยุดมือขณะจดบันทึก

[ ...สิ่งที่น่ากังวลอย่างหนึ่งคือ ห้องของเจ้าบ่าวกับเจ้าสาวอยู่ติดกัน ถ้าพี่สาวของเธอมาโผล่แถวนั้นแผนอาจล่มได้ ]

[ พี่สาวฉันน่าจะยังอยู่ในช่วงแต่งหน้าอยู่ตอนนั้นค่ะ อีกอย่างพวกเขายังมีช่วง First Look ที่โบสถ์ตามกำหนดการด้วย… ]

ชิราทามะซังพูดเสียงเบา พลางกัดขนมสวิสโรลทั้งชิ้น

เธอกำลังพยายามเพิ่มน้ำหนัก 2 กิโลกรัม ในขณะที่ยานามิกำลังลดน้ำหนัก

[ อย่าหักโหมเกินไปล่ะ เสี่ยงสุขภาพตัวเองมันไม่คุ้มหรอก ]

[ ทุกคนพยายามกันเต็มที่ ฉันก็อยากทำส่วนของตัวเองให้ดีที่สุดเหมือนกันค่ะ ]

ชิราทามะซังพูดพร้อมน้ำตาคลอเบ้า แต่ขนมสวิสโรลดูเหมือนจะไม่ลดลงเลย ยานามินี่สุดยอดจริง ๆ…

ในขณะที่กำลังคิดทบทวนความเห็นที่มีต่อยานามิ ประตูห้องชมรมก็เปิดออกพร้อมเสียงดังเอี๊ยด

[ ขะ-ขอพักแป๊บนะ… ]

ยานามิในชุดวอร์มเดินเข้ามา หลังจากวิ่งออกกำลังกายเพื่อลดน้ำหนัก

เธอทิ้งตัวลงบนเก้าอี้แล้วพยายามเปิดขวดน้ำ แต่ทันใดนั้น อาซากุโมะซังก็คว้าขวดไปจากมือเธอ

[ อาซากุโมะจัง? ]

[ อันนี้น้ำตาลเยอะเกินไป ฉันทำเครื่องดื่มแคลอรี่ต่ำมาให้ ดื่มนี่แทนค่ะ ]

อาซากุโมะซังพูดพลางยื่นกระติกน้ำร้อนให้

[ ข้างในมีอะไรเหรอ? ]

[ ...มันช่วยลดน้ำหนักได้ค่ะ ]

[ ไม่ต้องพูดมากแล้วเอามาเถอะ ! ]

ยานามิซดเครื่องดื่มในกระติกเข้าไปรวดเดียวจบ ดื่มอะไรแบบนั้นเร็วขนาดนั้นปลอดภัยจริงเหรอ?

ขณะที่ผมดูด้วยความกังวล อาซากุโมะซังก็ยื่นนาฬิกาจับเวลาให้ผม

[ เอาล่ะ มาจำลองบทสนทนาและจัดการเวลาให้กระชับขึ้น นุคุมิซึซังช่วยจับเวลาให้หน่อยได้มั้ยค่ะ? ]

[ อ่า ได้สิ ]

ประธานนักเรียนโฮโคบารุจะเป็นคนจัดการบทสนทนาส่วนใหญ่ในวันงาน แต่ผมต้องประสานงานกับชิราทามะซังที่จะแฝงตัวเข้าไปในโบสถ์ด้วย เลยต้องเตรียมตัวให้พร้อมทั้งสองงาน

หลังจากจำลองเหตุการณ์ตั้งแต่เริ่มจนจบเสร็จ ผมสังเกตเห็นยานามินั่งเหม่อลอยด้วยสายตาว่างเปล่า

[ เธอไม่เป็นไรใช่มั้ย? ขาดน้ำหรือเปล่า? ]

[ นี่ การกินมัน….หมายถึงอะไร…? ]

เธอเริ่มพูดอะไรแปลก ๆ ที่ไม่เหมือนตัวเองปกติ

[ ไม่น่าไหวแล้วล่ะ เดี๋ยวไปซื้อข้าวปั้นมาให้ดีมั้ย? ]

ยานามิส่ายหัวช้า ๆ

[ ความอยากอาหารคืออะไร…? ทำไมผู้คนตายเมื่อถูกฆ่าล่ะ…? ]

จากนั้นเธอก็ดื่มเครื่องดื่มของอาซากุโมะอีกอึกใหญ่ เจ้านั่นมันคงล้ำยุคเกินไปสำหรับมนุษย์แล้วมั้ย?

แต่ถึงอย่างนั้น การเสียสละก็จำเป็นเพื่อความสำเร็จ…

ขณะที่ผมหาเหตุผลมาปลอบใจตัวเอง ยานามิก็ค่อย ๆ ลุกขึ้นยืน

[ เอาล่ะ ฉันคิดว่าจะออกไปวิ่งอีกสักรอบ ]

[ พักอีกสักหน่อยเถอะ ]

[ ฉันรู้สึกว่าฉันทำได้ ฉันวิ่งไปถึงอเมริกาได้เลย ]

แน่นอนว่านั่นก็แค่ความรู้สึก แต่ผมไม่ควรขัดขวางแรงจูงใจของเธอ ผมยิ้มและส่งเธอออกไป

[ ...อาซากุโมะซัง เครื่องดื่มนั่น—มันปลอดภัยจริง ๆ ใช่มั้ย? ถูกกฎหมายแน่นะ? ]

[ ค่ะ ปลอดภัยแน่นอน ฉันตรวจสอบกฎหมายทั้งหมดแล้ว ]

ผมหยิบแก้วน้ำของตัวเองที่ดื่มไปครึ่งหนึ่งขึ้นมา แต่ไม่ได้ดื่มต่อ แล้ววางกลับลงบนโต๊ะ

...ตอนกลับถึงบ้านผมจะลบเบอร์โทรของอาซากุโมะซังออกจากโทรศัพท์ของคาจูแน่นอน

◇

หลังจากจบการประชุมในห้องชมรม ผมมายืนอยู่ที่ทางออกด้านตะวันออกของสถานีโทโยฮาชิ

ผมแวะมาระหว่างทางกลับบ้าน เพื่อไปดูร้านหนังสือและร้านอนิเมะในอาคารสถานี

ขณะที่มองโปสเตอร์งานอีเวนต์ที่ติดอยู่บนผนัง จู่ๆ ก็เปลี่ยนใจเดินไปทางลานด้านทิศใต้แทน มันแค่ความคิดชั่ววูบ เลยไม่สามารถอธิบายเหตุผลได้

ถ้าผมยังยืนกรานไปตามแผนเดิมและแวะร้านหนังสือ ผมก็คงไม่ได้พบกับยานามิ ที่กำลังกดหน้าแนบกระจกของร้านอุด้งแบบยืน พร้อมกับมองคนในร้าน

เธอกำลังมองคนกินอาหารไปพร้อมกับกินกล้วยอยู่...

…อีกนิดเดียวเธอก็จะดูน่าสงสัยแล้ว ผมไม่อยากทำแบบนี้เลย แต่ดูเหมือนจะต้องเข้าไปทัก

[ ยานามิซัง ทำอะไรอยู่น่ะ? ]

[ อ๊ะ นุคุมิซึคุง ]

ยานามิเหลือบมามองผม ก่อนจะกัดกล้วยอีกคำ

[ ฉันรู้สึกว่าตอนนั้นฉันทำตัวแปลกๆ เลยอยากมาสงบสติอารมณ์สักหน่อย ]

ดีแล้ว อย่างน้อยเธอก็เริ่มกลับมาเป็นตัวเองบ้าง ถึงแม้ว่าสภาพปกติของเธอก็ไม่ได้ดูจะปกติอะไรนัก…

[ งั้นเธอก็เลยมาพักอยู่ตรงนี้? ]

[ ใช่ ฉันกำลังกินอุด้งอากาศ ]

...เอ่อ ? หรือว่าเธอยังไม่ปกติเท่าไหร่

ยานามิมองผมด้วยสายตาคมกริบ

[ ถ้าอยากลดน้ำหนักเร็วๆ ก็ต้องควบคุมอาหารใช่มั้ย? วันนี้ฉันกินแค่กล้วยมาตั้งแต่เช้า ]

[ งั้นกล้วยที่กินอยู่นี่ ก็คืออุด้งอากาศ ? ]

[ ใช่แล้ว การกินกล้วยไปพร้อมกับมองคนกินอุด้ง ก็เหมือนฉันกินอุด้งเองไง มันเติมเต็มทั้งร่างกายและจิตใจของฉันเลยนะ ]

[ จิตใจเธอได้เติมเต็มแล้วเหรอ? ]

[ ...ไม่เลย ]

งั้นเธอก็แค่ทำตัวแปลกๆ เท่านั้นแหละ

แต่ว่าครั้งนี้ยานามิพยายามลดน้ำหนักจริงจัง แม้ว่าการไดเอตของเธอมักจะดูพิลึกๆ แต่คราวนี้เธอจริงจังกับมัน

[ ลดมื้ออาหารทันทีแบบนี้ไม่ส่งผลเสียต่อสุขภาพเหรอ? ]

[ ไม่ต้องห่วง ฉันกินให้พอเผื่อไว้สำหรับช่วงแบบนี้แล้ว ]

อ๋อ เธอเตรียมตัวไว้ล่วงหน้าแล้วสินะ

[ ต้องแสดงความเป็นรุ่นพี่ให้เธอดูสักหน่อย ]

[ ยานามิซังสนใจชิราทามะซังจริงๆ ด้วย ]

[ แน่นอนสิ ใครจะรู้ว่าถ้าปล่อยนายไว้จะทำอะไรเธอบ้าง? ถ้าแค่ถ่ายรูปอย่างเดียว นั่นก็ดีที่สุดแล้ว ]

...ผมเถียงไม่ได้เลย ยานามิกินกล้วยหมดแล้ว แล้วก็หมุนเปลือกกล้วยไปมาในมือ

[ นอกจากนั้น เวลามองเธอ มันก็เหมือนมองตัวเองเมื่อปีก่อน ฉันปล่อยผ่านไม่ได้จริงๆ ]

[ พูดถึงเมื่อปีก่อน... ]

ทุกอย่างเปลี่ยนไปเมื่อตอนที่ฮิเมมิยะซังย้ายมาอยู่ห้องเดียวกันกับเรา

ยานามิเข้าใจว่าเธอไม่ใช่นางเอกของฮาคามาดะ โซสุเกะ อีกต่อไปแล้ว ตอนนี้เธอเป็นแค่ "เพื่อน A" ของเขา

[ บางทีทุกอย่างคงต่างออกไปถ้าฉันบ้าบิ่นเหมือนเธอ ]

ยานามิระลึกถึงช่วงเวลาที่การกระทำบ้าระห่ำของชิราทามะดูเหมือนเป็นความสิ้นหวัง เธอไม่อาจทำแบบนั้นได้เมื่อปีก่อน

แต่ตอนนี้ ยานามิเข้าใจแล้ว

[ ตอนนั้นฉันรู้ว่าการสารภาพรักกับโซสุเกะต้องจบด้วยการถูกปฏิเสธ ฉันเลยไม่กล้าก้าวไปข้างหน้า แค่พยายามรักษาสิ่งที่มีอยู่เท่านั้น ]

รอยยิ้มของยานามิแฝงไว้ด้วยความเย้ยหยันตัวเอง

[ อย่าเข้าใจผิดล่ะ ฉันพอใจกับมันแล้ว และไม่เสียใจอะไร ]

[ อ่า ฉันเข้าใจ ]

ถึงเราจะพูดคุยกันจริงจัง แต่เราก็ยังดูเหมือนคนประหลาดที่ยืนมองคนอื่นกินอุด้ง

ผมหยิบถุงพลาสติกจากกระเป๋าเป้ แล้วเก็บเปลือกกล้วยที่ยานามิกินเสร็จแล้ว

[ หลังจากเรื่องทั้งหมดนี้จบแล้ว ไปกินราเมงกันมั้ย? ผมเลี้ยงเอง ]

[ ...ก็ได้ แต่ นุคุมิซึคุง นายจะทำให้ฉันกลับมาอ้วนรึไง? ]

[ นั่นก็หมายความว่าเธอจะกลับมาเป็นตัวเองเหมือนเดิมใช่มั้ยล่ะ? ]

[ หืม งั้นฉันจะแสดงพลังที่แท้จริงให้ดู เตรียมตัวไว้เลยนะ ]

เธอยิ้มอย่างเจ้าเล่ห์

ผมยิ้มตอบอย่างกระอักกระอ่วน รู้สึกเสียใจกับข้อเสนอของตัวเองทันที

พลังที่แท้จริงของยานามิงั้นเหรอ? ดูเหมือนต้องถอนเงินมาเตรียมไว้สักหน่อยแล้ว

บ่ายวันถัดมา ในวันที่สี่ของวันหยุดยาวห้าวัน ผมยืนพิงกำแพงในโถงทางเดินนอกห้องชมรมอยู่ข้างๆ ประธานนักเรียน

บนประตูตรงหน้ามีป้ายแขวนไว้ว่า <กำลังเปลี่ยนชุด! ห้ามผู้ชายเข้า!>

เรากำลังรอให้ยานามิกับชิราทามะซังออกมา ประธานนักเรียนยื่นถุงขนมเยลลี่ผลไม้เล็กๆ ให้ผม

[ นุคุมิซึคุง กินมั้ย? ]

[ อ๊ะ ขอบคุณครับ ]

ผมหยิบเยลลี่หนึ่งเม็ดจากถุง และใส่เข้าปาก ลิ้มรสความหวานเปรี้ยวของรสส้มแมนดาริน

...ไม่นึกว่าเธอจะพกขนมแบบนี้ติดตัว

ประธานนักเรียนยิ้มเจื่อนๆ ขณะที่ผมครุ่นคิด

[ ขนมขบเคี้ยวดูไม่เหมาะกับภาพลักษณ์ของฉันใช่มั้ยล่ะ ? ]

[ ไม่ใช่ครับ แค่ประหลาดใจ ผมคิดว่าประธานน่าจะเป็นคนจริงจังและมีความยับยั้งชั่งใจมากกว่า ]

[ น้ำหนักฉันขึ้นยาก เลยไม่ค่อยจำกัดเรื่องการกินขนม ]

ประธานพูดพลางหยิบกัมมี่อีกเม็ดใส่ปาก

จริงด้วยสิ ผู้หญิงแบบนี้ก็มีเหมือนกัน อย่างเช่น ชิราทามะซัง

การอยู่กับยานามินาน ๆ ทำให้ความคิดปกติของผมแตกสลายหมด ต้องระวังตัวหน่อย...

[ ไม่ใช่ครับ คือที่ผมแปลกใจคือสถานการณ์ทั้งหมดนี่ต่างหาก ]

[ หมายถึงอะไรเหรอ? ]

[ ก็...ไม่เคยคิดว่าประธานจะเข้ามามีส่วนร่วมในเรื่องแบบนี้ ]

[ ก็บอกไปแล้วนี่ ว่าฉันเองก็เคยเจ็บปวดจากความรักที่พูดออกมาไม่ได้เหมือนกัน ]

ประธานพูดพลางจ้องผมด้วยสายตาที่คมกริบ

ด้วยความคาดหวัง ผมเปิดประตูห้องชมรมวรรณกรรมเข้าไป คิดว่าข้างในคงว่างเปล่า แต่กลับพบว่ามีคนอยู่ในนั้น
