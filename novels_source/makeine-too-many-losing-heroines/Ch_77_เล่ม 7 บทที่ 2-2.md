เล่ม 7  บทที่ 2-2

วันอาทิตย์ที่อากาศแจ่มใส สมาชิกชมรมทั้งเก่าและใหม่ทั้งสี่คนมายืนอยู่ที่ AEON Mall โทโยคาวะ

ผมยืนอยู่กลางทางเดินหลัก เงยหน้ามองขึ้นไปยังพื้นที่กว้างใหญ่

ทั้งทางเดินเป็นอาคารสามชั้นที่มีลักษณะเป็นโถงโปร่งโดยมีร้านค้าต่าง ๆ เรียงรายอยู่สองข้างทาง พื้นที่นี้เปรียบได้กับห้างสรรพสินค้าสามชั้น

นี่เป็นครั้งแรกที่ผมมาที่แบบนี้ และมันก็…ใหญ่มาก

ข้าง ๆ ผม โคมาริก็เงยหน้ามองโถงนั้น ปากของเธออ้าเล็กน้อย

[ …อุเอะห์ ม-มันใหญ่มากเลยนะเนี่ย ]

ใช่ มันใหญ่มาก นั่นคือทั้งหมดที่เราพูดออกมาได้เมื่อเจออะไรที่ชวนตะลึงขนาดนี้

ในขณะที่ผมกับโคมาริยืนอ้าปากค้างกันอยู่ ยานามิก็ยืดอกพร้อมใบหน้าที่ดูภาคภูมิใจ

[ เอาล่ะ เดี๋ยวฉันจะสอนวิธีสนุกกับห้างนี้ให้เอง ในฐานะคนที่เคยมาที่นี่มาก่อน ]

[ เธอเนี่ยนะ? ]

ผมเผลอพูดออกไปโดยไม่ทันคิด และยานามิก็หันมาจ้องผมด้วยสายตาดุๆ

[ มีปัญหาหรือไง? นายเองก็เกือบจะขึ้นรถไฟสายอีดะแทนที่จะขึ้นเมเท็ตสึไม่ใช่เหรอ? ]

มันก็อยู่ที่ประตูเดียวกันนั่นแหละ ผมกำลังจะเถียงกลับ แต่-

[ ฉันอยากฟังเคล็ดลับจากรุ่นพี่ยานามิค่ะ! ]

ชิราทามะซังที่สวมเดรสลายดอกสองสี กระโดดเข้ามาสนับสนุนยานามิอย่างรวดเร็ว

ยานามิพยักหน้าด้วยความพอใจ

[ ชิราทามะจัง เธอนี่มีแววจริง ๆ การจะสนุกกับห้างนี้ให้เต็มที่— ]

[ ค่ะ! ต้องทำยังไงบ้างคะ? ]

พวกเราสามคนตั้งใจฟังอย่างใกล้ชิด ยานามิพูดด้วยความมั่นใจ

[ อันดับแรก เราต้องหาที่นั่งจิบชา ]

[ ไม่เร็วไปหน่อยเหรอ? ]

ผมอดไม่ได้ที่จะพูดแทรก และยานามิก็ยักไหล่พลางถอนหายใจ

[ ฟังนะ แค่เดินผ่านห้างแบบนี้ก็ใช้เวลาเยอะแล้ว แล้วพอเดินครบหนึ่งรอบก็จะลืมไปหมดว่าต้นทางมีอะไรบ้าง เลยต้องวนรอบสองโดยไม่รู้ตัว เป็นกับดักชัด ๆ ]

[ เอ่อ จริง ๆ ถ้าได้เดินสองรอบก็น่าจะดีนี่นา เพราะมันทำให้มองสิ่งเดิมในมุมใหม่ได้อีกครั้ง ]

[ ไม่ใช่หรอก ลองคิดดูสิว่าถ้ากินอะไรตอนต้นรอบ แล้วมาเจออะไรที่ดีกว่าในช่วงท้าย ทั้งเงินค่าขนมและกระเพาะของเธอก็มีขีดจำกัดนะ เพราะงั้นเราต้องนั่งจิบชา วางแผนก่อน ]

ถึงแม้เงินค่าขนมอาจเป็นปัญหา แต่เรื่องกระเพาะของยานามิไม่ใช่สิ่งที่เราต้องกังวลแน่ ยืนยันได้เลย

[ โอเค เข้าใจแล้ว งั้นเราจะไปหาคาเฟ่หรืออะไรทำนองนั้นใช่มั้ย? ]

[ ตรงนั้นมีโซนขายเครื่องดื่มกับขนมอยู่ ไปกันเถอะ ]

พวกเราเดินตามยานามิไปยังพื้นที่ที่มีร้านขายของหวานและเครื่องดื่มหลากหลาย

มีร้านขายน้ำมะนาว ไอศกรีม ครีมพัฟ และช็อกโกแลต

ดวงตาของยานามิเปล่งประกายด้วยความตื่นเต้น เอาล่ะ เตรียมพร้อมเข้าสู่โหมดลุยกันเลย—

◇

หลังจากจับจองโต๊ะมุมหนึ่งได้ ผมก็เอนหลังพิงเก้าอี้อย่างเหนื่อยล้า

[ …ทำไมแค่เลือกเครื่องดื่มมันถึงได้เหนื่อยขนาดนี้นะ? ]

สรุปสั้น ๆ เลย การมาอยู่กับยานามิคือความผิดพลาด ความจริงที่ว่ากระทั่งโคมาริกับชิราทามะซังยังเงียบไปเลยแสดงว่าพวกเธอรู้จักนิสัยของยานามิดีแล้ว…

ยานามินั่งอยู่ฝั่งตรงข้ามผม ในขณะที่ผมจิบชาโฮจิฉะเย็นของตัวเอง

[ เฮ้ เลือกที่ดีนี่ ]

[ นี่จองรออยู่นานเลยนะ ? ]

[ งั้นก็สมควรได้รับคำชมล่ะ ยอดเยี่ยมมาก ]

ยานามิวางเครื่องดื่มสีเขียวบนโต๊ะ

ที่ก้นแก้วเต็มไปด้วยวาราบิโมจิชิ้นเล็ก ๆ ราดด้วยมัทฉะรสหวานด้านบน และปิดท้ายด้วยไอศกรีมซอฟต์เสิร์ฟมัทฉะ

[ …เลือกอะไรที่ดูหนักหน่วงมากเลยนะ ]

[ ใช่ นี่คือสมูทตี้มัทฉะวาราบิโมจิ ฉันกำลังลดน้ำหนักอยู่ เลยสั่งแค่เครื่องดื่ม ]

เธอพูดในขณะที่ใช้หลอดหนาดูดวาราบิโมจิขึ้นมา

[ แต่นั่นมันแคลอรีสูงไม่ใช่เหรอ? ]

[ นุคุมิซึคุง นี่ใช้มัทฉะนิชิโอะนะ และมันก็เป็นสมูทตี้ ]

[ อืม… ]

เสียงดูดวาราบิโมจิดังขึ้น

………?

[ เอ๊ะ เดี๋ยว นั่นคือคำอธิบายของเธอเหรอ? จบแล้ว? ]

ยานามิมองมาที่ผมด้วยท่าทางภูมิใจ

[ นุคุมิซึคุง รู้มั้ยว่าความหมายดั้งเดิมของการไดเอตคืออะไร? ]

[ เอ่อ? หมายถึงลดน้ำหนัก? ]

[ ผิดแล้ว เดิมทีคำว่าไดเอตหมายถึง 'มื้ออาหารประจำวัน' เพราะงั้นฉันเลยเลิกใส่ใจกับตัวเลขที่ขึ้น ๆ ลง ๆ ชั่วคราวไปแล้ว ]

[ งั้นแปลว่าเธอล้มเลิกไปแล้วสินะ? ]

[ ไม่ได้ล้มเลิกนะ! ]

โอเค เข้าใจละถ้าเธอจะยืนกรานแบบนั้นก็ไม่ผิดอะไร

[ แต่ว่าคำว่า 'มื้ออาหารประจำวัน' มันหมายถึงการใส่ใจกับสิ่งที่กินทุกวันไม่ใช่เหรอ? ]

[ การไดเอตมันเป็นแนวคิดน่ะ เข้าใจมั้ย? มันเป็นเรื่องของมุมมอง ]

[ อ้อ เหรอ? ]

เธอเริ่มพูดอะไรเพ้อเจ้ออีกแล้ว ผมเลยตั้งสมองตัวเองเป็นโหมดไม่รับการรบกวน

[ สุดท้ายแล้วการไดเอตมันขึ้นอยู่กับจินตนาการนะ ตามทฤษฎีไดเอตล่าสุด ความตั้งใจที่จะลดน้ำหนักช่วยลดแคลอรีได้ มัตฉะสมูทตี้—ดูสิ นี่เต็มไปด้วยสิ่งที่ดูสุขภาพดีใช่มั้ย? เพราะงั้นการดื่มสิ่งนี้ก็ไม่มีเหตุผลที่มันจะไม่ช่วยลดน้ำหนัก ]

นี่คือสิ่งที่เรียกว่าการไดเอตสมัยนี้เหรอ? เหมือนสู้กันด้วยพลังพิเศษเลย

[ ถ้าเพิ่มเซ็มเบ้รสสลัดเข้าไปก็คงสมบูรณ์แบบล่ะสิ ]

[ อ๊ะ เริ่มเข้าใจแล้วสินะ นุคุมิซึคุง! ]

ยานามิยิ้มอย่างภูมิใจพลางดูดซอฟต์เสิร์ฟมัทฉะไปด้วย อย่างไรก็ตาม คำว่า "สลัด" ในเซ็มเบ้รสสลัดไม่ได้หมายถึงผัก แต่หมายถึงน้ำมันสลัดที่ใช้ทำมันต่างหาก

หลังจากเรียนรู้ "ความจริง" เกี่ยวกับการไดเอต ผมก็หวังจริง ๆ ว่าจะมีใครมาช่วยจัดการยานามิที

ผมมองไปรอบ ๆ และไม่นานก็เห็นโคมาริกับชิราทามะซัง

พวกเธอดูเหมือนจะหลงท่ามกลางฝูงคนที่หนาแน่น เดินวนเวียนไปมาอย่างไร้จุดหมาย

ดูเหมือนว่าโคมาริจะไม่สามารถเอาตัวรอดในโตเกียวได้เหมือนกัน จำไว้ละ

[ ขอโทษที่ให้รอนะคะ! ]

ชิราทามะซังกับโคมาริกลับมาหลังจากถูกยานามิไปช่วยไว้

แต่ละคนถือซอฟต์เสิร์ฟมัตฉะไว้ในมือ ซอฟต์เสิร์ฟของชิราทามะซังมีท็อปปิ้งชิราทามะด้วย—ตั้งใจเลือกหรือแค่บังเอิญ?

/* TL: ชิราทามะคือโมจิกลมๆเล็กๆ */

[ สุดท้ายพวกเราก็เลือกร้านเดียวกับพวกรุ่นพี่ค่ะ แต่พอซื้อเสร็จแล้วก็ต่อแถวผิดจนหลงทางไปเลย ]

ชิราทามะซังยิ้มด้วยท่าทางน่ารักเหมือนเดิมก่อนจะนั่งลงตรงข้ามผม

โคมารินั่งข้างเธอ และผมก็คลี่แผนที่ห้างออกบนโต๊ะ

[ -งั้นเราจะเริ่มจากตรงไหนดี? ]

ยานามิเพ่งมองแผนที่ด้วยสีหน้าจริงจัง

[ นี่ ฉันเห็นแซนด์วิชผลไม้มาน่ะ แล้วก็มีร้านราเม็งในฟู้ดคอร์ท หรือจะลองสปาเกตตี้บนกระทะร้อนของ Ciao ก็ได้ แต่ตอนนี้ยังไม่เที่ยงเลย… ]

[ จะกินทุกอย่างนั้นแยกจากมื้อเที่ยงเหรอ? ]

โคมาริเปลี่ยนสมองตัวเองเป็นโหมดไม่รับการรบกวนแล้วกินซอฟต์เสิร์ฟมัตฉะไปพลางพยักหน้าเหมือนหุ่นยนต์

ส่วนชิราทามะซังยิ้มครึ่งหนึ่งอย่างสุภาพ อีกครึ่งหนึ่งดูงง ๆ ว่ายานามิพูดจริงหรือเล่น

ขอโทษนะ แต่ยัยคนนี้พูดจริงน่ะสิ

พอรู้ว่าผมเป็นคนเดียวที่พอจะควบคุมสถานการณ์นี้ได้ เลยรีบดื่มชาโฮจิฉะเย็นจนหมด

[ เอ่อ งั้นเริ่มจากเดินดูร้านกันหน่อยมั้ย? ไหน ๆ ก็มาถึงแล้ว หาไอเดียเขียนเรื่องไปพลาง คุยกันไปพลาง ]

จุดประสงค์หลักของการออกมาครั้งนี้คือการสร้างความสัมพันธ์ในหมู่สมาชิกชมรม โดยเฉพาะระหว่างรุ่นพี่รุ่นน้อง

ยานามิพยักหน้าอย่างกระตือรือร้นกับข้อเสนอของผม

[ ถ้างั้นฉันขอแนะนำร้านเนื้อร้านนึงนะ ตู้โชว์ที่เรียงเนื้อไว้ดูน่าประทับใจมาก ]

ผมว่าแบบนั้นไม่ได้เรียกว่าเดินดูร้านนะ

ชิราทามะซังยกมือขึ้นพนมตรงหน้าอกอย่างกระตือรือร้น

[ ลองไปดูร้านเสื้อผ้าก่อนดีมั้ยคะ? รุ่นพี่ยานามิ เสื้อของรุ่นพี่น่ารักมาก เลยอยากให้ช่วยเลือกชุดบ้าง ]

[ เอ๋? จริงเหรอ? เสื้อของฉันตัวนี้พอใช้เงินไปเยอะอยู่เหมือนกัน ดีใจนะที่มีคนชม! ]

ยานามิหันมามองผมด้วยสายตาแปลก ๆ ส่วนโคมาริที่นั่งข้าง ๆ ก็โดนลูกหลงไปด้วย

ดูเหมือนว่าพวกเราคงต้องตามน้ำไป ผมรีบลุกขึ้นทันที

[ โอเค งั้นไปกันเลย! ]

โคมาริเงยหน้ามามองผมด้วยสายตาคมกริบ

[ ข-ขอกินให้เสร็จก่อน ]

[ โทษทีนะ พอดีไม่เก่งเรื่องเดินไปกินไป ]

ผมพยักหน้าเงียบ ๆ แล้วนั่งลงต่อ

การเดินชมสินค้าตามหน้าร้านคือการเพลิดเพลินกับการดูของในร้านโดยไม่ได้ซื้ออะไรเลย

ถึงแม้คำว่า "ช้อปปิ้ง" จะดูแปลก ๆ เมื่อไม่มีการซื้อเกิดขึ้น แต่สามสาวจากซึวะบุกิก็ไม่ได้สะทกสะท้าน พวกเธอพากันตื่นเต้นสนุกสนานขณะชื่นชมเสื้อผ้าแฟชั่นสุดเก๋

ขอแก้คำพูดก่อนหน้านี้ ดูเหมือนโคมาริกำลังลนลานอย่างหนัก

[ ฉ-ฉันใส่เสื้อผ้าอยู่แล้ว! ม-ไม่จำเป็นต้องลองใส่ใหม่หรอก! ]

ทำไมเธอโกรธที่ผมทายถูกกันล่ะ? ไม่เข้าใจเลยจริง ๆ

แต่ก็ดี อย่างน้อยก็รู้รสนิยมเธอแล้ว ได้เวลาไปซื้อของจากร้านอนิเมะแล้วสิ…

◇

หลังจากร้านหนังสือ จู่ ๆ ยานามิก็เสนอให้ไปเล่นเกมอาเขต ซึ่งน่าประหลาดใจไม่น้อย

สุดท้ายพวกเราก็ไปเล่นเกมยิงซอมบี้แบบ VR กัน ผมเคยได้ยินชื่อเกมนี้มาก่อน แต่ไม่คิดว่าจะได้เล่นจริง ๆ โดยเฉพาะเล่นกันสี่คน

หลังจากเล่นจบรอบหนึ่ง ยานามิยืดตัวและชวนคุยกับโคมาริ

[ โคมาริจัง เธอเก่งเกมยิงมากเลย มีเคล็ดลับอะไรมั้ย? ]

[ ขะ-ขอแค่ตั้งใจจะฆ่า… ]

โคมาริใช้มือปัดผมหน้าม้าของเธอกลับไปด้วยท่าทางมั่นใจ

[ อ๋อ แค่ตั้งใจจะฆ่าสินะ? ]

[ ช-ใช่ ตั้งใจจะฆ่า ]

...ทำไมพวกเธอสองคนมองมาที่ผมล่ะ?

ผมรู้สึกไม่ค่อยสบายใจ เลยเบนสายตาหนี และดันไปสบตากับชิราทามะซังเข้า

[ รู้สึกขาสั่นเลยค่ะ เกมมัน….เข้มข้นมาก…. ]

เธอพูดพร้อมเอานิ้วชี้ทั้งสองข้างแตะที่ขมับแล้วยิ้ม น่ารักแบบจงใจแท้ ๆ

[ โคมาริจัง ฉันเห็นโต๊ะฮอกกี้อากาศอยู่ตรงนั้น ไปแข่งกันมั้ย? ]

[ ฉ-ฉันเก่งกว่าที่เธอคิดนะ ร-รู้มั้ย? ]

จริงเหรอ? ผมอยากเห็นโคมาริเก่งในเกมฮอกกี้อากาศจริง ๆ เลย…

ขณะที่กำลังจะตามพวกเธอไป ชิราทามะซังก็ดึงแขนเสื้อผมเบา ๆ

[ เอ่อ… พอดีว่าเริ่มเหนื่อยแล้ว ประธานพอจะไปพักเป็นเพื่อนสักหน่อยได้มั้ยคะ ? ]

[ ได้สิ ไม่มีปัญหา เดี๋ยวไปบอกยานามิซังกับโคมาริก่อนนะ— ]

ผมหันไปดู แล้วก็เห็นว่ายานามิกับโคมาริหายลับไปในกลุ่มคนแล้ว

ในขณะที่ผมลังเลว่าจะตามพวกเธอไปดีมั้ย ชิราทามะซังก็ดึงแขนเสื้อผมแรงขึ้นอีกนิด

[ .…..ฉันควรพูดให้ชัดกว่านี้ ]

[ หือ? ]

พอผมหันกลับมา ก็เห็นดวงตาคู่โตของเธออยู่ใกล้กว่าที่คิด

คำพูดกระซิบของเธอที่ตามมา ทำให้เสียงอึกทึกในอาเขตหายไปทันที

[ —เราสองคน……หนีไปด้วยกันสักพักเถอะ ]
