เล่ม 7 บทที่ 2-1

โคนุกิเซ็นเซนั่งอยู่ฝั่งตรงข้ามของโต๊ะ จิบกาแฟจากแก้วมัคและยิ้มให้ผมอย่างอ่อนโยน

[ ริโกะซังเป็นไงบ้างช่วงนี้? ]

[ ในห้องชมรมก็ดูร่าเริงดีครับ เมื่อวานนี้ยังเห็นเธออ่านนิตยสารเก่าของชมรมอยู่เลย ]

ผมจิบชาญี่ปุ่นคั่วจากกระติกน้ำของตัวเอง

...ผ่านไปหนึ่งสัปดาห์แล้วตั้งแต่วันนั้น ชิราทามะซังมาที่ห้องชมรมทุกวันหลังเลิกเรียน

พวกเราพูดคุยเรื่องทั่วไปกันบ้าง แล้วเธอก็กลับไปตรงเวลาทุกครั้งหลังครบหนึ่งชั่วโมง แต่ระหว่างเธอ ยานามิ และโคมาริ ยังคงมีกำแพงบางๆ ขวางกั้นอยู่ เธอยังช่วยผมเก็บยางลบถึงสองครั้งด้วย

[ การมีที่ยืนในโรงเรียนมันเป็นเรื่องดีนะ ช่วยดูแลเธอไปก่อนก็แล้วกัน ]

[ แต่ห้องชมรมวรรณกรรมเหมาะกับเธอจริงๆ เหรอครับ ? ถ้าเธอเข้ากับเพื่อนร่วมชั้นได้จะไม่ดีกว่าเหรอ? ]

[ อาระ ? เธอกับโคมาริซังก็เป็นแบบนั้นจนถึงไม่นานมานี้ไม่ใช่เหรอ? ]

...ก็จริง แต่พวกเราก็ยังเป็นแบบนั้นอยู่นิดหน่อย

โคะนุกิเซ็นเซมองเหม่อเหมือนกำลังคิดถึงอะไรบางอย่าง

[ ตอนที่ยังเด็ก เรามักคิดว่าโรงเรียนคือทุกสิ่งทุกอย่างในชีวิต นั่นก็เพราะโลกอื่นดูไกลเกินไปสำหรับเรา ]

[ โลกอื่น ? ]

เธอพยักหน้าเบาๆ ตอบคำถามที่ผมทวน

[ นั่นแหละ เด็กๆ เลยมีแต่จะต่อต้านหรือไม่ก็ยอมแพ้ ฉันเองก็เคยมีปัญหาตอนมัธยมปลายเหมือนกันนะ ถึงนายจะไม่เชื่อก็เถอะ ]

[ นี่เป็นจุดที่ผมควรจะแสดงความเห็นหรือเปล่าครับ? ]

โคนุกิเซ็นเซหัวเราะอย่างร่าเริงแทนที่จะตอบ

ในใจของเธอ ความทรงจำและอารมณ์ในช่วงวัยรุ่นคงยังคงชัดเจนและสดใส

เธอมองเห็นอะไรในตัวชิราทามะซัง หรือบางทีอาจเป็นสิ่งที่เธอมองไม่เห็น?

อย่างไรก็ตาม ความห่วงใยที่เธอมีต่อชิราทามะซังนั้นเป็นเรื่องจริง

แล้วก็มีอีกเรื่องหนึ่ง...

หลังจากคุยกันได้สักพัก ผมลองยกหัวข้อบางอย่างขึ้นมาพูด

[ ว่าแต่ อยากถามเกี่ยวกับทานากะเซ็นเซ แผนกวรรณคดีญี่ปุ่นครับ ]

[ อาระ? เกี่ยวกับเขาเหรอ? ถามมาได้เลย ]

[ คือ อยากรู้เกี่ยวกับนิสัยหรือบุคลิกของเขาน่ะครับ.. ]

[ บุคลิกของทานากะเซ็นเซเหรอ...? ]

ดวงตาของโคนุกิเซ็นเซหรี่ลงเล็กน้อย เผลอถามอะไรที่ไม่ควรไปหรือเปล่า ?

[ อืม คือเมื่อวันก่อนเขาแนะนำกิจกรรมที่เกี่ยวข้องกับชมรมวรรณกรรม มันทำให้ผมสงสัย... ]

โคนุกิเซ็นเซดูเหมือนจะเข้าใจคำอธิบายของผมและพยักหน้า

[ เอาล่ะ เขาเคยเป็นอาจารย์ที่ปรึกษาของชมรมวรรณกรรมมาก่อน คงยังรู้สึกผูกพันอยู่ ส่วนเรื่องนิสัยล่ะก็- ]

โคะนุกิเซ็นเซเงยหน้าขึ้นเหมือนกำลังค้นหาความทรงจำ

[ เขาเป็นคนจริงใจมาก โดยเฉพาะกับคู่ชีวิตของเขา ถึงขนาดที่สามารถปฏิเสธความสนใจจากเพื่อนร่วมงานคนอื่นได้อย่างนุ่มนวล ]

[ ...ขอโทษนะ ช่วยทำเหมือนว่าผมไม่ได้ยินเรื่องนี้ได้มั้ย ? ]

[ แน่นอน ถือเป็นการตัดสินใจที่ฉลาดดี ]

เธอหัวเราะเบาๆ และยื่นเม็ดลูกอมรสมิ้นต์ให้ผมจากกล่องเล็กๆ

ผมยื่นมือออกไปโดยไม่ทันคิด แต่รีบชักกลับมาอย่างรวดเร็ว

[ ไม่เป็นไร ผมไม่เอาดีกว่า ]

โคนุกิเซ็นเซยืนนิ่งไปครู่หนึ่ง ก่อนจะยักไหล่อย่างเสียดาย

[ ฉลาดจริงๆ นั่นแหละ ]

◇

ผมเดินไปยังห้องชมรมด้วยความเร่งรีบ ทบทวนบทสนทนาในหัว

โคนุกิเซ็นเซดูแปลกไปหน่อยตอนที่ผมพูดถึงทานากะเซ็นเซ... หรือว่าผมคิดไปเอง?

อย่างน้อยก็ได้รู้ว่าเขาไม่ใช่คนที่จะมีความสัมพันธ์แบบชั่วข้ามคืนกับเพื่อนร่วมงาน และความจริงใจของเขาก็น่าไว้วางใจ

ต่อให้ชิราทามะซังกับทานากะเซ็นเซมีส่วนพัวพันในเรื่องที่ไม่เหมาะสมกันจริงๆ มันก็ไม่ใช่เรื่องที่ผมควรเข้าไปยุ่ง...

เอาล่ะ ต้องรีบไปที่ห้องชมรมเดี๋ยวนี้เลย บรรยากาศในนั้นคงจะอึดอัดน่าดู

ผมรีบเดินผ่านทางเชื่อมไปยังตึกฝั่งตะวันตก แต่ก็หยุดชะงัก

ใช่แล้ว โคนุกิเซ็นเซบอกว่าทานากะเซ็นเซมีคู่ชีวิตอยู่แล้ว...

............

...ช่างเถอะ ผมไม่ควรยุ่งเรื่องนี้ ใช่ๆ

ผมตัดสินใจเก็บเรื่องนี้ไว้ในใจและเดินต่อไป

◇

เมื่อเข้าไปในห้องชมรม ผมก็รู้ว่าบรรยากาศไม่ได้แค่อึดอัด...

แต่มันแย่กว่านั้นมาก

ยานามิดูซีดเผือดเหมือนเถ้าถ่าน เธอหมดแรงจนทรุดตัวลงกับเก้าอี้

โคมาริยืนตัวแข็งหันหน้าเข้ากำแพง พร้อมสวมเฮดโฟนฟังเพลง เข้าสู่โหมด "ไม่มีคำพูดไหนเข้าถึงฉันได้" ซึ่งเกิดขึ้นประมาณทุกสองเดือน

[ อ๊ะ! ประธาน! ]

ชิราทามะซังรีบยกมือขึ้นจับอกตัวเอง แล้ววิ่งมาหาผมอย่างร้อนรน

[ เอ่อ เกิดอะไรขึ้น ? ]

[ ไม่แน่ใจเหมือนกันค่ะ ตอนแรกเราก็คุยกันปกติดี แล้วก็... ]

เข้าใจล่ะ งั้นแสดงว่าไม่มีใครรู้จริงๆ ว่าเกิดอะไรขึ้น

ผมข่มความรู้สึกอยากจะเดินหนีไป แล้วเข้าไปใกล้ยานามิ

[ เอ่อ ยานามิซัง เป็นอะไรรึเปล่า? ดื่มน้ำหวานสักหน่อยมั้ย? ]

[ ...ไม่เป็นไร ฉันแค่เสียหายทางจิตใจนิดหน่อย ]

ยานามิปัดผมออกจากหน้าแล้วส่ายหัวอ่อนแรง

ชิราทามะซังทำให้คนที่แข็งแกร่งอย่างยานามิทรุดได้ถึงขนาดนี้เชียว...

เธอทำอะไรลงไปกันแน่ ชิราทามะซัง ?

[ ...เอาเถอะ เดี๋ยวชงชาให้ดีกว่า ]

ใช่เลย เวลาสงสัยต้องชงชา ผมเริ่มต้มน้ำทันที ขณะที่ชิราทามะซังก็เริ่มวางถ้วยชารอบตัวผม

[ ขอโทษที่ไม่ได้ใส่ใจมากกว่านี้นะคะ ในฐานะรุ่นน้อง ฉันน่าจะเป็นคนชงชาก่อน ]

[ อ๊ะ ไม่เป็นไร ชมรมเราไม่มีกฎเข้มงวดแบบนั้น ]

ในห้องชมรมวรรณกรรม ทุกคนเท่าเทียมกัน...แต่ทำไมผมต้องเป็นคนชงชาทุกทีเลยนะ...?

[ ...ประธานดูเป็นผู้ใหญ่มากค่ะ ]

[ หา? ]

[ ประธานใจเย็นแล้วก็คุยง่าย ฉันเคยคิดว่ารุ่นพี่ปีสองน่าจะน่ากลัวกว่านี้ แต่ฉันโล่งใจที่ประธานเข้าถึงง่ายแบบนี้ ]

นี่เป็นครั้งแรกที่มีคนพูดแบบนี้กับผม หวังว่าอีกสองคนจะได้ยินด้วยนะ

ผมมองยานามิกับโคมาริพลางรินชาใส่ถ้วย

[ พอได้คุยกับคนอื่นจริงๆแล้วจะพบว่าพวกเขาใจดีมากกว่าที่คิด ลองคุยกับเพื่อนร่วมชั้นดูมั้ยล่ะ? ]

[ อืม สาวๆ ที่ห้องดูไม่ชอบฉันเท่าไหร่ เลยจะคุยกับพวกผู้ชายแทน สงสัยฉันจะออกแนวห้าวๆ ไปหน่อยค่ะ ฮิๆ ]

ชิราทามะซังแลบลิ้นขึ้เล่นน้อยๆ

เข้าใจแล้วว่าทำไมผู้หญิงคนอื่นถึงไม่ชอบเธอ เธอดูน่ารักน่าเอ็นดูจนใครๆ ก็อยากปกป้อง

[ ชาได้แล้วค่ะ ทุกคน~ ]

ชิราทามะซังประกาศพร้อมแจกถ้วยชา แต่ยานามิที่หมดสภาพและโคมาริที่ยังหันหน้าเข้ากำแพงก็ไม่มีปฏิกิริยาใดๆ

ผมหยิบถ้วยของตัวเองขึ้นมา แล้วชิราทามะซังก็นั่งลงข้างๆผม

[ วันนี้ประธานมาช้าจังค่ะ ไปไหนมาหรือเปล่า? ]

[ อืม พอดีไปหาโคะนุกิเซ็นเซมา เธอเป็นที่ปรึกษาชมรมเรา ]

[ ซาโยะซังสวยมากเลยนะคะ ฉันแอบชื่นชมเธออยู่ ]

ไม่แนะนำให้ทำแบบนั้นเลยนะ เชื่อเถอะ มันดีกว่าสำหรับเธอ

[ ว่าแต่ ชิราทามะซัง เธอรู้จักเซ็นเซมาก่อนใช่มั้ย? ]

[ ใช่ค่ะ ซาโยะซังเป็นเพื่อนของพี่สาวฉัน พวกเขาสนิทกันมานานแล้ว เธอเคยช่วยติวให้ฉันกับพาไปเที่ยวบ้าง ]

...อ๋อ งั้นเธอก็เคยไปเที่ยวกับโคะนุกิเซ็นเซสินะ สงสัยจังว่าเซ็นเซพาเธอไปไหนบ้าง

ขณะที่ลังเลว่าจะถามต่อหรือไม่ ชิราทามะซังก็ยิ้มอบอุ่นให้ เด็กคนนี้ทั้งอ่อนโยนและน่ารักจริงๆ เธอมีเสน่ห์ที่ดูเป็นธรรมชาติ...

ผมยิ้มตอบ แต่แล้วก็รู้สึกเหมือนมีบางอย่างจ้องผมอยู่

พอหันไปดู ก็พบว่ายานามิกำลังจ้องผมอยู่ด้วยสายตาขึ้นมองจากด้านล่าง

[ ...เหมือนจะสนุกดีนะ นุคุมิซึคุง ]

ใช่เลย จนกระทั่งเธอมาทำลายบรรยากาศนี่แหละ

[ เอ่อ ยานามิซัง ในเมื่อเธอกลับมาเป็นปกติแล้ว ขอเสนออะไรหน่อยได้มั้ย? ]

[ ...เสนอ? ]

ยานามิเงยหน้าขึ้นพลางเกาหัวอย่างงุนงง

ผมไม่อยากอธิบายเหตุผลหรอกนะ แต่ช่องว่างระหว่างเธอกับชิราทามะซังดูจะยิ่งห่างออกไปเรื่อยๆ

[ ใช่ เกี่ยวกับสุดสัปดาห์นี้...]

ผมเหลือบมองโคมาริที่ยังคงหันหน้าเข้ากำแพงพร้อมใส่เฮดโฟนอยู่

คุยกับเธอตอนนี้คงไม่มีประโยชน์...

ผมเลยโทรหาเธอแทน

[ อุ๊นา!? ]

โคมาริสะดุ้งเล็กน้อยตอนรับสาย ผมเปลี่ยนโทรศัพท์ตัวเองเป็นโหมดลำโพงแล้ววางมันลงบนโต๊ะ แบบนี้เธอน่าจะได้ยินพวกเราคุยกันแล้วล่ะ

[ เอาล่ะ ลองอีกครั้งแล้วกัน แบบนี้เป็นไง? พวกเราออกไปข้างนอกกันวันอาทิตย์นี้ดีมั้ย? ]

ในช่วงเวลาหนึ่ง ห้องชมรมตกอยู่ในความเงียบงัน

ไม่นาน ยานามิก็เอ่ยขึ้นด้วยสีหน้างุนงง

[ ออกไปข้างนอก? จะไปเข้าค่ายฝึกอะไรรึเปล่า? ]

[ อาจจะไม่ถึงขั้นเข้าค่ายฝึกเต็มรูปแบบ แต่ลองคิดว่าเป็นการไปทัศนศึกษาสบาย ๆ เราอาจใช้โอกาสนี้ระดมความคิดกันระหว่างประชุมชมรม ]

เมื่อฤดูร้อนปีที่แล้ว สมาชิกชมรมก็ใกล้ชิดกันขึ้นจากการเข้าค่ายฝึก— หรืออย่างน้อยก็รู้สึกแบบนั้น แม้จะมีเหตุการณ์ไม่คาดฝันเกิดขึ้น แต่สุดท้ายก็มีคนถูกปฏิเสธหนึ่งคน ในขณะที่อีกสองคนกลับได้เป็นคู่กัน นับว่าผลลัพธ์โดยรวมเป็นบวก

ด้วยตรรกะเดียวกัน การออกไปข้างนอกด้วยกันน่าจะช่วยกระชับความสัมพันธ์ของชมรม

ชิราทามะเป็นคนแรกที่ยกมือขึ้น

[ น่าสนุกจัง ! ฉันอยากไปค่ะ! ]

ยานามิที่มองชิราทามะซึ่งดูตื่นเต้น กลับก้มหน้าลงมองโทรศัพท์ด้วยสีหน้าไม่สบอารมณ์

[ มันกระทันหันเกินไป ฉันก็มีแผนเหมือนกันนะ โอเคมั้ย? ใช่ ฉันมีอะไรที่ต้องทำอยู่ ]

โคมาริที่ยังคงยืนหันหน้าเข้ากำแพงก็พยักหน้าเห็นด้วย

...เฮ้อ พวกเธอช่างไม่ให้ความร่วมมือกันเลย แต่อย่างว่า มันก็กะทันหันเกินไปจริง ๆ
