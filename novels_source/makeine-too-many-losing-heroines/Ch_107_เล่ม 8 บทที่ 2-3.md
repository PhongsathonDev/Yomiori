เล่ม 8 บทที่ 2-3

หลังเลิกเรียนสองวันต่อมา ในที่สุดช่วงเวลาแห่งการเลือกตั้งก็เริ่มต้นขึ้น

ผมเดินไปตามทางเดินเคียงข้างเทียร่าซังพลางไล่ดูแผ่นกระดาษในมือไปด้วย

[ เอ่อ...ต่อไปคือไปเยี่ยมชมชมรมศิลปะ อีกสามสิบนาทีมีนัดกับชมรมซอฟต์บอล ถ้ารวมเวลาย้ายที่ ก็ต้องให้จบในยี่สิบนาที ]

[ รับทราบค่ะ รองประธานชมรมศิลปะเป็นคนรู้จักของฉันอยู่แล้ว เลยได้ฟังข้อมูลล่วงหน้ามาเรียบร้อยค่ะ ]

ผมรีบตามหลังเทียร่าซัง ที่เร่งก้าวขึ้นบันไดไปอย่างเร็ว

...ผมประเมินการเตรียมตัวเลือกตั้งประธานนักเรียนต่ำไปจริง ๆ

นึกว่าแค่เตรียมใบปลิวก็พอแล้ว แต่กลับต้องเดินสายหาผู้มีสิทธิเลือกตั้งกันจริงจังราวกับการเลือกตั้งของจริง

[ นี่ มันไม่ผิดกฎเลือกตั้งเหรอ? ไปขอคะแนนเสียงกับผู้มีสิทธิเลือกตั้งแบบนี้ ]

[ การไปรับฟังความต้องการของผู้มีสิทธิเลือกตั้งนั้นได้รับการอนุญาตค่ะ ฉันก็เช็กกับคุณครูแล้วด้วย ]

เทียร่าซังเดินขึ้นบันไดถึงชั้นบนสุด แล้วแว่บมองนาฬิกาข้อมือ

[ ดูเหมือนจะไปถึงตรงเวลาพอดีเลยนะคะ ]

[ ไม่หรอก ทางเดินช่วงนี้มันยาวกว่าที่คิด ถ้าไม่รีบหน่อยจะไปไม่ทันเวลาที่นัดไว้นะ ]

[ ทำไมถึงรู้ละเอียดขนาดนั้นล่ะคะ? ]

ไม่ต้องบอกก็รู้ การฝึกฝนอย่างเข้มงวดเพื่อเอาตัวรอดในช่วงพักระหว่างคาบมันให้ผลตอบแทนแล้วต่างหาก

ผมยิ้มน้อย ๆ โดยไม่พูดอะไร แล้วเร่งฝีเท้าแซงหน้าเทียร่าซังไป

◇

ระหว่างทางกลับจากการพูดคุยกับชมรมซอฟต์บอล เทียร่าซังก็หยุดยืนหน้ายิม

[ มีอะไรเหรอ? วันนี้หมดคิวแล้วนี่ ]

[ เปล่าค่ะ พึ่งนึกขึ้นได้ว่าชมรมบาสชายกำลังซ้อมอยู่ พอดีหาเวลานัดกับประธานชมรมไม่ค่อยได้ เลยจะลองไปขอคุยตรงๆ เลยดีกว่า ]

ขณะถอดรองเท้าข้างเธอ ผมก็ถามด้วยความสงสัย

[ หาเวลานัดไม่ได้ขนาดนั้นเลยเหรอ? ชมรมบาสชายยุ่งขนาดนั้นเชียว? ]

[ ไม่ได้ยุ่งหรอกค่ะ แต่โดนผู้จัดการชมรมกันไม่ให้เจอประธานชมรม คงคิดว่าฉันมาหาเพราะชอบใครในชมรมแน่ๆ… ]

เทียร่าถอนหายใจยาว ว่ากันว่าชมรมบาสกับชมรมฟุตบอลเป็นที่ฮอตของสาวๆ ในโรงเรียน ก็เคยแอบได้ยินเพื่อนผู้หญิงในห้องพูดกันแบบนั้นอยู่เหมือนกัน

[ ชมรมฮิตๆนี่ก็ลำบากเหมือนกันนะ ชมรมวรรณกรรมนี่ไม่มีเรื่องรักๆ ใคร่ๆ ให้วุ่นวายเลย สบายดีแท้ ]

[ … ]

เทียร่าเธอหันมามองผมด้วยแววตาเหมือนอยากพูดอะไร

[ มีอะไรก็พูดมาเถอะครับ ]

[ …มีหลายอย่างที่อยากพูด แต่ตอนนี้ขอหาเวลานัดคุยให้ได้ก่อนดีกว่าค่ะ ]

เธอเอื้อมมือจับประตูหนักๆ ของโรงยิม

ผมเลยช่วยเปิดให้ แล้วเสียงอึกทึกก็ทะลักออกมาทันที

ฝั่งหนึ่งเป็นชมรมบาสชาย อีกฝั่งเป็นชมรมวอลเลย์หญิง

ผมมองเทียร่าที่กำลังเดินไปหาผู้จัดการชมรม แล้วก็มองไปทางฝั่งบาสชาย

ผมไม่เข้าใจหัวใจผู้หญิงหรอก แต่หนุ่มหล่อสูงหุ่นดีนี่ก็ดูดีจริงแหละ

อืม เบอร์ 10 ที่เพิ่งชู้ตลงเมื่อกี้นี่เท่ใช้ได้…

ขณะที่กำลังเหม่อมองอยู่ ก็รู้สึกได้ว่าสมาชิกชมรมบาสชายเริ่มแอบมองผม

อะไร อินโทรเวิร์ดอย่างผมมันแปลกนักรึไง

แต่พอสังเกตดีๆ พวกเขาไม่ได้มองแค่ผม

สายตาของพวกเขามุ่งไปยังฝั่งวอลเลย์หญิง ที่กำลังซ้อมแข่งกันอยู่… และในหมู่พวกเธอนั่น มีสองคนที่ผมคุ้นหน้า

──ยานามิ อันนะ กับ ซากุไร ฮิโรโตะ

ทั้งสองคนยังอยู่ในชุดนักเรียน หัวเราะคิกคักกันขณะตบลูกบอล

บรรยากาศดูสนุกแบบนั้น มันอะไรกัน

เป็นผู้ชายทั้งที ดันมามัวเล่นสนุกกับสาวๆ แบบนี้ มันน่าเศร้าจริงๆ

ขณะที่กำลังถอนหายใจอยู่ ซากุไรคุงก็วิ่งจากฝั่งวอลเลย์มาหาผม ทิ้งยานามิไว้คุยกับใครบางคนที่น่าจะเป็นประธานชมรม

[ นุคุมิซึคุง นายก็มาด้วยเหรอ มากับบาโซริจังสินะ? ]

[…ก็ประมาณนั้น ]

ผมตอบเสียงอ้อมแอ้ม แล้วซากุไรก็ก้มหัวลงเล็กน้อยเหมือนเกรงใจ

[ …ขอโทษนะ ]

[ หา? ไม่เห็นต้องขอโทษเลย── ]

ผมกำลังจะพูดต่อ แต่เขาก็ส่งยิ้มเจื่อนๆ มาให้

[ ก็บอกว่าจะถอยแล้วแท้ๆ ดันกลายเป็นว่าไปขัดขวางบาโซริจังซะงั้น สุดท้ายก็โกหกนุคุมิซึคุงด้วย ]

[ ผมไม่ถือหรอก… ]

ผมเหลือบมองไปทางเทียร่าซังเธอดูเหมือนกำลังโต้เถียงกับผู้จัดการบาสชายอย่างดุเดือด

ซากุไรหัวเราะฝืดๆ

[ ในห้องประชุมก็รู้สึกอึดอัดนิดหน่อยนะ ]

ก็จริงอยู่

เทียร่าซังเป็นคนดี แต่ไม่ค่อยเก็บสีหน้าเก่งเท่าไหร่

[ แต่ถ้าจะลงชิงตำแหน่งประธานนักเรียน ก็น่าจะมีอะไรในใจล่ะนะ ]

[ มั้งนะ ความรู้สึกน่ะ บางทีตัวเองก็ยังไม่เข้าใจเลย ]

ซากุไรยิ้มเศร้าอย่างบอกไม่ถูก

[ ──ไม่คิดเลยว่าตัวเองจะตัดใจได้ยากขนาดนี้ ]

น้ำเสียงของเขาเหมือนพึมพำกับตัวเอง ทำให้ผมอดมองหน้าเขาไม่ได้

แล้วเสียงใสๆ ก็แทรกเข้ามา

[ อ๊ะ นุคุมิซึคุงก็มาด้วยเหรอ? ]

ยานามิเดินเข้ามาพร้อมเช็ดเหงื่อด้วยผ้าเช็ดหน้า

[ อ๋อ พอดีมีธุระกับชมรมบาสนิดหน่อยน่ะ ]

[ จะไปแจกมันจูพิษใช่มั้ยล่ะ ? ]

[ มันจูพิษ? ]

คำพูดอันตรายทำเอาผมเผลอทวน

ยานามิกอดอกอย่างภูมิใจ

[ เคยได้ยินว่าช่วงเลือกตั้งเขาจะแจกมันจูพิษกันน่ะ มันคือขนมที่อร่อยจนถึงตายเลยล่ะ ]

เอิ่ม… จริงเหรอเนี่ย ถ้าเป็นเธอก็คงกินเข้าไปโดยไม่ลังเลเลยแหละ

[ ขอโทษที่ให้รอนะคะ นุคุมิซึซัง พรุ่งนี้หลังเลิกเรียน ขอเวลานิดหน่อยก่อนซ้อม── ]

เทียร่าซังกลับมาพร้อมจดอะไรลงสมุด ก่อนจะเงยหน้าแล้วเอ่ยขึ้น

[ อ๊ะ ซากุไรคุงก็มาด้วยเหรอ ]

[ อืม พอรู้ว่านัดกับชมรมบาสชายสำเร็จนี่สุดยอดเลยนะ เราเองยังโดนปฏิเสธเลย ]

เขาเหลือบมองยานามิด้วยแววเหมือนมีความหมายแฝง ว่าแล้ว…ยานามิเคยปฏิเสธรุ่นพี่ประธานชมรมบาสคนนั้นสินะ…

ไม่รู้ว่าเธอรู้ตัวมั้ย ยานามิก็ตบไหล่ผมเบาๆ

[ นี่นุคุมิซึคุง ดูนั่นสิ…ยัยนั่นทำอะไรอยู่น่ะ ]

[ หืม? ]

ที่มุมประตูยิม มีผู้หญิงคนหนึ่งยืนถือกล้อง DSLR อยู่

เธอเป็นสาวแต่งตัวดูแฟชั่นหน่อยๆ กระโปรงสั้น พอเห็นเราหันไปมองก็ค่อยๆ หลบไป

[ พวกที่เหลือจากชมรมดูนกค่ะ ตอนนี้กลายเป็นชมรมหนังสือพิมพ์ไปแล้ว ]

เทียร่าพูดด้วยสีหน้าไม่พอใจ

เป็นแบบนั้นเองเหรอ…คนที่เขาลือกันว่าเป็นชมรมหนังสือพิมพ์น่ะ

ถึงจะใส่กระโปรงสั้นดูน่ารัก แต่คนเรานี่ดูแค่ภายนอกไม่ได้จริงๆ…

[ นุคุมิซึคุง มองหน้าฉันมีอะไรหรือเปล่า? ]

[ อ๊ะ เปล่า ไม่มีอะไร…]

แย่ละ เผลอมองยานามิแบบไม่รู้ตัวเลย

ก่อนที่เธอจะพูดอะไรอีก เทียร่าซังก็เบียดเข้ามาอยู่ตรงกลางระหว่างเรา

[ งั้นไปกันเถอะค่ะ นุคุมิซึซัง ]

[ เอ๊ะ วันนี้หมดงานแล้วไม่ใช่เหรอ ]

[ ยังเหลืออีกเยอะค่ะ รีบไปกันเถอะ เดี๋ยวจะรบกวนชมรมเขา ]

เธอเริ่มดันหลังผมเบาๆ แต่รู้สึกว่าแรงเยอะใช้ได้อยู่ เลยระหว่างที่ผมกำลังงุนงงกับแรงกดดันปริศนา ยานามิก็ดึงชายเสื้อซากุไรคุง

[ งั้น ซากุไรคุง ไปประชุมวางแผนกันเถอะ ]

[ อืม งั้นพวกเราสองคนก็ไปก่อนนะ ]

[ หะ ? อ้อ… ]

ยานามิเหลือบมองผมแวบหนึ่ง ก่อนจะคว้าแขนซากุไรไป

[ ใช่สิ ฉันมีขนมปังไส้ถั่วหวานอยู่สองก้อน แบ่งให้นายหนึ่งก้อนนะ ]

[ อ้าว ไม่ใช่ว่าทั้งสองก้อนเป็นของยานามิซังเหรอ? ]

[ ตอนนี้กำลังไดเอ็ตอยู่ กินได้แค่ก้อนเดียวเท่านั้นแหละ ]

ผมหันมองสองคนนั้นผ่านหางตา ก่อนจะถามเทียร่าซัง

[ ว่าแต่ งานถัดไปคืออะไรเหรอ? ]

[ ก็…ไม่แน่ใจเหมือนกันค่ะ ]

[ หา? ไหนบอกว่ายังมีงานอีกเยอะไง? ]

ผมหันไปมองเธออย่างสงสัย แต่เทียร่าซังกลับเบือนหน้าหนีอย่างไม่สบอารมณ์
