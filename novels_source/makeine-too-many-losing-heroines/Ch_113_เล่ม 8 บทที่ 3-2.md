เล่ม 8 บทที่ 3-2

เมื่อเสร็จธุระในห้องน้ำและกลับมาที่อัฒจันทร์หลักซึ่งมีที่นั่งผู้ชมอยู่ การแข่งขันรอบชิงชนะเลิศของวิ่ง 400 เมตรหญิงก็กำลังจะเริ่มขึ้น อีกยี่สิบนาทีจะถึงคิวของยากิชิโอะ…ทำไมรู้สึกตื่นเต้นแทนกันนะ…

ตอนกำลังจะเดินไปที่นั่ง มีใครบางคนโอบแขนจากด้านหลังมาที่บ่า

[ โย่, นุคุมิซึคุง ]

[ อ๋อ สวัสดีครับ ]

คนที่มาดักจับผมไว้ก็คือรุ่นพี่สึคิโนะกิ

ไม่สิ…เขาคงจงใจมาดักเราจริง ๆ แว่นตาของเขาเป็นประกายแวววับ

[ ได้ข่าวมานะ ว่าช่วงนี้ไปทำอะไรกับบาโซริจังมาล่ะสิ ]

[ เอ่อ…ก็แค่ช่วยหาเสียงเลือกตั้งนิดหน่อยน่ะครับ ]

[ งั้น ถ้าชนะเลือกตั้ง นายจะเข้าไปอยู่ในสภานักเรียนด้วยหรือไง ]

[ ไม่มีความคิดแบบนั้นหรอกครับ ]

ผมสลัดตัวออกจากแขนของรุ่นพี่สึคิโนะกิ

[ ตอนอยู่ปี2 รุ่นพี่เป็นรองประธานใช่มั้ยครับ? การเลือกตั้งเป็นยังไงบ้างเหรอครับ? ]

[ ลำบากสิ…ประธานน่ะ เป็นคนเหลาะแหละมาก ชวนฉันมาช่วยหาเสียงแท้ ๆ แต่ตัวเองกลับไม่ทำอะไรสักอย่าง ]

[ เห…งั้นรุ่นพี่เป็นคนเตรียมงานทุกอย่างเองเลยสินะครับ ]

รุ่นพี่สึคิโนะกิส่ายหน้า

[ เปล่าเลย ฉันก็ไม่ได้ทำอะไรเหมือนกัน นอกจากสุนทรพจน์ช่วยหาเสียงน่ะนะ ]

[ เอ๋? แค่นั้นก็ชนะได้เหรอครับ ]

[ ก็นั่นแหละ…หลังจากสุนทรพจน์วันนั้น ครูมารุมล้อมฉันด้วยแหละ…เป็นความทรงจำที่ไม่เลวเลย ]

…ไปก่อเรื่องอะไรมากันเนี่ย

ผมไม่กล้าถามต่อ แต่รุ่นพี่สึคิโนะกิยังคงพูดต่อด้วยแววตาเหม่อลอยเหมือนกำลังนึกถึงวันวาน

[ พอมาคิดดูแล้วก็ไม่เข้าใจจริง ๆ ว่าทำไมประธานถึงชวนฉัน เกรดก็ไม่ได้ดีอะไร ครูก็ไม่ได้เอ็นดูด้วย ]

[ ฮะ… ]

รุ่นพี่ไม่ได้พูดต่อ แต่หันไปมองสนามเงียบ ๆ

พอผมหันไปมองตาม เด็กผู้หญิงคนสุดท้ายในรอบชิง 400 เมตรก็เพิ่งวิ่งเข้าเส้นชัยพอดี

ในสนามเดียวกัน มีทั้งผู้ชนะและผู้แพ้

ผมมองภาพนั้นอย่างเหม่อลอย แล้วรุ่นพี่สึคิโนะกิก็พูดขึ้นมาเบา ๆ

[ หลังจากการเลือกตั้งจบแล้ว…นุคุมิซึคุงจะทำอะไรต่อล่ะ? ]

[ …หือ? ]

ผมก็พูดไปแล้วนะ ว่าไม่คิดจะเข้าร่วมสภานักเรียน…

แต่พอผมกำลังจะคิดถึงความหมายของคำถามนั้น รุ่นพี่สึคิโนะกิก็ยิ้มบาง ๆ

[ ขอโทษที่พูดอะไรแปลก ๆ กลับไปหาทุกคนกันเถอะ ]

[ อ๊ะ ครับ…ได้เวลาแล้วด้วย ]

ระหว่างที่เดินไปด้วยกัน รุ่นพี่สึคิโนะกิก็ยื่นมือมาขยี้หัวผมแรง ๆ อย่างไม่ทันตั้งตัว

[ อีะ เดี๋ยวสิครับ! อย่าทำแบบนั้นสิ! ]

[ นุคุมิซึคุงต่อจากนี้ต้องลำบากอีกเยอะ…สู้เขาล่ะ ]

…ตอนนี้ก็ลำบากพออยู่แล้วนะครับ

ผมทำหน้าเหมือนคนตาย ปล่อยให้เขาขยี้หัวต่อไปโดยไม่ขัดขืน

◇

การแข่งขันรอบชิงชนะเลิศวิ่ง 1500 เมตรหญิง โดยที่ยากิชิโอะยืนประจำอยู่เลนที่ 5

เมื่อเสียงประกาศเรียกชื่อดังก้องไปทั่วสนาม ยากิชิโอะยกมือข้างหนึ่งขึ้นทำความเคารพ ก่อนจะก้าวขึ้นสู่เส้นสตาร์ทด้วยบรรยากาศที่ดูเป็นผู้ใหญ่มากขึ้นกว่าวันที่เคยแข่งกับผม

พวกเรากลั้นหายใจรอช่วงเวลาเริ่มต้นของการแข่งขัน

ว่าไปแล้วนะ ข้างๆ ผมคือชิราทามะซัง กลิ่นหอมดีจัง… หรือว่าเปลี่ยนน้ำหอมใหม่อีกแล้ว?

ขณะกำลังเผลอคิดเรื่องนั้นอยู่ก็ได้ยินเสียงประกาศอันคุ้นเคย

── “ เข้าที่ “

นักกีฬาทุกคนโน้มตัวไปข้างหน้าเตรียมพร้อม แล้วในเสี้ยววินาทีต่อมา เสียงปืนสตาร์ทก็ดังขึ้น ยากิชิโอะพุ่งทะยานขึ้นนำทันที

จากแถวหน้าสุดของอัฒจันทร์ เสียงเชียร์ดังลั่นมาจากพวกชมรมกรีฑาของสึวะบุกิ

เสียงเชียร์ของพวกนั้นดังขึ้นอย่างตื่นเต้น ขณะที่โคมาริกำมือแน่นอยู่ที่หน้าอก มองดูการแข่งขันด้วยสายตาจริงจัง

ถึงจะเป็นห่วงอยู่บ้าง แต่ยากิชิโอะกลับเพิ่มความเร็วขึ้นไปอีก

วิ่งราวกับในสนามนี้มีแค่ตัวเองคนเดียว เหมือนไม่มีกลกลยุทธ์ ไม่มีการแย่งชิงตำแหน่ง แล้วก็ทิ้งห่างคู่แข่งออกไปเรื่อยๆ

── ฉันจะคว้าแชมป์ระดับประเทศให้ได้

วันนั้นในห้องพยาบาล ยากิชิโอะพูดแบบนั้นจริงๆ

ทั้งที่เป็นคนซุ่มซ่าม อ่อนไหวกว่าที่เห็น แต่ก็เลยยิ่งแข็งแกร่งกว่าใคร

เหลืออีกแค่หนึ่งรอบสุดท้าย ระยะห่างระหว่างอันดับหนึ่งกับอันดับสองยิ่งถ่างกว้างออกไป เหลือเพียงแค่เส้นชัยเท่านั้น

ผมลุกขึ้นยืนโดยไม่รู้ตัว แล้วตะโกนเรียกชื่อยากิชิโอะ

ทั้งที่ผลแพ้ชนะมันชัดเจนอยู่แล้ว แต่ไม่รู้ว่าทำไมถึงรู้สึกตื่นเต้นขนาดนี้

โคมาริก็ลุกขึ้นยืนข้างๆ กัน ร้องเชียร์ด้วยรอยยิ้ม

ยากิชิโอะวิ่งเข้าเส้นชัยโดยทิ้งห่างอันดับสองไปหลายวินาที เธอชูมือซ้ายขึ้นส่งสัญญาณไปยังอัฒจันทร์ แต่รู้สึกเหมือนยังไม่รู้สึกพอใจ

[ สะ…สะสะสะ! สำเร็จ ! สุดยอดมาก! ]

โคมาริผู้ตื่นเต้นกระโดดโลดเต้นพยายามจะโถมตัวมากอดผม แต่เปลี่ยนใจไปกอดยานามิแทน สองคนกอดกันกระโดดดึ๋งๆ ดีแล้วล่ะนะ…

ผมเลยยืนเก้อๆ ไม่รู้จะทำยังไงดี อยู่ๆ รุ่นพี่ทามากิก็ตบไหล่ผมเบาๆ

[ ถ้าไม่รังเกียจ ฉันก็มีอกให้ซบอยู่นะ ]

[ เอ่อ… เกรงใจครับ]

เราสองคนหัวเราะให้กันด้วยอารมณ์ประหลาด

[ สองคนคุยอะไรกันคะ? อกของฉันก็ว่างอยู่เหมือนกันนะคะ ]

ชิราทามะซังยืนกางแขนรออยู่ตรงหน้า

……จะดีเหรอเนี่ย?

ลังเลได้เสี้ยววินาที รุ่นพี่ซึคิโนะกิก็โผล่มาข้างหลัง ช้อนอุ้มชิราทามะซังขึ้นทั้งตัว

[ โอเค , เดี๋ยวพี่สาวปิดช่องว่างในหัวใจให้เอง ! ]

[ ว้าว ซึคิโนะกิซังแข็งแรงจัง! แล้วนี่จะพาไปไหนกันคะ? ]

……ชิราทามะซังโดนพาตัวไปซะแล้ว

สงสัยที่ผ่านมา ใครที่คิดจะแตะต้องรุ่นพี่ทามากิ คงโดนแบบนี้สินะ

ยังไม่ทันได้พักหายใจ เงาร่างเล็กๆ ก็วิ่งปราดเข้ามา

อาซากุโมะซังนั่นเอง หน้าผากของเธอเปล่งประกาย มือทั้งสองแกว่งไปมาแรงๆ

[ สุดยอดค่ะ! เลม่อนซังสุดยอดมาก! ]

[ อาซากุโมะซังก็มาดูด้วยเหรอ? ยากิชิโอะวิ่งได้สุดยอดเลยเนอะ ]

อาซากุโมะซังพยักหน้าเงียบๆ เหมือนพูดไม่ออก จากนั้นก็หมุนตัวกลับแล้ววิ่งจากไป

……เป็นคนอยู่ไม่สุขจริงๆ นั่นแหละ อ๊ะ ถ้าอาซากุโมะซังอยู่ ที่นั่นต้องมีอายาโนะ…

มองไปตามทางที่เธอวิ่งกลับไป เห็นอายาโนะยืนอยู่ เธอกำลังใช้ผ้าเช็ดหน้าซับน้ำตา

เข้าใจนะว่าตื้นตัน แต่ร้องต่อหน้าแฟนนี่มัน…

ในขณะที่ผมกำลังลุ้นแบบคนอื่นเขา ที่ลู่ก็เริ่มการแข่งขัน 1500 เมตรชายต่อ

วันนี้เหลืออีกไม่กี่รายการ นักกีฬาของสึวะบุกิก็หมดคิวแล้ว เหลือแค่รอพิธีมอบรางวัล

ผมนั่งกลับลงมาที่ม้านั่ง พยายามตั้งสติให้สงบ

ยากิชิโอะ—ยัยนั่นพูดแล้วทำจริง คว้าตั๋วสู่ระดับประเทศมาได้ขาดลอย

ที่บอกว่าจะคว้าแชมป์ประเทศ … มีแววเป็นจริงขึ้นมาแล้วล่ะ

[ เฮ้อ เลม่อนจังนี่วิ่งเร็วจริงนะー ]

ยานามิเดินมานั่งข้างๆ ผม พูดด้วยน้ำเสียงนิ่งๆ

[ เร็วกว่าธรรมดามากเลย ปีที่แล้วถ้าได้เวลาแบบนี้ ระดับประเทศก็คงมีลุ้นแล้ว ]

[ หืมー สมกับเป็นเลม่อนจังー ]

ยานามิโยนป๊อปคอร์นเข้าปากแล้วเคี้ยวตุ้ยๆ

[ แล้ว… ต้องชนะอีกกี่รอบถึงจะได้ไประดัยประเทศ? ]

……หือ? ยานามิดวงตาใสปิ๊งราวลูกแก้วเลย

[ เอ่อ… ที่จริงแข่งรอบนี้ก็คือรอบชิงระดับเขตแล้ว ชนะรอบนี้ก็ได้ไปประเทศเลย ]

[ เหー]

เธอเคี้ยวป๊อปคอร์นต่ออย่างไม่สะทกสะท้าน

[ หา? งั้นเมื่อกี้เป็นรอบชิงเหรอ!? เลม่อนจังเร็วจริงๆ เลย! ]

[ อะー ใช่ ยากิชิโอะเร็วจริงๆ นั่นแหละ ]

ผมพยักหน้ารับคำด้วยรอยยิ้ม ในฐานะคนคุมยานามิ

── การแข่งขันกรีฑามัธยมปลายโทไค รอบชิง 1500 เมตรหญิง

ยากิชิโอะ เลม่อน นักเรียนมัธยมปลายสึวาบุกิ ชั้นปี 2 ในวันนั้น เธอเข้าเส้นชัยเป็นอันดับหนึ่ง คว้าสิทธิ์ไปแข่งระดับประเทศได้สำเร็จ

◇

วันจันทร์ถัดมา หลังเลิกเรียน ความรู้สึกจากเมื่อวานยังคงเกาะติดในใจผม

ผมยืนมองโปสเตอร์เลือกตั้งของซากุไรคุงที่ติดอยู่บนทางเดินด้วยความรู้สึกแปลกๆ คล้ายลอยไปลอยมา

ซากุไรคุงยิ้มสดใสและยื่นมือข้างหนึ่งมาหาผม

มีนักเรียนหญิงบางคนกำลังถ่ายรูปโปสเตอร์ของซากุไรคุงอยู่… อย่างที่คิด เป็นที่นิยมจริงๆสินะ

ในกระดาษแสดงนโยบายที่ติดข้างๆ กัน มีหัวข้อเช่น “สภานักเรียนที่เปิดกว้าง” และ “ปฏิรูประบบชมรม” เรียงรายอยู่

…เดี๋ยวนะ ตรงท้ายๆ เหมือนจะเขียนอะไรแปลกๆ อยู่?

[ ฟุฟุ… นี่แหละ ชนะขาดแล้วนะ ]

เสียงแทรกขึ้นมาพร้อมกับการปัดผมอย่างมีจริตคือ ยานามิ

เธอเคาะกระดาษแสดงเจตจำนงด้วยสีหน้าภาคภูมิ

[ ข้อสุดท้ายในกระดาษนโยบาย ฉันเป็นคนคิดเองนะ ว่าไง? นุคุมิซึคุงก็อยากจะลงคะแนนแล้วใช่มั้ย ? ]

[ ที่ปลายนิ้วของยานามิ เขียนไว้ว่า “อัพเดทเมนูโรงอาหารบนโฮมเพจของสภานักเรียน! " ]

ดีแล้ว ที่ซากุไรคุงยังคงมีสติ

[ ยานามิซังไปโรงอาหารเหรอ? ปกติก็กินข้าวกล่องนี่ ]

[ คิดตื้นไปแล้วนุคุมิซึคุง ตื้นมาก ]

ยานามิซังหยิบขอบขนมปังออกมาจากกระเป๋า แล้วแกว่งไปมาอยู่ตรงหน้าผม

[ ฟังนะ ถ้ากินข้าวกล่องไปพร้อมกับดูเมนูโรงอาหาร… คิดว่าจะเกิดอะไรขึ้นล่ะ? ]

[ ก็ทำหกไง ยานามิซังก็ชอบทำหกนี่ ]

[ ไม่หกสักหน่อยนะ ? พอดูเมนูไปด้วย กินข้าวกล่องไปด้วย จะรู้สึกเหมือนกับได้กินอาหารชุดประจำวันของโรงอาหารด้วยไง ได้ความพึงพอใจสองมื้อในมื้อเดียว ถือเป็นสุดยอดวิธีไดเอ็ตเลยนะ! ]

ยานามิพูดด้วยสีหน้าภูมิใจ ก่อนจะกินขอบขนมปังเข้าไป

…ถึงเนื้อหาจะดูตลก แต่การกินแค่ชุดเดียวก็คงเป็นการไดเอ็ตสำหรับยานามิแน่นอน

ผมพยักหน้าเข้าใจ ก่อนจะละสายตาไปยังแผ่นแสดงนโยบายของ เทียร่าซัง ที่ติดอยู่ข้างๆ

มีหัวข้อจริงจัง เช่น “เพิ่มงบชมรม” และ “ทำให้กิจกรรมสภานักเรียนโปร่งใสมากขึ้น”

…ที่จริง การย่อข้อความต้นฉบับของเทียร่าซังให้ลงตัวกับจำนวนตัวอักษรที่กำหนดนี่ล่ะ ลำบากมาก โดยเฉพาะการเกลี้ยกล่อมเธอ

ในขณะที่กำลังรำลึกถึงความลำบากนั้น ยานามิก็เอาขอบขนมปังมาจิ้มแก้มผม

[ นี่ โปสเตอร์ของบาโซริซังล่ะ? ยังไม่ได้ทำเหรอ? ]

… จริงสิ แล้วโปสเตอร์ของเทียร่าซังเป็นยังไงกันนะ?

ผมหยิบสมาร์ทโฟนขึ้นมา ข้อความจากเทียร่าซังก็ขึ้นมาพอดี
