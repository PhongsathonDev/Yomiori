เล่ม 6 บทที่ 1-1

หลังจากกระแสวาเลนไทน์ผ่านพ้นไป ซูเปอร์มาร์เก็ตใกล้โรงเรียนก็เริ่มเก็บช็อกโกแลตที่ขายไม่หมดไปไว้ในโซนสำหรับไวท์เดย์

ระหว่างที่ผมเดินผ่าน กลิ่นหอมหวานของช็อกโกแลตก็ปลุกความทรงจำที่ยังสดใหม่ขึ้นมา

เสียงอิเล็กทรอนิกส์คุ้นเคยที่เปิดในพื้นหลังชวนให้นึกถึงอดีตที่ชวนคิดถึง

ขณะเดินเข็นรถอย่างสบาย ๆ สายตาผมก็สะดุดกับฮินะอาราเระในโซนของพิเศษ

…ใช่แล้ว อาทิตย์หน้าคือวันฮินะมัตสึริ

ที่บ้านเรามีตุ๊กตาฮินะอยู่ แต่คาจูเคยยืนกรานว่า "นี่เป็นตัวแทนท่านพี่กับหนู" ตั้งแต่เรายังเป็นเด็ก เล่นเอาผู้ใหญ่ปวดหัวกันเลยทีเดียว

[ อ้อ นี่ไง ]

แทนที่จะหยิบฮินะอาราเระ ผมเลือกขนมแบบดั้งเดิมข้างๆแทน มันเป็นขนมที่ชวนให้คิดถึง เป็นโมจิสีชมพูเล็กๆ บรรจุในห่อแบนๆ

[ ขนมโปรดตั้งแต่เด็กๆใช่มั้ยล่ะ? จำได้ว่าเคยพยายามเสียบมันบนไม้จิ้มฟันให้ได้เยอะที่สุดด้วย ]

เด็กสาวที่หยิบของลงรถเข็นอย่างไม่คิดอะไรก็คือ ยานามิ อันนะ จากชมรมวรรณกรรม

[ ไม่เคยทำหรอก แค่สงสัยเพราะรุ่นพี่ชิกิยะทานอยู่เมื่อวันก่อน ]

[ …รุ่นพี่ชิกิยะ? ]

ยานามิไม่ตอบ แต่กลับจ้องเขม็งใส่ผม

[ นุคุมิซึคุง ช่วงนี้นายดูแปลกๆ ไปนะ ไม่คิดแบบนั้นเหรอ? ]

[ ไม่เลย หมายถึงแปลกยังไง? ]

ยานามิผลักรถเข็นอย่างไม่สบอารมณ์และเดินนำไป

[ หมายถึงว่า ‘นุ’ ใน ‘นุคุมิซึ’ คือ ‘นุ’ ที่หมายถึง ‘ล้ำหน้า’ ไงล่ะ ]

/* 抜け駆け (นุเคะกะเคะ) แปลว่า ล้ำหน้า,นำหน้า,ทำก่อนคนอื่น */

[ หา? ]

ผมตอบไปแบบไม่ได้ใส่ใจอะไร ยานามิส่งสายตาตำหนิมาให้

[ เราเป็นพันธมิตรคนไร้คู่รักด้วยกันไม่ใช่เหรอ? แต่พักนี้ดูเหมือนพวกนายจะจีบกันเกินไปนะ? ]

นี่เป็นเรื่องใหม่สำหรับผมเลยทีเดียว ระหว่างเลือกที่จะไม่มีคู่กับไม่มีคู่เพราะหาไม่ได้มันห่างกันเป็นคนละเรื่องเลยนะ

และช่วงหลังมานี้ ผมก็เริ่มรู้สึกว่ายานามิก็อยู่ฝั่งเดียวกันกับผมบนหุบเหวลึกนั้น

[ ถ้ากับรุ่นพี่ชิกิยะล่ะก็มันไม่ใช่อย่างที่คิดหรอก เอาล่ะ ไปซื้อของให้เสร็จแล้วกลับไปห้องชมรมกันเถอะ ]

จริงๆ แล้วยานามิกับผมออกมาซื้อขนมตามคำขอของรุ่นพี่สึกิโนะคิ

นานแล้วที่เราไม่ได้ยินข่าวจากเธอ คิดว่าเธออยากจะมาทักทายพวกเราบ้าง แต่ไม่เลย มันคือคำขอให้ซื้อของให้ต่างหาก

ยานามิก้มตัวลงมองในรถเข็น

[ เรามีทั้งมันฝรั่งทอด ช็อกโกแลต และน้ำผลไม้กับชา ครบหมดแล้วใช่มั้ย? ]

ผมเหลือบมองในรถเข็น

[ เราจำเป็นต้องมีบะหมี่ถ้วยเยอะขนาดนี้เลยเหรอ? เธอแค่ขอให้เราซื้อขนมกับน้ำผลไม้เท่านั้นเองนะ ]

[ อ้อ นุคุมิซึคุง เคยกินอาหารญี่ปุ่นฟูลคอร์สหรือไคเซกิบ้างมั้ย? ]

นี่เธอกำลังหาเรื่องผมอยู่หรือเปล่า?

...แต่เดี๋ยวก่อน หรือว่าที่บ้านยานามิบะหมี่ถ้วยถือว่าเป็นอาหารญี่ปุ่นแบบเป็นทางการกันนะ

ในขณะที่ผมลังเลด้วยความรู้สึกไม่สู้ดี ยานามิก็หยิบบะหมี่ถ้วยขึ้นมาพร้อมรอยยิ้ม

[ รู้มั้ยว่าที่ร้านอาหารแบบนั้นจะมีข้าวและซุปปิดท้ายมื้อ ? บะหมี่ถ้วยมีทั้งคาร์บและซุป เพราะงั้นมันเหมือนเรากินทั้งสองอย่างในครั้งเดียวเลย ]

เข้าใจแล้ว ผมพยักหน้าอย่างไร้อารมณ์

[ ได้ แต่เราไม่จำเป็นต้องมีเยอะขนาดนี้หรอก เอาของที่อยากกินมาใส่ในนี้ก็พอ ยานามิซัง ]

[ แน่นะ? คนอื่นอาจจะหิวก็ได้ ]

[ เราไม่หิวหรอก เอางบที่เหลือไปซื้อไทยากิจะดีกว่า ตรงนี้มีร้านขนมอยู่ด้วย ]

ดวงตาของยานามิเป็นประกายเมื่อได้ยินคำว่าไทยากิ

[ มีดังโงะด้วยใช่มั้ย? งั้นฉันขอเอาแค่บะหมี่ถ้วยอันนี้แล้วกัน! ]

สิ่งที่ยานามิถือขึ้นมาอย่างยิ้มแย้มคือบะหมี่ยากิโซบะ

[...แต่มันไม่มีซุปไม่ใช่เหรอ? นั่นไม่ขัดกับที่เธอพูดเรอะ? ]

[ ฉันก็แค่อยากกินเองน่ะ โอเคมั้ย? ]

ถ้าเธออยากกินก็ตามใจเถอะ

ขณะที่ผมยืนเข้าแถวที่แคชเชียร์ ยานามิก็กลับมาจากที่เอาบะหมี่ถ้วยไปเก็บและสะกิดผมเบาๆ ด้วยศอก

[ นี่ ทำไมรุ่นพี่สึกิโนะคิถึงส่งพวกเรามาซื้อของกันล่ะ? ]

[ เอ๋? บางทีอาจจะมีเรื่องดีเกิดขึ้นก็ได้นะ... ]

-นี่เป็นช่วงปลายเดือนกุมภาพันธ์ ฤดูการสอบเข้ามหาวิทยาลัยกำลังเข้าสู่ช่วงโค้งสุดท้าย

รุ่นพี่สึกิโนะคิสอบไม่ผ่านมาแล้วห้ามหาวิทยาลัย เหลืออีกแค่โอกาสเดียวเท่านั้น

จากที่ผมได้ยินมาจากโคมาริ ความหวังกับมหาวิทยาลัยสุดท้ายก็ดูจะน้อยนิดเหมือนกัน

จำได้ว่าวันนี้น่าจะเป็นวันที่ประกาศผลรอบสุดท้ายพอดี

เมื่อเห็นผมมีสีหน้าไม่ค่อยดี ยานามิก็พยักหน้าเห็นด้วย

[ ถ้าเธอผ่าน ก็คงได้อวดพวกเราไปแล้วล่ะใช่มั้ยล่ะ? นี่ไม่ใช่การฉลอง แต่เป็นการกินปลอบใจ แน่นอนแหละ ]

ผมอยากจะตอกกลับไป แต่ก็คิดหนักอยู่ชั่วขณะ

[...อ่า ใช่เลย แน่นอนแหละ ]

ผมพยักหน้า

พรุ่งนี้คือการเริ่มต้นของการเดินทางอันยาวไกลของรุ่นพี่สึกิโนะคิในฐานะโรนิน

เพราะงั้นวันนี้ใจดีกับเธอหน่อยแล้วกัน....
