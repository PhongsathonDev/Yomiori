บทที่ 8-ทานากะซังแห่งบ้านชิราทามะ

ที่อาคารเรียนหลังเลิกเรียน ผมจัดเนคไทให้เข้าที่หน้าห้องสภานักเรียน

......ข้างในมีวี่แววของคนอยู่

แค่มาส่งเอกสารก็คงไม่เป็นไรหรอก แต่ปัญหาคือใครอยู่ข้างในต่างหาก

ปัจจุบัน สมาชิกสภานักเรียนประกอบด้วย ประธานเทียร่าซัง รองประธานซากุไรคุง และเลขาฯชิราทามะซัง รวม 3 คน

ถ้าคนที่อยู่ข้างในมีแค่เทียร่าซังคนเดียว บรรยากาศมันจะแปลกๆ เพราะงั้นอยากเลี่ยงจังแฮะ

ขอร้องล่ะ กาชา SSR ซากุไร จงออกทีเถอะ......

[ ......ขออนุญาตครับ ]

เมื่อเปิดประตูห้องสภานักเรียน ก็พบนักเรียนหญิงคนหนึ่งยืนอยู่ ชิราทามะ ริโกะ นั่นเอง

SR---ชิราทามะซังดึงมือที่กำลังยื่นไปที่ชั้นหนังสือกลับมา แล้วส่งยิ้มหวานให้ผม น่ารักจัง

[ ประธาน~ มีธุระอะไรเหรอคะ? ]

[ เอ่อ คือเอาเอกสารรายงานบัญชีของเดือนก่อนมาส่งน่ะ ]

[ ว้า นึกว่ามาหาฉันซะอีกค่ะ ]

ชิราทามะซังก้าวกระโดดเข้ามาหาอย่างร่าเริง แล้วกุมมือผมไว้พร้อมกับเอกสาร

[ เอ้า พูดมาสิคะว่ามาหาฉัน ]

เฮ้ยๆ อย่ามาล้อรุ่นพี่เล่นสิ

แค่โดนจับมือแค่นี้ จะให้พูดแบบนั้นได้ยังไ──

[ ครับ มาหาครับ ]

?! ปากมันขยับไปเอง......เหรอ?

ในขณะที่กำลังสั่นกลัวกับพลังการยั่วยวนของชิราทามะซัง เธอก็เพิ่มแรงบีบมือขึ้น

[ งั้นประธานคะ สุดสัปดาห์นี้ มาเที่ยวบ้านของแฟนสาวสุดที่รักไหมคะ? ]

แฟนสาว? อ้อ จะว่าไปเรื่องโกหกที่ว่าคบกับผม ยังได้ไปต่อสินะ

ทำไมคนรอบตัวถึงชอบแกล้งทำเป็นมีแฟนกันจังนะ......

[ เอ่อ เรื่องนั้นน่ะ คิดว่ารีบแก้ความเข้าใจผิดจะดีกว่ามั้ย ]

[ แต่ว่า พี่สาวอยากเจอแฟนฉันน่ะสิคะ ]

เอ๊ะ พี่สาวชิราทามะอยากเจอผม? ไม่สิ ตอนนี้ต้องเรียกว่าทานากะซังแล้วสินะ

[ ขอโทษนะ แต่ไม่ไหวหรอก โกหกแบบนั้นไปตลอดไม่ได้หรอก พูดความจริงไปเถอะ ]

[ ถ้าฉันโสดขึ้นมา ก็จะอ้อนพี่ชายเหมือนเมื่อก่อนไม่ได้แล้วสิคะ คนที่บอกให้เล็งพี่ชายก็คือประธานไม่ใช่เหรอ? ]

[ นั่นมัน── ]

เมื่อเห็นผมพูดไม่ออก ชิราทามะซังก็ขยับตัวเข้ามาใกล้จนโบผูกผมแทบจะสัมผัสกัน

[ ──จะรับผิดชอบไหมคะ? ]

◇

......ทำไมถึงกลายเป็นแบบนี้ไปได้นะ

สามวันถัดมาเป็นวันอาทิตย์ ผมนั่งรถไฟสายอัตสึมิจากโรงเรียนสึวาบุกิมา 3 สถานี แล้วเดินต่ออีก 10 นาที มาอยู่ในย่านที่พักอาศัยที่ไม่คุ้นตา

[ เอ่อ ที่นี่สินะ......]

เมื่อละสายตาจากแผนที่ในสมาร์ทโฟน ตรงหน้าคือบ้านเดี่ยวสองชั้นที่ดูเก่าแต่ได้รับการดูแลอย่างดี ที่ป้ายชื่อเขียนว่า 『ชิราทามะ』 คงไม่ผิดที่แน่

ผมหยุดนิ้วที่กำลังจะกดกริ่งเอาไว้ในวินาทีสุดท้าย

──ครั้งนี้ ต้องมาเยือนในฐานะแฟนหนุ่มของชิราทามะซัง

ผมที่ไม่ค่อยรู้อะไรเกี่ยวกับตัวจริงของเธอเลย จะแสดงบทแฟนหนุ่มตบตาพี่สาวแท้ๆ ได้รึเปล่านะ

ถ้าเป็นในไลท์โนเวลหรือมังงะ คงเป็นสถานการณ์ที่โดนสงสัยแล้วถูกสั่งให้จูบพิสูจน์ต่อหน้า──อะไรทำนองนั้น ถ้าแพทเทิร์นนั้นผมเคยอ่านมาประมาณ 3 รอบได้

................

..................เอาเถอะ ไปสายตามนัดมันไม่ดีนี่นะ อื้ม

พอตั้งสติจะกดกริ่ง ก็มีเสียงทักมาจากด้านหลัง

[ โอ้ นุคุมิซึ มาตรงเวลาเลยนี่นา ]

[ อาจารย์?! ]

ไม่แปลกที่จะตกใจ เพราะอาจารย์อามานัตสึของเรายืนอยู่ตรงนั้น

อาจารย์อมานัตสึไม่สนใจผม แล้วกดกริ่งทันที

『ค่า รอสักครู่นะคะ』

เสียงที่ตอบกลับมาจากอินเตอร์โฟน เป็นเสียงผู้หญิงที่ฟังดูเซ็กซี่อย่างประหลาด

เสียงคุ้นๆ แฮะ ลางสังหรณ์ไม่ดีเลย......

คนที่โผล่หน้าออกมาจากประตูที่เปิดออกคือ──ครูห้องพยาบาลโรงเรียนสึวาบุกิ โคนุกิ ซาโยะ

อาจารย์โคนุกิขยิบตาให้แล้วคว้าแขนผมไว้

[ เชิญจ้ะ มิโนริกับริโกะจังกำลังรออยู่เลย ]

[ ทำไมอาจารย์ถึงมาอยู่ที่นี่ได้ครับ ]

[ นุคุมิซึ มาถึงขั้นนี้แล้วห้ามหนีนะเว้ย ]

ผมที่ตกอยู่ในสภาวะจำยอมกึ่งหนึ่ง ถูกอาจารย์ทั้งสองลากตัวเข้าไปในบ้านอย่างไม่ปรานี

ที่ที่ถูกพาไปคือห้องรับแขกของบ้านชิราทามะ ที่อีกฝั่งของโต๊ะเตี้ยในห้องแบบญี่ปุ่น──มีผู้หญิงสองคนนั่งอยู่

ทั้งสองคนที่นั่งอยู่ลุกขึ้นเมื่อเห็นผม

[ คาซึฮิโกะซัง ยินดีต้อนรับค่ะ! ]

คนหนึ่งคือแฟน(ปลอมๆ)ของผม ชิราทามะ ริโกะ และอีกคนคือ──

[ ยินดีต้อนรับจ้ะ นุคุมิซึคุง ขอบคุณที่ช่วยดูแลริโกะเสมอนะ ]

จาก ชิราทามะ มิโนริ ที่เปลี่ยนเป็น ทานากะ มิโนริ จับมือที่ยื่นมานั้นตอบกลับไปอย่างกล้าๆ กลัวๆ

◇

[ นี่จ้ะ คาซึฮิโกะซัง เชิญเลย ]

[ อ่า ขอบคุณครับ...... ]

ผมจิบชาเขียวที่ชิราทามะซังยกมาให้ พลางสังเกตท่าทีของเหล่าอาจารย์ที่นั่งเรียงกันอยู่ตรงหน้า

ตรงกลางคือพี่สาวริโกะ ทานากะ มิโนริ ขนาบข้างซ้ายขวาด้วยอาจารย์โคนุกิและอาจารย์อามานัตสึ

ในขณะที่กำลังหวาดกลัวกับความอึดอัด ชิราทามะซังที่นั่งข้างๆ ก็วางมือลงบนต้นขาของผมเบาๆ

[ ตื่นเต้นเหรอคะ? ]

[ ไม่หรอก ก็......]

เมื่อเห็นผมอึดอัด พี่สาวริโกะก็ยิ้มให้อย่างรู้สึกผิด

[ ขอโทษนะ ที่จู่ๆ ก็เรียกมา คงมีธุระสินะ ]

ไม่มีครับ

ในที่สุดก็เริ่มชินกับสถานการณ์ที่คุ้นเคย จึงวางถ้วยชาที่ถือค้างไว้ลง

[ เอ่อ วันนี้มีธุระอะไรเหรอครับ...... ทำไมถึงเรียกผมมาที่นี่ ]

[ เพราะเป็นแฟนคนแรกของริโกะ เลยอยากคุยด้วยสักครั้งน่ะ ]

[ พี่ตั้งหน้าตั้งตารอเจอคาซึฮิโกะซังมาตลอดเลยนะคะ ]

เมื่อน้องสาวช่วยเสริม พี่สาวริโกะก็ยิ้มออกมาอย่างเป็นกันเอง

[ ขอโทษริโกะด้วยนะ อุตส่าห์เป็นวันหยุดแท้ๆ ]

[ ไม่เป็นไรค่ะ ได้เดทที่บ้านกับคาซึฮิโกะซัง ถือว่ากำไรแล้วล่ะค่ะ ]

งั้นเหรอ นี่คือเดทที่บ้านสินะ ถ้าคบกับชิราทามะซัง ก็จะได้เดทที่บ้านแบบนี้สินะ......งั้นเหรอ......

ขณะที่กำลังจิบชาอีกครั้ง พี่สาวริโกะก็พูดเรื่องนี้ขึ้นมา

[ นี่ นุคุมิซึคุง ชอบริโกะตรงไหนเหรอ? ]

[ เอ๊ะ ]

ถามถึงส่วนที่ชอบของคนที่ไม่ใช่แฟนเนี่ยนะ......?

ชิราทามะซังมองผมเหมือนนึกสนุก ส่วนเหล่าอาจารย์สึวาบุกิก็นั่งรอฟังคำตอบด้วยสีหน้าเหมือนกำลังประเมินราคา จะพูดอะไรมั่วซั่วไม่ได้เด็ดขาด

[ เอ่อ ก็ใจดี...... เป็นแม่ศรีเรือน...... แล้วก็......]

อึก สายตาทั้ง 4 คู่ทิ่มแทงมาที่ผม

[ ช่วยเก็บยางลบให้......แล้วก็เป็นคนที่น่าเป็นห่วงจนละสายตาไม่ได้มั้งครับ ]

พอพูดจบ ผมก็แอบมองดูท่าทีของพี่สาวริโกะ

......วันนี้เพิ่งได้เห็นหน้าชัดๆ เป็นครั้งแรก หน้าตาสะสวยคล้ายกับชิราทามะซังมาก

ผมยาวกว่าน้องสาวนิดหน่อย ความสวยที่ผสมผสานระหว่างความเป็นผู้ใหญ่กับความไร้เดียงสา เวลาอยู่หน้าชั้นเรียนคงโดดเด่นมากแน่ๆ ถ้าไม่ได้เกี่ยวข้องอะไรกัน ก็อยากขอให้มาเปลี่ยนเป็นครูประจำชั้นอยู่หรอก

พี่สาวริโกะหันไปมองน้องสาวด้วยสายตานึกสนุก

[ หุหุ งั้นเหรอ ริโกะ รู้สึกยังไงบ้างจ๊ะ? ]

[ อื้ม อยากได้ยินอีกจัง~ ยังไหวใช่มั้ยคะ คาซึฮิโกะซัง? ]

เอ๊ะ จะให้โกหกเพิ่มอีกเหรอ

อาจารย์อามานัตสึส่งสายตาจ้องเขม็งมา ส่วนอาจารย์โคนุกิก็ขยิบตาให้ทำไมไม่รู้ อึดอัดชะมัด อึดอัดมากๆ

──สุดท้าย กว่าจะถูกปล่อยตัว ฉันต้องยกข้อดีเพิ่มอีก 10 ข้อ พอสองพี่น้องลุกไปเตรียมกาแฟ ผมก็ฟุบลงกับโต๊ะอย่างหมดแรง

[ ......เฮ้ย นุคุมิซึ ]

[ ครับ มีอะไรครับ ]

พอเงยหน้าขึ้น อาจารย์อามานัตสึที่เท้าคางอยู่ก็โบกมือพั่บๆ

[ แกกับบาโซริห้อง F เป็นอะไรกัน? ]

[ เปล่าครับ...... ก็แค่เพื่อน ]

[ โห เข้าไปในบ้านเพื่อนงั้นเหรอ? อีกฝ่ายเป็นผู้หญิงนะเห้ย? ]

ถ้าจะพูดแบบนั้น ช่วยจัดการเรื่องที่ห้องผมกลายเป็นพื้นที่สาธารณะทีเถอะ พวกนั้นถือวิสาสะบุ๊กมาร์กเว็บในเบราว์เซอร์คอมผมด้วยซ้ำ

พอตอบแบบคลุมเครือ อาจารย์โคนุกิก็แทรกขึ้นมา

[ แหม ถึงไม่ได้คบกัน ก็ใช่ว่าจะเข้าห้องไม่ได้ซะหน่อย ยิ่งเป็นแบบนั้นความรู้สึกผิดศีลธรรมยิ่งเร้าใจไม่ใช่เหรอ ]

ขอบคุณที่ช่วยแก้ต่างครับ แต่ถ้าเป็นไปได้ช่วยเลี่ยงคำพูดที่ชวนให้เข้าใจผิดทีเถอะครับ

อาจารย์อามานัตสึหันไปค้อนอาจารย์โคนุกิ ก่อนจะหันกลับมาทางผมอีกครั้ง

[ แล้วกับยากิชิโอะล่ะ เป็นไงบ้าง เรื่องที่โรงเก็บของพละเมื่อปีก่อนยังจำได้ใช่มั้ย ]

แน่นอน สัมผัสนั้น──ไม่ใช่สิ วิกฤตการณ์ถึงชีวิตนั้นใครจะลืมลง

[ เอ่อ อันนั้นเข้าใจผิดกันไปใหญ่แล้วครับ เดิมทีผมกับยากิชิโอะไม่ได้เป็นอะไรกันสักหน่อย ]

[ แบบนั้นก็ดีไม่ใช่เหรอ เพราะไม่ได้เป็นอะไรกัน ไฟรักถึงได้โชติช่วงไงล่ะ ]

อาจารย์โคนุกิ ช่วยเงียบปากหน่อยได้ไหมครับ

สีหน้าของอาจารย์อามานัตสึเริ่มบึ้งตึงขึ้นเรื่อยๆ ผมไม่ผิดแท้ๆ

[ นี่ นุคุมิซึ ถ้าคบกันแล้วเลิกกัน หรือไปคบคนอื่นก็อาจจะมีบ้างแหละนะ แต่ไอ้การเปลี่ยนผู้หญิงรอบตัวไปเรื่อยเนี่ย ฉันว่ามันยังไงอยู่นา? ]

[ ผมไม่ได้ทำแบบนั้นนะครับ ]

......ทำไมถึงโดนเข้าใจผิดแบบนั้นได้นะ

จริงอยู่ที่ฤดูร้อนปีก่อน มีคนเห็นผมกอดกับยากิชิโอะสภาพกึ่งเปลือยในโรงเก็บของพละ แล้วเรื่องที่ไปบ้านเทียร่าซังก็โดนแฉ แถมยังโกหกว่าคบกับชิราทามะซังอีก
