วันที่ 6 มิถุนายน──วันเกิดของคาจูที่คนทั้งโลกควรจารึกไว้

ผมลอบมาที่บ้านยากิชิโอะโดยไม่ให้คาจูรู้ตัว

เพื่อหลีกเลี่ยงความบาดหมางโดยไร้สาเหตุ การทำเค้กจึงย้ายมาทำที่บ้านของยากิชิโอะ

บ้านยากิชิโอะอยู่ในระยะเดินเท้าจากบ้านผม จึงเหมาะที่จะเป็นสถานที่จัดงาน ยิ่งไป

กว่านั้น──

[ นุคุมิซึคุง เชิญจ้ะ! ไม่ต้องเกรงใจ เข้ามาเลยๆ ]

[ ขอโทษที่รบกวนกะทันหันนะครับ ]

คุณแม่ของยากิชิโอะตกลงที่จะช่วยสอนวิธีทำให้ ดีใจจังเลย

ในห้องนั่งเล่นของบ้านยากิชิโอะที่ถูกพาเข้ามามีกลิ่นธูปลอยอบอวล และในห้องครัวก็มีอุปกรณ์ทำอาหารวางเรียงราย

พอวางวัตถุดิบที่ซื้อมาไว้บนเคาน์เตอร์ คุณแม่ของยากิชิโอก็ยื่นผ้าพับไว้ให้ผม

[ อะ นี่จ้ะ ใช้ผ้ากันเปื้อนผืนนี้นะ ]

[ขอบคุณครับ ......จะว่าไปเลม่อนซังล่ะครับ? ]

มองไปรอบๆ แต่ไม่เห็นเงาของยากิชิโอในห้องนั่งเล่น

คุณแม่ของยากิชิโอะสวมผ้ากันเปื้อนให้ตัวเอง แล้วพูดอย่างไม่ยี่หระ

[ เลม่อนไปชมรมจ้ะ เด็กคนนั้น ใกล้จะแข่งแล้วเลยเครื่องติดน่าดู]

[เห]

งั้นในบ้านนี้ก็มีแค่ผมกับแม่ของยากิชิโอะสองคน? เดี๋ยวสิ ถ้ามีศักดิ์เป็นภรรยา งั้นสามีก็น่าจะอยู่ที่ไหนสัก──

[สามีไปทำงานต่างจังหวัดจ้ะ ไม่ต้องเกรงใจนะ]

[อ๊ะ ครับ!]

สามีไปทำงานต่างจังหวัด──ลูกสาวไปชมรม──ภรรยาที่มีเจ้าของแล้วของที่ดูยังสาวและสวย────

อะไรกันพล็อตที่เคยเห็นในการ์ตูนที่ไหนสักเรื่อง แน่นอนว่าคงไม่มีเรื่องแปลกๆ เกิดขึ้นหรอก แต่คุณแม่ของยากิชิโอะนี่จะว่ายังไงดี──พออยู่ใกล้ๆ แล้วรู้สึกใจคอไม่ดี

ชอบกล ใจคอไม่ดีเลย

ขณะที่กำลังใส่ผ้ากันเปื้อนด้วยความประหม่า คุณแม่ของยากิชิโอะก็อ้อมมาข้างหลังแล้วผูกเชือกให้

[เอ่อ ผมทำเองได้ครับ]

[ไม่เป็นไรน่า บ้านเรามีแต่ผู้หญิง มีเด็กผู้ชายมาหาแบบนี้สนุกดีออก]

ครับ ผมเองก็สนุกครับ

......ไม่ใช่สิ ไม่ใช่เวลามาสนุกกับแม่เพื่อนนะ

จุดประสงค์วันนี้คือมาทำเค้กวันเกิดให้คาจู ไม่ได้มานัดพบลับๆ กับภรรยาชาวบ้าน

ระหว่างที่กำลังปั้นหน้าเคร่งขรึมด้วยพลังใจอันยอดเยี่ยม

──กริ๊ก ประตูห้องนั่งเล่นเปิดออก

เด็กผู้หญิงใส่แว่นตาในชุดนอนเดินขยี้ตาเข้ามา คนที่ลากตุ๊กตากระต่ายตัวใหญ่จนย้วยมาด้วยก็คือ ยากิอิโมะจังหรือ ยากิชิโอะ นางิจัง นั่นเอง

<tl: ยากิอิโมะโตะจัง หรือก็คือ คุณน้องสาวยากิ>

คุณแม่ยากิชิโอะตกใจผละออกจากผม

[ นางิ ลูกยังไม่เปลี่ยนชุดอีกเหรอ?]

[ อือ......เมื่อวาน อ่านหนังสือจนดึกเลยตื่นสายอะ]

เธอเดินเตาะแตะไปที่ตู้เย็น หยิบนมออกมาแล้วนั่งลงที่โต๊ะ

ยากิอิโมะจังที่ดื่มนมดังอึกๆ ทั้งที่ยังงัวเงีย สักพักคงสังเกตเห็นผม ก็เลยหยุดกึก ทันใดนั้น

พรวด! พ่นนมออกมาอย่างอลังการ

คุณแม่ยากิชิโอะรีบวิ่งเข้าไปหาลูกสาวที่กำลังสำลัก ดูเหมือนผมจะทำเรื่องแย่ๆ ลงไปซะแล้ว......

ผมผูกเชือกผ้ากันเปื้อนให้แน่น พลางหลบสายตาจากยากิอิโมะจังที่ไอจนน้ำตาเล็ด

◇

การทำเค้กเริ่มขึ้นภายใต้การแนะนำของคุณแม่ยากิชิโอะ

ขณะร่อนแป้งเค้ก ผมเหลือบมองบรรยากาศในห้องนั่งเล่น เห็นยากิอิโมะจังที่เปลี่ยนเสื้อผ้าแล้วกำลังจ้องผมเขม็ง

......รู้สึกไม่สงบเลยแฮะ

ถึงจะไม่ได้ทำเรื่องไม่ดีไม่งามก็เถอะ แต่จะบอกว่าไม่ได้คิดเลยก็คงพูดได้ไม่เต็มปาก เด็กม.ปลายปี 2 ก็อยู่ในวัยที่ละเอียดอ่อนแบบนั้นแหละ

ระหว่างที่แก้ต่างให้ตัวเองและทำงานไปเรื่อยๆ เสียงกริ่งหน้าบ้านก็ดังขึ้น

ราวกับรอจังหวะที่คุณแม่ยากิชิโอะเดินออกจากห้องนั่งเล่นไป ยากิอิโมะจังก็เปิดปากพูด

[เอ่อ คุณเป็นอะไรกับพี่สาวคะ]

......หือ? หมายความว่าไง?

พยายามอ่านเจตนาจากสีหน้า แต่ดวงตาภายใต้กรอบแว่นนั้นเต็มไปด้วยความระแวดระวัง

[ เอ่อ ก็อยู่ชมรมวรรณกรรมเหมือนกัน......ก็เป็นความสัมพันธ์ประมาณนั้นแหละ]

พอตอบแบบกลางๆ ไป ยากิอิโมะจังก็ทำแว่นตาสะท้อนแสงวูบ

[ ที่ผ่านมาพี่สาว ไม่เคยพาผู้ชายชมรมกรีฑามาที่บ้านเลยนะคะ]

[อา]

ก็แหงสิ มีคนที่ชอบอยู่แล้ว จะพาผู้ชายคนอื่นเข้าบ้านได้ไง

[ แค่เป็นคนในชมรมเดียวกัน จริงๆ เหรอคะ?]

[ อา จริงครับ]

แม้ผมจะตอบด้วยความจริงใจ แต่ยากิอิโมะจังก็ยังนิ่งเงียบจ้องเขม็งมาที่ผม

เอ๋......ผม พูดอะไรแปลกๆ ไปรึเปล่านะ

ท่ามกลางบรรยากาศน่าอึดอัด ประตูห้องนั่งเล่นก็เปิดออก

[──นึกว่าเป็นพี่สาวของรุ่นพี่ยากิชิโอซะอีกค่ะ]

[ต๊ายตาย เป็นแม่ของเลม่อนจ้ะ แม่!]

คนที่เดินเข้ามาในห้องนั่งเล่นอย่างอารมณ์ดีคือคุณแม่ยากิชิโอะ และคนที่อยู่ข้างหลังนั้นคือ──ชิราทามะซังกับยานามิ สองคนนั้นเอง ทำไมถึงมาอยู่ที่นี่ได้

ยานามิยิ้มกริ่มอย่างเจ้าเล่ห์ใส่ผมที่กำลังตกใจ

[ นุคุมิซึคุง มาเป็นผู้ช่วยให้แล้วนะ ]

──ไม่ได้ต้องการครับ ผมคิดว่าตัวเองเก่งมากที่กลืนคำพูดนั้นลงคอไปได้

ยานามิผูกเชือกผ้ากันเปื้อนพลางเอาไหล่มาชนผม

[ ทำไมถึงเงียบจังล่ะ? ถ้าดีใจก็พูดออกมาตรงๆ สิ ]

[ ที่จะทำต่อจากนี้คือเค้กวันเกิดไม่มีส่วนของยานามิซังหรอกนะ? ]

[ ก็แหงสิ ส่วนของตัวเองฉันเอามาเองเรียบร้อยแล้ว ]

สิ่งที่ยานามิหยิบออกมาคือขนมปังแผ่น

......ขนมปังแผ่น? เอ่อ ส่วนของยานามิคือขนมปังแผ่นหมายความว่า

[ หรือว่าบ้านยานามิซัง ปักเทียนบนขนมปังแผ่นในวันเกิดเหรอ?]

[ ก็ต้องไม่อยู่แล้วสิ  นุคุมิซึคุงมองบ้านฉันเป็นแบบไหนกันเนี่ย ]

ยานามิยักไหล่เหมือนจะบอกว่าช่วยไม่ได้นะ

[ นี่นะ ครีมสดมักจะเหลือติดชามหรือจานใช่ไหมล่ะ? พอเป็นเด็กม.ปลายแล้ว จะให้เลียก็กะไรอยู่ ก็เลยเอาขนมปังมาปาดครีมสดที่เหลือแล้วกินไงล่ะ ]

[ เข้าใจแล้ว แต่ทำไมถึงกินขนมปังไปแล้วล่ะ  ]

[ มันเป็นแบบหั่น 6 แผ่น กินสักแผ่นก็ไม่เป็นไรหรอก ชิราทามะจังจะกินด้วยไหม? ]

ชิราทามะซังที่สวมผ้ากันเปื้อนระบายลูกไม้น่ารักส่ายหน้า

[ ไม่เป็นไรค่ะ กินข้าวเช้ามาแล้ว ]

[ ฉันก็กินมาแล้วนะ? ]

ระหว่างที่ปล่อยยานามิไว้กับชิราทามะซังแล้วทิ้งระยะห่างออกมา คุณแม่ยากิชิโอะก็มายืนข้างๆ ด้วยรอยยิ้ม

[ แหมๆ นุคุมิซึคุงเนื้อหอมจังนะ ]

[ เปล่าครับ โดนล้อเล่นตลอดเลยครับ ]

อ้าว? คุณแม่ยากิชิโอะ ตาไม่ได้ยิ้มด้วยแฮะ คิดไปเองมั้ง......

ระหว่างทำโน่นทำนี่ การทำเค้กที่มีผู้ช่วยเพิ่มมาสองคนก็เริ่มขึ้นอีกครั้ง

ยานามิล้วงมือเข้าไปในถุงใส่วัตถุดิบ แล้วควานหาของข้างใน

[ นุคุมิซึคุง เนยอยู่ไหน?」 ]

[ จะกินเหรอ? ]

[ ไม่กินย่ะ จะชั่งตวงวัตถุดิบต่างหาก ]

ยังไงก็คงกินอยู่ดี ช่วยนับส่วนที่ลงท้องเข้าไปคำนวณด้วยแล้วกัน

[ เอ่อ ถ้าจำไม่ผิดอยู่ในถุงนั้น── ]

พอจะหาเนย ชิราทามะซังก็ยื่นห่อของมาจากด้านข้าง

[ ถ้าไม่รังเกียจ ใช้เจ้านี่ไหมคะ? พอดีที่บ้านมีเนยอร่อยๆ อยู่ ก็เลยเอามาด้วยค่ะ  ]

คุณแม่ยากิชิโอเห็นดังนั้นก็ทำหน้าตกใจ

[ อุ๊ย เนยเอชิเร่นี่นา เอามาใช้ได้เหรอจ๊ะ? ]

[ ค่ะ ใช้ได้เต็มที่เลยค่ะ เพราะเป็นวันเกิดของคาจูซังสุดที่รักนี่คะ ]

ไม่รู้ทำไมชิราทามะซังถึงพูดพลางมองมาที่ผม

ถ้ารักคาจูขนาดนั้น ก็ช่วยญาติดีกันให้มากกว่านี้หน่อยเถอะครับ
