เล่ม4 บทที่3-1

วันที่ 21 ธันวาคม เช้าวันจันทร์

ท้องฟ้าแจ่มใส ราวกับว่าฝนที่ตกเมื่อวานเป็นเพียงความฝัน

ถึงผมจะมาถึงโรงเรียนก่อนเวลาหนึ่งชั่วโมง แต่โรงเรียนก็เปิดแล้ว

ไม่ใช่แค่ชมรมกีฬาเท่านั้นที่มาเช้าขนาดนี้

มีเสียงเครื่องดนตรีดังมาจากห้องดนตรี ชมรมออร์เคสตรากำลังเตรียมตัวสำหรับการแข่งขัน

ผมเดินเข้าไปในอาคารฝั่งตะวันตกขณะฟังเสียงเพลง ไฟในห้องศิลปะที่เงียบสงบก็เปิดอยู่

มีทั้งนักเรียนและครูอยู่ในนั้น

ห้องชมรมวรรณกรรมอยู่ที่ปลายสุดของอาคารฝั่งตะวันตก ผมหาวและเช็คเวลาบนนาฬิกา

ปกติ เวลานี้คาจูคงจะโดนไล่ออกจากห้องผมเพราะพยายามจะเปลี่ยนเสื้อให้ผม

มีคนอยู่ในห้องชมรม ผมตัดสินใจเปิดประตู

[ อรุณสวัสดิ์ นุกุมิซึ ไม่ได้เจอกันนานเลยนะ ]

คนที่เงยหน้าขึ้นจากหนังสืออ้างอิงเคมีด้วยความง่วงก็คืออดีตประธานชมรม ทามากิ ชินทาโร่

เขาเป็นนักเรียนเตรียมสอบเข้ามหาวิทยาลัยและเป็นแฟนของรุ่นพี่สึกิโนะคิ

[ ฉันได้ยินจากโคโตะเมื่อวาน ขอโทษด้วยนะ ]

รุ่นพี่ทามากิพูดพร้อมกับยิ้มอย่างขมขื่น ผมก็ยิ้มกลับไปแบบเดียวกัน

[ ขอโทษ ที่ไม่ได้บอกก่อนหน้านี้ ผมควรจะบอกให้เร็วกว่านี้ ]

ผมบอกเขาไปเมื่อวานว่าผมอยากคุยกับเขา เพราะงั้นเขาจึงตัดสินใจว่าเราควรเจอกันที่ห้องชมรมตอนเช้า

บางทีรุ่นพี่ทามากิอาจจะรู้ว่าเกิดอะไรขึ้นระหว่างรุ่นพี่สึกิโนะคิกับชิกิยะซังในอดีต

[ โคโตะไม่ให้เธอบอกใครใช่มั้ย? ทำไมยืนอยู่แบบนั้นล่ะ มานั่งสิ ]

ผมนั่งลงบนเก้าอี้ตรงหน้าเขา

[ ช่วงนี้ฉันก็ยุ่งกับเรื่องของตัวเองอยู่เหมือนกัน ]

รุ่นพี่ทามากิมองหนังสืออ้างอิงของเขาอีกครั้ง เขาดึงโพสต์อิทออกแล้วแปะลงบนหน้าหนังสือ

[ ได้ยินว่ารุ่นพี่จะย้ายไปเรียนสาขาวิทยาศาสตร์นี่ มีเวลาเตรียมตัวสอบพอมั้ยครับ ? ]

— ย้ายไปเรียนสาขาวิทยาศาสตร์ แม้ว่าเขาจะเรียนอยู่ในสายศิลป์ในชั้นมัธยมปลาย แต่เขากำลังจะเรียนสาขาวิทยาศาสตร์ในมหาวิทยาลัย

การเปลี่ยนใจในเทอมสองของปีสามคงไม่ใช่เรื่องง่าย นอกจากนี้ มหาวิทยาลัยแห่งชาติที่เขาตั้งเป้าหมายไว้นั้นขึ้นชื่อว่าเป็นที่ที่สอบเข้ายากที่สุดในจังหวัด

[ ฉันยังได้เกรด A ในการสอบจำลองเมื่อไม่กี่วันที่ผ่านมาอยู่ มหาวิทยาลัยแห่งชาตินั่นเป็นตัวเลือกแรกของฉันมาตลอด บางที มันอาจจะแย่กว่านี้ก็ได้ ]

[ สุดยอดไปเลย แล้วรุ่นพี่สึกิโนะคิล่ะ? ]

รุ่นพี่ทามากิยิ้มออกมาอย่างขมขื่นแฝงด้วยความกังวลเล็กน้อย

[ อาจจะเป็นมหาวิทยาลัยเอกชนในนาโกย่า เธอสมัครทุกสาขาที่สนใจ แต่คะแนนสอบจำลองของเธอ...เฮ้อ จะว่าไปก็กลาง ๆ ล่ะนะ ]

ไม่ว่าผลลัพธ์จะเป็นอย่างไร แต่ทั้งสองจะต้องเดินไปตามเส้นทางที่แตกต่างกันในฤดูใบไม้ผลินี้

ไม่ใช่แค่รุ่นพี่สึกิโนะคิเท่านั้น รุ่นพี่ทามากิเองก็คงกังวลเหมือนกัน

การเลิกราที่เกิดจากแผนอนาคตที่ต่างกันเป็นเรื่องที่เกิดขึ้นบ่อยๆ

[ ขอโทษจริง ๆ ที่พารุ่นพี่ออกมาในช่วงเวลายุ่งๆแบบนี้ ]

[ ฉันไม่โทษนุคุมิซึหรอก อย่ามาขอโทษฉันเลย ฉันจะคุยกับครูแล้วก็ประธานนักเรียนเอง ให้ฉันจัดการเรื่องโดจินชิที่ถูกยึดไว้เถอะนะ? ]

เขายิ้มให้เพื่อพยายามลดความกังวลของผม

แต่รุ่นพี่ก็ขมวดคิ้วทันทีเมื่อเห็นผมทำหน้าเคร่งเครียดขณะพยายามยิ้มตอบ

[ เป็นอะไรไป? มีอะไรอีกหรือเปล่า? ]

[ จริง ๆ แล้ว ครูหรือประธานนักเรียนเองก็ยังไม่รู้เรื่องของหนังสือเล่มนั้น คนเดียวที่มีความเกี่ยวข้องโดยตรงก็คือรองประธานน่ะ ]

ความงุนงงปรากฏขึ้นบนใบหน้าของรุ่นพี่ทามากิอย่างชัดเจน

[ รองประธานคือบาโซริซังปีหนึ่งใช่มั้ย? เด็กคนนั้นไปก่อเรื่องใหญ่ขนาดนี้ได้ยังไง? ]

[ ดูเหมือนว่าเธอจะมีความคิดเห็นเยอะมากต่อชมรมวรรณกรรม หรือจะพูดว่า ต่อรุ่นพี่สึกิโนะคิน่าจะตรงกว่า ]

ผมถอนหายใจเป็นครั้งแรกของเช้านี้

[ ...เธอบอกให้ผมร่วมมือด้วยตอนที่ผมพยายามเอาโดจินชิคืนมา เธอบอกว่าถ้าอยากได้หนังสือคืน จะต้องทำตามที่เธอบอก ]

[ ทำตามที่เธอบอก? นั่นมันคล้ายๆการขู่ชัด ๆเลยไม่ใช่เหรอ ? ]

มันไม่ได้แค่คล้าย ๆ หรอก มันเป็นการขู่แบบชัดเจนเลย

[ ใช่ ลองฟังนะ คำขู่นั้นคือ- ]

[ ...ที่นายจะพูดน่ะมันโอเคเหรอ? ]

ผมหยุดนิ่งไปครู่หนึ่งแล้วมองหน้ารุ่นพี่

[ -ให้ยุติความสัมพันธ์ระหว่างชิกิยะซังกับรุ่นพี่สึกิโนะคิ ]

หน้ารุ่นพี่กระตุกเมื่อได้ยินเช่นนั้น ผมรีบเข้าประชิดตัวเขาเมื่อเห็นว่าเขารับรู้แล้ว

[ เกิดอะไรขึ้นระหว่างสองคนนั้นครับ? ]

ผมถามออกไป รุ่นพี่ทามากิขมวดคิ้วแล้วครุ่นคิด

จากนั้นเขาก็ค่อย ๆ ส่ายหัวช้า ๆ

[ ...ขอโทษนะ ขอเวลาฉันคิดหน่อย ]

[ เข้าใจแล้ว ]

จริง ๆ แล้วมีอะไรเกิดขึ้นระหว่างสองคนนั้นมั้ย? ไม่สิ จากท่าทีคลุมเครือของรุ่นพี่ทามากิ-

ผมหยุดคิดและยิ้มแห้ง ๆ ตอนนี้ไม่ใช่เวลาที่จะสืบเรื่องนั้น

ตอนนี้ผมควรจะคิดถึงวิธีแก้ปัญหานี้

[ แต่ผมต้องการความช่วยเหลือจากรุ่นพี่นะ พอช่วยได้มั้ย? ]

[ ฉันไม่ว่าอะไรหรอก นายจะทำอะไรล่ะ? ]

[ สองคนนั้นน่าจะเป็นอย่างเดียวที่สามารถจบเรื่องนี้ได้ใช่มั้ย? พวกเขาต้องพบกันและพูดคุยกันให้จบ ]

รุ่นพี่ทามากิดูเหมือนหมดแรงหลังจากได้ยินแบบนั้น

[ นายคิดว่าพวกเขาจะเจอกันด้วยดีเหรอ? โดยเฉพาะโคโตะ ]

[ พวกเขาคงไม่หรอก โดยเฉพาะรุ่นพี่สึกิโนะคิ ]

อีกอย่าง สองคนนั้นเพิ่งจะทะเลาะกันเมื่อวานนี้

แต่ถ้าเราไม่ทำอะไรตอนนี้ หน้าต่างแห่งโอกาสนี้จะปิดตลอดไป

[ ถ้าความสัมพันธ์ของพวกเขาบิดเบี้ยวไปแล้ว พวกเขาจำเป็นต้องมีเหตุผลบางอย่าง เช่น เหตุการณ์พิเศษหรือศัตรูร่วมกัน อะไรก็ได้ เราจำเป็นต้องสร้างโอกาสขึ้นมา ]

[ ฉันเข้าใจว่านายกำลังจะพูดอะไร แต่จะทำอะไรล่ะ? ]

[ เอ่อ ให้ผมยืมนี่หน่อย ]

ผมหยิบยางลบจากกล่องดินสอของรุ่นพี่ทามากิและวางมันไว้ตรงกลางโต๊ะ

[ สมมติว่ารุ่นพี่ทามากิกำลังจะไปเจอกับรุ่นพี่สึกิโนะคิที่ไหนสักแห่ง และชิกิยะซังก็ต้องมาเจอในเวลาเดียวกัน ]

หลังจากนั้นผมก็ถอดฝาปากกาไฮไลต์ออกแล้ววางไว้ข้าง ๆ ยางลบ

[ เมื่อพวกเขาสังเกตเห็นกันและกัน คนที่พวกเขานัดเจอจะโทรมาบอกว่าจะมาสาย นั่นจะบังคับให้พวกเขารอด้วยกัน ]

[ หมายความว่าเราต้องโกหกเพื่อให้พวกเขาเจอกันเหรอ? ]

[ ไม่เชิง เราต้องทำให้พวกเขารู้ว่าพวกเขาถูกหลอก เราต้องกลายเป็นศัตรูร่วมกันของพวกเขา ]

[ จะลองก็ไม่เสียหาย.. ]

รุ่นพี่ทามากิแตะฝาปากกาที่ยืนอยู่ข้าง ๆ ยางลบ

ฝาปากกาหมุนวนไปมาแล้วกลับมาที่ตำแหน่งเดิม

[ แต่เราทำได้แค่หวังว่ามันจะได้ผล ]

[ มันก็ถือว่าเป็นการ 'ยุติ' ได้แล้วถ้ามีใครหนีออกจากสถานการณ์นั้น ]

บางทีการฟื้นฟูความสัมพันธ์ของพวกเขาเป็นเพียงหนึ่งในผลลัพธ์ มันไม่จำเป็นต้องเป็นผลลัพธ์ที่ถูกต้อง

คำขอจากเทียระซังคือการ 'ยุติ' ความสัมพันธ์ของพวกเขา

[ เอาล่ะ ตอนนี้ปัญหาคือเราจะนัดสองคนนั้นออกมายังไง? ]

รุ่นพี่หยิบโทรศัพท์ออกมาแล้วมองที่หน้าจอ

[ วันคริสต์มาสอีฟคือวันพฤหัสใช่มั้ย? ฉันมีแผนจะไปเจอกับโคโตะที่งานแสดงไฟหน้าสถานี เราจะไปกินข้าวเย็นกันหลังจากนั้น ]

คริสต์มาส งานแสดงไฟนีออนประดับหน้าสถานี

[ นี่เป็นการแก้แค้นของรุ่นพี่จากปีที่แล้วหรือเปล่า? ]

พวกเขายังไม่ได้คบกันในคริสต์มาสปีที่แล้ว

รุ่นพี่ทามากิพลาดโอกาสสุดพิเศษใต้แสงไฟนีออนไป

หลังจากความผิดพลาดมากมาย พวกเขาก็กลายเป็นคู่รักกันในที่สุด แต่หลายอย่างก็เกิดขึ้นมากมาย ใช่ หลายอย่างเลย

[ งั้น ทำไมนายไม่บอกให้ชิกิยะซังไปที่นั่นด้วยล่ะ? นี่คงเป็น 'เหตุการณ์พิเศษ' ตามที่นุคุมิซึพูดใช่มั้ย? ]

[ แต่รุ่นพี่โอเคกับเรื่องนี้เหรอ? นี่เป็นคริสต์มาสแรกหลังจากคบกับเธอเลยนะ ]

[ ฉันรอจนถึงมื้อเย็นได้ นายรู้มั้ย? อีกอย่าง โคโตะกับฉันยังมีปีหน้าและอนาคตอีกไกล ]

รุ่นพี่ทามากิดูเหมือนจะลำบากใจเล็กน้อย เขายิ้มตามปกติ

[ ฉันไม่รู้ว่าชิกิยะซังกำลังคิดอะไรอยู่ แต่พวกเขาเคยมีความสัมพันธ์ที่ดีมาก จะจบกันแบบนี้มันดู... ]

[ ดูเศร้าไปหน่อย? ]

[ ไม่หรอก มันเหมือนกับ....ความรับผิดชอบมากกว่า ]

— ความรับผิดชอบเหรอ รุ่นพี่เริ่มเก็บของก่อนที่ผมจะถามอะไรได้อีก

[ 6 โมงเย็นวันพฤหัสบดี งานแสดงไฟหน้าสถานี โคโตะน่าจะถึงตอนนั้นพอดี จากนั้นนุคุมิซึจะโทรหาชิกิยะซัง ]

[ เข้าใจแล้ว ผมไม่ควรให้เธอรู้ว่ารุ่นพี่สึกิโนะคิอยู่ที่นั่น.. ]

รุ่นพี่ทามากิออกจากห้องไปแล้ว ผมยังคงนั่งอยู่ในห้องคิดถึงแผนนี้

ผมจะโทรหาชิกิยะซังให้ออกมาดูงานแสดงไฟนีออนหน้าสถานีในคืนวันที่ 24 สิ่งที่จะเกิดขึ้นต่อไปจะขึ้นอยู่กับวันนั้น

...เอ๊ะ? เดี๋ยวก่อน วันที่ 24 ธันวาคม ซึ่งก็คือ...

...ผมกำลังชวนชิกิยะซังมาใช้เวลาช่วงคริสต์มาสอีฟด้วยกัน?

◇

[ งั้น เจอกันนะ ฉันจะไปเรียนเสริมแล้ว ]

หลังเลิกเรียน ในห้องชมรม ยากิชิโอะไหล่ตกและเดินออกไปข้างนอก เหลือแค่โคมาริกับผมในห้อง

รู้สึกแย่นิดหน่อยที่เห็นยากิชิโอะเดินเข้าออกห้องชมรมหลังจากที่เธอถูกห้ามเข้าร่วมกิจกรรมของชมรมเพราะสอบตก อย่างไรก็ตาม พวกคนในชมรมวรรณกรรมก็มักจะนั่งเล่นอยู่เฉย ๆ ในห้องนี้อยู่แล้ว...

ผมคิดเรื่องนั้นพลางเปิดปฏิทินในโทรศัพท์
