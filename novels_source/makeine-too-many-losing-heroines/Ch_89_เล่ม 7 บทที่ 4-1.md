เล่ม 7 บทที่ 4-1

วันหยุดยาวในช่วง Golden Week ได้จบลงแล้ว และพวกเราสี่คน คือ ยานามิ ประธาน ชิราทามะซัง และผม มารวมตัวกันในห้องชมรมหลังเลิกเรียน อาซากุโมะซังยืนอยู่ข้างกระดานไวท์บอร์ด พร้อมหน้าผากที่เปล่งประกายจากความมุ่งมั่นในขณะที่พูดกับพวกเรา

[ แผนการสำหรับปฏิบัติการแก้แค้นครั้งใหญ่ของชิราทามะ ริโกะ เสร็จสมบูรณ์แล้ว การปฏิบัติการนี้แบ่งออกเป็นสองขั้นตอนหลัก ขั้นแรก- ]

เธอเขียนคำว่า "Phase 1" ด้วยตัวหนาบนกระดานไวท์บอร์ด

[ เป้าหมายของขั้นตอนที่ 1 คือการให้ริโกะปลอมตัวเป็นยานามิซังและแฝงตัวเข้าไปในสถานที่จัดงาน ]

ยานามิยกนิ้วโป้งขึ้น ขณะที่เคี้ยวกล้วยไป

แผนการควบคุมอาหารของเธอกำลังไปได้ดี และเธอก็ดูมีแรงจูงใจเต็มที่

[ อย่างไรก็ตาม ริโกะซังตัวจริงรู้จักจากพนักงานที่สถานที่จัดงานแล้ว ถึงจะปลอมตัวไปก็ยากสำหรับคนอื่น การแฝงตัวเข้าไปในงานเป็นไปได้ยาก ]

เธอขีดเขียน "8:30" บนกระดาน

[ ดังนั้น ริโกะซังตัวจริงจะเข้าไปในสถานที่จัดงานในชุดนักเรียนก่อน เพื่อสร้างการรับรู้กับพนักงาน หลังจากนั้นเธอจะสลับตัวกับยานามิซังที่ปลอมตัวไปแล้ว ริโกะซัง เข้าใจขั้นตอนนี้ใช่มั้ย? ]

ชิราทามะซังพยักหน้าหงอยๆขณะที่ดูดครีมถั่วแดงจากหลอด ขอโทษนะ เธอเข้าใจขั้นตอนจริงๆเหรอ?

แผนการเพิ่มน้ำหนักของเธอไม่ได้ผลเท่าที่ควร- ยานามิน่าจะเพิ่มน้ำหนักได้ 2 กิโลกรัมภายในพริบตา แต่สำหรับชิราทามะซังมันเป็นเรื่องที่ยาก เราเร่งเธอเกินไปไม่ได้ด้วย

[ สิ่งที่สำคัญที่สุดในปฏิบัติการนี้คือการป้องกันไม่ให้ใครรู้ว่า ริโกะซังตัวจริงอยู่ในชุดเจ้าสาว ถ้าเราทำให้พวกเขาคิดว่าเธออยู่ในชุดนักเรียน ถึงแม้จะมีใครเห็นเธอในชุดเจ้าสาว ก็จะไม่มีใครสงสัยว่าเป็นเธอ เพราะพวกเขาคิดว่า ยานามิซังที่ปลอมตัวเป็นริโกะซังก็ยังคงอยู่ในงาน ]

หลังจากที่แน่ใจว่าทุกคนเข้าใจแล้ว อาซากุโมะซังก็เริ่มเขียนบนกระดานอีกครั้ง

[ เมื่อการสลับตัวสำเร็จแล้ว เราก็จะเข้าสู่ขั้นตอนที่ 2 ]

เธอวงกลมคำว่า "Phase 2" ด้วยปากกาแดง

[ รุ่นพี่โฮโคบารุที่ปลอมตัวเป็นช่างภาพ และนุคุมิซึซังจะเข้าสถานที่จัดงาน งานของพวกเธอคือล่อความสนใจให้ได้มากที่สุด ขณะที่พวกเธอกำลังทำเช่นนั้น ยานามิซังในฐานะริโกะซังปลอม จะช่วยริโกะซังตัวจริง ซึ่งตอนนั้นจะอยู่ในชุดเจ้าสาว แล้วแอบเข้าไปในโบสถ์ ]

ยานามิพยักหน้าด้วยสีหน้าเคร่งขรึม ขณะที่ยังจ้องไปที่เปลือกกล้วยที่เธอกินเสร็จแล้ว

ส่วนชิราทามะซัง…..หน้าตาของเธอดูซีดๆไปหน่อย

[ พอริโกะซังสามารถแฝงตัวเข้าไปในโบสถ์ได้แล้ว ยานามิซังจะให้สัญญาณ จากนั้น รุ่นพี่โฮโคบารุกับนุคุมิซึซังก็จะพาทานากะเซ็นเซไปที่โบสถ์ โดยอ้างว่าเป็นการทดสอบกล้อง ]

อาซากุโมะซังปิดฝาปากกาด้วยเสียงดังแล้วยิ้มอย่างสดใส

[ ตอนนี้ สิ่งที่สำคัญที่สุดคืองานถ่ายภาพ นุคุมิซึซังต้องแน่ใจว่า ริโกะซังจะไม่อยู่ในสายตาของทานากะเซ็นเซ และ ต้องรับผิดชอบพาพวกเขาไป ]

[ เอ่อ แล้วจะทำยังไง ? ]

[ เราต้องเกี่ยวข้องกับคนจริงๆ เพราะงั้น ต้องปรับตัวให้เข้ากับสถานการณ์ ]

[ ปรับตัวให้เข้ากับสถานการณ์... ]

ผมกำลังจะโต้แย้ง แต่ก็เห็นอาซากุโมะซังวางกองกระดาษหนาๆ ลงบนโต๊ะ

[ ถ้าทำตามคู่มือเล่มนี้น่าจะทำออกมาได้ดีเลย ส่วนที่ต้องปรับตัวนั้นก็ขึ้นอยู่กับเล่มนี้ด้วย ]

เธอเปิดปกคู่มือ

[ โดยเฉพาะขั้นตอนที่ 2 ต้องทำให้เสร็จในเวลานิดเดียว ตั้งแต่ 9:30 ถึง 10:00 น. เรามีโอกาสแค่ครั้งเดียว ไม่มีการลองผิดลองถูก ]

ตารางเวลาอย่างละเอียดสำหรับวันนั้นถูกบันทึกไว้อย่างระมัดระวังในคู่มือ

ทานากะเซ็นเซจะมาถึงสถานที่จัดงานตอน 9:00 น. ประธานและผมในฐานะช่างภาพปลอมจะเข้าสถานที่ตอน 9:30 น. และเราจะต้องทำการถ่ายภาพให้เสร็จก่อน 10:00 น. และออกจากงานก่อนที่ช่างภาพตัวจริงจะมาถึง

[ ถ้ามีคำถามก็ถามได้เลยนะคะ ]

เหล่าสมาชิกแผนของอาซากุโมะซังแลกเปลี่ยนสายตากัน มีคำถามเยอะเลย แต่...เอาล่ะ เริ่มที่คำถามพื้นฐานกันก่อน

[ ตารางเวลาบอกว่าเวลารวมญาติคือ 10:30 น. ชิราทามะซังจะเข้าที่ 8:30 น. แล้วเขาจะให้เธอเข้าไปมั้ย ? ]

[ การที่แม่หรือพี่สาวของเจ้าสาวจะมาส่งเธอที่งานเป็นเรื่องธรรมดา เพราะงั้นไม่เป็นปัญหาอะไร เจ้าสาวจะเข้ามาเวลา 7:30 น. เพื่อเปลี่ยนชุดและแต่งหน้าทำผม ในช่วงนั้นเธอจะยุ่งจนไม่ได้มาหาชิราทามะซัง ]

อาซากุโมะซังเปิดคู่มืออีกครั้ง

[ การตกแต่งโบสถ์จะเสร็จประมาณ 9:00 น. หลังจากนั้นจะไม่มีคนเข้าออกโบสถ์มากนัก ]

อาซากุโมะซังดูมั่นใจมาก ด้วยเหตุผลบางอย่าง แต่ประธานดูเหมือนจะสงสัย

[ คำถามง่ายๆ แต่เธอรู้ข้อมูลได้ยังไง? ]

[ ในช่วงวันหยุดนี้ฉันได้ดูงานแต่งงานไปห้าครั้ง และโคมาริซังก็แอบเก็บข้อมูลมาเยอะมากด้วย ]

...โคมาริ? แต่เธอดูเหมือนจะไม่ใช่คนที่เหมาะที่สุดในการสืบข่าวเลย

ยานามิเองก็เหมือนจะสงสัยเหมือนกัน สีหน้าของเธอแสดงออกมาอย่างชัดเจน

[ โคมาริจังทำยังไงล่ะ? ไม่โดนเจ้าหน้าที่รักษาความปลอดภัยไล่เหรอ? ]

อาซากุโมะซังหยิบสมุดสเก็ตช์ที่ปกสีดำและส้มออกมา

[ เธอไปนั่งอยู่ในลานจอดรถใกล้ๆ สถานที่จัดงาน สเก็ตภาพวิวไปเรื่อยๆ พร้อมกับเฝ้าสังเกตการเข้าออกของคน ]

สมุดสเก็ตช์ถูกส่งมาให้ดู เผยให้เห็นภาพวาดรายละเอียดสวยงามของสภาพแวดล้อมรอบๆ สถานที่

เมื่อพลิกหน้าผมพบว่า มีโน้ตเขียนไว้เล็กๆ ในมุม ซึ่งบันทึกเวลาการเข้าออกของผู้คน

[ เมื่อวานนี้เธอเฝ้าสังเกตโบสถ์จากหลังคาของโรงเรียนคิริโนกิ เธอรู้จักการเข้ามาออกของเจ้าหน้าที่ดี ]

[ นั่นดูแย่มากนะ แต่ว่าทำไมไม่บอกเราล่ะ ? น่าจะบอกไว้หน่อย ]

ประธานรับสมุดสเก็ตช์จากมือผมและจ้องมันอย่างตั้งใจ

[ อาจจะเตรียมตัวไว้เผื่อว่าแผนมันจะพลาด ถ้าแผนล้มเหลวแล้วเราทุกคนต้องถูกพักการเรียน มันจะเป็นหายนะเอา ]

...ใช่ นั่นมันสมเหตุสมผล เธอคงกังวลที่เห็นเรากำลังเดินหน้ากับแผนบ้าบอของพวกนี้

ดังนั้นเธอเลยเก็บข้อมูลนี้มาเงียบๆ

[ โคมาริซังขอให้ฉันเก็บเรื่องนี้เป็นความลับ เพราะงั้น ช่วยเก็บเงียบๆ ด้วยนะ ]

อาซากุโมะซังยิ้มขี้เล่นพร้อมยกนิ้วขึ้นที่ริมฝีปาก

คำว่า "ความลับ" คงไม่มีความหมายสำหรับเธอ

ยานามิที่ยังเปิดผ่านคู่มืออยู่เงียบๆ ได้พูดขึ้น

[ นี่ ชิราทามะจังจะเปลี่ยนชุดเจ้าสาวที่งานเหรอ? ถ้าเธอแอบเข้าออกไปกลับที่โรงเรียนคิริโนกิ จะไม่เด่นเกินไปเหรอ ? [

[ เนื่องจากประวัติของชิราทามะซัง การพกกระเป๋าขนาดใหญ่จะต้องเด่นแน่นอน และยังมีโอกาสที่ญาติคนใดคนหนึ่งอาจมาถึงก่อนเวลา ดังนั้นการเอาชุดเข้าไปในงานเลยเป็นเรื่องที่เสี่ยงเกินไป แน่นอนว่าชุดเจ้าสาวจะถูกซ่อนไว้ใต้เสื้อโค้ทระหว่างการเดินทาง ]

[ นั่นคือเหตุผลที่เราเลือกชุดที่เคลื่อนไหวได้ง่ายและไม่เทอะทะ ]

ชิราทามะซังเสริม ก่อนจะดูดครีมถั่วแดงจากหลอกอีกที

เมื่อเราหมดคำถาม อาซากุโมะซังวางเหรียญขนาด 10 เยนสีดำขนาดเท่ากับเหรียญสองเหรียญลงบนโต๊ะ หนึ่งในนั้นมีปุ่ม

[ และยานามิซัง ช่วยเอาคลิกเกอร์นี้ไป อันที่มีปุ่มนะ ]

[ คลิกเกอร์? กินได้มั้ย.... ]

[ มันกินไม่ได้นะ อันนี้จะมีตัวรับที่สั่นเมื่อคุณกดปุ่มนี้ ]

อาซากุโมะซังอธิบายพร้อมกับกดปุ่มเพื่อทดสอบ ตัวรับอีกชิ้นสั่นเบาๆ

[ กดครั้งเดียวหมายถึง 'เดินหน้า', กดสองครั้งหมายถึง 'ถอยหลัง', และสามครั้งหมายถึง 'หยุด' ถ้ามากกว่านั้นก็หมายถึง 'ออกไปจากที่นั่นด่วน' ชิราทามะซังจะถือตัวรับที่สั่นนี้ และเธอจะทำตามคำสั่ง ]

เข้าใจแล้ว การใช้ปุ่มกดที่ทำให้สั่นมันง่ายและชัดเจนกว่าการใช้โทรศัพท์หรือสัญญาณมือ

ความรู้สึกตื่นเต้นที่เกิดขึ้นนั้นคงเป็นเพราะจิตใจผมกำลังหลุดไปที่ไหนซักที่

[ เมื่อการถ่ายภาพเสร็จสิ้น พวกเธอสองคนในฐานะช่างภาพปลอม ต้องพาทานากะเซ็นเซขึ้นไปบนชั้นบน ในขณะเดียวกัน ยานามิซังจะพาชิราทามะซังออกจากสถานที่จัดงาน ช่วยทบทวนรายละเอียดในคู่มืออีกครั้งด้วยค่ะ ]

พอมองดูอีกที คู่มือนี้มันหนามากเลย...

ในขณะที่ผมลังเล ก็สังเกตเห็นว่า ปกของคู่มือมีสี่เหลี่ยมเล็กๆ ที่เขียนว่า "ตราประทับอนุมัติ"

[ เอ่อ ตราประทับนี้คืออะไร? ]

[ งั้นก็ช่วยอนุมัติแผนการนี้อย่างเป็นทางการด้วยค่ะ หัวหน้าผู้ดำเนินการ! ]

อาซากุโมะซังพูดในขณะที่มองมาที่ผม... ผมเป็นหัวหน้าผู้ดำเนินการเหรอ?

ผมสะดุ้งนิดหน่อย แต่เธอก็ก้มตัวเข้าใกล้

[ เอาเลย ประทับตราเลย! กดลงไปเลย! ]

[ เอ่อ แต่ไม่มีตราประทับ... ]

ชิราทามะซังยื่นตราประทับให้ผม

[ เพราะงั้นฉันเลยทำตราประทับมาให้แล้วค่ะ ฉันยังเตรียมหมึกให้เรียบร้อยแล้วด้วย เชิญใช้เลยค่ะ ]

...เธอไปทำตราประทับให้ผมจริงๆ………ขอบคุณมาก

หลังจากที่พวกเขากดดัน ผมก็จุ่มตราประทับลงในหมึกและประทับลงบนกลางหน้าปกของคู่มืออย่างมั่นใจ

นี่เป็นครั้งแรกที่ผมได้เห็นตราประทับที่สวยงามพร้อมชื่อ นุคุมิซึ คาซึฮิโกะ อยู่บนนั้น

◇

วันก่อนปฏิบัติการ

พวกเราตกลงกันว่าจะพักผ่อนในวันนี้ เพื่อเตรียมตัวให้พร้อมสำหรับวันพรุ่งนี้
