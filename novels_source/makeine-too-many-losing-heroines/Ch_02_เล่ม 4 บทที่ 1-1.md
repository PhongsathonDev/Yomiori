บทที่ 1 : ถึงจะดูแบบนี้ แต่ฉันก็เป็น OO เหมือนกันนะ ?

ห้องชมรมหลังเลิกเรียน กาน้ำบนเตาส่งไอน้ำออกมา

ผมคลายเนกไทและเปิดหนังสือของผม

วันนี้วุ่นวายตั้งแต่เช้าเลย

ท่าทางสุดอับอายนั่นทำให้ผมต้องยอมให้ไลท์โนเวลที่เพิ่งซื้อมาถูกยึดไป

ผมพยายามลืมความทรงจำแย่ ๆ นี้และจดจ่อกับหนังสือแทน

[ เน่ นุคุมิซึคุง เบื่อแล้วอะ ]

เด็กสาวที่นั่งอยู่ตรงหน้าโต๊ะพูดขึ้นอย่างเกียจคร้าน

ยานามิ อันนะ เธอเป็นสมาชิกชมรมวรรณกรรมปีหนึ่งเหมือนกัน เธอคือนางเอกผู้พ่ายแพ้ที่ถูกปฏิเสธโดยเพื่อนสมัยเด็กเมื่อฤดูร้อนที่ผ่านมา

นอกจากนั้นเธอก็เป็นแค่เด็กผู้หญิงธรรมดา...คิดว่านะ? ผมจะไม่ขุดลึกไปกว่านี้ สิ่งเดียวที่มั่นใจก็คือบรรยากาศไม่ได้อึดอัดและคลุมเครือเลย แม้ว่าในห้องนี้จะมีแค่เราสองคน

ยานามิเอนตัวลงกับโต๊ะ เธอกำลังกินอะไรบางอย่างและทำเสียงแปลก ๆ “โมคิว โมคิว”

[ ..นี่ สีม่วงๆที่ออกจากเธอนั่นมันอะไร ? ]

[ มันคือลูกอมเหนียวน่ะ หนังสือบอกว่ากินอะไรที่ต้องเคี้ยว ๆ แล้วจะผอมลง ]

ยานามิยื่นถุงเปล่าของลูกอมเหนียวมาให้ผม

ลูกอมเป่ายิ้งฉุบ เป็นขนมที่ทำในโทโยฮาชิ มีปลายที่เป็นรูปกรรไกร กระดาษ และค้อน บนลูกอมเหนียวยาวๆนี่

[ นี่เป็นเทรนด์มานานแล้วนะ ? นุคุมิซึคุง นายเป็นพวกไม่กินดะงะชิเหรอ? ]

ผมกินนะ แต่เธอกินจากด้านที่เป็นรูปร่างไป นี่มันต่างจากการกินลูกอมเหนียวยาวๆปกติยังไงกันล่ะ?

ยานามิดูดลูกอมเหมือนกำลังกินบะหมี่

[ ฉันเบื่อจริงๆนะ การกินนี่เป็นสิ่งเดียวที่ฉันทำได้ ฉันซื้อมาสิบสองถุง แต่คงอยู่ไม่เกินสามวัน ]

[ ถ้าเธอเบื่อทำไมทำการบ้านล่ะ? วันนี้เรามีเยอะนะ]

ยานามิมองผมอย่างไม่พอใจ

[ นุคุมิซึคุง นายไม่คิดว่านายเย็นชาไปหน่อยเหรอ? นี่ เพื่อนผู้หญิงที่นายสนใจอยู่นิดหน่อยตอนนี้กำลังเบื่อนะ ]

ยานามิตบโต๊ะด้วยฝ่ามือ เธอขมวดริมฝีปากอย่างไม่พอใจ

[ ...ยานามิซัง ช่วยเลิกยัดความคิดแปลก ๆ ใส่ฉันได้มั้ย ? ]

ผมไม่สามารถจดจ่อได้เลย ผมจึงตัดสินใจปิดนิยายที่รอดจากการโดนยึด ชื่อว่า

< ตั้งแต่เพื่อนสมัยเด็กของฉันอาศัยอยู่ในห้องใต้หลังคาฉันเลยซื้อน้ำยาฆ่าแมลงมา> ย่อว่า <โอซะบารุ>

<โอซะบารุ> เป็นการต่อสู้เชาวน์ปัญญาระหว่างตัวเอกและนางเอกที่พยายามอาศัยเขาอยู่ มันคือ <โฮม อโลน> แห่งโลกไลท์โนเวลนอกจากนี้ นางเอกเพิ่งจดทะเบียนบ้านของเธอที่บ้านของตัวเอกในเล่มล่าสุดด้วย

ยานามิยังคงตบโต๊ะเพื่อประท้วงเรื่องการไม่ใส่ใจของผม

[ นุคุมิซึคุง นายเป็นประธานชมรมวรรณกรรมแล้วนะ ? ฉันคิดว่าประธานควรมีหน้าที่ทำให้สมาชิกชมรมมีความสุขสิ? ]

ไม่หรอก

[ ยานามิซัง เธอยังไม่ได้เขียนร่างสำหรับนิตยสารชมรมเลยใช่มั้ย? ทำไมเธอไม่ทำตอนที่มีเวลาล่ะ? ]

[ จะเขียนทีหลัง ฉันมีไอเดียแล้ว มีไอเดียจริงๆนะ! ]

[ นั่นคือสิ่งที่คนที่เขียนอะไรไม่ได้เลยพูดออกมาใช่มั้ย ? ]

แทนที่จะโต้ตอบ ยานามิกลับแสดงสีหน้าเศร้าหมอง เธอดูเหมือนกำลังคิดอะไรอยู่

จากนั้นเธอก็มองผมเป็นครั้งคราว

[..เกิดอะไรขึ้นหรือเปล่า ยานามิซัง? ]

ผมไม่ได้สนใจจริง ๆ หรอก แต่ก็ยังถามอยู่ดี ผมเป็นประธานนี่นา

[ เอ่อ ไม่ใช่ว่ามีคนเสนอให้เราไปงานปาร์ตี้ของห้องหลังพิธีปิดภาคเรียนเหรอ ? ]

ปาร์ตี้ห้อง? ผมไม่เกี่ยวอะไรกับเรื่องนั้น แต่-

[ พิธีปิดภาคเรียนคือวันที่ 25 ใช่มั้ย? ]

ผมพูดด้วยน้ำเสียงที่สงบ แต่คำตอบของผมคือเสียงต่ำจนเหมือนกำลังคลานบนพื้น

[ ...ก็คือคริสต์มาส ]

เปลวไฟดำลุกโชนในดวงตาของยานามิ เธอยืนขึ้นทันที

[ แล้วก็ โซสุเกะกับคาเรนจังเป็นคนจัดงานปาร์ตี้ ]

[ เอ๊ะ แต่สองคนนั้น- ]

ผมเงียบไปครึ่งทาง ยานามิจ้องผม

[ คู่รักมักจะจีบกันในวันคริสต์มาสอีฟ นั่นเป็นเหตุผลที่ฉันไม่ต้องกังวลเรื่องวันที่ 25 พ่อแม่ของคาเรนจังทำงานที่อังกฤษ เพราะงั้นเธออาศัยอยู่คนเดียว ]

ผมเข้าใจ เราไม่จำเป็นต้องกังวลเรื่องนั้นจริง ๆ

[ ฉันยังลังเลว่าจะเข้าร่วมดีมั้ย ถึงจะโดนชวนแล้วก็เถอะ นายล่ะ นุคุมิซึคุง? ]

[ แล้วผมจะทำอะไรได้? ก็ไม่ได้โดนชวนนิ่ ]

[ ...อืม งั้นก็พักเรื่องนุคุมิซึคุงไว้ก่อน ]

เรื่องของผมถูกพักเอาไว้

[ ถึงฉันจะปฏิเสธก็ไม่เป็นไร แต่มันจะดูเหมือนฉันคิดมากไปมั้ย? ดูสิ จะทำยังไงในเมื่อมีคู่รักอยู่ทุกที่อะ ? โซสุเกะกับคาเรนจังจะอยู่ด้วยกันในคืนคริสต์มาสอีฟ แล้วถ้าเจอพวกเขาวันต่อมาฉันจะทำยังไง ? ฉันควรแกล้งทำเป็นไม่รู้เรื่องดีมั้ย? มันจะดูแปลกๆถ้าฉันไม่ไปร่วมงาน แต่ถ้านุคุมิซึคุงไปด้วย แทนที่จะบอกว่านายทำหน้าที่เป็นเครื่องรางเพื่อความปลอดภัย รู้สึกเหมือนว่านายแค่มาเป็นเพื่อนฉันมากกว่า ]

นั่นเป็นข้อแก้ตัวที่ยาวนานมาก

[ วันนั้นเป็นวันเกิดของผม คงไม่ไปหรอก น้องสาวจะฉลองให้ผมด้วย ]

[ เอ๊ะ? วันเกิดนุคุมิซึคุงตรงกับวันคริสต์มาสเหรอ? ]

[ อืม ใช่ ]

[ เข้าใจแล้ว คริสต์มาสปีนี้ยกเลิกสินะ… ]

ไม่ใช่แบบนั้นสักหน่อย

ดวงตาของยานามิส่องประกายขึ้น เธอตบมือ

[ ดีเลย นี่ไม่ใช่เวลาไปฉลองให้คนตายหรอก มาเถอะ เรามาจัดงานวันเกิดให้นุคุมิซึคุงกันดีมั้ย!? ]

เอ๊ะ เธอจะฉลองวันเกิดใหผมเหรอ?

ผมค่อนข้างตกใจเพราะนี่เป็นครั้งแรกที่ผมเจอสถานการณ์แบบนี้ ยานามิยิ้มให้ผม

[ มาจัดงานเลี้ยงสาว ๆ ฉลองวันเกิดให้นุคุมิซึคุงกันเถอะ! ถ้าเป็นเลม่อนจังกับโคมาริจัง พวกเธอน่าจะมาได้ เพราะพวกเธอไม่มีแฟนนี่ ? ]

งานเลี้ยงสาว ๆ เหรอ นั่นดูเหมือนจะเป็นการฉลองที่ไม่นับผมที่ยังมีชีวิตอยู่เลย

[ ยากิชิโอะก็คงจะไปงานเลี้ยงวันคริสต์มาสเหมือนกัน ใช่มั้ย? ]

[ อ๊ะ ไม่ ๆ ๆ นุคุมิซึคุง ฉันไม่ยอมให้เพื่อนของฉันไปสถานที่อันตรายแบบนั้นหรอก ]

ยานามิหยิบแพ็คลูกอมเหนียวอีกถุงหนึ่งออกมาจากกระเป๋าเสื้อของเธอ แล้วแกะห่อออกมา

[ เขาไม่ได้เอาปืuจ่อหัวบังคับให้เธอไปหรอกนะ ถ้าไม่ชอบก็บอกปฏิเสธไปตรง ๆ สิ ไม่จำเป็นต้องฝืนตัวเองหรอก ]

[ ก็อาจจะเป็นแบบนั้นแหละ แต่พอไม่มีอะไรทำในวันคริสต์มาสก็ดูจะเหงามาก ถ้าฉันแกล้งทำเป็นยุ่ง… ]

ยานามิหยิบลูกอมรูปกรรไกรใส่ปาก ดวงตาของเธอไร้ความรู้สึก

[ จริง ๆ แล้วมันรู้สึกว่างเปล่าน่ะ ]

เสียง โมคิว โมคิว โมคิว โมคิว ของการเคี้ยวดังสะท้อนในห้องชมรม

[...ยานามิซัง เธอควรไปงานเลี้ยงวันคริสต์มาสนะ เดาว่าคงมีคนโสดคนอื่น ๆ อยู่เหมือนกัน แล้วทำไมเธอไม่ชวนยากิชิโอะแล้วปกป้องเธอเองล่ะ? ]

ถึงแม้ผมจะไม่รู้ว่าเธอปกป้องอะไรอยู่

[ อ้อ, การจับคู่—อ่ะ ไม่สิ ฉันควรพูดว่าฉันจะไปเป็นเพื่อนเธอมากกว่า ลองถามเลม่อนจังดูก่อนว่าเธอจะไปมั้ย ]

ยานามิเริ่มกดโทรศัพท์ของเธอ

ผมถอนหายใจออกมาด้วยความโล่งใจเพราะความเงียบกลับมาอีกครั้ง “ดิง ดิง” เสียงริงโทนโทรศัพท์ดังขึ้น

— จากกระเป๋าในมุมห้อง

[ นั่นกระเป๋าของยากิชิโอะใช่มั้ย? ทิ้งกระเป๋าไว้ที่นี่แล้ว….เธอหายไปไหน? ]

[ เลม่อนจังคงอยู่ในคลาสเรียนพิเศษใช่มั้ย ? เธอตกข้อสอบไฟนอลน่ะ ]

พอมาคิดอีกที ยากิชิโอะเอาแต่ฝึกหมุนดินสอก่อนสอบนี่นา

ถ้าเป็นอย่างนั้น...

[ ยานามิซัง แน่ใจแล้วเหรอว่าไม่ต้องไป? ]

[ ไป? ไปไหนเหรอ? ]

ยานามิเอียงหัว

[ คลาสเรียนพิเศษสำหรับคนที่สอบตก มันเริ่มไปแล้วไม่ใช่เหรอ? ]

[ หา!? ฉันไม่ได้สอบตกย่ะ ! ]

เข้าใจแล้ว ผมแค่รู้สึกว่าผลสอบของเธอน่าจะไม่ผ่าน

[ ถึงหน้าตาฉันจะดูแบบนี้ แต่คะแนนมันโอเคเลยนะ เดี๋ยวจะพิสูจน์ให้นายดูตอนนี้เลย! ]

ยานามิหยิบกระดาษใบเล็กและยาวออกมาจากกระเป๋าโรงเรียนแล้วเอามายื่นให้ผม

นี่ต้องเป็นใบคะแนนสอบไฟนอลของเธอสินะ เอ่อ...เธอได้ที่ 135 จากทั้งหมด 228 คน?

ถึงมันจะไม่ได้แย่มาก แต่เกรดแบบนี้คุ้มค่าที่จะเอามาโชว์ด้วยความมั่นใจขนาดนี้จริง ๆ เหรอ? ผมไม่เข้าใจเลย...

ผมคิดหาปฏิกิริยาที่เหมาะสมไม่ได้ หลังจากนั้น ประตูห้องชมรมก็ถูกเปิดออก

คนที่ค่อย ๆ เดินเข้ามาจากประตูที่เปิดออกคือรองประธานชมรมวรรณกรรม โคมาริ ชิกะ

ร่างเล็ก ๆ ของเธอเต็มไปด้วยความกล้าเท่าๆกับตัวเธอ สำหรับผมแล้วเธอเป็นสาวน้อยจอมเหิมเกริม

โคมาริปิดประตูด้วยหลังมือของเธอ เธอมองไปรอบ ๆ ห้องชมรมด้วยความกังวล

[ มีอะไรเหรอ โคมาริจัง? ถ้าเธอกลัว ให้ฉันเตะนุคุมิซึคุงออกไปมั้ย? ]

[ ฉ-ฉันทนไหว- ]

โคมาริหันหลังกลับไปดูที่ประตูตรงกลาง เธอตัวสั่นด้วยความกลัว

[ บ-บอกเธอว่าฉันไม่อยู่ที่นี่! ]

[ เอ๊ะ, เฮ้ โคมาริ ]

โคมาริหลบลงใต้โต๊ะ ประตูถูกเปิดอีกครั้ง

ชายเสื้อโค้ทสีขาวของเธอพลิ้วไปตามลม คนที่เข้ามาในห้องชมรมคือที่ปรึกษาชมรมวรรณกรรม โคนุกิ ซาโยะ

ถึงแม้เธอจะเป็นพยาบาลโรงเรียน แต่ร่างกายของเธอก็เต็มไปด้วยองค์ประกอบที่เย้ายวน น่าเสียดายที่เธอไม่ค่อยมาเยี่ยมชมรมและมักจะอยู่ในห้องพยาบาล

[ ขอบคุณสำหรับการทำงานนะครับเซนเซ มีอะไรหรือเปล่าครับ? ]

[ อาระ ขอบคุณพวกเธอเช่นกัน ทั้งสองคน โคมาริซังเข้ามาที่นี่ก่อนหน้าฉันหรือเปล่า? คิดว่าเธอมุ่งมาที่นี่นะ ]

เซนเซมองไปรอบ ๆ ห้องชมรม

ยานามิกับผมมองหน้ากันแล้วก็ส่ายหัว

[ วันนี้พวกเราไม่ได้เจอเธอเลย เกิดอะไรขึ้นเหรอครับ? ]
