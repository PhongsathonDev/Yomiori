ชิราทามะซังวางหมอนอิงสีชมพูน่ารักลง แล้วตบมันปุๆ

เดทที่บ้านครึ่งหลัง ผมโดนชวนให้เข้ามาในห้องของชิราทามะ ริโกะ

[ เอ้า เชิญนั่งค่ะ คาซึฮิโกะซัง ]

[ อะ อื้ม รบกวนด้วยนะ...... ]

[ ขอโทษที่พี่สาวพูดมากนะคะ เหนื่อยแย่เลยใช่ไหมคะ? ]

[ อืม เหนื่อย ]

ผมตอบตามตรง แล้วนั่งลงบนหมอนอิง

การได้เข้าห้องนอนผู้หญิง(ถ้าไม่นับบ้านโคมาริ)ก็เป็นครั้งที่ 2 ต่อจากห้องของเทียร่าซัง

ห้องของชิราทามะซังเป็นพื้นไม้โทนสีขาว มีโต๊ะเครื่องแป้งตั้งอยู่ริมผนัง

ภายในห้องมีกลิ่นหอมของน้ำหอมจางๆ ลอยอยู่ ทุกครั้งที่ชิราทามะซังขยับตัว อากาศในห้องก็จะไหววูบอย่างน่ารื่นรมย์

──นี่แหละคือห้องของเด็กผู้หญิงของจริง

ถึงจะโดนชวนมาก็เถอะ แต่แฟนปลอมๆ มาอยู่ที่นี่จะดีเหรอ......

ในขณะที่กำลังทำตัวไม่ถูกกับความรู้สึกผิดศีลธรรม ชิราทามะซังก็วางหมอนอิงอีกใบข้างๆผมแล้วนั่งลง

[ เอ๊ะ ทำไมมานั่งข้างๆ ล่ะ ]

[ ก็ฉันเป็นแฟนของคาซึฮิโกะซังนี่คะ เรื่องปกติค่ะ ]

อ้อ นั่นสินะ ชิราทามะซังเป็นแฟนผม เพราะงั้นนั่งข้างๆ ก็ไม่มีปัญ──

[ ไม่ๆๆ แค่แกล้งคบกันไม่ใช่เหรอ? อีกอย่างอยู่ในห้องกันสองต่อสอง ไม่ต้องเรียกชื่อจริงก็ได้มั้ง ]

[ อื้ม แต่เดี๋ยวอาจจะมีใครได้ยินเข้าก็ได้นี่คะ แถมอุตส่าห์ได้อยู่กันสองต่อสองทั้งที── ]

ชิราทามะซังซบหัวลงบนไหล่ของผม

[ ลองแกล้งเป็นแฟน──ต่ออีกนิดไหมคะ? ]

[ เอ๊ะ?! ]

สองต่อสองในห้องแฟน ถ้าพูดถึงสิ่งที่แฟนหนุ่มจะทำก็คือ────

เดี๋ยว นี่มันแย่แล้ว ผมก็เป็นผู้ชายนะ ถ้าเผลอตัวไปจับข้อพับขาหรืออะไรเข้าจะเป็นเรื่องใหญ่นะเฮ้ย

[ ชิราทามะซัง ล้อเล่นแบบนั้นไม่ดีนะ ]

[ ถ้าแกล้งทำเพราะล้อเล่นเนี่ย ไม่ได้เหรอคะ? ]

[ ไม่หรอก ก็ไม่ใช่ว่าไม่ได้...... ]

[ ......เพราะแค่แกล้งทำ พรุ่งนี้จะลืมไปก็ได้ค่ะ ]

น้ำหนักของหัวชิราทามะซังที่ซบบนไหล่ เพิ่มขึ้นเล็กน้อย

นี่คงเป็นการล้อเล่นของเธอนั่นแหละ เพราะล้อเล่นเลยไม่ถือเป็นจริงเป็นจัง แต่ว่ากลิ่นหอมหวานและนุ่มนวลนี่มัน ปล่อยไว้แบบนี้สักหน่อยก็คง──

ในขณะที่ตัวแข็งทื่อทำอะไรไม่ถูก ก็ได้ยินเสียงฝีเท้าเดินเข้ามาใกล้ห้องจากทางเดิน

เสียงฝีเท้าที่ค่อนข้างหนักหยุดลงหน้าประตู แล้วเคาะอย่างเกรงใจ

『ทั้งสองคน ขอเวลาหน่อยได้ไหม?』

[ [อึ๊ก!!] ]

เสียงนี้มันอาจารย์ทานากะนี่นา ชิราทามะซังรีบดีดตัวขึ้น แล้วไปเปิดประตู

[ พี่คะ มีอะไรเหรอ? ]

[ เห็นว่านุคุมิซึคุงมา ก็เลยว่าจะมาทักทาย── ]

สายตาของอาจารย์ทานากะที่กำลังพูดค้างไว้ หยุดอยู่ที่หมอนอิงสองใบที่วางคู่กัน

เขารีบละสายตา แล้วยิ้มออกมาอย่างสุขุม

[ แล้วก็ซื้อเค้กมาด้วย ลงไปกินข้างล่างด้วยกันไหม ]

ชิราทามะซังยืนขวางวิสัยทัศน์ของอาจารย์ทานากะ แล้วประกบมือเข้าหากันอย่างดีใจ

[ ว้าว ขอบคุณค่ะ คาซึฮิโกะซัง ลงไปข้างล่างกันเถอะค่ะ ]

[ อะ อื้ม ]

ผมพยักหน้าอย่างเก้ๆ กังๆ แล้วเดินออกจากห้องพร้อมกับชิราทามะซัง

อาจารย์ทานากะทำหน้ากระอักกระอ่วน...... ผมเองก็เหมือนกัน

◇

──เดทที่บ้านที่ทำเอากระเพาะแทบทะลุ จบลงแล้ว

ผมยืนกรานปฏิเสธที่จะให้ไปส่ง แล้วโค้งคำนับให้เหล่าอาจารย์ที่หน้าประตูบ้านชิราทามะ

[ ขอบคุณที่เชิญมาวันนี้นะครับ ]

[ ดีใจที่ได้คุยกันเยอะแยะเลยนะ ไว้เจอกันที่โรงเรียนจ้ะ ]

ขณะที่จับมือกับอาจารย์ทานากะ อาจารย์อมานัตสึก็ตบไหล่ผม

[ เออ นุคุมิซึ เข้มแข็งไว้นะ ถ้าถึงเวลาเอาจริงเมื่อไหร่ก็ไปปรึกษาโคนุกิจังซะ ]

[ ใช่จ้ะ ยินดีต้อนรับเสมอ เตียงห้องพยาบาลว่างรอตลอดนะ ]

ผมพยักหน้าแล้วยิ้ม พลางสาบานในใจว่าจะไม่เข้าใกล้ห้องพยาบาลไปสักพัก

พอจะกลับ พี่สาวริโกะก็เดินเข้ามาใกล้ๆ อย่างเนียนๆ แล้วกระซิบที่ข้างหูผม

[ ──ฝากริโกะด้วยนะ คุณประธาน ]

เธอยิ้มอ่อนโยนให้ผมที่ยืนตัวแข็ง ก่อนจะตบหลังเบาๆ แล้วผละออกไป

......คนคนนี้เป็นพี่สาวของชิราทามะ ริโกะ จริงๆ ด้วยแฮะ

ผมเป็นห่วงอนาคตของอาจารย์ทานากะพลางรีบเดินออกจากบ้านชิราทามะ

◇

ผมกำลังเดินไปที่สถานีที่ใกล้ที่สุด บนถนนเลนเดียวที่ไม่มีทางเท้า

พอรถมาก็หลบไปยืนริมทาง พลางแหงนมองท้องฟ้าที่ดวงอาทิตย์ใกล้จะลับขอบฟ้า

......ครั้งนี้รอดมาได้ แต่ถ้าเป็นแบบนี้ต่อไปคงลำบากแน่

ควรจะคุยกันให้รู้เรื่อง แล้วบอกความจริงไปซะที

จริงอยู่ที่ชิราทามะซังตัวนิ่มและตัวหอม แต่ผมไม่ใช่คนที่จะหวั่นไหวกับเรื่องแค่นั้นหรอก

..................อืม ไม่ใช่คนที่จะหวั่นไหวหรอกนะ

[ คาซึฮิโกะซางงง รอด้วยค่ะ ]

พอหันไปตามเสียง ก็เห็นชิราทามะซังวิ่งตามมาจากด้านหลัง

พอตามทัน ชิราทามะซังก็เอามือทาบอกเพื่อปรับลมหายใจ

[ เป็นอะไรไป ลืมของอะไรไว้เหรอ ]

[ ในฐานะแฟน ก็กะว่าจะไปส่งคาซึฮิโกะซังที่สถานีน่ะค่ะ ]

ชิราทามะซังส่งยิ้มที่สมบูรณ์แบบมาให้ แต่ผมไม่หวั่นไหวอีกแล้ว

[ คราวนี้พวกอาจารย์ไม่อยู่แล้ว ไม่ต้องแกล้งทำแล้วก็ได้นะ ]

[ จนกว่าจะกลับถึงบ้าน ก็ถือว่าเป็นแฟนกันอยู่นะคะ? ]

เธอพูดอย่างขี้เล่น แล้วทำท่าจะเดินนำหน้าผมไป

......เอาเถอะ ไม่ได้หวั่นไหวสักหน่อย จะยอมตามน้ำไปอีกนิดก็ได้

[ เดี๋ยว ไม่ใช่ทางนั้นนะ ]

[ ไม่ได้จะไปสถานีเหรอคะ? ]

[ ทางนี้รถมันเยอะอันตราย ไปทางอื่นกันเถอะ ]

ถ้าฉันคนเดียวก็ไม่เป็นไร แต่ถ้าเดินกับชิราทามะซัง คงปล่อยให้เป็นแบบนั้นไม่ได้

ขณะที่เดินย้อนกลับทางเดิม จู่ๆ ชิราทามะซังก็ก้มหัวให้

[ คาซึฮิโกะซัง วันนี้ขอบคุณมากนะคะ ช่วยได้มากเลยค่ะ ]

[ ไม่หรอก ก็ลงเรือลำเดียวกันแล้วนี่นะ เรื่องแบบนี้เกิดขึ้นบ่อยจะตาย ]

[ หุหุ บ่อยเหรอ แฟนฉันนี่เนื้อหอมจังนะคะ ]

น้ำเสียงติดตลกของชิราทามะซัง ทำให้ผมเผลอยิ้มมุมปาก

ก็นะ ที่ไปเจอครอบครัวเพื่อนนี่ไม่ใช่เรื่องโกหก ทั้งทำเค้กกับแม่ยากิชิโอะ ทั้งโดนน้องสาวยากิชิโอะพ่นนมใส่ ทั้งเล่นจิบิสุเกะ ทั้งโดนน้องชายบาโซริเห็นตอนเล่นหูแมว

[ งั้นขอตอบแทนสำหรับครั้งนี้นะคะ อยากได้อะไรไหมคะ? ]

[ แค่เดินไปส่งที่สถานีก็พอแล้วล่ะ ]

พูดตามตรง ขอไม่ติดหนี้บุญคุณไปมากกว่านี้ดีกว่า

ผมพูดทีเล่นทีจริง แต่ชิราทามะซังกลับเงียบกริบ

อ้าว เมื่อกี้พูดอะไรน่าขยะแขยงไปรึเปล่านะ เริ่มรู้สึกสังหรณ์ใจแปลกๆ แล้วสิ

[ เอ่อ คือเมื่อกี้ไม่ได้มีความหมายแฝงอะไรนะ── ]

[ บอกตามตรง อยู่ที่บ้านโดนรุมซักฟอกแน่เลยหนีออกมาน่ะค่ะ ]

ชิราทามะซังพูดแค่นั้นแล้วก็เงียบไปอีก

......ก็นะ คงงั้นแหละ

พวกเราเดินเคียงคู่กันไปทั้งที่ยังเงียบงัน

พอหยุดรอสัญญาณไฟที่สี่แยก ชิราทามะซังก็มองเหม่อไปยังรถที่วิ่งผ่านไปมา

[ การต้องเป็นเด็กดีต่อหน้าพี่สาวกับพี่ชายเนี่ย──มันเหนื่อยหน่อยๆ นะคะ ]

[ ............งั้นเหรอ ]

สีหน้าที่ชิราทามะซังแสดงออกมาให้เห็นเป็นบางครั้ง คือเด็กผู้หญิงที่เปราะบางสมวัย

ผมพูดอะไรไม่ออก ได้แต่ยืนอยู่ข้างๆ เท่านั้น

สัญญาณไฟเปลี่ยนเป็นสีเขียว พวกเราเริ่มออกเดินโดยไม่พูดอะไร

ขณะที่เดินบนทางเท้าเลียบทุ่งนา ผมก็พูดเรื่องที่ติดใจเมื่อกี้ออกมา

[ พี่สาวเธอ คงรู้ตัวแล้วมั้งว่าเราไม่ได้คบกัน ]

[ ......ทำไมถึงคิดแบบนั้นล่ะคะ? ]

น้ำเสียงจริงจังของชิราทามะซัง ทำเอาชะงักไปชั่วครู่

[ ตอนจะกลับ เขาเรียกผมว่าคุณประธานน่ะ ]

[ ประธาน──]

พอได้ยินแบบนั้น ชิราทามะซังก็คิดอยู่ครู่หนึ่ง ก่อนจะเอ่ยปาก

[ ──หลุดพิรุธไปรึเปล่าคะ? ]

[ เห ? ]

[ โดนลองเชิงแล้วค่ะ พี่สาวกำลังรอให้คาซึฮิโกะซังหลุดพิรุธออกมาอยู่น่ะสิ ]

[ หมายความว่าความแตกแล้วเหรอ? ]

ชิราทามะซังส่ายหน้าทั้งที่ยังมองตรงไปข้างหน้า

[ ถ้าพี่สาวมั่นใจแล้ว คงไม่แกล้งแหย่แบบนั้นหรอกค่ะ การกุมความลับไว้ จะเป็นฝ่ายกุมความได้เปรียบมากกว่า ]

[ งะ งั้นเหรอ ]

......สองพี่น้องคู่นี้ ใช้ชีวิตอยู่คนละมิติกับผมจริงๆ

เอาล่ะ มาบ้านชิราทามะครั้งนี้ขอให้เป็นครั้งแรกและครั้งสุดท้าย ผมจะใช้ชีวิตที่บ้านนุคุมิซึ สัมผัสก้อนขนฟูๆ กับคาจูให้สบายใจดีกว่า

[ คาซึฮิโกะซัง เดินช้าลงหน่อยสิคะ ]

[ อะ โทษที ]

ชิราทามะซังไม่สนใจผมที่กำลังลนลาน เธอเริ่มเดินทั้งที่ยังควงแขนอยู่
