เล่ม 6 บทที่ 2-4

สถานที่ที่ผมอยู่ตอนนี้ถือเป็นจุดที่ดีที่สุด หากคุณกำลังมองหามุมเงียบๆ ใกล้สถานีโทโยฮาชิ

บริเวณนี้รู้จักกันในชื่อ "เวสต์สเตชั่น" บางช่วงอาจคึกคักไปด้วยรถมารับ-ส่งผู้โดยสาร แต่ถ้าไม่นับช่วงเวลานั้น ที่นี่กลับเงียบสงบอย่างน่าประหลาด ราวกับความคึกคักของสถานีเป็นแค่เรื่องโกหก

พวกเราเดินไปเงียบๆ โดยไม่พูดอะไรกันมากนัก ออกจากอาคารสถานีแล้วเลี้ยวขวาเดินไปตามถนนที่ขนานกับรางรถไฟ

ร้านอิซากายะเล็กๆ เรียงรายเริ่มเปิดให้บริการอย่างช้าๆ ราวกับว่านี่ยังเป็นช่วงเช้า

[ ขอโทษที่รบกวนนะ ]

[ ไม่หรอก ฉันสิที่ต้องขอโทษที่เข้ามายุ่งวุ่นวายกันายแบบแปลกๆ นั่นมันเกินไปจริงๆ ]

ครับ เกินไปมากจริงๆ คุราตะซังเกาหัวจมูกตัวเองเล็กน้อยเหมือนกำลังเขิน

[ ฉันคิดว่าเลม่อนอาจจะมีแฟน นั่นเลยเป็นเหตุผลว่าทำไมเธอถึงจะลาออกจากชมรม ]

[ แล้วคิดว่าเธอเป็นแฟนผมเหรอ ? ]

เธอพยักหน้า พลางส่งยิ้มแห้งๆ มาให้

[ นายมาหาเลม่อนตอนงานซึวะบุกิใช่มั้ย? ]

งานซึวะบุกิ... อ๋อ ใช่ ตอนนั้นเพื่อนร่วมชั้นสมัยม.ต้นพยายามเข้าไปคุยกับยากิชิโอะ แต่กลับถูกปฏิเสธอย่างไร้เยื่อใย

[ ใช่ ผมไปดูทีมวิ่งของเธอมา ]

[ เลม่อนน่ะป๊อปนะ ถึงเธอจะดูเหมือนไม่สนใจผู้ชาย แต่จริงๆก็ระวังตัวมาก ]

เฮ้อ การเป็นคนดังนี่ลำบากจริงๆ

[ นั่นแหละ เลยสงสัยว่าทำไมท่าทีของเธอถึงดูต่างออกไปเวลาอยู่กับนาย ]

หรือเธอหมายถึงผมดูเหมือนไม่ใช่ผู้ชายในสายตายากิชิโอะ...?

[ แต่ชมรมกรีฑาไม่ได้มีกฎห้ามคบกันนี่ ทำไมต้องกังวลขนาดนั้น? ]

[ นายไม่คิดเหรอว่าเลม่อนเป็นพวกที่จะเสียคนเพราะผู้ชาย? ]

[ เป็นไปไม่ได้หรอก- ]

...ว่าไปแล้วมันก็อาจจะจริง

จากท่าทีของเธอเวลาอยู่ใกล้อายาโนะที่ยังไม่ใช่แฟนด้วยซ้ำ ถ้ามีแฟนจริงๆ อาจจะเป็นปัญหาได้…

[ จริงด้วย ยากิชิโอะนี่ดูเหมือนอาจจะหลงผิดได้ง่ายๆเลยต้องระวังให้มากขึ้นแล้ว ]

[ …ควรจะระวังจริงๆ นั่นแหละ ]

คุราตะซังจ้องผมเขม็งราวกับจับผิด

[ งั้นพวกเธอถึงกับพยายามจะถ่ายรูปผม 'นอกใจ' เพื่อเอาไปให้ยากิชิโอะดู แล้วให้เธอเลิกกับผมสินะ? ]

[ ก็ใช่ เราอยากช่วยเอซของชมรมกรีฑาจากผู้ชายเลวๆที่จะมาหลอกเธอ ]

เธอหัวเราะ พลางเผยฟันขาวสวยๆ เห็นรอยยิ้มนั้นแล้ว ผมตัดสินใจว่าจะเชื่อเธอ

ระหว่างที่เธอเดินนำไป ผมเอ่ยเรียกคุราตะซัง

[ ...ยากิชิโอะเคยมาคุยกับผมก่อนหน้านี้ เธอถามว่าผมจะเข้าชมรมกลับบ้านด้วยกันกับเธอมั้ย ]

คุราตะซังหันกลับมามองแล้วเลิกคิ้ว

[ ด้วยกัน? หมายถึงทั้งคู่จะลาออกจากชมรมวรรณกรรม? ]

ผมพยักหน้า และเธอก็หัวเราะเสียงใส

[ ก็สมเป็นเธอจริงๆนั่นแหละ เธอคงรู้สึกผิดที่ลาออกจากชมรมกรีฑาอย่างเดียว นายถูกลากไปจริงๆ สินะ ]

เธอหัวเราะอีกครั้ง

[ เลม่อนน่ะเก่งมากนะ ฉันรู้ดี เพราะตอนแรกที่เธอเข้ามา เราเคยแข่งวิ่งระยะสั้นกัน ]

[ งั้นหมายความว่าตอนนี้รุ่นพี่ไม่ได้วิ่งระยะสั้นแล้วเหรอ? ]

[ ฉันวิ่งไม่เร็วพอ ตอนเลม่อนเข้ามา ฉันถูกถอดจากทีม เลยย้ายไปวิ่งระยะกลางแทน ]

เธอหยุดผมไม่ให้พูดอะไรด้วยสายตา

[ ตอนนั้นมีคนบอกให้ฉันเตรียมตัวรับตำแหน่งหัวหน้าชมรมตั้งแต่เนิ่นๆ แต่มันคงดูไม่ดีถ้าหัวหน้าชมรมไม่ได้ลงแข่งเลย ]

เธอไม่ได้พูดสิ่งนี้เพื่อขอความเห็นใจ แต่มันคือความภูมิใจของเธอ ซึ่งเป็นส่วนสำคัญในตัวตนของเธอ

เราเดินมาถึงสุดทางโดยไม่ได้พูดอะไรต่อ

[ ก็เลยสงสัยว่าเธอยังเป็นห่วงฉันที่ย้ายไปวิ่งระยะกลางหรือเปล่า... ]

คุราตะซังหันกลับมาก่อนที่ผมจะหาคำตอบให้เธอทัน

[ ฉันกลับก่อนนะ ต้องไปเจอพวกนั้นแล้ว ]

[ ครับ ขอบคุณสำหรับเรื่องของยากิชิโอะนะครับ ]

[ ขอบคุณเหมือนกัน ถ้ามีอะไรเกิดขึ้นก็บอกมาได้เลยนะ ]

[ รุ่นพี่! ]

ผมเรียกเธอแบบลืมตัว คุราตะซังหันมามองด้วยความสงสัย

[ ถ้าไม่นับในฐานะหัวหน้าชมรม แต่เป็นในฐานะรุ่นพี่ อยากให้ยากิชิโอะกลับมาหรือเปล่า? ]

ดวงตาเธอเบิกกว้างเหมือนกำลังจะตอบ แต่สุดท้ายก็ปิดปากเงียบ ก่อนจะยิ้มอย่างเขินอายให้ผม ซึ่งไม่เคยเห็นเธอทำมาก่อน

[ ขอโทษนะ แต่ฉันเป็นแฟนคลับของเธอคนนั้นที่สุดเลยล่ะ ]

ขณะที่มองรุ่นพี่วิ่งจากไปหลังพูดแบบนั้น ผมก็นึกถึงยากิชิโอะ

สดใสเหลือกเกินแต่ในขณะเดียวกันก็บอบบางเหลือเกิน

เธอแทบไม่เคยแสดงความอ่อนแอให้ใครเห็น ถ้าเมื่อไหร่รอยยิ้มของเธอเริ่มจางลง คงต้องมีใครสักคนอยู่ข้างเธอ-

เสียงเบรกจักรยานดัง *เอี๊ยด!* ขัดจังหวะความคิดของผม

ตามมาด้วยเสียง *ปึ้ก!* ผมโดนชนเข้าเต็มๆ

[ น-นายมายืนขวางกลางถนนทำไม? ]

[ แล้วทำไมถึงขี่จักรยานชนผมล่ะ…? ]

แน่นอนว่าเป็นโคมาริที่ปั่นจักรยานมาชนผม เธอจ้องผมเขม็งผ่านหน้าม้าที่ปิดหน้าไว้

[ ท-ทำอะไรอยู่เนี่ย? ทำไมวันนี้ไม่มาชมรม ]

— เพราะมีผู้หญิงที่เหมือนคนบ้าคนหนึ่งมาวุ่นวายกับผม

ผมกลั้นคำพูดนั้นไว้ และทำเพียงยักไหล่

[ ผมออกไปตามหายากิชิโอะ แต่หาไม่เจอ ]

โคมาริลงจากจักรยานแล้วจ้องมองไปในทิศทางที่คุราตะซังเพิ่งเดินไป

[ คะ...คนเมื่อกี้คือใคร? ]

[ อ๋อ คุราตะซัง รุ่นพี่ปีสอง หัวหน้าชมรมกรีฑาหญิง ]

[ ชะ...ชมรมกรีฑา...เหรอ? คะ...คุยเรื่องยากิชิโอะกันเหรอ? ]

[ ใช่ ดูเหมือนจะพักจากชมรมกรีฑาด้วย พวกเราเลยแลกเปลี่ยนข้อมูลกันเกี่ยวกับเธอ ]

ผมเลือกที่จะไม่พูดถึงแผนล่อผมไปถ่ายรูปเพื่อหลีกเลี่ยงความเข้าใจผิด

โคมาริทำหน้าลำบากใจขณะพยายามจะเข็นจักรยานออกไป

[ อึ่ก... ]

[ เป็นอะไรเหรอ? ]

[ อะ...อือ โซ่หลุดน่ะ ]

ถ้าขี่จักรยานชนอะไรเข้าเต็มๆมันก็ต้องเป็นแบบนี้แหละ

ผมรู้สึกซะใจนิดหน่อยที่โคมาริพาตัวเองเข้าไปอยู่ในสถานการณ์ที่วุ่นวายแบบนี้ แต่ก็ปล่อยให้เธอตื่นตระหนกอยู่คนเดียวไม่ได้หรอก

ผมเลื่อนจักรยานไปจอดข้างถนนก่อนจะลองหมุนบันไดจักรยานเพื่อตรวจดูโซ่

[ ฮะๆ ดูเหมือนว่าโซ่มันหลุดนะ ]

[ ร-รู้แล้ว ! ]

แต่นี่มันความผิดของเธอนะ แล้วเราจะแก้ยังไงดี...?

ขณะที่ผมย่อตัวลงเพื่อค้นหาวิธีแก้ในสมาร์ทโฟน โคมาริก็เดินมาหยุดยืนข้างๆผม

[ น-นายซ่อมได้มั้ย? ]

[ อืม ช่วยค้นหาวิธีซ่อมในเน็ตให้หน่อยได้มั้ย? ]

[ ด-ได้เลย ]

โคมาริยื่นหน้าจอมาให้ผมหลังจากเธอแตะโทรศัพท์อยู่พักหนึ่ง

[ จ-เจอวิดีโอแล้ว ]

[ อ๋อ ดีเลย ]

ขณะที่เธอเอนตัวมาดู ผมของโคมาริก็เฉียดแก้มผมเบาๆ จั๊กจี้ดี

โคมาริเริ่มพูดเสียงเบาๆ ในขณะที่ผมกำลังสู้กับโซ่จักรยาน

[ พ-พรุ่งนี้จะมาที่ห้องชมรมมั้ย? ]

[ อยากไปนะ แต่ก็ยังเป็นห่วงยากิชิโอะอยู่เหมือนกัน ]

[ ย-ยากิชิโอะสำคัญก็จริง แต่คิดถึงชมรมวรรณกรรมด้วยสิ ]

ก็ใช่ แต่ตอนนี้ผมกำลังซ่อมโซ่เพราะเธออยู่นะ

[ พ-พิธีจบการศึกษาจะจัดสุดสัปดาห์นี้ นี่เป็นโอกาสสุดท้ายที่จะได้เห็นรุ่นพี่ในชุดเครื่องแบบ ]

ตอนนี้เป็นเดือนมีนาคม เวลาของรุ่นพี่เหลือน้อยเต็มที และการเตรียมตัวสำหรับปีหน้าก็รอไม่ได้

[ โอเค โทษที พรุ่งนี้จะไป ]

ผมพูดขอโทษอย่างจริงใจ แต่โคมาริยังดูเหมือนมีบางอย่างในใจ

[ มีอะไรอีกหรือเปล่า? ]

[ ...ร-เรื่องทำวารสารชมรม ]

[ อันที่เตรียมไว้สำหรับพิธีจบการศึกษาใช่มั้ย? ต้นฉบับพร้อมแล้วนะ ]

วารสารฉบับนี้เป็นของขวัญเซอร์ไพรส์สำหรับรุ่นพี่ในวันจบการศึกษา

ผมไม่มีอะไรต้องกังวล เพราะผมเป็นคนแรกที่เขียนต้นฉบับเสร็จ

[ พรุ่งนี้เรามาพิมพ์กันเลยมั้ย หรือจะไปพิมพ์ตอนนี้เลยก็ได้ ]

[ ร-รออีกหน่อยดีกว่า ]

[ มีอะไรหรือเปล่า? หรือว่าต้นฉบับของเธอยังไม่พร้อม? ]

[ ต้นฉบับน่ะพร้อมนานแล้ว แต่... ]

โคมาริหยุดชะงักก่อนจะพูดต่อ

[ ฉ-ฉันอยากให้ยากิชิโอะ ข-เขียนอะไรบางอย่างด้วย ]

[ ...เข้าใจละ ]

ยากิชิโอะเป็นเพื่อนคนแรกที่โคมาริสนิทด้วยตอนปีหนึ่ง เธอคงรู้สึกกังวลกับสถานการณ์ตอนนี้

[ แล้วก็ ผลสอบของรุ่นพี่ทามากิจะออกสัปดาห์หน้า บางทีรอถึงตอนนั้นน่าจะดีกว่า ]

[ ช-ใช่ รุ่นพี่ทามากิก็ลุ้นหนักเหมือนกัน... ]

คำพูดท้ายประโยคของเธอดูเบาจนแทบจะเลือนหายไป

สถานการณ์ของรุ่นพี่ทามากิที่เปลี่ยนสายไปเรียนวิทยาศาสตร์ตอนปีสาม ดูไม่ค่อยสู้ดีนัก คะแนนที่เขาประเมินเองจากการสอบครั้งก่อนอยู่ในระดับเสี่ยง และการสอบครั้งต่อไปจะยิ่งยากกว่าเดิม

สังเกตว่าโคมาริเริ่มประหม่าอย่างเห็นได้ชัด ตั้งแต่รู้ว่ารุ่นพี่สึคิโนะกิสอบติด

[ ว่าแต่ ทำไมเธอถึงวิ่งวุ่นอยู่แถวนี้? ที่นี่ไกลจากถนนใหญ่พอสมควรเลยนะ ]

ผมเปลี่ยนเรื่องเพื่อคลายบรรยากาศอึดอัด โคมาริเงยหน้าขึ้นมาตอบ

[ ฉ-ฉันไปไหว้ศาลเจ้าขอให้เขาสอบผ่าน แล้วก็อ่านเจอในเน็ตว่าการไหว้จิโซจะช่วยได้ ]

[ มีจิโซอยู่แถวนี้ด้วยเหรอ? ]

[ ฉ-ฉันลองไปทุกที่ที่นึกออกแล้ว ตอนนี้ก็เลยหาแถวสถานี ]

มิน่าล่ะ เธอถึงได้วนเวียนอยู่แถวนี้ เธอนี่จริงจังเรื่องนี้มากเกินคาดเลย...

[ ไว้จะลองมองหาดูตอนมีเวลาว่างแล้วกัน ]

[ ข-ขอบคุณนะ… ]

ตามคำแนะนำในวิดีโอ ผมใส่โซ่กลับเข้าที่ แล้วหมุนล้อจักรยานไปทิศตรงข้าม

โซ่ขยับเข้าที่พร้อมเสียงคลิกแน่น

[ เรียบร้อยแล้ว ]

[ ห-โหว ยอดเลย ]

ใช้เวลาประมาณ 10 นาที วิดีโอสอนออนไลน์นี่สุดยอดจริงๆ

[ โซ่ดูหลวมไปหน่อยนะ เธอน่าจะพาไปให้ร้านจักรยานตรวจดู ]
