เล่ม 6 บทที่ 2-6

พิธีจบการศึกษาเป็นไปอย่างราบรื่น

หลังจากที่คำกล่าวของท่านอาจารย์ใหญ่สิ้นสุดลง ก็มาถึงช่วงเวลาของการมอบประกาศนียบัตร

นักเรียนทุกคนไม่ได้ขึ้นไปบนเวที คนที่ขึ้นไปมีแค่ตัวแทนห้องเรียนเท่านั้น นักเรียนที่เหลือแค่ลุกขึ้นยืนและตอบรับเมื่อโดนเรียกชื่อ

ชื่อถูกเรียกไปทีละคน ทีละคน เวลาก่อนการจบการศึกษาก็เหลือน้อยลงทุกที

เสียงสะอื้นจากบรรดาผู้จบการศึกษาเริ่มดังขึ้นในอากาศ และบรรยากาศนั้นก็ดูเหมือนจะส่งผลให้นักเรียนรุ่นน้องเริ่มมีเสียงสูดน้ำมูกตามมาเช่นกัน

[ ยานามิจัง ไหวมั้ย? ] [ นี่ เอากระดาษทิชชูไป] [ แต่ห้ามกินนะ ]

...ยานามิกำลังร้องไห้หนักมาก

[ เฮ้อ ดันอินไปกับบรรยากาศเกินไปหน่อย ]

ฟืดดด... ยานามิใช้ทิชชูที่เพื่อนไปให้เช็ดจมูกของตัวเอง

ได้เห็นยานามิดูปกติแบบนี้ ทำให้ผมรู้สึกสบายใจขึ้นมานิดหน่อย

ขณะที่ผมตั้งใจฟังรายชื่อของนักเรียนผู้จบการศึกษาที่ถูกเรียก ก็พบว่าตอนนี้เป็นช่วงของนักเรียนครึ่งหลังของห้อง 3E

สองสมาชิกของชมรมวรรณกรรมปีสามอยู่ในห้องถัดไป คือห้อง 3F ดังนั้นชื่อที่ถูกเรียกในตอนนี้จึงไม่ได้มีความหมายอะไรสำหรับผม... แต่เดี๋ยวนะที่โดนเรียกเมื่อกี้...ใครชื่อ "พารุรุ" นะ ? อยากรู้จังว่าชื่อเขียนยังไง

เสียงของเธอก็น่ารักด้วย น่าเสียดายที่ไม่ได้เห็นเธอจากด้านหลัง...

ขณะที่ผมปล่อยความคิดล่องลอยไปถึง พารุรุ โยโดบาชิ ของห้อง 3E รายชื่อนักเรียนห้อง 3F ก็ถูกเรียกขึ้นมา

ชื่อที่คุ้นเคยปรากฏขึ้นมาพร้อมกับความรู้สึกบางอย่างในใจของผม

< ทามากิ ชินทาโร่ >

รุ่นพี่ทามากิ ลุกขึ้นเงียบๆ ตอบด้วยเสียงต่ำๆ ว่า "ครับ" แล้วก็นั่งลงทันที

ร่างสูงๆของเขากลมกลืนไปกับกลุ่มนักเรียนเมื่อเขากลับไปนั่ง

ผมพยายามยืดคอเพื่อมองหาเขา แต่รายชื่อก็ยังถูกเรียกต่อไป

แล้วอีกชื่อที่คุ้นเคยก็ดังขึ้น

< สึคิโนะกิ โคโตะ >

นักเรียนหญิงที่มัดผมสองข้างอย่างกระฉับกระเฉงลุกขึ้นยืน พร้อมตอบเสียงใสว่า "ค่ะ!" ด้วยน้ำเสียงที่อาจจะกระตือรือร้นเกินไปเล็กน้อย

หลังจากที่รุ่นพี่สึคิโนะกินั่งลง รายชื่อนักเรียนคนถัดไปก็ถูกเรียก

...และนั่นก็เป็นจุดสิ้นสุด

แน่นอนว่าพิธีจบการศึกษายังคงดำเนินต่อไป

แต่สำหรับพวกเขาทั้งสองคน ชีวิตมัธยมปลายและกิจกรรมทั้งหมดได้จบลงไปแล้ว เหลือเพียงตอนจบที่ต้องเฝ้าดูต่อไป

พิธีก็ยังคงดำเนินไปในลักษณะที่เรียบง่ายแต่ก็แฝงไปด้วยความเศร้า และก่อนที่ผมจะรู้ตัว คำกล่าวจากตัวแทนนักเรียนที่ยังเหลืออยู่ก็เริ่มขึ้น

ตัวแทนนักเรียนคนนี้คือ "โฮโคบารุ ฮิบาริ"

เสียงที่เปี่ยมไปด้วยจังหวะของเธอช่วยปรับบรรยากาศที่เครียดคลายลงเล็กน้อยในโรงยิม

ผมนึกถึงพิธีจบการศึกษาตอนม.ต้นเมื่อปีที่แล้ว ตอนนั้นมีนักเรียนที่ร้องไห้

ในตอนนั้น ผมมองพวกเขาด้วยสายตาที่ไร้ความรู้สึก

แต่ตอนนี้ ผมกลับเข้าใจความรู้สึกเหล่านั้นได้มากขึ้น

ความรู้สึกเหงาและไม่อยากแยกจากกัน... และยานามิก็ยังคงร้องไห้หนักเหมือนเดิม

ผมยิ้มแห้งกลบเกลื่อนความรู้สึกเศร้าของตัวเอง และอวยพรให้รุ่นพี่ในใจเงียบๆ

◇

พิธีจบการศึกษาผ่านพ้นไปอย่างราบรื่น โดยไม่สะทกสะท้านต่ออารมณ์ของผม

เมื่อพิธีเสร็จสิ้น เรากลับมายังห้องเรียน ไม่มีการเรียนการสอนในวันนี้ นี่จึงเป็นช่วงโฮมรูมครั้งสุดท้าย

แม้แต่อามานัตสึเซนเซที่ปกติร่าเริงสดใส วันนี้กลับดูหม่นหมองเล็กน้อย ขณะมองพวกเราไปรอบๆ

[ พิธีจบการศึกษาวันนี้ดีมากเลยนะ คำกล่าวของประธานนักเรียนคนปัจจุบันกับคำตอบของอดีตประธานก็ดูเหมือนจะถูกบีบ- เอ่อ ไม่สิ เตรียมตัวมาอย่างดี ไม่ใช่แค่การแสดง... ว่า มันน่าประทับใจจริงๆ ]

เก่งมากครับคลังคำศัพท์ของเซนเซ

การพูดติดๆ ขัดๆ ของอามานัตสึเซนเซยังคงดำเนินต่อไป

[ อันที่จริง วันนี้มีนักเรียนชายมาขอเบอร์ตั้งห้าคนแน่ะ นี่แสดงว่า ถ้าฉันเอาจริงขึ้นมา การหาแฟนนี่คงง่ายมากๆ ใช่มั้ยล่า ? สงสัยจังว่าทาคาซากะทำอะไรอยู่ ]

อามานัตสึเซนเซเหมือนหลุดไปในความฝันเกี่ยวกับช่วงเวลาที่เคยรุ่งเรือง แล้วจู่ๆ ใบหน้าของเธอก็หมองลง

[...เดี๋ยวนะ เด็กพวกนั้นชวนโคนุกิจังไปเที่ยวด้วย ไม่ใช่ว่าฉันเป็นแค่เหยื่อล่อเพื่อให้พวกเขาเข้าหาเธอหรอก…ใช่มั้ย ? ]

เมื่อความจริงที่หลบเลี่ยงเธอมาหลายปีปรากฏ อามานัตสึเซนเซทรุดตัวลงบนโต๊ะครู

[ ไม่แปลกใจเลยที่พวกเขาไม่ตอบรับตอนฉันชวนไปเดทกันแค่สองคน... ]

ห้อง 1C เงียบกริบ ขณะที่อามานัตสึเซนเซกำลังลิ้มรสความขมขื่นที่แทรกซึมอยู่ในความทรงจำแสนหวานของเธอ เสียงพูดคุยจากห้องถัดไปบอกว่าโฮมรูมของพวกเขาน่าจะจบแล้ว

เซนเซที่ยังคงซบหน้าลงกับโต๊ะ ยกมือขวาขึ้นโบกอย่างไร้เรี่ยวแรง

[ เอาล่ะ วันนี้จบแค่นี้ ถ้ามีเพื่อนที่กำลังจบการศึกษา ไปบอกลาให้เรียบร้อยด้วย และอย่าได้สร้างความทรงจำหวานชื่นเด็ดขาด! ]

แม้ในวันแบบนี้ อามานัตสึเซนเซก็ยังคงเป็นตัวของตัวเอง แต่เพื่อนร่วมชั้นที่ชินกับนิสัยของเธอก็ลุกขึ้นเตรียมตัวออกไปอย่างรวดเร็ว

ผมมองหายากิชิโอะ ก่อนจะเห็นเพียงแค่เธอที่รีบออกจากห้องไป

ผมไม่ได้จะตามเธอไป แค่ลังเลอยู่ตรงนั้นเท่านั้น ยานามิที่กลับมาเต็มพลังอีกครั้ง เดินเข้ามาหาผม

[ ฉันจะไปทักคนรู้จักแถวประตูทิศตะวันออกก่อนนะ เดี๋ยวจะไปที่ห้องชมรมทีหลัง โอเคมั้ย? ]

[ อืม เข้าใจแล้ว ]

ทางเดินที่มีต้นทิวลิปเรียงรายจากประตูทิศตะวันออกเป็นจุดถ่ายรูปที่นักเรียนที่จบการศึกษานิยมมาก...

รุ่นพี่ทามากิกับคนอื่นๆ น่าจะอยู่ที่นั่นตอนนี้ บางทีผมอาจจะลองไปดูบ้าง...

หลังจากส่งยานามิที่เดินไปพร้อมเพื่อนๆ ผมก็ลุกขึ้นตาม

ในตอนที่ผมเดินไปตามทางเดินที่แน่นขนัด ก็พบว่าตัวเองเดินข้างๆ กับนักเรียนชายคนหนึ่ง

ฮาคามาดะ โซสึเกะ เพื่อนสมัยเด็กของยานามิ และแฟนของฮิเมมิยะ คาเรน

[ นุคุมิซึ จะไปทางเดินต้นทิวลิปเหรอ? ]

[ คิดว่าน่าจะลองไปดู อาจได้แรงบันดาลใจเขียนนิยายบ้าง ]

[ สมเป็นสมาชิกชมรมวรรณกรรมจริงๆ แล้วอันนะได้เขียนอะไรบ้างหรือเปล่าล่ะ? ]

[ เขียนไปเยอะเลย นายยังไม่ได้อ่านเหรอ ฮาคามาดะ? ]

ฮาคามาดะยักไหล่แล้วยิ้มสดใส

[ เธอไม่อยากให้มันถึงหูครอบครัวผ่านฉันน่ะสิ ]

น่าสนใจดีแบบนี้ก็คงมีบ้าง

แน่นอนว่าการอ่านงานเขียนของคนในครอบครัวอาจจะรู้สึกแปลกๆ โดยเฉพาะถ้าเป็นนิยายของน้องสาว

กลุ่มนักเรียนหญิงวิ่งผ่านเราไปพร้อมเสียงกรรไกรคลิกๆ ขณะที่พวกเรากำลังคุยกัน

[ พวกนั้นทำอะไร? กำลังเริ่มก่อสงครามอะไรรึเปล่า? ]

[ เป็นการเอากระดุมเม็ดที่สองจากชุดนักเรียนที่จบการศึกษาน่ะ มันเป็นธรรมเนียมที่มีมานานแล้ว ]

[ เหมือนการดวลกันเพื่อเอากระดุมมาเลยแฮะ... ]

ผมไม่เคยรู้ว่าที่ซึวะบุกิมีธรรมเนียมที่เหมือนหลุดมาจากไลท์โนเวลแบบนี้ ฮาคามาดะหัวเราะก่อนจะโบกมือเบาๆ

[ กระดุมของชุดเราถูกเย็บติดกับแจ็คเก็ต เพราะงั้นถ้าใครอยากให้ ต้องเอากรรไกรมาตัดออก ]

ผมพยักหน้าเข้าใจเหมือนเพิ่งได้คำตอบว่าทำยังไงถึงเอากระดุมมาได้ คงจะอายน่าดูถ้าคนที่จบการศึกษาต้องถือกรรไกรไปด้วย

[ รู้มั้ย? เขาบอกว่าคู่รักที่จบการศึกษาจะแลกกระดุมเม็ดที่สองกับริบบิ้นที่สองกันด้วย ]

[ เดี๋ยวนะ ริบบิ้นที่สองคืออะไร? ]

[ ริบบิ้นที่สองก็คือริบบิ้นที่สองจากบนลงล่างไงล่ะ ฉันต้องมั่นใจว่าฉันจะได้แลกกับคาเรนในอีกสองปีข้างหน้า ]

ฮาคามาดะตอบเหมือนไม่มีอะไร

ริบบิ้นที่สองเป็นเรื่องที่คุ้นเคยกันสินะ? หรือว่าผมตกข่าว?

หลังจากที่กลุ่มนักเรียนหญิงถือกรรไกรวิ่งลับตาไป ฮาคามาดะก็ลดเสียงลงแล้วถาม

[ นี่ นุคุมิซึ ช่วงนี้มีอะไรเกิดขึ้นระหว่างนายกับยากิชิโอะหรือเปล่า? อันนะดูเป็นห่วงมากเลย ]

[ เอ่อ... ก็... ]

เธอเป็นห่วงถึงขนาดตามพวกเราตอรไปเดท และยังจัดฉากเป็นศาลจำลองในร้านอาหารครอบครัวอีก

นี่คงจะเป็นสิ่งที่เรียกว่า ‘มิตรภาพที่ไม่ธรรมดา’ ระหว่างสาวแนวกีฬาอย่างยากิชิโอะกับสาวแนวยานามิ

[ การเป็นที่รู้จักก็มีปัญหาของมันเอง นายในฐานะแฟนของฮิเมมิยะซังก็น่าจะเข้าใจใช่มั้ย? ]

ผมตอบกลับไป ก่อนจะมองลงไปยังทางเดินต้นทิวลิปจากหน้าต่างทางเดิน

ฝูงชนที่กำลังปะปนกันระหว่างนักเรียนที่จบการศึกษาและนักเรียนปัจจุบันทำให้ยากที่จะมองหาคนที่ผมรู้จัก

สายตาผมจับจ้องไปยังเด็กสาวคนหนึ่งที่แอบอยู่หลังต้นไม้ ผมสั้นและรูปร่างเพรียวบางของเธอทำให้ผมจำได้ทันที... ยากิชิโอะ?

ขณะที่ผมหยุดมอง เด็กสาวอีกคนก็เดินเข้าหาเธอจากข้างหลัง — รุ่นพี่สึคิโนะกิ

◇

...ตลอดสามปีที่ผ่านมา เธอเดินไปตามทางที่เรียงรายไปด้วยต้นทิวลิป

สึคิโนะกิ โคโตะ เป็นนักเรียนห้องปีสามห้องF แห่งโรงเรียนมัธยมปลายซึวะบุกิ เธอเงยหน้าขึ้นมองกิ่งก้านของต้นทิวลิปผ่านแว่นตาของเธอ

กิ่งไม้ที่ไร้ใบอย่างสิ้นเชิงในขณะนี้เริ่มเผยให้เห็นถึงชีวิตใหม่ที่กำลังจะผลิบาน

เธอจะออกจากโทโยฮาชิไปก่อนที่ดอกตูมเหล่านี้จะเบ่งบานเต็มที่

แม้เธอจะยังนึกภาพชีวิตใหม่ไม่ออก แต่สิ่งหนึ่งที่เธอมั่นใจคือ ชินทาโร่จะอยู่เคียงข้างเธอ
