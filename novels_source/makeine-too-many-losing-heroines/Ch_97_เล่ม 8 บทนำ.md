เล่ม 8 บทนำ

หลังเลิกเรียน ณ ห้องสมุดโรงเรียนมัธยมสึวะบุกิ

ผมละสายตาจากหนังสือในมือลง และเหยียดตัวบิดขี้เกียจอยู่ด้านหลังเคาน์เตอร์ยืมหนังสือ

ปลายเดือนพฤษภาคม หลังจากสอบปลายภาค ห้องสมุดก็เงียบสงบอย่างเห็นได้ชัด

[ วันนี้ไม่มีแขกเลยแฮะ ]

[ กะ...ก็ดีแล้วนี่ จะได้ไม่ต้องพูดอะไรมาก ]

เสียงตอบกลับมาจากด้านข้างโดยที่เจ้าตัวไม่ได้ละสายตาจากหนังสือเลยก็คือ โคมาริ จิกะ รองประธานชมรมวรรณกรรม

วันนี้พวกเราช่วยงานเป็นเวรประจำห้องสมุดด้วยกันสองคน

──ผ่านมาเดือนหนึ่งตั้งแต่ชมรมวรรณกรรมรุ่นใหม่ได้ถือกำเนิดขึ้น

หลังจากหลุดพ้นจากสถานะงดทำกิจกรรมชั่วคราวในที่สุดพวกเราก็ได้กลับมาเริ่มกิจกรรมอีกครั้ง และจนถึงตอนนี้ก็ยังคงสงบสุขเกินคาด

จะว่าไป ช่วงที่ชมรมโดนระงับนั่นแหละ ที่ผมต้องเจอกับนรกของจริง—เพราะทุกคนใช้บ้านผมเป็นห้องชมรมแทน

ใครที่คิดว่าผมพูดเกินจริง ลองนึกถึงความรู้สึกของเด็กหนุ่มม.ปลายที่หนังสือสะสมลับๆ หลังชั้นถูกหมุนเวียนให้นักเรียนหญิงอ่านต่อกันดูสิ

แต่ตอนนี้ ช่วงเวลาที่น่าอับอายนั่นก็ผ่านไปแล้ว ผ่านไปแล้วจริงๆ...

ผมเปิดหนังสือสารานุกรมนกอย่างสบายใจ

[ โคมาริ รู้มั้ยว่าเหยี่ยวฟอลคอน จริงๆ แล้วมันเป็นญาติกับนกแก้วนะ ]

[ อ๊ะ...ไอ้บ้า หัวนายกลายเป็นนกแก้วไปแล้วรึไง ]

ปกติเธอก็เงยหน้าขึ้นมาตอบแบบนี้แหละ

ผมยักไหล่อย่างเหนื่อยหน่ายแล้วเลื่อนสารานุกรมไปตรงหน้าโคมาริ

[ จริงๆ นะ การวิเคราะห์ DNA ล่าสุดพิสูจน์มาแล้ว ]

[ เอ๋...จริงด้วย ]

เห็นมั้ยล่ะ ผมไม่ได้พูดลอยๆ หรอกนะ เชื่อใจกันบ้างสิ

ขณะที่ส่องดูหนังสืออยู่ โคมาริก็พึมพำเบาๆ

[ มะ...ไม่คิดว่านายจะสนใจนกอะไรแบบนี้ด้วย ]

[อ่า ก็คิดว่าอยากลองมีงานอดิเรกกลางจ้างหมือนวัยรุ่นทั่วไปดูบ้าง ]

[มะ...ไม่เข้าใจ แล้วทำไมต้องนกด้วย? ]

[ ก็นกไม่จำเป็นต้องมองเห็นตัวมันก็สนุกได้ แค่ฟังเสียงร้องก็พอ...อย่างอาจารย์ทานากะน่ะ ถึงขั้นแค่ได้ยินเสียงก็เดาได้เลยว่าอยู่ตรงไหน—ไม่ต้องเห็นตัวจริงก็ยังได้ ]

[ นั่นมันไม่ใช่งานอดิเรกสำหรับวัยรุ่นแล้วล่ะมั้ง... ]

หา? ไม่ใช่เหรอ? แต่พวกมันอยู่ข้างนอกนะ

[ โรงเรียนเรายังมีชมรมส่องนกเลยนะแบบนั้นก็น่าจะถือว่าเป็นงานอดิเรกของวัยรุ่นได้ ]

[ อะ...อ๋อ ชมรมนั่นเขาไม่ได้ส่องนกแค่นกน่ะสิ ก็เลยโดนพักกิจกรรมแบบไม่มีกำหนดไง ]

จะว่าไปก็เหมือนจะเข้ากับคำว่าวัยรุ่นอยู่หรอก...

โคมาริดันหนังสือกลับมาให้ผม แล้วแอบชำเลืองมองผมจากหางตา

[ มะ...ไม่ใช่อะไรหรอก แต่พักนี้ยัยนั่นยังมาอยู่มั้ย? ร...รุ่นน้องปีหนึ่งคนใหม่นั่นน่ะ ]

อ่า? หมายถึงชิราทามะสินะ?

[ ก็แทบจะมาทุกวันเลยมั้ง อยู่ตลอดเวลานั่นแหละ ]

[ เอ๋?! มะ...มาทุกวันเหรอ? ]

[ หือ? ชิราทามะอยู่ที่ห้องชมรมทุกวันนะ เธอก็น่าจะรู้อยู่แล้วไม่ใช่เหรอ? ]

[ ปะ-ไปตายซะ ]

ทำไมผมถึงโดนด่าเนี่ย...

จะว่าไปก็ ตอนที่หมดสถานะงดทำกิจกรรมชั่วคราวใหม่ๆ ยัยนั่นยังบุกมาที่บ้านผมอยู่เลย แล้วก็โดนคาจูไล่กลับไปหน้าประตูแบบไม่ไว้หน้าเลยด้วย อยากให้สองคนนั้นสนิทกันให้มากกว่านี้หน่อยจริงๆ...

หลังจากเหตุการณ์วุ่นวายที่งานแต่งงานจบลง ชิราทามะก็กลายเป็นสมาชิกประจำของชมรมวรรณกรรมอย่างสมบูรณ์

ยานามิก็ถูกขนมหวานปราบไปเรียบร้อย ส่วนยากิชิโอะก็ยังเป็นยากิชิโอะเหมือนเดิม

โคมาริที่ผมเป็นห่วงที่สุด ก็สามารถพูดคุยกับชิราทามะได้ถึงสองคำถ้าอารมณ์ดี

ตัวชิราทามะเอง ผมเห็นบางครั้งก็ยืนคุยกับอาจารย์ทานากะอยู่ตรงทางเดิน

ถ้าไม่รู้เรื่องราวเบื้องหลัง หลายๆคนคงคิดว่าเป็นแค่นักเรียนกับคุณครูที่ดูสนิทกันดีเท่านั้น

ไม่มีใครคิดหรอกว่าเธอคือแมวขโมยที่พยายามแย่งพี่เขยจากพี่สาวแท้ๆ-

จังหวะนั้นเอง มีใครบางคนยื่นหนังสือมาที่เคาน์เตอร์ที่ผมนั่งอยู่ แสดงว่ายังมีแขกอยู่

ชื่อหนังสือที่ผมหยิบมาดูคือ < เริ่มต้นใส่ใจชีวิตตนเองด้วยสมุนไพรจีน >

ชื่อบนบัตรยืมคือ—เทียร่า บาโซริ

[ เอ่อ...ขอยืมเล่มนี้ค่ะ ]

[ อ๊ะ ได้เลยครับ ]

รองประธานนักเรียนหญิง กับทรงผมรวบตึงที่เป็นเอกลักษณ์

ดูจากภายนอกก็เป็นคนจริงจังแบบสุดๆ แต่เอาจริงๆ แล้วผมว่าเธอแปลกนิดหน่อยนะ

ระหว่างที่ผมกำลังดำเนินการ เทียร่า บาโซริ ก็ยืนมองไปรอบๆ อย่างกระสับกระส่าย

[ เอ่อ เสร็จแล้วครับ ]

[ หือ? อ๋อ ขะ...ขอบคุณค่ะ ]

แม้จะรับหนังสือไปแล้ว เธอก็ยังยืนอยู่ตรงนั้นไม่ยอมไปไหน

[ กำลังหาเล่มอื่นอยู่เหรอ? ]

[ เอ่อ คือวันนี้...ฉันมีเรื่องจะคุยกับนุคุมิซึซังค่ะ ]

[ หืม? ]

เทียร่ามองโคมาริที่ยืนนิ่งสนิทอยู่แวบหนึ่ง แล้วกระแอมเบาๆ

[ นุ...นุคุมิซึซัง! ฉันมาเพราะมีเรื่องจะขอร้องค่ะ! ]

[ หา? ]

[ ………… ]

แล้วจะเงียบทำไมล่ะ...

โคมาริเตะผมเบาๆ ใต้เคาน์เตอร์ ผมเลยจำใจต้องพูดขึ้น

[ เอ่อ...เรื่องขอร้องนั่นคืออะไรเหรอ? ]

[ อะ ใช่ค่ะ! เอ่อ ขอร้องก็คือว่า...คือว่า ฉัน...ไม่ได้หมายความว่าแบบนั้นนะคะ คือหมายถึง...ฉันอยาก...อ๊ากกก! ]

เทียร่าก้มตัวลงแล้วฟาดฝ่ามือลงบนเคาน์เตอร์ดังปัง

[ ก็คือว่า ฉัน──ต้องการตัวคุณค่ะ! ]

…ว่าไงนะครับ?

ผมหันไปพูดกับเทียร่าที่กำลังหอบหายใจอย่างหนัก ด้วยน้ำเสียงนิ่งเรียบ

[ คือ...เทียร่าซัง ตอนนี้ผมอยู่เวรที่ห้องสมุด รอให้หมดเวรก่อนจะได้มั้ย ? ]

[ ...คะ เข้าใจแล้วค่ะ งั้นฉันจะรอ และอีกอย่าง—อย่าเรียกฉันด้วยชื่อจริงสิคะ ]

เทียร่าโค้งศีรษะเล็กน้อย แล้วเดินไปนั่งที่เก้าอี้ใกล้ๆ เคาน์เตอร์ พร้อมกับเปิดหนังสืออ่าน

ผมถอนหายใจเบาๆ แบบไม่ให้ใครได้ยินขณะมองเธอ

…เฮ้อ ดูท่าจะมีเรื่องวุ่นๆ เริ่มต้นขึ้นอีกแล้วล่ะ

แล้วอีกอย่าง โคมาริ อย่าเตะผมใต้เคาน์เตอร์ได้มั้ย
