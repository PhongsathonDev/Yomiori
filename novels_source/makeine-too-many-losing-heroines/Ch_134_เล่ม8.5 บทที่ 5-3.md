[ นุคจัง อ้ามมมม ]

[ ค่ะ อ้ามม ]

คาจูรับช้อนที่กอนจังยื่นให้เข้าปาก

พอเลียเศษไข่ที่ติดอยู่ตรงมุมปากแผล็บๆ คาจูก็พยักหน้าหงึกๆ

[ กอนจังฝีมือพัฒนาขึ้นนะเนี่ย ความนุ่มฟูระดับนี้แม้แต่คาจูก็ทำไม่ได้เลยนะ ]

[ จะให้ทำให้กินอยู่ฝ่ายเดียวได้ไงล่ะ นุคจัง อ้ามมมม ]

กอนจังตักข้าวห่อไข่ขึ้นมาอีกช้อน แล้วยื่นไปที่ปากของคาจู

[ กอนจังไม่กินเหรอ? ]

[ วันนี้เป็นวันตามใจนุคจังนี่นา กินอีกสิ? ]

[ อื้ม จะยอมให้ตามใจอีกนะ ]

งั่ม งั่ม

กอนจังมองดูคาจูเคี้ยวตุ้ยๆ อย่างมีความสุข พลางกินข้าวห่อไข่เข้าไปคำหนึ่ง

ข้าวห่อไข่นุ่มฟูที่ซุ่มซ้อมมาประสบความสำเร็จอย่างงดงาม แบบนี้ไม่ว่าจะทำให้ใครกินก็คงไม่น่าอายแล้วล่ะ

คาจูมองกอนจังที่แก้มคลายยิ้มออกมาด้วยสายตาเหมือนรู้ทัน

[ เอ๊ะ? หรือว่านี่ เป็นการซ้อมเพื่อให้ใครบางคนกินรึเปล่านะ ]

[ ………… ]

กอนจังดึงแก้มของคราจูจากทั้งซ้ายและขวาอย่างเงียบเชียบ ยืดดด

[ กอนจัง ไหนบอกว่าจะตามใจงายยยー ]

[ ถึงจะตามใจแต่ก็มีขอบเขตนะ ]

หลังจากเพลิดเพลินกับแก้มของคาจูสักพัก กอนจังก็ปล่อยมือพลางหัวเราะ

[ วันเกิดแท้ๆ ไม่ซื้อเค้กมาจะดีเหรอ? ]

[ เอะเฮะเฮะ วันนี้ท่านพี่จะอบเค้กให้น่ะสิ เก็บไว้รอตื่นเต้นทีเดียวไง ]

กอนจังมองใบหน้าที่มีความสุขของคาจูู

ที่ผ่านมา ของขวัญวันเกิดของคาจู คือการที่ท่านพี่อยู่ด้วยกันทั้งวัน

แต่ปีนี้กลับแยกกันทำกิจกรรม แถมท่านพี่ยังท้าทายการทำขนมซึ่งเป็นอาณาเขตของคาจูอีกต่างหาก

──นุคุมิซึ คาจู อายุ 15 ปี

เพื่อนที่ในใจเคยมีแต่เรื่องของท่านพี่จนเต็มปรี่ กำลังค่อยๆ เปลี่ยนไปทีละน้อย

บางทีคนที่เปลี่ยนไปก่อนอาจจะเป็นท่านพี่และคาจูอาจจะจำใจต้องเปลี่ยนตามก็ได้

แต่ว่าคาจู ไม่แสดงท่าทีแบบนั้นออกมาเลยแม้แต่น้อย......

[ ท่านพี่พยายามจะหลอกถามเค้กที่คาจูชอบแบบเนียนๆ ความไม่เอาไหนตรงนั้นก็น่ารักดีนะ แค่ดูประวัติการค้นหากับตารางงานก็รู้เรื่องเซอร์ไพรส์หมดเปลือกแล้ว แต่ก็คิดว่าจะแกล้งตกใจยังไงดีนะมาตั้งแต่เมื่อวานแล้ว── ]

กอนจังมองคาจูที่พูดไปเรื่อยๆ อย่างสนุกสนาน แล้วส่ายหน้าเบาๆ

──อยากให้เป็นนุคจังคนเดิมต่อไปอีกสักหน่อยจังเลยนะ

กอนจังตักข้าวห่อไข่ด้วยช้อน แล้วป้อนใส่ปากของคาจูที่ยังคงพูดไม่หยุด

◇

ผมใช้ถุงมือกันความร้อนจับแม่พิมพ์สปันจ์เค้ก แล้วนำเข้าเตาอบที่วอร์มไว้ที่ 170 องศา

พอปิดประตูแล้วตั้งเวลา ที่เหลือก็แค่รอ

คุณแม่ยากิชิโอชะโงกมองผ่านกระจกเตาอบแวบหนึ่ง แล้วหันกลับมาหาพวกเรา

[ เอาล่ะ ระหว่างนี้มาเตรียมครีมกันเถอะ ]

คุณแม่ยากิชิโอแบ่งงานให้อย่างคล่องแคล่ว

ขณะที่กำลังถูกห้อมล้อมด้วยความอุ่นใจของภรรยาชาวบ้าน ผมก็สังเกตเห็นยานามิกำลังจ้องเขม็งไปที่กล่องวิปครีม

[ อันนั้น จะใช้นะอย่าดื่มเชียว ]

[ ไม่ดื่มหรอก แค่คิดว่าเป็นวิปครีมของจริงสิน้าเฉยๆ ]

เอ๊ะ ครีมมีของปลอมด้วยเหรอ หรือว่าวิปครีมที่ผมคิดว่าเป็นวิปครีมมาตลอด คือหอยเม่นสีขาวหรือน้ำคั้นจากสัตว์กันแน่......?

ขณะที่กำลังหวาดกลัวกับสิ่งที่ยังไม่รู้ ชิราทามะซังก็ช่วยเก็บผ้าเช็ดจานที่ตกพื้นให้

[ มีวิปครีมที่ทำจากน้ำมันพืชอยู่ด้วยค่ะ ราคาถูกกว่าครึ่งหนึ่ง เลยใช้ได้สะดวกกว่าน่ะค่ะ ]

[ เหรอ งี้นี่เอง อะ ขอบใจนะ ]

[ นั่นแหละค่ะ ฮึบ เช็ดมือให้ประธานซะเลย ]

ถูๆๆ ไม่รู้ทำไมชิราทามะซังถึงมาเช็ดมือผม

[ ......ทั้งสองคนช่วยกันทำงานหน่อยเถอะ เอาล่ะ จะตีวิปครีมแล้วนะ ]

[ ยานามิซัง ทำไมขนมปังแผ่นถึงเหลือแผ่นเดียวแล้วล่ะ ]

[ เพราะวันหมดอายุคือวันนี้ ก็เลยต้องรีบกินน่ะสิ ]

[ ปกติไม่เห็นจะสนใจเรื่องพวกนั้นเลยนี่ ]

ยานามิส่ายนิ้ว จุ๊ๆๆ

[ นุคุมิซึคุง วันควรบริโภคก่อนกับวันหมดอายุมันต่างกันนะ วันหมดอายุมันแบบว่า เข้มงวดกว่าน่ะ ]

งั้นเหรอ สนใจยานามิไปก็ช่วยไม่ได้ ทำงานของตัวเองดีกว่า......

ระหว่างที่กำลังเตรียมสตรอว์เบอร์รี คุณแม่ยากิชิโอะที่ล้างจานอยู่ก็มองนาฬิกาบนผนัง

[ อุ๊ย ป่านนี้แล้วเหรอเนี่ย ทุกคนจะกินข้าวเที่ยงกันไหม? ]

[ ไม่ครับ จะให้รบกวนขนาดนั้น── ]

[ ค่า ! ทานค่า~! ]

ยานามิตอบรับอย่างร่าเริง

เป็นภาพที่เคยเห็นที่ไหนสักแห่ง แค่ไม่โดนผลักล้มลงไปก็ถือว่าดีแล้วล่ะมั้ง

คุณแม่ยากิชิโอะหัวเราะคิกคักพลางเช็ดมือด้วยผ้าขนหนู

[ ไม่ต้องเกรงใจหรอกจ้ะ มีโซเมนที่ได้มาอยู่ เดี๋ยวต้มให้กินนะ ]

[ โซเมน── ]

รอยยิ้มของยานามิแข็งค้าง ผ่านไปหนึ่งปี แผลใจก็ยังไม่เยียวยาสินะ

ข้างๆ คุณแม่ยากิชิโอะที่เตรียมอาหารกลางวัน ยานามิกำลังคนวิปครีมด้วยแววตาปลาตาย

......ยานามิ จะเลียวิปครีมเท่าไหร่ก็ได้นะ

◇

ตอนที่ยานามิกินโซเมนกำที่ 6 หมด สปันจ์เค้กก็อบเสร็จพอดี

ปาดครีม วางสตรอว์เบอร์รีลูกสุดท้ายลงไปก็เป็นอันเสร็จสมบูรณ์

ถอยออกมาเล็กน้อยเพื่อเช็คสมดุลโดยรวม ปรับองศาของสตรอว์เบอร์รีนิดหน่อย

[ เยี่ยม──ประมาณนี้ละมั้ง ]

ในที่สุดเค้กก็เสร็จสมบูรณ์ พอพยักหน้าอย่างพอใจ ยานามิกับชิราทามะซังก็ปรบมือแปะๆ

[ สุดยอดเลย ! น่ากินมากๆ! ]

[ สมแล้วที่เป็นประธานค่ะ」

[ อ่า ทำออกมาได้ดีจริงๆ ]

ระดับความฟูของเนื้อเค้ก ความแข็งของวิปครีมและการตกแต่ง ไม่น่าเชื่อเลยว่าเป็นฝีมือของคนที่ทำครั้งแรก นี่ต้องเป็นเพราะฝีมือของภรรยาชาวบ้านแน่ๆ

[ ทำออกมาดีมาก......น่ากินจริงๆ...... ]

[ นั่นสินะ ยานามิซังห้ามกินนะรู้ไหม? ]

ขณะที่ดึงตัวยานามิที่ขยับเข้าไปใกล้เค้กโดยไม่รู้ตัวออกมา คุณแม่ยากิชิโอะก็เริ่มเรียงวัตถุดิบที่เหลือ

[ เหลือเยอะเลยนะเนี่ย จะให้ห่อกลับไปเลยไหม? ]

[ เป็นวัตถุดิบสำรองครับ ถ้าไม่รังเกียจช่วยรับไว้เถอะครับ ]

[  จะดีเหรอ? งั้นมาอบเค้กอีกก้อนกันเถอะ ทุกคนจะกินใช่ไหม ]

[ ค่ะ แน่นอนค่ะ! ]

ยานามิตอบรับด้วยเสียงอันยอดเยี่ยม แล้วเริ่มเตรียมทำเค้กก้อนที่สองกับชิราทามะซัง

ผมมองดูภาพนั้นด้วยหางตา พลางเก็บเค้กที่เสร็จแล้วลงกล่อง

[ ──น้องสาว คงจะดีใจนะจ๊ะ ]

คุณแม่ยากิชิโอะที่มายืนข้างๆ ตั้งแต่เมื่อไหร่ไม่รู้เอ่ยทัก

[ ครับ ปกติมีแต่ฝ่ายได้รับการดูแล นานๆ ทีก็อยากจะตอบแทนบ้างน่ะครับ ]

[ น้องสาวเรียนที่โมโมโซโนะเหมือนนากิสินะ เป็นพี่น้องสองคนเหรอ? นุคุมิซึคุงเป็นลูกชายคนโต? ]

[ อ๊ะ ครับ ใช่ครับ ]

[ วิเศษไปเลยนะ อยากให้ลูกบ้านฉันมีพี่ชายแบบนุคุมิซึคุงจัง คุณพ่อคุณแม่ทำงานอะไรกันเหรอ? มีโยกย้ายไปทั่วประเทศบ้างไหม? ]

คุณแม่ยากิชิโอะรุกหนักน่าดูแฮะ

งไม่รู้ทำไม แต่ไอ้นี่คงเป็นสิ่งที่เรียกว่าการสนทนาตามประสาภรรยาชาวบ้านสินะ

[ พ่อแม่เป็นพนักงานบริษัทธรรมดาครับ ถึงจะย้ายงานก็น่าจะอยู่ภายในจังหวัดนะครับ ]

[ อย่างนี้นี่เอง ช่วงนี้อากาศร้อนขึ้น สามีฉันความดันสูงอยู่ด้วยเลยเป็นห่วงน่ะ ครอบครัวนุคุมิซึคุงมีใครป่วยบ้างไหม? มีโรคประจำตัวรึเปล่า? ]

[ หา ที่บ้านผมทุกคนแข็งแรงเกินเหตุเลยครับ ]

[ แหม วิเศษจัง ]

......อะไรกันบทสนทนานี้ คุณแม่ยากิชิโอะ ทำไมถึงถามเรื่องครอบครัวผมขนาดนี้เนี่ย ตอนที่เล่าโปรไฟล์ของตระกูลนุคุมิซึจนครบ ประตูห้องนั่งเล่นก็เปิดออกอย่างแรง

[ กลับมาแล้ว! กลิ่นหอมจังเลยเนอะー ]

ลูกสาวคนโตบ้านยากิชิโอะ กลับมาแล้ว เธอเช็ดเหงื่อที่ไหลพลางชะโงกหน้าเข้ามาในครัว

[ อ้าว จะทำกันตอนนี้เหรอ? ]

ยานามิถือเนยไว้ในมือ แล้วยิ้มกว้าง

[ เลม่อนจัง ที่จะทำต่อจากนี้คือของแถมต่างหาก กินได้ไม่อั้นเลยนะ ]

[ รุ่นพี่ไม่มาทำด้วยกันเหรอคะ? ]

พอชิราทามะชวนซัง ยากิชิโอะก็ทำหน้าดีใจ

[ ดีเลย ฉันก็อยากทำ! ]

คุณแม่ยากิชิโอะวางผ้าขนหนูลงบนหัวของยากิชิโอที่กำลังจะยื่นมือเข้ามา

[ เลม่อน เช็ดเหงื่อแล้วไปเปลี่ยนเสื้อผ้าให้เรียบร้อยก่อนสิลูก ]

[ ค่าー นุคคุง รอเดี๋ยวนะ ]

[ ไม่ล่ะ ผมจะกลับแล้ว]

[ เอ๋ー อยู่ต่ออีกนิดสิ ]

ไม่รู้ทำไมยากิชิโอะถึงขยิบตาให้ผม ก่อนจะเดินออกจากห้องนั่งเล่นไป ร่าเริงเหมือนเดิมเลยนะ

ขณะที่กำลังชื่นชมและเอาถุงใส่กล่องเค้ก คุณแม่ยากิชิโอะก็กระซิบเสียงเบากับผม

[ ขอโทษนะ ปกติเด็กคนนี้จะเรียบร้อยกว่านี้น่ะ เห็นแบบนั้นแต่ก็มีความเป็นแม่บ้านแม่เรือน คิดว่าน่าจะเป็นเจ้าสาวที่ดีได้นะ ]

[ อา งั้นเหรอครับ ]

คงตอบได้แค่นั้น จะว่าไปยากิชิโอะทำอาหารเป็นด้วยเหรอ ได้ยินว่าตอนเข้าค่ายเมื่อปีก่อนทำไฟลามตอนบาร์บีคิวจนเกือบเกิดโศกนาฏกรรมนี่นา......

ผมฟังเรื่องที่คุณแม่ยากิชิโออวยลูกสาวไม่หยุด พลางจินตนาการถึงชีวิตครอบครัวกับยากิชิโอะอย่างเหม่อลอย

◇

ระหว่างทางกลับจากบ้านยากิชิโอะ ไม่รู้เป็นครั้งที่เท่าไหร่แล้ว ที่ผมส่งสายตาไปยังกล่องเค้กที่ถืออยู่ในมือ

ภาพใบหน้าตกใจของคาจูตอนเห็นเค้กทำเองลอยขึ้นมา

ขณะที่กำลังเดินอย่างระมัดระวังเพื่อไม่ให้มันเขย่า ก็ได้ยินเสียงฝีเท้าของใครบางคนวิ่งเข้ามาจากด้านหลัง

[ ท่านพี่ กลับมาแล้วเหรอคะ? ]

[ ความลับ แล้วคาจูไปข้างนอกกับใครมาล่ะ? ]

[ งั้นของคาจูก็ความลับค่ะ ]

คิดไปเองรึเปล่านะ ว่ารอยยิ้มไร้เดียงสานั้นดูเป็นผู้ใหญ่ขึ้นนิดหน่อย

ผมมองลงไปเห็นเครื่องประดับผมรูปดอกไม้ติดอยู่ที่ผมสีดำของคาจู

[ เครื่องประดับผมนั่น น่ารักดีนะ]

พอทักออกไปเฉยๆ คาจูก็เงยหน้ามองด้วยใบหน้าเปี่ยมสุข

[ ค่ะ กอนจังให้เป็นของขวัญวันเกิดค่ะ! ท่านพี่เนี่ย ถ้าเป็นเรื่องของคาจูละก็รู้ไปหมดทุกอย่างเลยนะคะ!  ]

[ เห ไปเที่ยวกับกอนโด ซังมาสินะ ]

พอความลับแตก คาจูก็ทำปากยื่นอย่างจงใจ

[ ท่านพี่ ขี้แกล้งค่ะ ]

[ โทษที โทษที ]

พอผมหัวเราะขอโทษ คาจูก็ยื่นมือมา

[ งั้นถ้าจูงมือ จะยอมยกโทษให้ก็ได้ค่ะ ]

มามุกนี้ปฏิเสธไม่ได้แฮะ พอกุมมือไปตามตรง คาจูก็หัวเราะ เอะเฮะเฮะ

[ ยอมยกโทษให้ค่ะ ท่านพี่]

[ อืม ขอบใจนะ ]

จูงมือกัน เดินกลับบ้านพลางหัวเราะไปด้วยกันสองคน

คาจูเป็นนักเรียนเตรียมสอบ ผมเองก็กลับดึกเพราะชมรมวรรณกรรมบ่อยขึ้น

สักวันหนึ่ง การได้มาฉลองวันเกิดด้วยกันแบบนี้ก็คงจะไม่มีอีกแล้ว

ดูเหมือนวันนี้จะไปเที่ยวบ้านกอนโดซังมา แต่อีกไม่นาน──

ผมมองคาจูที่ฮัมเพลงอยู่ข้างๆ แล้วพึมพำในใจ

ยังไงซะการมีแฟนก็ยังเร็วไปสำหรับคาจู
