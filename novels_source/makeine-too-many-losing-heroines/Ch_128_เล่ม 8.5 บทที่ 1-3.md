ภายในห้องสมุดโรงเรียนสึวะบุกิเนืองแน่นไปด้วยเหล่านักเรียนที่มาติวหนังสือสอบ

นักเรียนหญิงคนหนึ่งเดินเข้ามาพร้อมกระเป๋าและกล่องใส่แมลง เธอนั่งลงที่โต๊ะตัวที่ว่างอยู่ก่อนจะบิดขี้เกียจขนานใหญ่

[ เอาละ พยายามเข้าตัวเรา ]

ขณะที่เธอกำลังรื้อของในกระเป๋า ก็มีใครบางคนมานั่งลงข้างๆ เธอคนนั้นคือ โคมาริ นั่นเอง

[ ! ]

โคมาริคว้าชายเสื้อของยากิชิโอะที่กำลังจะลนลานลุกขึ้นเอาไว้

[ นะ... นั่งลง ]

[ ......จ้า ]

ยากิชิโอะยอมนั่งลงแต่โดยดี ก่อนจะเอ่ยปากถามอย่างกล้าๆ กลัวๆ

[ ......โคมาริจังก็มาตามจับฉันด้วยเหมือนกันเหรอ? ]

[ ตะ... ตามหาอยู่ก็จริง แต่ไม่ได้จะมา... จับ ]

โคมาริเริ่มกดสมาร์ทโฟนของตัวเองโดยไม่พูดอะไร

ยากิชิโอะมองหน้าโคมาริจากทางหางตาด้วยความรู้สึกอึดอัด

[ คือฉันน่ะ ตั้งใจว่าจะติวสอบจริงๆ แล้วนะ สำนึกผิดแล้วด้วยล่ะ? ]

[ ระ... รู้อยู่แล้วล่ะน่า ]

กริ๊ง เสียงแจ้งเตือนจากสมาร์ทโฟนของยากิชิโอะดังขึ้น

[ สะ... ส่งเอกสารสรุปเนื้อหาที่ต้องเตรียมสอบครั้งนี้ไปให้แล้วนะ ]

[ เห? โคมาริจังเป็นคนทำให้เหรอ? ]

[ จะ... จริงๆ ฉันก็อยากทำเองหรอกนะ แต่ฉันยังไม่เข้าใจเนื้อหาพอที่จะสอนคนอื่นได้ เพราะงั้น... ]

คราวนี้เป็นฝ่ายโคมาริที่หลบสายตาด้วยความเขินอาย

[ ละ..เลยไปขอให้... อายาโนะ มิตสึกิ... ช่วยทำให้น่ะ ]

[ ──มิตสึกิเหรอ?! ]

ยากิชิโอะคว้าไหล่โคมาริที่ยังคงหลบสายตาแล้วยื่นหน้าเข้าไปจ้องอย่างแรง

[ โคมาริจัง เป็นเพื่อนกับมิตสึกิตั้งแต่เมื่อไหร่เนี่ย?! ]

[ ปะ... เปล่า เพิ่งเคยคุยกันวันนี้ครั้งแรกนี่แหละ ]

คนขี้อายอย่างโคมาริเนี่ยนะ ไปขอร้องนักเรียนชายที่แทบจะแค่รู้จักหน้าค่าตากันเฉยๆ

ท่ามกลางยากิชิโอะที่ตกใจจนพูดไม่ออก โคมาริก็พึมพำต่อไป

[ กะ... ก็หมอนั่นเคยติวหนังสือให้เธอมาก่อนไม่ใช่เหรอ ]

[ ......อืม ]

ถึงจะเป็นช่วงเวลาที่ยากลำบาก แต่ก็เป็นวันคืนที่สำคัญมากเช่นกัน

ยากิชิโอะนิ่งเงียบพลางเปิดดูเอกสารที่ส่งมาในสมาร์ทโฟน

ข้างในนั้นมีตั้งแต่ตารางเช็คระดับความเข้าใจ แผนภาพแสดงความคืบหน้า ไปจนถึงการสรุปวิธีการเรียนตามลำดับขั้นตอนอย่างละเอียด

[ เพิ่งไปขอร้องมิตสึกิวันนี้เองไม่ใช่เหรอ? ทำไมถึงมีเอกสารละเอียดขนาดนี้ได้ล่ะ? ]

[ มะ..หมอนั่นบอกว่า..เตรียมเผื่อไว้แล้ว...ผะ..เผื่อว่าจะมีเหตุการณ์แบบนี้เกิดขึ้น... น่ะ ]

โคมาริขมวดคิ้วพลางกระซิบเสียงเบา

[ มะ... หมอนั่น สติยังดีอยู่ใช่ไหม ]

พอเห็นสีหน้าเป็นกังวลของโคมาริ ยากิชิโอะก็เผลอหลุดขำออกมา

[ มิตสึกิ ก็มีมุมแบบนั้นบ้างแหละ ]

──ใช่แล้ว อายาโนะ มิตสึกิ คือผู้ชายแบบนั้นแหละ

ชอบเอาใจใส่ กังวลล่วงหน้าเกินเหตุ และเป็นคนดีซื่อบื้อไปซะทุกเรื่อง

และเขาก็เคย──ชอบเลม่อนมาก่อน

ในขณะที่ยากิชิโอะกำลังจมอยู่ในภวังค์ความหลังพลางจ้องหน้าจอสมาร์ทโฟน โคมาริที่อยู่ข้างๆ ก็กางตำราเรียนออก

[ถะ... ถ้ามีตรงไหนไม่เข้าใจ จะสอนให้ก็ได้นะ ]

[ จะดีเหรอ? โคมาริจังเองก็ต้องอ่านสอบเหมือนกันนี่นา ]

โคมาริหันหน้าหนีไปทางอื่นด้วยความขัดเขินก่อนจะพูดขึ้นว่า

[ ก็... ฉันเองก็ตั้งตารอที่จะได้เห็นเธอวิ่งในอินเตอร์ไฮเหมือนกันนี่นา ]

[......ขอบใจนะ โคมาริจัง ]

โดนทำดีให้ขนาดนี้แล้ว ถ้าไม่พยายามก็คงเสียชาติเกิดนักวิ่งแน่ๆ

ยากิชิโอะตบแก้มตัวเองเพื่อเรียกสมาธิ ก่อนจะเปิดตำราเรียนขึ้นมา
