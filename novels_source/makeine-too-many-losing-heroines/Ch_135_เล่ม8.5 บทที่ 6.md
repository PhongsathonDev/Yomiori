โรงเรียนสึวาบุกิในยามเช้าตรู่

ที่คลังเก็บของในอาคารเรียนเก่าอันไร้ผู้คน มีนักเรียนหญิงอยู่คนหนึ่ง

อาซากุโมะ จิฮายะ ชั้น 2-E อยู่ที่นั่น

อาศัยแสงอาทิตย์ยามเช้าที่ส่องผ่านหน้าต่างกับแสงสะท้อนจากหน้าผาก เธอจ้องมองเข้าไปยังสายไฟที่วิ่งอยู่หลังผนังที่ถูกเลาะออก

เป็นเรื่องปกติที่มักพบได้ในสิ่งปลูกสร้างเก่าๆ แต่อาคารเรียนเก่าแห่งนี้ผ่านการปรับปรุงซ้ำแล้วซ้ำเล่า จนทำให้เส้นทางของสายไฟจำนวนมากกลายเป็นเรื่องลึกลับ สิ่งที่ควรมีอยู่ในแบบแปลนกลับไม่มี หรือในทางกลับกัน ก็มีสายไฟที่ไม่ได้ระบุไว้ในแปลนวิ่งผ่านไปมา

และอาคารเรียนเก่ามักถูกใช้ในกิจกรรมนอกหลักสูตรหรือวัตถุประสงค์ส่วนตัวของนักเรียนบ่อยครั้ง สำหรับนักเรียนมัธยมปลายธรรมดาอย่างเธอแล้ว จึงเป็นสถานที่ที่เหมาะที่สุดในการปลดปล่อยความอยากรู้อยากเห็น

ทันใดนั้น หน้าผากของอาซากุโมะที่กำลังมองดูหลังผนังก็ทอแสงเจิดจ้าขึ้น

[ ......เจอแล้ว! ]

ส่งเสียงพึมพำออกมาอย่างกลั้นความตื่นเต้นไว้ไม่อยู่ เธอเจอสายไฟที่ตามหาจนได้

ถ้าใช้เส้นนี้ละก็ จะสามารถเข้าถึงระบบเครื่องเสียงของอาคารเรียนเก่าได้ทั้งหมด

จากการซ่อมแซมและก่อสร้างเพิ่มเติมหลายต่อหลายครั้ง จนไม่รู้ด้วยซ้ำว่ายังมีอยู่หรือไม่ แต่มันยังคงเหลืออยู่จริงๆ

ที่เหลือก็แค่ตรวจสอบว่าสายไฟยังใช้งานได้ถึงไหน และเชื่อมต่อส่วนที่ตายแล้วเข้ากับวงจรใหม่──

ในขณะที่อาซากุโมะกำลังวางแผนในหัว เธอก็สังเกตเห็นเสียงฝีเท้าที่ใกล้เข้ามายังคลังเก็บของ

......ใกล้กว่าที่คิด การที่ไม่รู้ตัวจนถึงขนาดนี้ คงต้องโทษความประมาทของตัวเองเท่านั้น

อาซากุโมะรีบยัดเครื่องมือในมือเข้าไปในมุมมืด แล้วหันไปเผชิญหน้ากับประตู

คำอธิษฐานที่ขอให้เดินผ่านไปนั้นไร้ผล──ประตูถูกเปิดออกอย่างแรง

[ ......โอ๊ะ อาซากุโมะคุงเองเหรอ ]

ตัวละครตัวที่สองคือ อดีตประธานนักเรียน โฮโคบารุ ฮิบาริ

คงไม่ได้คาดคิดว่าจะมีคนอยู่ก่อนแล้ว อาซากุโมะจึงส่งยิ้มทักทายโฮโคบารุที่กำลังประหลาดใจ

[ อรุณสวัสดิ์ค่ะ มาทำอะไรในเวลาแบบนี้เหรอคะ? ]

[ กำลังติวภาษาอังกฤษกับกลุ่มอาสาสมัครน่ะ เห็นว่าที่นี่มีไวท์บอร์ดที่ไม่ได้ใช้เลยกะว่าจะมาขอยืมหน่อย ]

[ ตายจริง ถ้าอย่างนั้นก็น่าจะเป็นตัวนี้หรือเปล่าคะ ]

อาซากุโมะชี้ไปยังไวท์บอร์ดที่พิงอยู่ข้างผนัง

หลังเงากองลังกระดาษ มีไวท์บอร์ดแบบมีขาตั้งสภาพเก่าแก่ตั้งสงบนิ่งอยู่

[ อ้อ อันนี้แหละ ดูท่าทางจะเอาออกมาลำบากหน่อยนะ ]

[ เดี๋ยวฉันช่วยค่ะ ไม่ต้องเกรงใจ ]

[ ขอบใจนะ ของหนักๆ เดี๋ยวฉัน── ]

[ เชิญตามสบายเลยค่ะ! รุ่นพี่ช่วยจัดการของด้านในทีนะคะ ]

โฮโคบารุที่ถูกรุกด้วยความกระตือรือร้นได้แต่พยักหน้า แล้วเริ่มย้ายของด้านในออก

อาซากุโมะอาศัยจังหวะใช้ร่างกายบังรูบนผนังอย่างแนบเนียน พร้อมกับวางลังกระดาษทับซ้อนปิดหน้าเอาไว้

[ ทางนี้ย้ายเสร็จแล้วค่ะ รุ่นพี่ล่ะคะ เป็นยังไงบ้าง? ]

[ อืม ทางนี้ก็เรียบร้อยดี เอาละ น่าจะขยับได้แล้ว ]

โฮโคบารุที่เอื้อมมือไปจับไวท์บอร์ด ส่งสายตาที่ดูเคลือบแคลงสงสัยกลับมา

[ จะว่าไป อาซากุโมะคุง──มาทำอะไรแต่เช้าขนาดนี้งั้นเหรอ? ]

[ คือว่า── ]

อีกฝ่ายคือโฮโคบารุ ฮิบาริ เธอไม่ได้กำลังลองเชิงอยู่แน่ๆ

เมื่ออาซากุโมะตัดสินใจได้เช่นนั้น จึงค่อยๆ เลือกคำพูดอย่างระมัดระวังก่อนจะเอ่ยปาก

[ ฉันเองก็กะว่าจะมาติวกับเพื่อนเหมือนกัน เลยลองมาหาดูว่ามีอะไรพอจะใช้ได้บ้างน่ะค่ะ ]

[ อาซากุโมะคุงก็ด้วยเหรอ ถ้าต้องการอะไรก็ถามฉันได้นะ── ]

การเคลื่อนไหวของโฮโคบารุที่กำลังขยับไวท์บอร์ดหยุดชะงักลง

เธอสังเกตเห็นเครื่องมือหลายชิ้นที่ปรากฏออกมาจากการเคลื่อนย้ายข้าวของ

[ อาซากุโมะคุง นั่นคืออะไรเหรอ ]

[ ......แหม่ คืออะไรกันนะคะ ]

โฮโคบารุหยิบแผ่นพลาสติกเล็กๆ ที่รูปร่างคล้ายช้อนรองเท้าขึ้นมา

[ นี่มันอุปกรณ์งัดแงะคอนโซลนี่นา ทำไมถึงมาอยู่ที่นี่ได้ล่ะ ]

[ ตายจริง รุ่นพี่รู้จักด้วยเหรอคะ ]

[ ญาติของฉันชอบแต่งรถน่ะ เคยเห็นตอนเขาทำงานอยู่บ้าง ]

โฮโคบารุมองดูเครื่องมือที่วางกองกันอย่างระเกะระกะ

[ มีทั้งมัลติมิเตอร์ แล้วก็คีมย้ำสายไฟ งั้นเหรอ ของที่ไม่เคยเห็นก็เยอะเหมือนกันนะ ]

[ดูรุ่นพี่จะมีความรู้เรื่องนี้จังเลยนะคะ]

[พอดีพ่อแม่ของฉันมีใบอนุญาตช่างไฟฟ้าน่ะ เลยคุ้นเคยมาตั้งแต่เด็กๆ ]

ทันใดนั้น สายตาของโฮโคบารุก็จ้องตรงมายังอาซากุโมะ

จะพูดให้ถูกคือ จ้องไปยังหลังแผ่นหลังของอาซากุโมะ ตรงรูบนผนังที่พอมองเห็นแวบๆ หลังกองลังกระดาษนั่นเอง──

[ อาซากุโมะคุง ผนังข้างหลังนั่นมันเป็นยังไงเหรอ ]

[ อุ๊ย มีรูอยู่ตรงนี้ด้วยเหรอคะเนี่ย ]

อาซากุโมะแสดงอาการตกใจราวกับเพิ่งเคยสังเกตเห็นเป็นครั้งแรก

โฮโคบารุขยับลังกระดาษออก แล้วจ้องมองเข้าไปในรูผนัง

[ ใครมาเจาะรูทิ้งไว้แบบนี้กัน── ]

[ พวกช่างน่ะค่ะ ]

อาซากุโมะยืนยันด้วยน้ำเสียงเด็ดขาด

[ สงสัยคงอยู่ระหว่างทำงานน่ะค่ะ เรื่องเครื่องมือที่วางทิ้งไว้ก็น่าจะเป็นเพราะเหตุผลนั้นด้วย ]

เมื่อเห็นคำพูดที่เต็มไปด้วยความมั่นใจของอาซากุโมะ โฮโคบารุก็พยักหน้าตามอย่างว่าง่าย

[ งั้นเหรอ แต่ดูเหมือนจะมีเครื่องมือราคาแพงอยู่ด้วย ปล่อยไว้แบบนี้มันไม่ค่อยปลอดภัยนะ เดี๋ยวฉันจะเอาไปส่งที่ห้องธุรการ── ]

[ เดี๋ยวจัดการเองค่ะ! ]

เมื่อเห็นอาซากุโมะร้องทักขึ้นมาทันควัน โฮโคบารุจึงพยักหน้าด้วยรอยยิ้มเจื่อนๆ

[ อืม ฝากด้วยนะ งั้นฉันขอตัวก่อนละกัน ]

[ ค่ะ ขอบคุณมากนะคะ! ]

ในขณะที่กำลังเข็นไวท์บอร์ดออกไป โฮโคบารุก็หยุดชะงักลงทั้งที่ยังหันหลังอยู่

[......แต่ก็น่าแปลกนะ ]

คำพูดที่เหมือนจะชักชวนให้สงสัย

แม้จะลังเลอยู่ครู่หนึ่ง แต่ความยากรู้อยากเห็นก็เอาชนะความระแวดระวังได้ อาซากุโมะจึงถามกลับไป

[ ที่ว่าแปลกนี่ คือเรื่องอะไรเหรอคะ? ]

[ ตอนที่ฉันอยู่ปี 1 เคยมีเหตุการณ์ฟ้าผ่าจนแผงจ่ายไฟของอาคารเรียนเก่าไหม้ไปหมด เพราะมันกู้คืนลำบาก เลยได้ยินมาว่าเขาเชื่อมต่อสายไฟของอาคารเก่าเข้ากับอาคารฝั่งตะวันตกไปแล้ว ]

[............ ]

โฮโคบารุพูดต่อไปราวกับจะตอบโต้ความเงียบของอาซากุโมะ

[ สายไฟตรงนั้นไม่น่าจะมีการใช้งานแล้วนะ พวกช่างเขากำลังซ่อมบำรุงส่วนไหนกันอยู่นะ ]

[ ............นั่นสินะคะ ฉันเองก็ไม่ทราบเหมือนกัน ]

เมื่อได้ยินน้ำเสียงที่ระแวดระวังของอาซากุโมะ โฮโคบารุที่ยังหันหลังอยู่ก็โบกมือให้

[ อา อย่าเก็บไปใส่ใจเลย แค่บ่นพึมพำคนเดียวน่ะ ]

[ ไม่หรอกค่ะ เป็นเรื่องที่น่าสนใจมากเลย ]

แม้ประตูห้องจะปิดลงแล้ว แต่อาซากุโมะก็ยังคงจ้องมองมันอยู่อย่างนั้น

──โฮโคบารุ ฮิบาริ ไม่ได้มีดีแค่ความใจดีสมกับเป็นอดีตประธานนักเรียนโรงเรียนสึวาบุกิ

โรงเรียนนี้มีคนที่น่าสนใจเยอะจริงๆ นั่นแหละ

[ ......เพราะแบบนี้ไงล่ะ ถึงอยากจะรู้จักให้มากขึ้น ]

อาซากุโมะกำคีมย้ำสายไฟในมือแน่น แล้วหันกลับไปเผชิญหน้ากับรูบนผนังอีกครั้ง
