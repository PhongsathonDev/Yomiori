[ โซสึเกะ ยินดีต้อนรับจ้ะ! ]

คาเรนเปิดประตูหน้าบ้านออกกว้างพร้อมกับส่งเสียงทักทายอย่างร่าเริง

วันนี้เธอจัดเซสชันติวหนังสือก่อนสอบกับฮากามาดะ โซสึเกะ แฟนหนุ่มของเธอ

[ รบกวนด้วยนะ วันนี้ฝากตัวด้วยล่ะ ]

โซสึเกะวางกระเป๋าที่ดูหนักอึ้งลงบนพื้น

[ ทางนี้ก็ฝากตัวด้วยเหมือนกันนะจ๊ะ กระเป๋าใบน้ัน── ]

กระเป๋าบอสตันสีดำเงาวับดูเหมือนจะอัดแน่นไปด้วยของข้างใน

อึก คาเรนกลืนน้ำลายลงคอ

[ ……เอาของมาเยอะแยะเลยนะเนี่ย ]

[ อา แค่หนังสือเรียนกับหนังสืออ้างอิงที่จำเป็นสำหรับอ่านสอบก็เยอะขนาดนี้แล้วล่ะ ]

โซสึเกะที่ถอดรองเท้าแล้วยิ้มออกมาอย่างสดใส

[ อ๊ะ อย่างนั้นเองเหรอ ]

[ ? คาเรน เป็นอะไรไปน่ะ ]

[ ปะ เปล่าจ้ะ! เอาล่ะ รีบเข้ามาสิ! ]

ใช่แล้ว วันนี้คืองานติวหนังสือที่แสนจะบริสุทธิ์และจริงจัง จะมาทำตัวเหลวไหลก่อนสอบไม่ได้เด็ดขาด

ขณะที่คาเรนคอยย้ำเตือนตัวเองในใจแล้วเดินเข้ามาในห้องนั่งเล่น สายลมเย็นๆ ก็พัดผ่านเข้ามาทางหน้าต่างที่เปิดอยู่

[ เข้ามาเลยจ้ะ ]

[ ขอบใจนะ บ้านของคาเรนเนี่ย พอเป็นชั้นบนสุดแล้วก็เย็นสบายดีจริงๆ แฮะ ]

แมนชั่นที่ฮิเมมิยะ คาเรนอาศัยอยู่คนเดียวเป็นตึก 9 ชั้น ด้านหน้ามีถนนกั้นกับสวนสาธารณะ และอยู่ในระยะที่เดินไปโรงเรียนมัธยมปลายสึวาบุกิได้

ตอนที่โซสึเกะกำลังมองออกไปข้างนอก คาเรนก็มายืนเคียงข้างในระยะที่ไหล่แทบจะชนกัน

[ วันนี้อากาศแอบร้อนนิดนึงเนอะ จะอาบน้ำก่อนก็ได้นะ? ]

[ โทษที ตัวฉันเหม็นเหงื่อหรือเปล่า ]

[ เอ๊ะ? ฉันไม่ได้รังเกียจหรอกนะ── ]

โซสึเกะหยิบแผ่นเช็ดเหงื่อออกจากกระเป๋าแล้วเริ่มเช็ดตัว

แบบนั้นมันก็…… โซสึเกะหันกลับมามองคาเรนที่ยืนจ้องอยู่ด้วยความสงสัย

[ เป็นอะไรไป จ้องซะเขม็งเลย]

[ เปล่าจ้ะ! เดี๋ยวไปเอาชามาให้นะ ]

คาเรนรีบวิ่งไปที่ตู้เย็นพลางเอามือทาบอกขนาดใหญ่ของตัวเองแล้วสูดหายใจเข้าลึกๆ

ใช่แล้ว ยังไงซะวันนี้ก็คืองานติวหนังสือ จะทำตัวเหลวไหลไม่ได้เด็ดขาด──

◇

[ ใช่จ้ะ ถูกต้องแล้ว ]

คาเรนลูบหัวของโซสึเกะ ก่อนจะใช้มืออีกข้างจดลงในหนังสืออ้างอิง

[ ครึ่งแรกมันขยายคำว่า temptation ก็เลยแปลว่าลิลิธเป็นคนชวนเขามาที่บ้านน่ะ ]

[ อย่างนี้นี่เอง วิธีสอนของอาจารย์คาเรนเนี่ยเข้าใจง่ายจริงๆ ด้วย ]

พอเขาพูดติดตลก คาเรนก็ใช้นิ้วจิ้มแก้มของโซสึเกะเบาๆ

[ นักเรียนเก่งด้วยล่ะมั้ง ให้รางวัลหน่อยดีไหมน้า? ]

[ งั้น ขอยืมหนังสือนิยายต้นฉบับภาษาต่างประเทศที่เพิ่งยืมไปคราวก่อนเล่มต่อไปหน่อยได้ไหม]

[ อ่านจบแล้วเหรอ? ]

โซสึเกะเกาจมูกแก้เขินใส่คาเรนที่กำลังประหลาดใจ

[ ก็มีจุดที่ไม่ค่อยเข้าใจอยู่บ้างหรอกนะ แต่กะว่าจะเน้นอ่านเอาปริมาณไปก่อนสักพักน่ะ พวกบทสนทนาเนี่ย ที่ต่างประเทศเขาพูดกันแบบนั้นจริงๆ เหรอ? ]

[ อืม ก็ขึ้นอยู่กับสถานที่และยุคสมัยด้วยแหละนะ อย่างประโยคเมื่อกี้นี้── ]

คาเรนชี้ไปที่หนังสืออ้างอิง

[ ถ้าเป็นฉันคงใช้คำว่า seduce ล่ะมั้ง มันก็แค่ความแตกต่างของบริบทนิดหน่อยแหละนะ ]

เซสชันติวหนังสือของพวกเขาสองคนดำเนินต่อไปอย่างราบรื่น

เมื่อนาฬิกาบอกเวลาเลย 16.00 น. คาเรนก็แอ่นหน้าอกขนาดใหญ่ของเธอแล้วบิดขี้เกียจ

โซสึเกะดูเหมือนจะกำลังจดจ่ออยู่กับการเรียน เขามองสลับระหว่างหนังสืออ้างอิงกับสมุดจดด้วยสีหน้าจริงจัง

[ โซสึเกะ หิวน้ำไหม? ให้ชงชาให้หรือเปล่า ]

[ นี่ก็ยังมีอยู่นะ ไม่เป็นไรหรอก ]

คาเรนลุกขึ้นโดยไม่สนโซสึเกะที่กำลังเขย่าขวดชาพลาสติกให้ดู

[ ฉันอยากดื่มอะไรอุ่นๆ น่ะ เดี๋ยวชงชาฝรั่งให้นะ ]

พอไปยืนที่ห้องครัว คาเรนก็หยิบผ้ากันเปื้อนสีชมพูน่ารักมาสวม

[ แค่ชงชาก็ต้องใส่ผ้ากันเปื้อนด้วยเหรอเนี่ย ]

[ ก็โซสึเกะชอบผ้ากันเปื้อนไม่ใช่เหรอ? ]

โซสึเกะหัวเราะอย่างร่าเริง คงคิดว่าเธอพูดล้อเล่น

[ อะไรของเธอเนี่ย ฉันดูเป็นคนแบบนั้นหรือไง ]

[ก็พอฉันยืนอยู่ในครัวทีไร โซสึเกะชอบเข้ามาแกล้งอยู่เรื่อยเลยนี่นา ]

คาเรนพูดพลางเริ่มเตรียมชงชาฝรั่ง

ระหว่างที่เติมน้ำลงในกาน้ำ เธอก็เหลือบมองไปที่โซสึเกะ ซึ่งดูเหมือนจะยังคงตั้งใจเรียนอยู่เหมือนเดิม

[ โซสึเกะ ฉันกำลังใช้น้ำร้อนอยู่นะ ห้ามเข้ามาแกล้งเด็ดขาดเลยล่ะ ]

[ อืม เข้าใจแล้วน่า ]

โซสึเกะยังคงก้มหน้าก้มตาเรียนต่อไป ดูเหมือนจะจดจ่อกับการเรียนอย่างถึงที่สุด

[ ไม่ได้น้าー ]

[ ………… ]

โซสึเกะเปิดพจนานุกรมอังกฤษ-ญี่ปุ่นเงียบๆ ไม่มีทีท่าว่าสมาธิจะหลุดเลยแม้แต่น้อย

ใช่แล้ว วันนี้คือวันหยุดสุดสัปดาห์ที่สำคัญก่อนสอบปลายภาค ไม่มีเวลามาเล่นสนุกหรอก

คาเรนตั้งสติกลับมาชงชา ก่อนจะวางถ้วยชาลงตรงหน้าโซสึเกะ

[ เอ้า ระวังร้อนนะจ๊ะ ]

[ ขอบใจนะ ชงเผื่อฉันด้วยเหรอเนี่ย ]

คาเรนเผลอมองริมฝีปากของโซสึเกะที่กำลังดื่มชาอย่างลืมตัว ก่อนจะสะดุ้งแล้วตบแก้มทั้งสองข้างของตัวเอง

[ เอาล่ะ วันนี้เรามาเพื่ออ่านหนังสือสอบกันนี่เนอะ! ]

คำประกาศที่เพิ่งมาบอกเอาป่านนี้ทำเอาโซสึเกะตาโต

[ ก็แหงอยู่แล้วสิ คาเรน วันนี้เธอเป็นอะไรไปเนี่ย? ]

[ เปล่าจ้ะ ไม่มีอะไรหรอก เอาล่ะ รีบมาจัดการให้เสร็จๆ กันเถอะ! ]

[ อ๊ะ อืม ]

โซสึเกะกลับไปเรียนต่อแม้จะยังงุนงงอยู่บ้าง

เมื่อเห็นท่าทางแบบนั้น คาเรนก็ดึงสติกลับมา ในฐานะแฟน เธอต้องวางตัวไม่ให้โซสึเกะต้องอาย อันดับแรกต้องสลัดความคิดฟุ้งซ่านทิ้งไป แล้วตั้งใจเรียนให้เต็มที่

หลังจากเรียกความฮึกเหิมกลับมาและจิบชาไปหนึ่งคำ เธอก็สังเกตเห็นการแจ้งเตือนในสมาร์ทโฟน

พอมองดูก็พบว่าเป็นข้อความจากยานามิ

──พรุ่งนี้ มาอ่านหนังสือสอบด้วยกันไหม?

คำชวนจากเพื่อนสนิททำให้คาเรนเผลอยิ้มออกมา

──พรุ่งนี้ฉันว่างตั้งแต่เช้าเลยจ้ะ

คาเรนที่กำลังจะกดปุ่มส่งข้อความหยุดนิ้วไว้ในเสี้ยววินาทีสุดท้าย แล้วเหลือบมองไปทางโซสึเกะ

……โซสึเกะกำลังจ้องหนังสืออ้างอิงด้วยสีหน้าจริงจัง

ลูกกระเดือกที่ขยับช้าๆ ท่อนแขนที่มีเส้นเลือดปูดโปนอย่างลูกผู้ชายกำลังเปิดหน้าพจนานุกรม──

[ ……โซสึเกะ วันนี้อยู่กินข้าวเย็นด้วยกันไหม? ]

คำชวนกะทันหันทำให้โซสึเกะเงยหน้าขึ้นมาด้วยความตกใจ

[ จะดีเหรอ? คาเรนก็ยุ่งอยู่ไม่ใช่เหรอ ]

[ วัตถุดิบก็มีพร้อม แล้วก็ถือเป็นการเปลี่ยนบรรยากาศด้วยน่ะ ]

[ ขอบใจนะ งั้นเดี๋ยวฉันส่งข้อความบอกที่บ้านว่าไม่ต้องเตรียมข้าวเย็นไว้ให้ ]

[ อืม อาจจะกลับดึกด้วยแหละนะ เอาล่ะ งั้นมาพยายามอ่านหนังสือกันต่อเถอะ! ]

คาเรนกำหมัดทั้งสองข้างแน่นเพื่อเรียกความตั้งใจอีกครั้ง

โซสึเกะมองภาพนั้นด้วยรอยยิ้มบางๆ

[ คาเรน ดูมุ่งมั่นจังเลยนะ ]

[ นั่นสินะ วันนี้ฉันอาจจะไฟแรงนิดหน่อยล่ะมั้ง ]

คาเรนส่งยิ้มที่งดงามราวกับดอกไม้ ก่อนจะพิมพ์ข้อความตอบกลับยานามิใหม่

──พรุ่งนี้ถ้าเป็นช่วงบ่ายล่ะก็ว่างจ้ะ
