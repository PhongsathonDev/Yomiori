เล่ม 6 บทที่ 1-5 บทคั่น

บนรถไฟสายด่วนที่มุ่งหน้าไปยังโองากิ

เด็กสาวตัวเล็กคนหนึ่งกำลังกำราวจับของรถไฟไว้แน่น แขนของเธอเหยียดจนสุด

เด็กสาวคนนั้นมีชื่อว่า นุคุมิซึ คาจู

เมื่ออยู่ลำพังบนรถไฟ เธอไม่อาจปกปิดแววตาแห่งความตื่นเต้นได้เลย—วันนี้ท่านพี่สุดที่รักของเธอกำลังออกเดท!

แม้ว่าเขาจะเคยออกไปกับผู้หญิงคนอื่นมาก่อน แต่เขาก็ยืนกรานเสมอว่า "นั่นไม่ใช่เดท" ทว่าคราวนี้ คำว่า "เดท" ได้ปรากฏอย่างชัดเจนในประวัติการค้นหาบนสมาร์ตโฟนของเขา

นอกจากนี้ยังมีการค้นหาเกี่ยวกับ “พิพิธภัณฑ์สัตว์น้ำทาเคชิมะ,” “เดทครั้งแรก,” และ “ชุดที่ควรใส่” ซึ่งเผยให้เห็นสถานที่และลักษณะของเดทครั้งนี้อย่างง่ายดาย

การตรวจสอบพยากรณ์อากาศและเส้นทางการเดินทางทำให้รู้วันที่แน่นอน

เพื่อเตรียมตัวสำหรับโอกาสนี้ เธอจึงโน้มน้าวพ่อของเธอให้ซื้อ “ชุดที่เหมาะกับท่านพี่” เพื่อให้มั่นใจว่าเดทครั้งนี้จะสมบูรณ์แบบ

แต่คาจูก็ยังสงสัยเกี่ยวกับตัวตนของคู่เดทของท่านพี่

เธอเคยแอบถาม ‘ยานามิ’ อย่างลับๆ แต่ก็ไม่ใช่เธอแน่นอน

ผู้สมัครที่เหลืออาจเป็น ‘โคมาริ’ หรือใครบางคนจากสภานักเรียน หรือบางทีอาจจะเป็นคนที่เธอไม่รู้จักเลยก็ได้

เพราะยังไงก็เป็นท่านพี่—เสน่ห์ของเขาย่อมไม่รอดพ้นสายตาของผู้หญิงที่อยู่รอบตัว

ประกาศบนรถไฟเริ่มดังขึ้น บ่งบอกว่ากำลังจะถึงสถานี กามาโกริ ในอีกประมาณ 10 นาที

[...ต้องเห็นด้วยตาตัวเองก่อน ]

คาจูที่มีสีหน้าเด็ดเดี่ยว ก้าวลงจากรถไฟและเดินลงบันไดเลื่อนไปยังชานชาลา

ท่านพี่คงจะถึงอควาเรียมแล้ว เมื่อจินตนาการถึงเขา เธอก็เดินผ่านประตูตรวจตั๋วและพบกับเด็กสาวตัวเล็กในชุดเสื้อพาร์กาเหลืองสดใส กางเกงขาสั้น และกระเป๋าเป้สีเขียวสดใส

[ ...โคมาริซัง? ]

[ อุ-อุน๊า!? ค-คาจูจัง? ทำไมเธอถึงอยู่ที่นี่!? ]

โคมาริที่ตกใจถึงกับย่อตัวลงต่ำ คาจูจึงเดินตรงไปหาเธอทันที

[ เธอเป็นคู่เดทของท่านชายจริงๆด้วย! ชุดนี้น่ารักมากเลยค่ะ! ชอบใส่เสื้อผ้าแบบนี้เหรอ? ]

[ ปะ-เปล่านะ นี่แค่…ของที่ญาติส่งมาให้น่ะ… ]

[ ชุดนี้ต้องทำให้ท่านพี่หลงเสน่ห์แน่เลย!]

[ ละ-หลงเสน่ห์…? ]

คาจูยื่นหน้าเข้าไปใกล้โคมาริที่กำลังกระพริบตาด้วยความงุนงง

ทันใดนั้นเอง เสียงที่คุ้นเคยก็ดังมาจากด้านหลังของคาจู

[...แสดงว่านุคุมิซึคุงกำลังเดทจริงๆ สินะ ]

เมื่อหันกลับไป คาจูเห็น **ยานามิ อันนะ **เดินสะบัดผมอย่างสง่างาม

[ ยานามิซัง!? เดี๋ยวนะ ท่านพี่ไม่ได้บอกว่ามีเดทแค่คนเดียวหรอกเหรอ!? ]

คาจูรีบเอามือปิดปากตัวเองหลังพูดออกไป ยานามิส่งยิ้มเจ้าเล่ห์มาให้

[ ก็เพราะนุคุมิซึคุงทำตัวแปลกๆ ตั้งแต่วันศุกร์ เลม่อนจัง ก็ดูเหมือนจะปิดอะไรบางอย่างไว้ และเธอก็ถามเรื่องวันอาทิตย์กับอควาเรียมอีก ]

[ ...แล้วทำไมพวกเธอถึงมาที่นี่ด้วย? ]

ยานามิเดินเข้าไปหาคาจู

[ เราก็มาด้วยเหตุผลเดียวกับเธอนั่นแหละ เราเข้าใจความรู้สึกของเธอนะ น้องสาวจัง! ]

[ เอ๊ะ!? ]

ยานามิพูดอย่างร่าเริงพร้อมจับมือคาจูแน่น

[ เธอมาเพื่อขัดจังหวะเดทใช่มั้ยล่ะ!? ]

...ไม่ใช่เลย

คาจูอยากจะปฏิเสธทันที แต่คำพูดกลับติดอยู่ในลำคอ

ยานามิส่งยิ้มปลอบใจมาให้ราวกับว่าเธอรู้ทุกอย่างแล้ว

[ พวกเขาไม่บอกเราเรื่องเดทนี้มันไม่ยุติธรรมเลย เราเลยต้องจับตาดูพวกเขาให้ดี ]

ยานามิพูดพร้อมกับขยิบตาให้

[ แต่รู้อะไรมั้ย น้องสาวจัง ฉันเข้าใจความรู้สึกเธอนะ แต่การขัดจังหวะเดทมันก็ดูเกินไปหน่อย…ว่ามั้ย? ]

...ขัดจังหวะเดท

คาจูไม่เคยคิดถึงเรื่องนี้มาก่อน แต่เธอก็ไม่สามารถปฏิเสธได้อย่างเต็มปาก

เธอแค่อยากจะเก็บภาพของท่านพี่ไว้ให้มากขึ้นอีกหน่อยเท่านั้นเอง...

คาจูพยายามเก็บความสับสนไว้และเอ่ยถามด้วยน้ำเสียงสงบ

[ เอ่อ แล้วทำไมถึงอยากจับตาดูเดทของท่านพี่ล่ะคะ…? ]

ยานามิยิ้มและตอบเหมือนเป็นเรื่องธรรมดา

[ ก็เพราะในชมรมวรรณกรรมของเรา มีกฎห้ามสมาชิกออกเดทกันน่ะสิ! ]

[ อุเอ๊!? ]

ท่ามกลางความวุ่นวายบริเวณทางออกสถานีกามาโกริ เสียงใหม่ดังแทรกเข้ามา

[ อะแฮ่ม นี่น้องสาวของนุคุมิซึคุงไม่ใช่เหรอ? ยานามิจัง เธอเชิญมาด้วยเหรอ? ]

คนที่สี่ที่ปรากฏตัวคือ สึกิโนะคิ โคโตะ อดีตรองประธานชมรมวรรณกรรม

เธอเดินเข้ามาพร้อมกับหมุนกุญแจรถเล่นในมือ

[ พวกเราเจอกันโดยบังเอิญน่ะ ดูเหมือนน้องสาวจังก็มาที่นี่เพื่อจับตาดูนุคุมิซึคุงเหมือนกัน ]

[ งั้นแสดงว่าเดทนี่เป็นเรื่องจริงสินะ หมอนั่นนี่ก็ไม่เบาเลยนะ ]

คาจูพยายามรวบรวมสติและปรับแผนในใจใหม่ เธอสูดลมหายใจลึกก่อนจะโค้งเล็กน้อยให้โคโตะ

[ ตั้งแต่เทศกาลซึวะบุกิกฌไม่ได้เจอกันเลย สึกิโนะคิซังก็มาขัดจังหวะ—เอ่อ หนูหมายถึง มาสังเกตการณ์เดทของท่านพี่เหมือนกันเหรอคะ ? ]

[ ฉันเองก็ไม่ค่อยเข้าใจเท่าไหร่หรอก แต่ฟังดูน่าสนุกดีเลยตามมาน่ะ! ]

สมเป็นตัวเธอดี คาจูคิดในใจ

ยานามิหันไปมองรอบๆ

[ น้องสาวจัง นุคุมิซึคุงจะมาถึงเมื่อไหร่เหรอ? ]

[ ท่านพี่ขึ้นรถไฟมาก่อน ตอนนี้เขาน่าจะถึงอควาเรียมแล้วค่ะ ]

แม้แผนจะเปลี่ยนไปเล็กน้อย แต่ก็ไม่ได้เป็นปัญหาอะไร

การตามใครสักคนไปด้วยกลุ่มใหญ่ที่เสียงดังเป็นเรื่องที่ไม่ฉลาดนัก แต่ในครั้งนี้กลับแตกต่างออกไป

ถ้าทั้งสามคนนี้ช่วยเบี่ยงเบนความสนใจ คาจูก็จะสามารถเข้าใกล้ท่านพี่ได้มากขึ้นอีก

คาจูโค้งให้เหล่ารุ่นพี่ทั้งสามพร้อมรอยยิ้ม

[ ถ้างั้นวันนี้ ให้คาจูเข้าร่วมกับทุกคนด้วยนะคะ ขอฝากตัวด้วยค่ะ ! ]
