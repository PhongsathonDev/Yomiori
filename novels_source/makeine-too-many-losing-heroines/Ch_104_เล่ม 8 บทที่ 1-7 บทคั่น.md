นก เล่ม 8 บทที่ 1-7  บทคั่น : ความทรงจำอันล้ำค่า

ห้องสภานักเรียนยามเย็นหลังเลิกเรียน

ประธานนักเรียน โฮโคบารุ ฮิบาริ กำลังใช้ผ้าถูพื้นที่บิดจนแห้งเช็ดโต๊ะของตนอย่างพิถีพิถัน

ซากุไร ฮิโรโตะ ฝ่ายการเงินที่กำลังจัดชั้นหนังสือหันมามอง พร้อมรอยยิ้มจาง ๆ

[ ทั้งที่ยังเหลือเวลาอีกตั้งเดือนหนึ่ง ก็ดูรีบจังเลยนะ ]

[ จะให้ฉันมาลนลานเก็บตอนใกล้จะไปมันไม่ใช่นิสัยฉัน การแสดงความเคารพต่อของพวกนี้ต้องสั่งสมทีละนิดๆต่างหาก ]

เมื่อพูดจบ เธอก็เอาผ้ากลับไปล้างในถังน้ำ

ต่อหน้าสายตากังวลของซาคุราอิ โฮโคะบาระก็เพียงยักไหล่ราวกับจะบอกว่าไม่ต้องห่วง

[ ฉันได้รับสสิ่งต่าง ๆ สืบทอดมาจากรุ่นพี่มากมาย หน้าที่ของฉันคือส่งต่อให้รุ่นถัดไป ]

จากนั้นเธอก็บิดผ้าอีกครั้ง และเริ่มเช็ดเก้าอี้

[ ฮิบาเน่ อยู่ในสภานักเรียนมาตั้งสองปี ความทรงจำคงเยอะน่าดูเลยสินะ ]

โฮโคะบาระหัวเราะอย่างคิดถึงอดีต

[ อื้ม ประธานรุ่นก่อนนี่ตัวแสบใช้ได้เลยล่ะ เทียบกับรุ่นพี่โคโตะก็ไม่แพ้กัน ]

[ โชคดีที่ผมเพิ่งเข้ามาในปีนี้แหละนะ ]

ซาคุไรหัวเราะก่อนจะทำสีหน้าจริงจังขึ้นมา

[ ไม่รู้ว่ายูเมโกะซังจะโอเคมั้ย เหมือนจะทำให้บะโซริจังโกรธอีกแล้วล่ะ ]

[ นั่นคือหลักฐานว่าพวกเขาสนิทกัน ชิกิยะน่ะพออยู่ต่อหน้าบาโซริคุงก็จะดูมีชีวิตชีวาขึ้นมาเลย ]

รองประธาน บาโซริ เทียร่า ตอนนี้เธอสมัครชิงตำแหน่งประธานนักเรียนคนต่อไปเรียบร้อยแล้ว

ขณะนี้ยังไม่มีผู้สมัครคนอื่น ถ้าผ่านการโหวตความไว้วางใจก็จะได้เป็นประธานแน่นอน

หาก โฮโคบารุ ฮิบาริ พ้นตำแหน่งแล้ว ซากุไรก็ตั้งใจว่าจะไม่ข้องเกี่ยวกับสภานักเรียนอีก

สภานักเรียนที่ไม่มีเธออยู่ ก็ไม่น่าสนใจพอที่จะอยู่ต่อแล้ว——

เขายืนยันกับตัวเองอีกครั้ง แล้วเผยรอยยิ้มอ่อนโยนประจำตัว

เมื่อมองไป ก็เห็นโฮโคบารุดูจะพอใจกับการทำความสะอาดแล้ว

เธอแขวนผ้าไว้ที่ขอบถัง แล้วกวาดตามองโต๊ะ

[ จริงสิ ก่อนจะลืม ขอเอาไปให้นายก่อน ]

โฮโคบารุหยิบแฟ้มหนึ่งขึ้นมาในมือ

[ เอกสารเกี่ยวกับข้อเสนอทั้งหมดรวมไว้ในนี้ การประชุมงบประมาณเสริมน่ะ ทุกปีวุ่นวายมากเลย เตรียมใจไว้ให้ดี ล่ะ ]

ซากุไรมองแฟ้มที่ยื่นมา แล้วส่ายหน้าช้า ๆ ราวกับลังเล

[ ฮิบาเน่ ผมไม่ได้อยู่สภานักเรียนต่อนะ ]

[ ……งั้นเหรอ ขอโทษนะ พูดไปตามความเคยชินน่ะ ]

โฮโคบารุยิ้มเจื่อน ๆ แล้วลูบผิวหน้าของแฟ้มเบา ๆ

[ ฉันก็ไม่รู้ทำไมเหมือนกันว่าทำไม แค่รู้สึกว่าน่าจะส่งต่อให้นายได้ ถึงจะรู้ว่ายังไงมันก็เป็นไปไม่ได้ ]

เธอนิ่งมองแฟ้มในมือนิ่งสักพัก แล้ววางมันกลับลงบนโต๊ะเหมือนจะสะบัดความรู้สึกบางอย่างทิ้งไป

[ เอาล่ะ วันนี้พอแค่นี้เถอะ ฮิโรโตะ มีอะไรให้ช่วยอีกมั้ย? ]

เธอพูดพลางจับถังไว้——

แล้วในชั่วพริบตา ถุงก็หลุดออกมาพร้อมเสียงดัง แกร๊ก

[ ฮิบาเน่──! ]

ซาคุไนเพิ่งจะยื่นมือออกไป แต่โฮโคบารุกลับคว้าขอบถังไว้ด้วยมืออีกข้างได้อย่างรวดเร็ว

ทั้งสองคนถอนหายใจอย่างโล่งอก

[ ฉันก็ไม่ใช่คนที่ให้คนอื่นคอยดูแลตลอดหรอกนะ ]

[ อา โล่งอกขึ้นเยอะเลย ]

[ คงจะเยอะมากเลยล่ะสิ ]

ทั้งคู่สบตากันแล้วยิ้มออกมา

——ในตอนนั้น โทรศัพท์มือถือของซาคุไรก็ดังขึ้น

เมื่อเขามองไปที่หน้าจอ รอยยิ้มก็ค่อย ๆ เลือนหาย

[ ……โคฮารุสินะ ไม่ต้องเกรงใจฉันหรอก รับเถอะ ]

ซาคุไรจ้องหน้าจออยู่พักหนึ่ง ก่อนจะพลิกโทรศัพท์คว่ำหน้าลงบนโต๊ะ

[ ไว้โทรกลับทีหลังก็ได้ เวลานี้ถ้าโทรมาก็คงไม่ใช่เรื่องด่วนหรอก ]

เขาพูดด้วยน้ำเสียงที่ไม่อาจบอกอารมณ์ได้ แล้วก็เดินเข้ามาหาโต๊ะของโฮโคบารุ

[ ฮิบาเน่ ขอผมดูแฟ้มเมื่อกี้หน่อยสิ ]

[ มีอะไรเหรอ สนใจอะไรขึ้นมาหรือเปล่า? ]

โฮโคะบารุยื่นแฟ้มให้

เขารู้ตัวว่าไม่อาจละสายตาจากแฟ้มนั้นได้เลย

นั่นทำให้ซากุไรยื่นมือออกไปด้วยสีหน้าจริงจัง ราวกับตัดสินใจบางอย่างได้แล้ว

[ ──อา พอดีเริ่มจะสนใจขึ้นมานิดหน่อยน่ะ ]
