เล่ม 7 บทที่ 3-2

เช้าวันต่อมา ผมนั่งขยี้ตาง่วง ๆ อยู่ที่โต๊ะในห้องชมรมวรรณกรรม

แม้ว่าวันนี้จะเป็นวันหยุด แต่ยานามิ ชิราทามะซัง และผมก็มาตามคำเรียกของประธานนักเรียน

ประธานยืนกอดอกอยู่ข้างโต๊ะ มองไปรอบ ๆ พวกเรา

[ ครบแล้วเหรอ? เมื่อวานยังมีอีกคนหนึ่งอยู่นะ ]

[ โคมาริแอบมองเข้ามาในห้องจากหน้าต่างเมื่อกี้ แต่วิ่งหนีไป เริ่มได้เลย ]

ประธานพยักหน้าแล้วติดแผ่นกระดาษแผ่นใหญ่ลงบนไวท์บอร์ดที่เธอเอามาด้วย

บนกระดาษเขียนด้วยพู่กันตัวโตว่า "ศูนย์บัญชาการแผนแก้แค้นของชิราทามะ ริโกะ "

ชิราทามะซังยกมือขึ้นอย่างเกรงใจ

[ ...เอ่อ อะไรคือ 'แผนแก้แค้น' ที่เขียนอยู่นี่เหรอคะ? ]

[ อ้อ ฉันให้คุณย่าของฉันเขียนให้เมื่อเช้าน่ะ ท่านเป็นอาจารย์ที่ได้รับการรับรองด้วย ]

เข้าใจละ ถึงว่าเลยเขียนได้สวยขนาดนี้ แต่ดูเหมือนจะไม่ใช่คำตอบที่ชิราทามะซังกำลังมองหา

ประธานกางเก้าอี้พับแล้วทิ้งตัวลงนั่งอย่างหนักแน่น

[ เรามาคุยเรื่องแผนกันเถอะ ตอนนี้เป้าหมายคืออะไร? การเตรียมการไปถึงไหนแล้ว? ]

[ เอ่อ... ]

พอเห็นชิราทามะซังดูสับสน ผมเลยพูดแทรกขึ้นมา

[ พวกเราพึ่งตั้งเป้าหมายกันเอง ยังไม่ได้ตัดสินใจเรื่องอื่นเลยนะ ]

ประธานพยักหน้าแล้ววางกระดาษแผ่นหนึ่งลงบนโต๊ะ

[ ถ้างั้น จะลองขอความช่วยเหลือจากผู้เชี่ยวชาญดูมั้ย? เมื่อวานฉันบังเอิญเจอนี่มา ]

มันเป็นใบปลิวทำมือที่เขียนว่า "ทุกเรื่องเกี่ยวกับการสืบแบบลับ ๆ! ปรึกษาได้ที่ ‘ที่ปรึกษาด้านการสืบสวนซึวะบุกิ’"

[ ว้าว นั่นอะไรคะ ประธาน ? ]

ยานามิเอนตัวเข้ามาพร้อมกับข้าวปั้นมื้อเช้าที่สองของเช้าวันนี้

ใบปลิวเต็มไปด้วยคำอย่างเช่น "ลับสุดยอด" "ถูกกฎหมาย 100%" "ไม่มีค่าธรรมเนียมเบื้องต้น" และ "อยู่ระหว่างจดสิทธิบัตร" โดยใช้ฟอนต์ที่ดูสดใส

นี่มันโฆษณาแนวอินดี้ที่ไม่น่าไว้ใจ ที่บางทีก็เห็นติดอยู่ตามเสาไฟฟ้าชัด ๆ

[ นี่ ประธาน นี่มันดูไม่น่าไว้ใจเลยนะครับ ]

[ ไม่ต้องห่วง เป็นนักเรียนโรงเรียนซึวะบุกิที่ทำการวิจัยอิสระ พวกเขาไว้ใจได้ ]

มีคนในโรงเรียนเราทำอะไรแบบนี้ด้วยเหรอ...?

ผมพอจะนึกถึงคนคนหนึ่งขึ้นมาได้ แต่ก็นะ ไม่น่าใช่หรอก

ในขณะที่กำลังรู้สึกไม่สบายใจ ประธานเหลือบมองนาฬิกาที่ติดอยู่บนผนัง

[ ใกล้ถึงเวลาแล้ว ฉันนัดปรึกษาไว้แล้วล่ะ ]

[ หา? ]

พอดีกับที่มีเสียงเคาะประตูดังขึ้น

ประตูค่อย ๆ เปิดออก เผยให้เห็นเด็กสาวคนหนึ่งที่ผมคุ้นหน้า

เธอโค้งตัวลงโดยที่หน้าผากของเธอเป็นประกาย

[ ฉัน อาซากุโมะ จิฮายะ จาก ‘ที่ปรึกษาด้านการสืบสวนซึวะบุกิ’ ค่ะ และนี่คือ— ]

จากข้างหลังเธอ เด็กสาวอีกคนที่คุ้นหน้าเดินออกมา

[ นุคุมิซึ คาจู ผู้ช่วยของเธอค่ะ พวกเราจะทำให้เต็มที่ค่ะ ]

เหล่าสมาชิกชมรมวรรณกรรมจ้องมองผมด้วยสายตาจับผิด

ไม่นะ นี่ไม่ใช่ความผิดผมหรอก……….ใช่มั้ย.……..? อ่า น่าจะไม่ใช่แหละ...

◇

อาซากุโมะซังจาก ‘ที่ปรึกษาด้านการสืบสวนซึวะบุกิ’ เขียนคำว่า "ข้อมูล" และ "การเตรียมตัว" ตัวใหญ่ ๆ ลงบนไวท์บอร์ด แล้ววงกลมรอบคำเหล่านั้น

[ ขั้นตอนแรกคือการรวบรวมข้อมูลและเตรียมการล่วงหน้า และ— ]

เธอเขียนคำว่า "เป้าหมาย" ตัวใหญ่กว่าเดิม

[ สิ่งสำคัญคือการแบ่งปันเป้าหมายภายในทีม ริโกะซัง งานแต่งคือเมื่อไหร่คะ? ]

[ อ่า ใช่ วันเสาร์หน้าค่ะ ]

งานแต่งจะจัดในอีกเก้าวัน ซึ่งเป็นสุดสัปดาห์แรกหลังวันหยุดโกลเด้นวีค

อาซากุโมะซังพยักหน้าแล้วเริ่มเขียนวันที่ตั้งแต่วันนี้ไปจนถึงวันงานแต่งเรียงลำดับลงบนไวท์บอร์ด

[ เรามีเดดไลน์ที่ชัดเจน ดังนั้นแทนที่จะจัดการความคืบหน้าด้วยเป้าหมายย่อย ๆ เราจะใช้วิธีจัดการด้วยงานแต่ละอย่าง ก่อนอื่นเราจะแบ่งปันข้อมูลและระบุงานที่จำเป็น วันหยุดโกลเด้นวีคจะเริ่มมะรืนนี้ ดังนั้นเราจะใช้เวลาช่วงนั้นเตรียมการให้เสร็จ ]

พวกเราจะใช้วันหยุดโกลเด้นวีคปีนี้เตรียมตัวทำเรื่องผิดกฎหมาย…เจ๋งไปเลย

หลังจากเขียนปฏิทินเสร็จ อาซากุโมะซังก็หันมาทางพวกเรา

[ เป้าหมายชัดเจนแล้ว พวกเราต้องถ่ายภาพงานแต่งของทานากะเซ็นเซกับริโกะซังโดยไม่ให้ใครจับได้ในวันงานแต่ง ]

...ปัญหาอยู่ที่เงื่อนไขนี้นี่แหละ เส้นทางสู่ความสำเร็จแคบมาก และมีอุปสรรคให้ข้ามมากมาย

เมื่อทุกคนเงียบกันไป ผมจึงยกมือขึ้นเล็กน้อย

[ เอ่อ เราอาจต้องยืดหยุ่นเป้าหมายตามสถานการณ์นะครับ ]

[ ถึงแม้จะต้องปรับเป้าหมาย การรวบรวมข้อมูลก็ยังจำเป็นอยู่ดี ก่อนอื่นมาดูสถานการณ์ปัจจุบันกัน ]

เมื่ออาซากุโมะซังให้สัญญาณ คาจูก็เปิดโปรเจคเตอร์ที่เตรียมมา

บนผนังสีขาวปรากฏภาพถ่ายมุมสูงของแผนที่เมือง

สถานที่จัดงานแต่งถูกทำเครื่องหมายไว้อย่างชัดเจน อยู่ใกล้ย่านใจกลางเมือง

มันอยู่ใกล้สวนสาธารณะมุไคยะมะ และติดกับโรงเรียนมัธยมปลายคิริโนะกิประจำจังหวัด

[ สถานที่นี้ถูกปิดกั้นจากภายนอก เราจึงมองเห็นภายในได้แค่จากรูปในเว็บไซต์ ริโกะซัง รู้แผนผังภายในมั้ยคะ? ]

ชิราทามะซังส่ายหน้าเงียบ ๆ

[ การเข้าใจแผนผังภายในเป็นเรื่องสำคัญอันดับแรก เดี๋ยวฉันจะให้ผู้ช่วยของฉันดูแลส่วนนี้ ]

เมื่ออาซากุโมะซังก้าวถอยไป คาจูก็เดินขึ้นมาแทน

[ คาจูไปสำรวจสถานที่มาเมื่อเช้านี้ค่ะ ]

[ เอ๊ะ? เมื่อไหร่กัน? ทำไมไม่เห็นไม่รู้เลย? ]

คาจูยังอุตส่าห์ทำอาหารเช้าและเตรียมเสื้อผ้าให้ผมด้วย

เธอขยิบตาให้ผมก่อนจะพูดต่อ

[ ผู้จัดการอยู่ที่ทางเข้า เลยมีโอกาสได้พูดคุยกับเขาค่ะ ที่นี่จัดงานแต่งแค่วันละสองงานเท่านั้น และมีบริการจัดงานในสวนแบบเป็นส่วนตัวด้วย ]

คาจูหยิบสมาร์ทโฟนขึ้นมาแล้วฉายภาพถ่ายบนหน้าจอโปรเจคเตอร์

[ สถานที่นี้ถูกล้อมด้วยกำแพงเพื่อความเป็นส่วนตัว โดยมีทางเข้าใหญ่เป็นทางเข้าทางเดียว ในวันงานแต่ง คนที่เกี่ยวข้องกับริโกะซังเท่านั้นถึงจะเข้าไปได้ค่ะ ]

...เข้าใจละ แบบนี้ไม่ง่ายเลย เพราะมันเป็นงานส่วนตัว เราจึงไม่สามารถปลอมตัวเป็นแขกของงานอื่นได้

[ แต่คาจู การที่ไปพูดคุยกับพนักงานสถานที่ มันไม่ดูน่าสงสัยเหรอ? ]

[ ไม่ค่ะ เขาเป็นสุภาพบุรุษมากเลย แถมยังให้บัตรธุรกิจหนูมาด้วย ]

— สุภาพบุรุษเหรอ แสดงว่าเป็นผู้ชายสินะ? แต่เพศไม่ได้สำคัญขนาดนั้นหรอก

[ ขอบัตรนั่นหน่อย คาจู เธอไม่ได้ให้ข้อมูลติดต่อพวกเขาไปใช่มั้ย? ]

พอผมจะลุกขึ้น ยานามิก็ดึงผมกลับมานั่งลงบนเก้าอี้

[ นั่งลงไปเลย นุคุมิซึคุง แล้วน้องสาวจังล่ะ ประทับใจอะไรเป็นพิเศษจากการสืบสวนบ้าง? ]

[ ค่ะ บรรยากาศดีมากเลย! สักวันนึง คาจูอยากแต่งงานที่นั่นค่ะ! ]

คาจูพนมมือไว้ที่อก ดวงตาเปล่งประกาย ขณะมองมาที่ผม

ประธานซึ่งเงียบฟังมาตลอด ขยับขาไขว้กันแล้วทำท่าคิดหนัก

[ อืม ถ้างั้นเราต้องสำรวจสถานที่ก่อน คาจูคุง มีไอเดียอะไรอีกมั้ย ? ]

คาจูพยักหน้าแล้วยิ้ม

[ ค่ะ วันเสาร์นี้มีทัวร์สถานที่ว่างเพราะมีคนยกเลิก คาจูจองพวกเราไว้แล้วค่ะ ]

โอ๊ะ เตรียมตัวไว้พร้อมขนาดนี้เลย จองทัวร์สถานที่ได้—

[ เดี๋ยวนะ เราจะเข้าร่วมโดยไม่มีแผนแต่งงาน มันไม่แปลกเหรอ ? แล้วพวกเราเป็นแค่นักเรียนมัธยมปลายนะ ]

อาซากุโมะซังยิ้มเหมือนเรื่องนี้ไม่ใช่ปัญหาอะไร

[ อาระ เราก็แค่ต้องแต่งงานกันในอนาคตเท่านั้นเอง ตอนนี้มาตัดสินใจกันก่อนว่าใครจะเข้าร่วมทัวร์ดี ]

อาซากุโมะซังค่อย ๆ มองไปรอบ ๆ พวกเรา

[ ยานามิซัง ลุกขึ้นทำไม ? ]

[ เอ๊ะ? คือ มันต้องเป็นคนที่ดูโตหน่อยใช่มั้ยล่ะ ? ]

[ ใช่ แต่เพราะงั้นเธอก็ควรนั่งลงนะ ]

ผมคิดเรื่องนี้อยู่ครู่หนึ่งก่อนจะช่วยให้เธอกลับไปนั่งบนเก้าอี้

นักเรียนมัธยมปลายที่ดูเป็นผู้ใหญ่ทั้งในรูปลักษณ์และการกระทำมันหายาก—

[ อืม? มีอะไรเหรอทุกคน? ]

สายตาทุกคู่หันไปทางประธาน อาซะกุโมะซังเดินเข้าไปหาเธอ

[ แล้วประธานล่ะ? ไปทัวร์ได้มั้ย ? ]

[ ฉันก็อยากช่วยนะ แต่วันเสาร์ฉันมีพิธีรำลึก เป็นงานครบรอบ 50 ปีคุณปู่ทวด ฉันคงพลาดไม่ได้ ]

ดวงตาของประธานเป็นประกาย ดูเหมือนเธอจะเป็นคนที่ชอบเข้าร่วมพิธีรำลึก…

[ ก็คงช่วยไม่ได้ งั้นนั่งลงก่อนนะ ยานามิซัง ]

ปัญหามาแล้ว ถ้าประธานไปไม่ได้ใครจะไปแทน?

เมื่อเธอเห็นความกังวลของพวกเรา ประธานก็พูดขึ้นมา

[ ลองถามชิกิยะดูสิ เธอเก็บความลับได้ดีนะ ]

ชิกิยะซังเหรอ…? เธอดูเป็นผู้ใหญ่ก็จริง แต่จะไว้ใจได้มั้ยเนี่ย?

คาจูไม่สนใจความกังวลของผม แล้วเขียนชื่อชิกิยะซังลงบนไวท์บอร์ด

อาซากุโมะซังเอียงคอเล็กน้อยขณะใช้นิ้วแตะคางอย่างน่ารัก

[ งั้น ใครจะเป็นคู่ของเธอดี? มีใครนึกออกมั้ย ? ]

อืม...คนที่ดูเข้ากันได้กับชิกิยะซังโดยไม่ดูแปลกเกินไป— อ๊ะ!

[ ถ้าเป็นอายาโนะล่ะว่าไง? เขาดูเป็นผู้ใหญ่ดีนะ แล้วถ้าใส่สูท... ]

[ ไม่ค่ะ ]

อาซากุโมะซังตอบสวนทันทีด้วยน้ำเสียงหนักแน่น

[ เอ๊ะ? แต่เขาน่าจะ... ]

[ ไม่ได้เด็ดขาดค่ะ ]

เธอยิ้มหวานมาให้ แต่ในดวงตานั้นไม่มีความยิ้มแย้มเลยสักนิด

[ เขามีนัดสำคัญที่เลี่ยงไม่ได้ในวันนั้น นุคุมิซึซัง ฉันจัดงานรำลึกให้ได้นะ ถ้าอยากได้ข้ออ้างบ้าง— ]
