เล่ม 5 บทที่ 3-4

รายงานจากชมรมวรรณกรรม - ฉบับพิเศษ

<ของขวัญปีใหม่> โดย ยานามิ อันนะ

ฉันมักจะทานอาหารเช้าที่ร้านสะดวกซื้อ

ช่วงนี้สิ่งที่ฉันชอบในพื้นที่พักผ่อนนี้คือ ไก่ย่างถ่านเสียบไม้(เกลือ) คิดว่าไม่จำเป็นต้องอธิบายหรอก

ใครที่สนใจสามารถดูตารางส่วนผสมได้เลย ใช่แล้ว แถวที่มีคาร์โบไฮเดรตนั่นแหละ

แม้ว่าฉันจะจำตัวเลขจริงๆ ไม่ได้ แต่นี่มคือแชมป์เลยเพราะคาร์โบไฮเดรตต่ำมาก

อีกอย่าง ฉันดื่มกาแฟดำร้อนแทนลาเต้ด้วย

นี่ก็เป็นแชมป์ในเรื่องของค่าที่ต่ำเช่นกัน นี่มันแชมป์สองรายการติดต่อกันเลย

ทุกวันนี้ ร้านสะดวกซื้ออนุญาตให้คุณเลือกความเข้มของกาแฟได้ตั้งแต่ "เบา" ถึง "เข้ม" แต่วันนี้รู้สึกว่ามันเข้มเป็นพิเศษ

ช่วงนี้ฉันหยุดออกจากบ้านแต่เช้า นั่นเป็นเหตุผลที่ฉันไม่เห็น OO-คุงไปโรงเรียนจากหน้าต่างเลย

[ อาโกะซัง ช่วงนี้เธอหยุดกินซาลาเปาเนื้อแล้วเหรอ? ]

คนที่พูดสิ่งที่ไม่จำเป็นนั่นคือเพื่อนร่วมชั้นของฉัน XX-คุง

เมื่อเร็วๆ นี้พวกเรามักจะนั่งกินด้วยกันที่มุมห้อง

และที่จริงฉันเคยกินซาลาเปาหมูต่างหาก นายมันมือสมัครเล่นจริงๆ

เขามักจะนั่งห่างจากฉันสองที่เสมอ คิดว่าตัวเองเป็นคนสำคัญหรือไง น่ารังเกียจจริงๆ

แม้ว่าเขาจะไม่สนใจคนอื่นในทุกๆเรื่อง แต่วันนี้เขายิ่งเลวร้ายกว่าเดิมอีก ไม่อยากจะเชื่อเลยว่าเขากินฮอทดอกอเมริกันในตอนเช้า

ใช่แล้ว คาร์โบไฮเดรตในฮอทดอกมีเกิน 30 กรัม

ฉันก็อยากจะกินบ้างอะ

อีกอย่าง วันนี้เขาก็ดื่มลาเต้แทนที่จะเป็นกาแฟ

ฉันก็อยากดื่มบ้างอะ

ฉันคิดว่าอาจจะขอเขากินสักคำ แต่แล้วก็มีเด็กผู้หญิงคนหนึ่งจากโรงเรียนของเรามาพูดกับ XX-คุง

ทั้งสองกระซิบอะไรบางอย่างกัน แล้วหลังจากนั้นไม่นาน เด็กผู้หญิงคนนั้นก็ไปกัดฮอทดอกของ XX-คุง ก่อนจะจากไป

...แม้ว่าฉันจะไม่รู้ว่าเธอเป็นใคร แต่อยากกินอาหารของคนอื่นเนี่ย เป็นผู้หญิงที่ตะกละและน่ารังเกียจจริงๆเลย

XX-คุงหัวเราะหลังจากที่ฉันกินไก่เสียบไม้เสร็จ

[ อาโกะซัง ยังหิวอยู่เหรอ? ]

หมอนี่หยาบคายเหมือนเคยเลย

XX-คุงยื่นอะไรบางอย่างให้ฉันพอฉันกำลังจะเมินเขา…..มันคือเต้าหู้แท่งรสพริกยูสุ

เต้าหู้แท่งนี้ให้โปรตีน 10 กรัมต่อแท่ง เคี้ยวหนึบๆ ดีด้วย

[ ฉันคิดว่าเธอน่าจะพยายามลดน้ำหนักช่วงนี้น่ะ…. นี่ของว่างเล็กๆ น้อยๆ สำหรับเธอ ]

...หมอนี่มันหยาบคายจริงๆนั้นแหละ

ฉันนึกถึงเด็กผู้หญิงคนนั้นขณะที่เคี้ยวเต้าหู้แท่งจากคนอื่น

เมื่อเปรียบเทียบระหว่างเต้าหู้แท่งกับการได้กัดฮอทดอกอเมริกัน ฉันคิดว่าเรื่องนี้ฉันชนะ

แม้จะรู้สึกอย่างนั้น แต่ไม่รู้ทำไม หัวใจของฉันรู้สึกคันนิดหน่อย น่ารำคาญจัง...

✧✧✧

หลังจากพิมพ์ฉบับร่างทั้งหมดเสร็จ ผมก็ยืนอยู่หน้าร้านเบเกอรี่ข้างถนนไม่ไกลจากโรงเรียน

ยานามิเรียกผมให้มาที่นี่ตอนกำลังจะกลับบ้าน

ยานามิซื้อขนมปังจากที่นี่บ่อยๆ แต่สำหรับผมนี่เป็นครั้งแรกที่มา...

ผมมองไปรอบๆ ก่อนจะเดินเข้าไปในร้าน ยานามิกำลังจ่ายเงินพอดี

[ โอ๊ะ มาแล้วเหรอนุคุมิซึคุง เอานี่ไปสิ อันนี้สำหรับนาย ]

เธอพูดแบบนั้นและยื่นขนมปังให้ผม เป็น "ขนมปังโอกุระ" ไส้ถั่วแดง

ยานามิชอบซื้อแบบนี้เสมอ ถ้าร่างกายเธอพร้อม เธอจะกินมัน 8 ครั้งต่อสัปดาห์

[ ขอบคุณนะ ฉันจะไปซื้อเครื่องดื่ม ถ้าเป็นนมล่ะโอเคมั้ย? ]

[ โอเค ]

ยานามิโบกมือขณะที่เธอเดินเข้าไปในร้าน ด้านในมีโต๊ะและเก้าอี้อยู่ เรานั่งกินที่นั่นได้

ผมหยิบนมและนั่งบนเก้าอี้ฝั่งตรงข้าม ยานามิเปิดห่อขนมปังและหัวเราะ

[ นุคุมิซึคุง นายโตขึ้นแล้วนะ ]

[ เอ๋ ว่าอะไรนะ? ]

ผมใส่หลอดลงในกล่องนมพร้อมคอยระวังสิ่งในที่เธอกำลังจะพูด

[ ก็เมื่อก่อนเจอกันแค่ 2 วินาที นายก็เริ่มถาม”ทำไม”แล้ว แต่ตอนนี้ นายคุยได้ปกติขึ้นแล้วนะ ]

ยานามิพูดแล้วกัดขนมปังคำใหญ่

...นั่นคงเป็นเพราะผมเรียนรู้แล้วว่า ต่อให้ถามตรงๆ ก็ไม่ได้อะไรกลับมาจากยานามิหรอก? นี่ถือว่าเป็นการเติบโตหรือเปล่า...?

[ ขอโทษที่ถามหลังจากได้ยินแบบนั้นนะ ทำไมถึงพามาที่นี่ล่ะ? ]

[ เอ๊ะ ก็ฉันหิวนี่นา ]

ดูสิ เรายังคุยกันไม่รู้เรื่องเหมือนเดิม ผมพยายามไม่ถอนหายใจแล้วเปิดห่อขนมปัง

[ ยานามิซังหิวตลอดเวลาเลยสินะ เอ่อ ถ้าเธออุตส่าห์เรียกผมมาที่นี่ แสดงว่าเธอมีอะไรอยากจะคุยกับฉันใช่มั้ย? ]

ยานามิหยิบสมุดเล่มเล็กขึ้นมาตอนกำลังเคี้ยวขนมปังอยู่

[ ง่ำ ง่ำ ง่ำ ง่ำ ง่ำ ]

อย่าพูดตอนที่กินอยู่สิ

อ๊ะ สมุดเล่มนี้...

[ นี่มันสมุดสำหรับไกด์ใช่มั้ย? เอามาให้ผมเหรอ ]

ยานามิกลืนขนมปังลงไปในคราวเดียว

[ นุคุมิซึคุง ทั้งที่มีชื่อนายในรายชื่แต่นายกลับไม่มาฟังบรรยาย ฉันเลยจะมาสรุปให้- ]

[ บาโซริซังบอกฉันไปหมดแล้วล่ะ ไว้เจอกันตอนบ่ายโมงที่โรงยิมก็พอ ]

[ เอ๊ะ ]

ยานามิหยุดมือขณะที่กำลังจะเสียบหลอดนม

[ ทำไมต้องเป็นยัยนั่นอะ? เธอไปตามหานายถึงที่เลยเหรอ? ]

[ ก็เพราะสภานักเรียนดูแลเรื่องวันเปิดบ้านนี่นา คงตามหาฉันเพราะไม่ได้ไปฟังบรรยาย ]

ไม่รู้ทำไม ยานามิมองผมด้วยสายตาเหมือนไม่พอใจ

ซักพักเธอก็เหมือนจะหายดี แล้วก็เปิดสมุดออก

[ เอาล่ะ นุคุมิซึคุง นายต้องดูแลพวกทาจิบานะคุงใช่มั้ย? เด็กที่ไปเดทกับน้องสาวนายที่ศาลเจ้าโทโยคาวะอินาริน่ะ ]

สีหน้าผมแข็งทื่อ และมองยานามิอย่างเคร่งเครียด

[ ...ยานามิซัง เธอรู้จักทฤษฎีแมวของชโรดิงเงอร์มั้ย? ]

ยานามิหยุดดื่มนมแล้วเอียงหัวสงสัย

[ ที่แมวตายเมื่อเปิดกล่องนั่นใช่มั้ย? ]

ใกล้เคียง แต่ไม่ใช่แบบนั้น

[ ในสถานการณ์แบบนี้ เหตุการณ์จะไม่แน่นอนจนกว่าจะได้เห็นโดยตรง ไม่ได้ปฏิเสธว่าคาจูสนิทกับทาจิบานะคุง แต่ก็ไม่มีหลักฐานว่าพวกเขาเดทกัน หรือไปไหนด้วยกัน ]

ยานามิส่ายหัวท่าทางจะไม่เชื่อ

[ นายยังพูดแบบนั้นอีกเหรอ? เลม่อนจังเล่าให้ฟังถึงสิ่งที่นายทำที่โมโมโซโนะแล้วนะ ไม่ใช่ว่าน้องสาวนายกับทาจิบานะคุงทำตัวคลุมเครือหรอ? พวกเขามีเดทกันในวันวาเลนไทน์—]

ยานามิหยุดชะงักทันที ด้วยดวงตาที่เบิกกว้าง

[ ใช่สิ สัญญาวันวาเลนไทน์ของคาจูกับทาจิบานะคุงต้องเกี่ยวกับวันเปิดบ้านแน่ๆ เป็นเรื่องปกติที่เพื่อนที่อยากเรียนที่ซึวะบุกิจะมาด้วยกันแหละ ใช่มั้ย? ]

[ แล้วเรื่องพวกที่เธอพูดถึงที่เขาแล้วไม่กล้าพูดต่อหน้าคนอื่นล่ะ? ]

[ คาจูเป็นเด็กวัยรุ่นนี่นา พอให้พี่ชายตัวเองคอยพานำ ก็ต้องรู้สึกอายบ้างแหละ ]

[ ...น้องสาวนายเป็นแบบนั้นเหรอ? ]

ก็ใช่ ยานามิเอามือจับคางแล้วเอียงหัว

[ แล้วช็อกโกแลตทำมือสำหรับคนพิเศษล่ะ? ]

อึก คำพูดของเธอจี้จุดผมไปเต็มๆ ผมรีบดื่มนมรวดเดียวหมดเพื่อเพิ่มแคลเซียม

[ ก็...ให้ช็อกโกแลตกับเพื่อนก็ได้เหมือนกันใช่มั้ยล่ะ? แน่นอนว่าไม่แปลกหรอกถ้าคาจูจะมีคนที่แอบชอบ แต่ตราบใดที่เธอไม่พูดเองเราก็ยังไม่รู้หรอก ]

[ อืม ก็คงเป็นอย่างนั้น ]

ยานามิตอบด้วยท่าทางใจเย็นก่อนจะดื่มนมจนหมด

[ ถ้านายเอาแต่ปฏิเสธ น้องสาวนายก็ไม่พูดอะไรกับนายหรอก ]

[ อืม... คงงั้น ]

[ ใช่แล้วล่ะ นุคุมิซึคุง เด็กมัธยมต้นจะมีแฟนถือเป็นเรื่องปกตินะ ]

ไม่รู้ทำไม รู้สึกว่าผมเถียงกับยานามิเรื่องนี้ไม่ได้เลย...

[ แต่มันก็ไม่แน่นอน... ]

[ โถ่...นายไม่ยอมแพ้เลยนะ ]

พูดอะไรก็พูดไปเถอะ ผมกัดขนมปังคำเล็กๆ เข้าปาก

[ นุคุมิซึคุง ทำไมกินช้าจัง? ]

ยานามิถามอย่างสงสัยด้วยน้ำเสียงใสซื่อ

[ ไม่รู้ว่าจะกินหมดหรือเปล่า แล้วถ้ากินมากไปก็คงกินข้าวเย็นไม่ลง ]

[ ไม่เป็นไรหรอก นายกินหมดได้แน่นอน ]

ยานามิตอบอย่างมั่นใจ

[ เอ๋ แต่— ]

[ นายต้องเชื่อมั่นในตัวเองมากกว่านี้สิ เด็กผู้หญิงอย่างฉันยังกินหมดเลย ทั้งๆ ที่เผลอซื้อมาสองชิ้น ]

เธอถึงซื้อมาให้ผมนี่เอง

เมื่อเห็นว่ายานามิมองผมกินขนมปังไปครึ่งหนึ่ง...ผมเริ่มรู้สึกอายที่จะกินต่อ

[ เอ่อ... เธออยากได้สักครึ่งนึงมั้ย ? ]

ผมพูดออกไปเพราะทนความอึดอัดไม่ไหว จากนั้นผมก็ได้เห็นรอยยิ้มที่น่ารักที่สุดของยานามิในวันนี้ เธอยื่นมือออกมา

[ ช่วยไม่ได้แหะ...เดี๋ยวฉันช่วยเอง ]
