บทที่9 ระยะห่างถึงเธอคือกี่ปีแสงกันนะ

คาบเรียนที่ 3 จบลง นักเรียนห้อง 2-C ต่างทยอยลุกจากที่นั่ง คาบต่อไปต้องเปลี่ยนห้องเรียน

โคมาริรอจนแน่ใจว่าเพื่อนร่วมชั้นส่วนใหญ่ออกจากห้องไปแล้ว ถึงได้เริ่มเตรียมตัวสำหรับคาบต่อไป

รอบตัวโคมาริที่กำลังงุ่มง่ามเตรียมหนังสือเรียน จู่ๆ ก็มีแสงสว่างเจิดจ้าเปล่งประกายขึ้นมา

──ฮิเมมิยะ คาเรน คาเรนมายืนอยู่ข้างโต๊ะของโคมาริ พร้อมส่งยิ้มสดใสไร้กังวลมาให้

[ โคมาริจังอยู่คนเดียวเหรอ? อันนะไปไหนซะล่ะเนี่ย ]

[ เหวอ……เอ่อ ค-คือว่า ]

เมื่อเห็นท่าทีประหม่าของโคมาริ คาเรนก็ลดระดับความเจิดจ้าลง

[ งั้นเหรอ เป็นเวรประจำวันก็เลยล่วงหน้าไปก่อนล่ะมั้ง ถ้างั้นก็เหลือแค่เราสองคนสินะ ]

[ ช-ใช่…… ]

โคมาริหอบหนังสือเรียนแล้วลุกพรวดขึ้นมา

[ ถ้างั้นก็ไปพร้อมกับฉัน──เดี๋ยวซี้! โคมาริจัง ไปด้วยกันสิ! ]

คาเรนรีบวิ่งเหยาะๆ ตามโคมาริที่ทำท่าจะเดินออกจากห้องไปคนเดียว

[ ไหนๆ ก็ไหนๆ แล้ว มาคุยกันหน่อยไหม ]

โคมาริพิมพ์ข้อความลงในสมาร์ทโฟนอย่างรวดเร็ว แล้วหันหน้าจอให้คาเรนดู

『แต่ว่า หลังจากนี้ต้องไปที่ห้องโสตทัศนศึกษาแล้วนี่นา』

[ ฉันก็จะไปเหมือนกันไง?! ]

ต่อให้เป็นฮิเมมิยะ คาเรนระดับ 8K ก็ตบมุกกลับแทบไม่ทัน คาเรนเอามือทาบอกตูมๆของตัวเองแล้วสูดหายใจเข้าลึกๆ

[ เอาล่ะ ขอถามควิซหน่อยนะ ชื่อเต็มของฉันคืออะไรเอ่ย ]

[ ……? ]

โคมาริจิ้มสมาร์ทโฟนก๊อกแก๊กๆ ด้วยความสับสนกับควิซที่โผล่มาแบบไม่มีปี่มีขลุ่ย

『ฮิเมมิยะ คาเรน』

[ ปิ๊งป่อง ถูกต้องจ้า ฉันชื่อฮิเมมิยะ คาเรน ส่วนชื่อเต็มของโคมาริจังคือ โคมาริ จิกะ──แต่ว่านะ ]

อะแฮ่ม คาเรนกระแอมไอเบาๆ

[ ของกินที่โคมาริจังชอบคืออะไรเอ่ย ]

[ อ-เอ่อ── ]

โคมาริจิ้มสมาร์ทโฟนด้วยความสับสนกับคำถามที่โพล่งขึ้นมา

『เต้าหู้ไข่』

พอเห็นคำตอบ คาเรนก็ตบมือดังแปะ

[ ถ้าเป็นเต้าหู้ไข่ฉันก็กินบ่อยนะ! วันก่อนซื้อจากเซโจอิชิอิมา อร่อยมากเลย โคมาริจังชอบของที่ไหนล่ะ ]

โคมาริลังเลเล็กน้อย ก่อนจะพิมพ์คำตอบลงในสมาร์ทโฟน

『เคยกินแต่แบบแพ็ก 3 ชิ้นที่ขายตามร้านขายยาเท่านั้นแหละ』

[ ……เอ่อ อื้ม เต้าหู้ไข่ไม่ว่าอันไหนก็อร่อยทั้งนั้นแหละเนอะ ]

คาเรนลดระดับความสว่างลงไปอีกขั้น……คุยไม่ค่อยสนุกอย่างที่คิดไว้เลยแฮะ

ระหว่างที่นางเอก 8K ฮิเมมิยะ คาเรน กำลังกลุ้มใจ โคมาริก็ค่อยๆ ยื่นหน้าจอสมาร์ทโฟนให้ดูอย่างกล้าๆ กลัวๆ

『จากตรงนี้ไปห้องโสตฯ ใช้เวลาอีก 85 วินาที ไม่ต้องฝืนชวนคุยก็ได้นะ』

พอแน่ใจว่าคาเรนเห็นข้อความแล้ว โคมาริก็เร่งฝีเท้าเดินทิ้งห่างคาเรนไป

คาเรนไม่รอช้า รีบสาวเท้าเข้าไปเดินเคียงข้างโคมาริอีกครั้งทันที

[ สำหรับฉัน การได้คุยกับโคมาริจังมันสนุกมากเลยนะ ]

[ ………… ]

แววตาของโคมาริฉายแววระแวดระวังอย่างปิดไม่มิด คาเรนรับรู้ถึงสายตานั้นด้วยรอยยิ้ม แล้วพูดต่อด้วยน้ำเสียงอ่อนโยน

[ ที่ถามไปก็ไม่ได้ฝืนหาเรื่องมาคุยหรอกนะ แค่คิดว่าถ้าค่อยๆ ทำความรู้จักโคมาริจังไปทีละเรื่องแบบนี้ ทุกๆ วันเราก็น่าจะสนิทกันมากขึ้นทีละนิดใช่ไหมล่ะ ]

แสงสว่างเริ่มเจิดจ้าขึ้นทีละน้อย เสียง BGM ค่อยๆ ดังใกล้เข้ามาจากที่ไกลๆ

[ แต่ถ้าทำให้รู้สึกอึดอัดก็ขอโทษด้วยนะ ฉันมักจะโดนดุบ่อยๆ ว่าชอบตีสนิทเกินเบอร์น่ะ ]

โป๊ะ คาเรนเขกหัวตัวเองเบาๆ

โคมาริที่เอาแต่เงียบมาตลอด ทำท่าจะหยิบสมาร์ทโฟนขึ้นมา──แต่แล้วก็เก็บมันกลับลงกระเป๋า

[ ฉ-ฉันเอง ก็……ม-ไม่ได้รังเกียจที่จะคุยด้วย หรอกนะ ]

โคมาริพึมพำด้วยน้ำเสียงแผ่วเบาราวกับยุงบิน ก่อนจะก้มหน้างุดจนใบหน้าแดงก่ำ

……น่ารักจัง คาเรนกลืนคำพูดที่เกือบจะหลุดปากออกไปลงคอ

ท่ามกลางเสียงอินโทร BGM ที่เผลอดังขึ้นมา จู่ๆ ก็มีเสียงทักทายอย่างร่าเริงแทรกขึ้น

[ อ้าว ทั้งสองคนกำลังจะไปไหนน่ะ คาบเรียนใกล้จะเริ่มแล้วนะ ]

เจ้าของเสียงคือ ยานามิ อันนะ เธอโผล่มาพร้อมกับกินขนมปังไส้ถั่วแดงที่เพิ่งซื้อจากสหกรณ์ไปด้วย

[ อันนะ คาบต่อไปเรียนที่ห้องโสตฯ นะ แล้วหนังสือเรียนเธอไปไหนล่ะ ]

[ หืม ? อ่อเหรอ ]

ว่าแล้วก็งับขนมปังไส้ถั่วแดงเข้าปากไปอีกคำ

[ อ-อีกอย่าง เธอเป็นเวรประจำวันไม่ใช่เหรอ ไม่รีบไป จะดีเหรอ ]

[ อ๊ะ จริงด้วย! ฝากบอกอาจารย์ให้เนียนๆ ด้วยนะ! ]

ยานามิยัดขนมปังที่เหลือเข้าปาก แล้วรีบวิ่งแจ้นกลับไปทางห้องเรียน

ทั้งสองคนมองตามแผ่นหลังนั้นไปพลางยักไหล่แล้วหันมาสบตากัน

[ อันนะก็ยังเป็นอันนะล่ะน้า คงต้องช่วยพูดกับอาจารย์ให้เนียนๆ หน่อยแล้ว ]

[ ง-งั้นฝากด้วยนะ ]

[ รับทราบ ฮิเมมิยะ คาเรน รับเรื่องแล้วจ้า! ]

เมื่อเจอคาเรนหัวเราะด้วยน้ำเสียงสดใสราวกับกระดิ่งกรุ๊งกริ๊ง โคมาริก็ส่งยิ้มเจื่อนๆ กลับไป──
