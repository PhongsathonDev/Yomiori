เล่ม 5 บทที่ 4-6

ผมเดินไปทางอาคารเรียนผ่านถนนที่เรียงรายไปด้วยต้นทิวลิป ขณะที่เดินไป ผมได้ยินเสียงโหวกเหวกและห้าวหาญของพวกชมรมกีฬาในสนาม

ผมแอบเหลือบมองไปในทิศนั้น ยากิชิโอะยืนอยู่ในกลุ่มของชมรมกรีฑา ที่นั่นยังมีสมาชิกจากชมรมเบสบอลและชมรมฟุตบอลด้วย

เธอเคยเป็นคนที่รักการเล่นกีฬาในโรงเรียนโมโมโซโนะ แต่ตอนนี้เธอแตกต่างไปแล้ว สาวคนนั้นกำลังตรวจเช็คตำแหน่งของผู้เข้าชมจากระยะไกล ผมสามารถบอกได้เลยว่าเธอจริงจังแค่ไหนจากจุดนี้

เด็กสาวคนนั้นจะได้เป็นรุ่นพี่ในเดือนเมษายนนี้ และเธอก็ต้องนำรุ่นน้องต่อไปสินะ?

ผมเองก็จะกลายเป็นรุ่นพี่เหมือนกัน แต่พวกเราต้องหาสมาชิกใหม่เข้าชมรมของเราก่อน

อย่างไรก็ตาม มีปัญหาที่ผมต้องแก้ไขก่อนหน้านั้น

คาจูหายตัวไปไหนก็ไม่รู้ และกอนโดซังก็รีบออกไปจากที่นั่นเหมือนถูกไฟลน

ผมไม่เชื่อว่าทั้งสองคนจะหายไปพร้อม ๆ กันด้วยความบังเอิญ

พวกเธอคงต้องกำลังตามหาทาจิบานะคุงอยู่แน่ ๆ

แม้ว่าผมอาจจะหยาบคายที่ขัดจังหวะพวกเขา แต่ก็ยังรู้สึกเหมือนพลาดอะไรบางอย่างไป-

[ นี่ นุคุมิซึคุงเหรอ? เธอแยกกับน้องสาวกับพวกเพื่อนๆของเธอ แล้วเหรอ? ]

ยานามิเรียกผม เธอกลับมาที่อาคารเรียนหลังจากออกจากชั้นวางรองเท้า

[ ...เอ่อ ประมาณนั้น ยานามิซัง เธอทำหน้าที่ไกด์ชมรมเสร็จแล้วเหรอ? ]

[ ฉันแยกกับพวกรุ่นน้องแล้ว เพราะพวกเขาจะไปกิจกรรมชมรมกัน อีกอย่าง บาโซริซังจากสภานักเรียนกำลังตามหานายเมื่อกี้น่ะ ]

[ ตามหาผม? ทำไมเหรอ? ]

...ผมทำอะไรที่ทำให้ถูกเธอตำหนิหรือเปล่าเนี่ย?

ผมคิดไปเรื่อย ๆ ยานามิจ้องผมด้วยสายตาที่น่าสงสัย

[ พักนี้นายดูมีท่าทีแปลก ๆ กับบาโซริซังนะ พวกเธอทำอะไรกันเหรอ? เกิดอะไรขึ้นหรือเปล่า? ]

[ ไม่มีอะไรหรอก คงเป็นเพราะเราคุยกันเรื่องวันเปิดบ้านโรงเรียนมากกว่า ]

ผมเคยช่วยเธอติวหนังสืออยู่บ้าง แต่จริง ๆแล้วมันไม่ใช่อย่างที่ยานามิกับผมพูดหรอก

ผมทำหน้าไม่รู้ไม่ชี้ พอเห็นสีหน้าผม ยานามิก็ไหล่ตกอย่างหมดอาลัยตายอยาก

[ ไปห้องชมรมกันเถอะ ถ้านายไม่มีอะไรทำ จะปล่อยโคมาริจังกับโคนุกิเซนเซอยู่ที่นั่นนานเกินไปมันไม่ดีหรอก ]

ยานามิพูดแล้วหยิบกล่องเล็ก ๆ ออกจากกระเป๋า

[ นั่นช็อกโกแลตเหรอ? เธอจะให้ใครน่ะ ? ]

ผมพูดออกไปอย่างไม่ใส่ใจ ด้วยเหตุผลบางอย่าง ยานามิยิ้มออกมาอย่างภาคภูมิใจ ใบหน้าของเธอดูเย่อหยิ่ง

[ ไร้เดียงสาเกินไปแล้วนุคุมิซึคุง วันวาเลนไทน์ไม่ได้มีไว้แค่ให้ช็อกโกแลตเท่านั้นนะ มันยังมีไว้สำหรับซื้อช็อกโกแลตด้วย ]

[ ซื้อช็อกโกแลต? เอ่อ ถ้าอยากให้ช็อกโกแลตเธอก็ต้องซื้อน่ะสิ- ]

“ไม่ๆ ไม่ใช่” ยานามิส่ายหัวแล้วพูดต่อ

[ ช่วงนี้ ร้านค้าจะสต็อกสินค้าต่าง ๆน่ะ แล้วก็จะมีของที่มีจำนวนจำกัดวางขายด้วย วันนี้เลยเป็นวันสำหรับการซื้อช็อกโกแลตให้ตัวเองเหมือนกัน ชิ้นนี้ที่ฉันถืออยู่นี่หายากนะ ไม่ใช่ของที่จะได้ลิ้มลองทุกวัน ]

โอ้ ไม่รู้เลยว่าสายกินจะมองวันวาเลนไทน์แบบนี้

ยานามิเปิดกล่อง หยิบช็อกโกแลตชิ้นหนึ่งแล้วส่งให้ผม

[ เอาล่ะ นุคุมิซึคุง เอานี่ไปกินสิ ลองดู ]

ถ้าผมปฏิเสธมันจะลำบากเอา ผมเลยเมินต่อช็อกโกแลตที่เธอยื่นให้ แล้วหยิบชิ้นหนึ่งจากในกล่อง

ชิ้นนี้เป็นทรงกลม ขนาดเกือบเท่ากับเหรียญ 100 เยน มีชั้นของผงโกโก้ด้านนอก นี่เป็นช็อกโกแลตรสทรัฟเฟิลมาตรฐาน แต่มันไม่ได้ดูแปลกอย่างที่ผมคิดไว้…

รสชาติของผงโกโก้และช็อกโกแลตแพร่กระจายไปทั่วปากทันทีหลังจากกลืนมันลงไป

รสชาติอื่น ๆ ก็เป็น- ช็อกโกแลต และ เอ่อ มันก็มีรสช็อกโกแลตนั่นแหละ ก็ใช่ มันรสช็อกโกแลตจริง ๆ

[ ขอบคุณนะ ...ยานามิซัง เธอทำอะไรอยู่น่ะ? ]

ยานามิยังคงถือช็อกโกแลตไว้ในมือแล้วจ้องเขม็งใส่ผม

[ นายไม่เห็นเหรอว่าฉันยื่นมือไป? ]

[ แต่ในมือเธอก็มีของอยู่ ผมก็อยากจะพูดแบบนั้นตั้งแต่ในห้องชมรมแล้วล่ะ มันรู้สึกไม่สะอาดเลยที่จะให้ของกับใครหลังจากที่เธอจับอะไรไป ]

[ ............ ]

ยานามิยัดช็อกโกแลตเข้าปากเงียบ ๆ เธอจ้องผมอย่างไม่พอใจ เกิดอะไรขึ้นกับเธอกันนะ…?

[ เอาล่ะ เธอควรไปเฝ้าห้องชมรมได้แล้ว คาจูหายตัวไป ฉันต้องไปหาเธอ ]

[ นายกำลังตามหาน้องสาวอยู่เหรอ? ฮะ งั้นแสดงว่ามีอะไรเกิดขึ้นจริง ๆ สินะ ]

ยานามิกดโทรศัพท์ในขณะที่พูดอยู่

[ เกิดอะไรขึ้นกันแน่- เธอรู้เรื่องอะไรที่ผมไม่รู้เหรอ? ]

[ แน่นอน ฉันไม่รู้หรอก แต่ทาจิบานะคุงอยู่ห้องเดียวกับน้องสาวนายนี่นา เขาน่าจะเป็นผู้ต้องสงสัยใช่มั้ยล่ะ? ฉันบอกได้เลยว่าอะไรต้องเกิดขึ้นจากท่าทีของนาย นุคุมิซึคุง ]

ยานามิเก็บโทรศัพท์แล้วเริ่มจ้องผมอีกครั้ง

[ นายลากฉันมาเกี่ยวกับเรื่องนี้ด้วย ฉันก็ต้องรับผิดชอบบ้างใช่มั้ยล่ะ? จะให้ฉันไม่สนใจได้ยังไง ]

[ ...ขอโทษนะ แต่ผมเองก็ยังไม่รู้ว่าเกิดอะไรขึ้นเหมือนกัน เอาเป็นว่าตอนนี้อยากจะยืนยันสถานการณ์ก่อน ]

ผมกำลังคิดว่าจะอธิบายเรื่องนี้กับเธอยังไงดี แล้วก็มีเด็กสาวร่างเล็กที่ผมยาวพลิ้วไหววิ่งออกมาจากสุดทางเดิน เธอคืออาซากุโมะซัง

[ อยู่นี่เอง นุคุมิซึซัง นี่ค่ะ ช่วยรับนี่ไปด้วย ]

อาซากุโมะซังหยิบกล่องเล็กๆบางๆออกมา กล่องนั้นมีริบบิ้นผูกอยู่ด้วย

ผมรับกล่องนั้นมาโดยไม่ทันคิด แล้วตาก็เบิกกว้างด้วยความตกใจ

[ นี่- อย่าบอกนะว่ามันเป็นช็อกโกแลต!? ]

[ ใช่ค่ะ เพราะฉันได้รับความช่วยเหลือจากคุณมาตลอด ]

อาซากุโมะซังยิ้มแล้วหมุนตัวเบาๆ

[ เอาล่ะ ฉันต้องไปเดทกับมิตสึกิซังแล้วล่ะค่ะ ]

[ เอ๊ะ? อ่า ขอบคุณนะ… ]

ไม่อยากจะเชื่อและมองที่ไปผมมองช็อกโกแลต หลังจากที่อาซากุโมะซังจากไป

จริงเหรอ? ผมได้ลองช็อกโกแลตตั้งเยอะแยะในห้องชมรมแล้ว ก็คิดว่าอาจจะนับเป็นช็อกโกแลตที่ให้ตามมารยาทได้ แต่ว่าตอนนี้ไม่ต้องนับมันแล้ว ถึงแม้มันจะเป็นแค่ช็อกโกแลตตามมารยาท ผม นุคุมิซึ คาซึฮิโกะ ได้รับช็อกโกแลตจากคนนอกจนได้ในวัย 16 ปี-

[ เฮ้ ]

ปึ๊ก ! ยานามิศอกเข้าที่ข้างลำตัวผม

[ โอ๊ย! ต้องการอะไรเนี่ย ? อารมณ์กำลังดีเลยนะรู้มั้ย? ]

[ ว่าแต่ ฉันยังไม่ได้ฟังความเห็นของนายเกี่ยวกับช็อกโกแลตเมื่อกี้เลยนะ ]

เธอมาขัดจังหวะผมเพราะเรื่องนี้เหรอ?

ผมพยายามกลั้นไม่ให้ถอนหายใจแล้วเอาช็อกโกแลตที่อาซากุโมะซังให้ใส่กระเป๋า

[ เอ่อ มันก็เป็นช็อกโกแลตมาก ๆ แหละ ใช่แล้ว รสชาติเหมือนช็อกโกแลตเลย ]

[ ...แล้วมันอร่อยมั้ย? ]

[ อืม ก็โอเคนะ มันก็เป็นช็อกโกแลตนี่นา ]

[ ............ ]

ยานามิศอกเข้าที่ข้างตัวผมอีกครั้ง เธอหันหลังให้ด้วยท่าทางไม่พอใจ

เอ๋...ก็ชมไปแล้วนี่นา

ไม่เข้าใจว่าทำไมเธอถึงโกรธขึ้นมาอย่างกระทันหัน ในขณะที่เธอชูโทรศัพท์ขึ้นเหนือไหล่แล้วเริ่มเขย่าไปมา

[ ฉันช่วยนายหาน้องสาวแล้ว นี่ไม่ใช่ท่าทางที่นายควรจะทำกับฉันนะ รู้มั้ย ? ]

[ หา? เธอเจอน้องสาวผมเมื่อไหร่เนี่ย ? ]

[ ฉันส่งข้อความไปในไลน์กลุ่มห้อง แล้วก็ได้คำตอบกลับมาทันที ]

เข้าใจแล้ว นี่คือวิธีที่เธอทำสินะ คาจูเองก็มาเตรียมตัวสำหรับเทศกาลสึวะบุกิเหมือนกัน น่าจะมีคนรู้จักเธอหลายคน

แถมผมยังไม่ได้เข้ากลุ่มไลน์นั้นเลยด้วยซ้ำ

[ ขอบใจมาก งั้น คาจูอยู่ที่- ]

ผมยื่นมือออกไป ยานามิถอยโทรศัพท์ออกห่างอย่างเงียบ ๆ

[ เอ๋? บอกผมทีว่าคาจูอยู่ที่ไหน ]

[ นุคุมิซึคุง มีอะไรบางอย่างที่นายต้องพูดก่อนใช่มั้ย? ]

[ หืม? ก็ขอบคุณเธอแล้วนี่นา ]

หน้ายานามิเปลี่ยนไปทันที เธอหันหน้ามาด้วยความโกรธ

...ผมทำอะไรผิดหรือเปล่านะ?

ผมจำไม่ได้ว่าทำอะไรให้ยานามิโกรธ แต่ผมจำได้ว่าเธอโกรธผมเป็นประจำอยู่แล้ว

เริ่มต้นจากสิ่งที่อยู่ตรงหน้าก่อน-

[ เอ่อ เธอหมายถึงว่าผมไม่ได้กินช็อกโกแลตของยานามิซังเหรอ? ]

เธอตอบสนองทันที คิ้วของยานามิเหยียดขึ้น ดูเหมือนว่าผมจะเดาถูก

[ ไม่ได้หมายความแบบนั้น อ่าา ดูสิ ช่วงนี้ไข้หวัดกำลังระบาดใช่มั้ย ? แล้ววันนี้ก็มีผู้เยี่ยมชมจากต่างชาติเยอะด้วย ฉันคิดว่าเราควรจะระวังตัวล่วงหน้า ]

ผมสังเกตปฏิกิริยาของยานามิแล้วอธิบายต่อ

[ คือว่านี่ก็เพื่อป้องกันการติดเชื้อ ไม่ได้บอกว่าแบคทีเรียที่อยู่บนมือของยานามิซังมีปัญหาอะไรหรอก ถึงแม้คนเราจะต่างกัน แต่การมีพวกมันอยู่จริงๆแล้วดีต่อมนุษย์นะ ]

[ อ-อ๋อ... ฉันคิดว่านายจะพูดอย่างอื่นซะอีก ]

ยานามิพยักหน้า ใบหน้าของเธอดูเหมือนกำลังมองนกแปลก ๆ อยู่

[ นุคุมิซึคุง นั่นไม่ใช่คำตอบที่ฉันอยากได้ยินเลยนะ แต่ฉันได้รับความรู้สึกของนายแล้วล่ะ ]

ผมไม่รู้ว่าเธอรับความรู้สึกอะไรไปบ้าง แต่ก็ดีแล้วที่เธอได้รับมัน

ยานามิชี้ไปที่ประตูทางออก

[ ได้ยินมาว่าเธออยู่ที่สนามยิงธนู เธออยู่กับเด็กผู้หญิงจากโรงเรียนเดียวกัน ลองไปดูที่นั่นสิ ]

[ ขอบคุณ ฉันจะไปแล้วนะ ]

ผมหันหลังกลับเตรียมที่จะออกไปหลังจากพูดจบ แต่ผมก็หยุดอีกครั้ง

[ ยานามิซัง ขอช็อกโกแลตอีกชิ้นได้มั้ย? ]

[ เอ๋? ได้สิ ]

ยานามิหัวเราะเบา ๆ แล้วส่งกล่องช็อกโกแลตให้ผม

[ นายคิดว่าอร่อยใช่มั้ยล่ะ? ]

[ เปล่านะ มันติดใจน่ะ ]

ผมหยิบช็อกโกแลตอีกชิ้นใส่ปากแล้วเดินออกจากประตู
