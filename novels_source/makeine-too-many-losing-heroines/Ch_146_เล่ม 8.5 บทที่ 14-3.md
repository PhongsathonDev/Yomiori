พอพระอาทิตย์เริ่มตกดิน มหกรรมเทมากิซูชิก็ได้เริ่มต้นขึ้น

ข้าวซูชิในถังไม้พร้อมด้วยสาหร่ายทะเลและวัตถุดิบปริมาณมหาศาล

ยานามิผู้รับหน้าที่จัดการกับสิ่งของปริมาณมหาศาล โปะข้าวและวัตถุดิบลงบนสาหร่ายจนพูนเป็นภูเขา ขจัดองค์ประกอบการห่อของเทมากิซูชิทิ้งไปเสียตั้งแต่เนิ่นๆ

[ ยานามิซัง นี่มันเทมากิซูชินะ ลองทำเป็นห่อดูสักหน่อยไหม? ]

[ นุคุมิซึคุงนี่จู้จี้จุกจิกจังเลยน้า เทมากิซูชิน่ะคือสัญลักษณ์แห่งอิสรภาพนะ ต้องโปะลงไปให้มากที่สุดเท่าที่จะโปะได้สิ ]

พูดจบยานามิก็อ้าปากงับคำโตอย่างห้าวหาญ การที่ไม่จิ้มแม้กระทั่งโชยุเนี่ยมันจะอิสระเกินไปแล้ว

ถึงอย่างนั้น มัวแต่มองยานามิไปท้องก็ไม่พองโตขึ้นมาหรอก เอาล่ะ ผมจะห่ออะไรดีนะ......

วัตถุดิบที่เตรียมไว้มีทั้งทูน่า แซลมอน แตงกวา ไข่ม้วน ทูน่ามายองเนส ปูอัด และไส้กรอกปลา──เรียกได้ว่ามีของพื้นฐานครบถ้วน

[ ......ไส้กรอกปลาเนี่ยนะ? ]

ผมเผลอพึมพำออกมา ยานามิก็เลยตวัดสายตาขวับมามอง

[ นุคุมิซึคุง พูดถึงเทมากิซูชิก็ต้องไส้กรอกปลาสิ กินคู่กับทูน่ามายองเนสก็เข้ากันสุดๆ ไปเลยนะ ]

ถ้าบ้านยานามิเขาว่าอย่างนั้นก็ช่วยไม่ได้ ขัดขืนไปก็เปล่าประโยชน์

[ งั้น ข้าวโพดคลุกมายองเนสก็เป็นรสชาติของบ้านยานามิด้วยงั้นสิ ]

[ ขะ ข้าวโพดคลุกมายองเนสมันขาดไม่ได้อยู่แล้ว ไม่ใช่หรือไง ]

ข้าวโพดคลุกมายองเนส มันเป็นธรรมเนียมของบ้านโคมาริต่างหาก

หรือว่าเทมากิซูชิจะขาดมายองเนสไม่ได้จริงๆ หลักฐานก็คือ ยากิชิโอะเองก็กำลังป้ายเนื้อครีมสีขาวลงไปในเทมากิซูชิเหมือนกัน──

[ เอ๊ะ? นั่นไม่ใช่มายองเนสไม่ใช่เหรอ ]

[ ครีมชีสไง ที่บ้านฉันใส่เจ้านี่เป็นเรื่องปกติน่ะ ]

บ้านยานามิกับบ้านโคมาริเป็นมายองเนส แต่บ้านยากิชิโอะเป็นครีมชีสสินะ

ขณะที่สัมผัสได้ถึงความเหลื่อมล้ำทางสังคม ผมก็คีบเนื้อปลาทูน่าวางลงบนข้าว เอาล่ะ ต่อไปก็──

[ เอ้า นี่ก็ของแนะนำจากฉันเหมือนกัน ]

ยานามิใช้ช้อนตักแป้งเทมปุระทอดกรอบมาโรยใส่เทมากิซูชิของผม

[ อย่าเอามาใส่ของผมตามอำเภอใจได้ไหม? ]

[ ไม่ว่าอะไรก็จะกลายเป็นรสเทมปุระหมดเลย ถือว่าคุ้มออกนะ ]

[ ไอ้การที่ไม่ว่าอะไรก็กลายเป็นรสเทมปุระหมดเนี่ยแหละที่น่าลำบากใจ ]

คำแรกขอตัดสินใจเป็นทูน่า แตงกวา และไข่ม้วนแล้วกัน ส่วนแป้งเทมปุระนี่เป็นส่วนเกินแต่ก็คงต้องยอมรับสภาพไป

[ ชินทาโร่ เลิกเล่นสมาร์ตโฟนตอนกินข้าวสักทีเถอะ ]

[ รอก่อนสิ กลุ่มฝึกงานทำท่าจะมีคนหลุดร่วงไปอีกคนแล้วเนี่ย ]

คนคนนี้ก็ยังความซวยไม่ขาดสายเหมือนเคย

……การได้มากินเทมากิซูชิพร้อมหน้ากันแบบนี้ ทำให้ผมนึกถึงตอนรวมญาติเลยแฮะ

จำได้ว่าสมัยก่อนผมเข้ากับพวกเด็กๆ ด้วยกันไม่ได้ จนคาจูต้องคอยเป็นห่วง

ขนาดกับญาติๆ ด้วยกันผมยังเป็นแบบนั้นเลย แต่ตอนนี้ผมกลับกำลังกินเทมากิซูชิร่วมกับคนอื่นอยู่

รู้สึกเหมือนกำลังฝันไปนิดๆ ผมเหม่อมองไปรอบๆ วงโต๊ะอาหาร

ยานามิกำลังสวาปามซูชิหน้าเปิดที่ไม่ใช่เทมากิซูชิอย่างเอาเป็นเอาตาย ส่วนยากิชิโอะกับโคมาริก็กำลังผลัดกันเอาวัตถุดิบแนะนำโปะใส่ซูชิของอีกฝ่าย

รุ่นพี่ทามากิกำลังห่อแซลมอนโดยมีรุ่นพี่สึกิโนกิคอยปลอบใจอยู่ข้างๆ

แต่ละคนต่างก็ใช้ชีวิตในแต่ละวันที่แตกต่างกันไป แต่ก็ได้มานั่งล้อมรอบโต๊ะอาหารเดียวกันแบบนี้

──ถึงจะยังรู้สึกจักจี้อยู่นิดหน่อย แต่ค่ำคืนแบบนี้ก็ดีเหมือนกันนะ

ผมวางไส้กรอกปลา ข้าวโพดคลุกมายองเนส และครีมชีสลงไป ก่อนจะใช้สาหร่ายทะเลม้วนห่อจนกลม

◇

ปาร์ตี้เทมากิซูชิดำเนินมาถึงช่วงท้ายเกมแล้ว ข้าวซูชิ 5 โกหมดเกลี้ยง และข้าวซูชิถังที่สองก็พร่องลงไปมากโข สาเหตุก็เห็นๆ กันอยู่ แต่ข้าวลดฮวบฮาบเร็วจริงๆ แฮะ……

[ อ๊ะ สาหร่ายทะเลหมดแล้วสินะครับ ]

[ แหม จริงด้วยสิ ยังมีอยู่อีกนะ รอเดี๋ยวนึงจ้ะ ]

รุ่นพี่สึกิโนกิลุกขึ้นเพื่อไปเตรียมสาหร่ายมาเพิ่ม

ไม่รู้ว่ารอไม่ไหวหรือยังไง ยานามิจึงตักข้าวซูชิโปะลงบนจานโดยตรง แล้วเริ่มเอาวัตถุดิบมาเรียงไว้ด้านบน

[ ยานามิซัง รอจนกว่าสาหร่ายจะมาไม่ได้เหรอ? อดทนอีกนิดนึงเถอะนะ ]

[ ……นุคุมิซึคุง ฉันลองคิดดูแล้วนะ เทมากิซูชินี่จำเป็นต้องมีสาหร่ายด้วยเหรอ ]

[ หา? ]

หมายความว่าไง กินเยอะเกินไปจนเพี้ยนไปแล้วหรือเปล่านะ

[ เอ่อ ถ้าไม่มีสาหร่ายมันก็ใช้มือห่อไม่ได้ไม่ใช่เหรอ? ]

[ มันมีคำว่าการปรุงรสในปากด้วยไม่ใช่เหรอ? หรือก็คือ ห่อในปาก──ไม่สิ ห่อในกระเพาะเอาก็ได้นี่นา ]

ข่าวเศร้า──ยานามิเพี้ยนไปแล้วจริงๆ ด้วย

ผมเผยรอยยิ้มอ่อนโยน และเออออรับคำพูดของยานามิ

[ นั่นสินะ อาจจะใช่อย่างนั้นก็ได้ ]

[ ถ้ายิ่งไปกว่านั้น ฉันรู้สึกว่าถึงไม่มีวัตถุดิบอื่นก็ยังเป็นเทมากิซูชิได้นะ ถ้าไล่ไปจนถึงจุดสุดท้าย เทมากิซูชิขั้นสุดยอดก็คือการมีแค่ข้าวเปล่าๆ นั่นแหละ ]

[ นั่นมันก็แค่ข้าวซูชิธรรมดาไม่ใช่หรือไง? ]

แย่ล่ะ เผลอตบมุกกลับไปซะแล้ว

ยานามิสวาปามเทมากิซูชิ(?)บนจานอย่างมูมมาม ก่อนจะพยักหน้าด้วยสีหน้าจริงจัง

[ อืม นี่มันคือเทมากิซูชิอย่างสมบูรณ์แบบเลยล่ะ นุกุมิซึคุงก็ลองทำดูสิ ]

[ ไม่ทำหรอก บอกแล้วไงว่าอย่าเอามาโปะใส่จานผมตามอำเภอใจน่ะ? ]

ระหว่างที่ผมกำลังยื้อแย่งกับยานามิ รุ่นพี่สึกิโนกิก็นำจานใส่สาหร่ายมาวางบนโต๊ะ

[ เอ้า สาหร่ายที่สั่งเพิ่มได้แล้วจ้าー ]

[ ขอบคุณมากค่า! ]

ยานามิรีบหยิบสาหร่ายขึ้นมาทันที แล้วโปะข้าวซูชิลงไปจนพูนเป็นภูเขา

[ ก็ใช้สาหร่ายนี่ แล้วไอ้เรื่องที่พูดมาเมื่อกี้มันคืออะไรกันเนี่ย? ]

[ ถ้ามีก็ต้องกินสิคะ รุ่นพี่ สาหร่ายนี่อร่อยจังเลยนะคะ ]

[ แหม รู้ด้วยเหรอ? เป็นของดีที่เก็บมาจากอ่าวมิคาวะเลยนะ ]

ผมปรายตามองทั้งสองคนที่กำลังคุยเรื่องอาหารแห้งกันอย่างออกรส พลางสบตากกับรุ่นพี่ทามากิ

……พวกเราเนี่ย ลำบากกันจังเลยนะครับ

◇

ฟู่ ยานามิยัดเยียดให้กินซะขนาดนั้นเลยเผลอกินเข้าไปซะเยอะเลยแฮะ......

ผมที่เพิ่งออกมาจากห้องน้ำ เดินสวนกับยากิชิโอะที่กำลังมุ่งหน้าไปทางโถงทางเข้า

[ จะออกไปไหนเหรอ? ]

[ ลืมเอาแปรงสีฟันมาน่ะสิ เลยว่าจะไปซื้อที่ร้านสะดวกซื้อหน่อย ]

[ เหรอ เป็นงั้นเองหรอกเหรอ ]

พอผมทำท่าจะเดินกลับไปที่ห้องนั่งเล่น ยากิชิโอะก็หรี่ตามองผมอย่างจับผิด

[ นี่ เด็กผู้หญิงกำลังจะออกไปข้างนอกตอนกลางคืนนะ ไม่มีอะไรจะพูดหน่อยเหรอ? ]

[ อะ ครับ ระวังตอนเดินถนนตอนกลางคืนด้วยนะครับ ]

ทั้งๆ ที่ผมก็ตอบกลับไปอย่างสมบูรณ์แบบแล้วแท้ๆ แต่ยากิชิโอะกลับถอนหายใจเฮือกใหญ่

[ เฮ้อ เวลาแบบนี้มันน่าจะอาสามาเป็นบอดี้การ์ดเดินไปด้วยกันไม่ใช่เหรอ? ]

บอดี้การ์ด......? คนที่อ่อนแอกว่ายากิชิโอะอย่างผมจะรับหน้าที่นั้นไหวเหรอเนี่ย

ถึงจะสงสัย แต่ดูจากบรรยากาศแล้วคงปฏิเสธไม่ได้แน่ๆ

[ เอ่อ งั้นขอไปหยิบสมาร์ตโฟ── ]

ผมที่กำลังจะกลับไปห้องนั่งเล่นถูกยากิชิโอะคว้ามือเอาไว้

[ รีบไปกันเถอะน่า ค่อยบอกทุกคนทีหลังก็ได้ ]

[ เอ๊ะ แต่ว่า ]

[ เอาเถอะน่า รีบไปก่อนที่จะมีคนจับได้กันเถอะ ]

ผมสอดเท้าเข้าไปในรองเท้าตามที่เธอบอกอย่างว่าง่าย

......ไม่ขัดขืนผู้ที่แข็งแกร่งกว่า นั่นแหละคือวิถีของผม

◇

ผมเดินเคียงข้างไปกับยากิชิโอะ บนทางเท้าเลียบถนนใหญ่แบบสองเลนฝั่งเดียว

พระอาทิตย์ตกดินไปแล้ว ทางเท้าถูกส่องสว่างด้วยไฟถนนและแสงไฟจากรถยนต์ที่สัญจรไปมา

ริมถนนมีแมนชั่นและปั๊มน้ำมันตั้งเรียงราย ผู้คนที่เดินสวนไปมาก็คงเป็นคนแถวนี้ที่กำลังรีบกลับบ้านกระมัง ดูเร่งรีบกันพิกล

[ พอพระอาทิตย์ตกแล้วรู้สึกดีจังเลยเนอะー ]

[ ใส่เสื้อแขนสั้นอาจจะหนาวไปหน่อยนะ ]

ยากิชิโอะดูอารมณ์ดีเป็นพิเศษ เธอเดินกระโดดเหยาะๆ ออกไปข้างหน้าผม แล้วหันขวับกลับมา

[ นี่ แข่งกันไปให้ถึงร้านสะดวกซื้อไหม? ]

[ ไม่แข่งหรอกน่า นี่ เดินถอยหลังแบบนั้นมันอันตรายนะ ]

[ ค่าー นุกคุงเนี่ย เหมือนแม่ฉันเลย ]

ยากิชิโอะพูดเหมือนงอนๆ แล้วก็เดินทิ้งห่างผมออกไป

ผมเดินตามหลังเธอไปโดยรักษาระยะห่าง พลางเหม่อมองแผ่นหลังนั้นไปเรื่อยเปื่อย

──ยากิชิโอะ เลม่อน แขนขาที่กรำแดด กับเรือนร่างที่กระชับสมส่วน

การที่เธอกุมมือประสานนิ้วไว้ข้างหลัง แล้วแผ่นหลังนั่นดูเหมือนอยากให้ผมชวนคุยเนี่ย เป็นผมที่หลงตัวเองไปเองหรือเปล่านะ

[ เอ่อ......วันนี้ซ้อมชมรมกรีฑาเป็นไงบ้าง ไม่เป็นไรเหรอ ]

เป็นคำพูดที่น่าเบื่อแม้แต่กับตัวเองก็เถอะ แต่ก็อยากให้ทุกคนนึกให้ออกด้วย ว่าคนที่อยู่ตรงนี้น่ะคือผมนะ

แผ่นหลังของยากิชิโอะสั่นไหวน้อยๆ เธอเดินต่อไปโดยไม่หันกลับมา

[ ซ้อมของวันนี้เสร็จเรียบร้อยแล้วล่ะ โค้ชก็บอกด้วยว่าพรุ่งนี้ให้หยุดพักแบบเต็มที่ไปเลย ]

[ หืม งั้นเหรอ ]

อ้าว บทสนทนาจบลงซะงั้น พูดอะไรผิดไปหรือเปล่าหว่า......

ระหว่างที่กำลังเปิดการประชุมทบทวนตัวเองในหัวไปพลางเดินไปพลาง ก็รู้ตัวว่าเดินห่างจากแมนชั่นมาไกลโขแล้ว

[ ร้านสะดวกซื้อนี่ยังไม่ถึงอีกเหรอ? ]

[ อืมー น่าจะเลยไปอีกหน่อยล่ะมั้ง ]

ยากิชิโอะพูดเรียบๆ แล้วเร่งฝีเท้าขึ้น

ผมเดินตามเธอไปเงียบๆ จนกระทั่งมาถึงทางแยกใหญ่

ฝั่งตรงข้ามของทางแยก มีกลุ่มอาคารขนาดใหญ่เรียงรายอยู่ ซึ่งดูบรรยากาศแตกต่างจากแมนชั่น

ตรงนั้นคือมหาวิทยาลัยที่รุ่นพี่ทามากิเรียนอยู่

[ ทางนี้ไม่น่าจะมีร้านสะดวกซื้อนะ กลับทางเดิมดีกว่าไหม ]

ยากิชิโอะไม่ตอบคำถามนั้น แต่หยิบสมาร์ตโฟนขึ้นมา

[ ......อ้า ยังทันเวลาอยู่แฮะ ]

[ ทันเวลาที่ว่านี่คือ? ]

[ นี่ไง สัญญาณไฟจะเปลี่ยนแล้วนะ ]

ยากิชิโอะออกตัววิ่งตรงไปยังทางม้าลาย ถึงจะไม่ค่อยเข้าใจก็เถอะ แต่ดูเหมือนว่าร้านสะดวกซื้อที่เป็นเป้าหมายจะอยู่เลยไปจากนี้ พอผมวิ่งตามเธอข้ามทางแยกมา ยากิชิโอะก็ไปหยุดยืนอยู่หน้าป้ายรถเมล์

[ เอ่อ......จะไปร้านสะดวกซื้อใช่ไหม ]

[ รอแป๊บนึงนะ ]

ยากิชิโอะชะโงกหน้าดูตารางเวลารถเมล์

ด้านหลังป้ายรถเมล์เป็นอาคารที่ดูเหมือนแมนชั่น ไม่คิดว่าที่นี่จะเป็นจุดหมายปลายทางได้

ทันใดนั้น รถเมล์คันหนึ่งก็วิ่งส่งเสียงดังกุกกักมาจอดตรงหน้า

เดี๋ยวก่อนสิ พวกเราไม่ใช่ผู้โดยสารสักหน่อย พอผมทำท่าจะถอยหลังไปก้าวหนึ่ง ยากิชิโอะก็คว้ามือผมไว้

[ นุกคุง เราจะขึ้นรถคันนี้กันนะ ]

เอ๊ะ จะไปร้านสะดวกซื้อแต่ต้องนั่งรถเมล์เนี่ยนะ? ที่นี่คือมหานครนาโกย่านะเฮ้ย

ยากิชิโอะไม่สนใจผมที่กำลังสับสน เธอออกแรงดึงผมให้ขึ้นไปบนรถเมล์

และทันทีที่พวกเราสองคนนั่งลงบนเบาะที่นั่งคู่ รถเมล์ก็เริ่มเคลื่อนตัวออกไป

[ นี่ ไม่ได้จะไปร้านสะดวกซื้อแล้วใช่ไหม จะไปไหนเนี่ย? ]

ยากิชิโอะหันมาหาผมที่กำลังอึ้งกับเหตุการณ์ที่พลิกผันอย่างกะทันหัน แล้วยิ้มอย่างซุกซนอยู่ข้างๆ บนเบาะที่นั่งแคบๆ
