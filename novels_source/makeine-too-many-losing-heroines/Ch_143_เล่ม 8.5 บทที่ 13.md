บทที่13 เนกไทกับเฟรนช์ฟรายส์

ผมอยู่ที่ร้านแฮมเบอร์เกอร์ข้างร้านหนังสือเซบุนคัง ซึ่งอยู่ไม่ไกลจากสถานีโทโยฮาชิ

คนที่นั่งล้อมโต๊ะเดียวกันคืออายาโนะ มิตสึกิ กับซากุไร ฮิโรโตะ

อายาโนะชูแก้วกระดาษขึ้น แล้วมองหน้าผมกับซากุไรคุงสลับกัน

[ เอาล่ะ เหนื่อยกันหน่อยนะสำหรับการเลือกตั้งสภานักเรียน──คัมปาย! ]

[[ คัมปาย ]]

พวกเราชนแก้วกระดาษพร้อมกับส่งเสียงร้อง การรวมตัวสุดปริศนานี้เป็นไอเดียของอายาโนะ เพื่อฉลองหลังจบการเลือกตั้งสภานักเรียน

ไม่รู้เหมือนกันว่าอดีตมิตรและศัตรูเขามาทำอะไรแบบนี้กันไหม แต่ในเมื่อซากุไรคุงได้เข้าสภานักเรียนไปแล้ว ตอนนี้ก็คงถือว่าไม่มีการแบ่งฝักแบ่งฝ่ายแล้วล่ะ

[ พวกนายสองคน เหนื่อยหน่อยนะสำหรับการเลือกตั้งสภานักเรียน ]

ไม่รู้ทำไมอายาโนะถึงหยิบเฟรนช์ฟรายส์ยื่นมาให้ผม

พอจำใจเอาเข้าปาก รสชาติของเกลือและน้ำมันก็แผ่ซ่านไปทั่วลิ้น ทำให้ใบหน้าของยานามิแวบเข้ามาในหัวอย่างเลี่ยงไม่ได้

ซากุไรคุงยิ้มแห้งๆ พลางหยิบเฟรนช์ฟรายส์เข้าปาก

[ ครั้งนี้โดนนุคุมิซึคุงกับบาโซริจังเล่นเข้าให้แล้วสิ สุนทรพจน์สนับสนุนนั่นเอาชนะไม่ได้เลยล่ะ ]

[ รู้สึกว่าบทบาทของผมโดนรุ่นพี่ชิกิยะแย่งไปหมดเลยนะ ]

เสียงหัวเราะเล็ดลอดออกมาจากอายาโนะและซากุไรคุง

[ ยูเมโกะซังเขาเป็นห่วงบาโซริจังน่ะ ไม่คิดเลยนะว่าจะทำถึงขนาดนั้น ]

ไม่รู้ทำไมแม้แต่ซากุไรคุงก็ยังหยิบเฟรนช์ฟรายส์ยื่นมาให้ ผมเลยเอาเข้าปากไป

ผมเองก็สั่งเฟรนช์ฟรายส์มานะ ทำไมสองคนนี้ถึงพยายามจะป้อนผมกันนักหนา

ในจังหวะที่บทสนทนาขาดห้วง จู่ๆ อายาโนะก็พูดเรื่องนี้ขึ้นมา

[ จะว่าไป ทำไมยานามิซังถึงมาเป็นผู้สนับสนุนให้ซากุไรได้ล่ะ? ]

……นั่นสิ เรื่องนั้นผมเองก็สงสัยอยู่เหมือนกัน

ซากุไรคุงมีสีหน้าลำบากใจเล็กน้อย ก่อนจะละปากออกจากหลอด

[ ผมเองก็ไม่ค่อยเข้าใจเหมือนกัน จู่ๆ เธอก็บอกว่าอยากจะสั่งสอนนุคุมิซึคุงให้รู้สำนึก ก็เลยอยากเป็นผู้สนับสนุนให้น่ะ ]

ทีกับผมล่ะบอกว่าอยากเป็นรองประธานเพื่อจะได้ใช้งบประมาณตามใจชอบแท้ๆ ดูเหมือนว่าต่อหน้าซากุไรคุงจะแสร้งทำตัวเรียบร้อยสินะ พอได้ยินแบบนั้น แว่นตาของอายาโนะก็ส่องประกายวับวับ

[……งั้นเองสินะ นุคุมิซึเนี่ยประมาทไม่ได้เลยนะ ]

[ หมายความว่าไงเนี่ย ]

[ ก็หมายความตามนั้นแหละ แล้วก็นายเนี่ย──มีความสัมพันธ์ยังไงกับบาโซริซังกันแน่ ]

ทำไมถึงมาคุยเรื่องเทียร่าซังเอาป่านนี้ ผมระแวงขึ้นมาแวบหนึ่ง แต่ก็คุยเรื่องเลือกตั้งสภานักเรียนกันอยู่นี่นา คงไม่มีความหมายลึกซึ้งอะไรหรอก ผมแสร้งทำเป็นใจดีสู้เสือแล้วเอื้อมมือไปหยิบเฟรนช์ฟรายส์

[ ยังไงเหรอ ก็ประมาณว่าเป็นเพื่อนกันล่ะมั้ง แค่นั้นแหละ ]

[ ช่วงนี้เห็นเดินด้วยกันที่โรงเรียนบ่อยๆ นี่นา หรือว่าคบกันอยู่เหรอ? ]

……หมอนี่ ทั้งที่เป็นคาแรคเตอร์คนซื่อบื้อแท้ๆ แต่ดันสังเกตเห็นเรื่องแบบนี้ซะได้

ผมดื่มโค้กเข้าไปอึกหนึ่งโดยพยายามไม่ให้ถูกจับได้ว่ากำลังหวั่นไหว

[ ก็แค่เด็กปีหนึ่งของชมรมวรรณกรรมเข้าสภานักเรียน ก็เลยคอยถามไถ่เรื่องต่างๆ เท่านั้นเอง ก็...สภานักเรียนปีนี้มีแค่ 3 คนนี่ เลยอยากรู้ว่าเป็นไปได้ด้วยดีไหมน่ะ ]

พอผมส่งสายตากลบเกลื่อนไป ซากุไรคุงก็พยักหน้ารับหงึกๆ

[ ผมกับบาโซริจังก็อยู่ปี 2 แล้ว ส่วนชิราทามะก็ทำหน้าที่ได้ดีเลยล่ะ ตั้งแต่เด็กคนนั้นเข้ามา พวกนักเรียนชายในชมรมก็ให้ความร่วมมือกันดีมากเลย ]

เหรอ คอยเก็บนู่นเก็บนี่ให้หรือเปล่านะ……แอบน่ากลัวแฮะ……

ซากุไรคุงที่เล่าเรื่องของชิราทามะซัง จู่ๆ ก็ทำสายตาเหม่อลอย

[ ……แต่ก็แลกมากับการที่คำร้องเรียนจากพวกผู้หญิงมากองอยู่ที่ผมหมดเลยน่ะสิ ]

ซากุไรคุง ยังคงลำบากไม่หยุดหย่อนเหมือนเคย พอผมปลอบใจพลางซักถามไปเรื่อยๆ ก็ดูเหมือนว่าชิราทามะซังจะเข้ากับเทียร่าซังได้แฮะ สองคนนั้นดูไม่น่าจะมีจุดร่วมกันได้เลย ไม่น่าเชื่อ

พอผมรู้สึกโล่งใจขึ้นมานิดหน่อย ซากุราอิคุงก็ส่งสายตาอย่างมีนัยยะมาให้

[ แต่ถ้าได้สมาชิกเพิ่มอีกสักคนก่อนถึงงานเทศกาลสึวาบุกิก็คงจะช่วยได้เยอะเลยนะ ]

[ ไปหาคนอื่นได้ไหมล่ะ? ]

ซากุไรคุงหัวเราะอย่างยอมแพ้เมื่อเห็นสีหน้ารังเกียจอย่างจริงจังของผม

[ งานเทศกาลสึวาบุกิปีนี้ คงจะให้คณะกรรมการจัดงานเป็นหลักในการดำเนินงาน น่าจะจัดการได้แหละนะ ]

งานเทศกาลสึวาบุกิเหรอ ปีที่แล้วโคมาริเป็นคนทำเนื้อหานิทรรศการให้ทั้งหมดเลย แต่ปีนี้จะทำยังไงดีล่ะ

นอกจากยากิชิโอะแล้ว ช่วงนี้โคมาริก็ดูจะคิดงานไม่ออก ส่วนยานามิก็ทำเป็นแต่เรื่องกิน แล้วชิราทามะซังก็น่ารักแถมตัวหอมอีกต่างหาก──

ขณะที่ผมกำลังเหม่อลอยคิดอะไรเพลินๆ จู่ๆ มือถือของซากุไรคุงก็ดังขึ้น

ซากุไรคุงมองหน้าจอแล้วยิ้มแห้งๆ ก่อนจะลุกขึ้นยืน

[ ขอโทษทีนะ ]

เขาถือสมาร์ทโฟนเดินไปที่มุมร้าน แล้วก็คุยโทรศัพท์กับใครบางคน

[ ก็บอกแล้วไงว่ามีนัดกับเพื่อนน่ะ──อืม เข้าใจแล้ว งั้นไว้คุยกันนะ ]

ซากุไรคุงวางสายแล้วเดินกลับมาที่โต๊ะพร้อมกับถอนหายใจเบาๆ

[ ขอโทษที่ทำให้วุ่นวายนะ ]

[ ไม่เป็นไรหรอก หรือว่าจะเป็นรุ่นพี่โฮโกบารุ? ]

[ อา……ไม่ใช่พี่ฮิบะหรอก แฟนผมน่ะ ทั้งที่บอกไปแล้วแท้ๆ ว่าวันนี้มีธุระ ]

โห แฟนเหรอ ถึงแฟนจะมีธุระก็ยังโทรหาเนี่ย น่ารักจังเลยน้า──

[ เดี๋ยวนะ นายมีแฟนแล้วเหรอ?! ]

พอผมเผลอร้องเสียงหลง ซากุไรคุงก็เกาแก้มด้วยความกระอักกระอ่วน

[ อืม ก็ก็นะ…… ]

[ โคฮารุซังสินะ นุคุมิซึไม่รู้เหรอ? ]

อายาโนะแกว่งน้ำแข็งในแก้วพลางพูดราวกับเป็นเรื่องปกติ

เอ๊ะ อายาโนะก็รู้เหรอ? คนที่ไม่รู้มีแค่ผมคนเดียวเหรอ? รู้สึกเศร้าแปลกๆ แฮะ

[ เพิ่งจะรู้เนี่ยแหละ…… ]

[ ไม่ได้ตั้งใจจะปิดบังหรอกนะ แค่อยู่คนละโรงเรียนกัน ก็เลยไม่ค่อยมีโอกาสได้บอกน่ะ ]

[ เหรอ……คบกันตั้งแต่เมื่อไหร่ล่ะ ]

[ ตั้งแต่สมัยประถมแล้วล่ะมั้ง ก็เหมือนเป็นความสัมพันธ์ที่ตัดกันไม่ขาดล่ะนะ ]

อึก?! คบกันตั้งแต่ประถม?

ขณะที่ผมกำลังตกตะลึงกับความแตกต่างระหว่างเขากับตัวผมที่มัวแต่ใจเต้นไปกับภาพประกอบไลท์โนเวล ความคิดหนึ่งก็แล่นเข้ามาในหัว

──ไม่ใช่รุ่นพี่โฮโกบารุสินะ

แน่นอนว่าผมรู้ว่าสองคนนั้นไม่ได้มีความสัมพันธ์แบบนั้น

แต่ไม่ต้องสงสัยเลยว่าทั้งคู่ต่างก็คิดว่าอีกฝ่ายเป็นคนพิเศษ

อายาโนะมองพวกเราที่บทสนทนาขาดห้วงไป ก่อนจะเอ่ยปากขึ้น

[ พอเป็นเรื่องแฟนทีไร ซากุไรมักจะพูดจาอ้ำๆ อึ้งๆ ทุกทีเลยนะ มีเรื่องอะไรหรือเปล่า? ]

[ เพราะคบกันมานานน่ะสิ เลยกลายเป็นว่าไม่รู้จะคุยอะไรกันเฉยๆ ความสัมพันธ์ก็ดีอยู่หรอกนะ── ]

ซากุไรคุงหลบสายตาไปมาเหมือนกำลังหาคำพูด

[ การคบกันน่ะ มันไม่ได้มีแต่เรื่องดีๆ เสมอไปหรอกนะ ]

พอเจอคำพูดนั้นเข้าไป ผู้ชายซื่อบื้ออย่างเขาก็ถึงกับเงียบไปเลย

[ ขอโทษทีที่ทำให้บรรยากาศแปลกๆเดี๋ยวไว้หาโอกาสแนะนำให้พวกนายสองคนรู้จักนะ ]

[ อา ทางฉันต่างหากที่ต้องขอโทษ ไว้คราวหน้าพวกเราไปทริปเปิลเดตกันเถอะ ]

อายาโนะพูดด้วยท่าทีรู้สึกผิด ว่าแต่ ผมจะต้องไปร่วมวงคนเดียวงั้นเหรอเนี่ย

ว่าแต่ เด็กม.ปลายเนี่ย การมีแฟนมันเป็นเรื่องปกติขนาดนั้นเลยเหรอ……?

ผมคาบหลอดกระดาษที่เริ่มเปื่อยยุ่ยพลางปล่อยความคิดให้ล่องลอยไป

────แฟนเหรอ อีกไม่นานผมคงต้องให้คำตอบกับการสารภาพรักของเทียร่าซังแล้วล่ะ

คนที่อยากให้เลื่อนการให้คำตอบออกไปคือเทียร่าซัง ถึงอย่างนั้นผมก็ไม่คิดว่าปล่อยไว้แบบนี้จะดีหรอก แต่ตอนนี้ผมก็แค่ขอยืมคำพูดของเธอมาใช้เป็นข้ออ้างไปก่อน

เดี๋ยวก่อนนะ ถ้ายังขืนปล่อยให้คลุมเครือแบบนี้ต่อไป มีความเป็นไปได้ที่เทียร่าซังจะเป็นฝ่ายปฏิเสธผมเองนะ

ถ้าเป็นแบบนั้น แปลว่าผมโดนหักอกงั้นเหรอ……?

ผมคิดเรื่องไร้สาระพรรค์นั้นพลางโยนเฟรนช์ฟรายส์ที่เย็นชืดเข้าปากรวดเดียว
