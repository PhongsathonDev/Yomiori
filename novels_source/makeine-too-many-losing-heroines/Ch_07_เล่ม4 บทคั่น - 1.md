บทคั่น หวังว่านายจะแสดงความสามารถให้ฉันเห็นนะ

โรงเรียนมัธยมต้นโมโมโซโนะ เด็กชายและเด็กหญิงยืนอยู่ตรงข้ามกันที่ด้านหลังของโรงเรียน

[ ขอโทษนะ ฉันคบกับนายไม่ได้ ]

เด็กผู้หญิงตัวเล็กผมดำก้มหน้าลงเล็กน้อย

ความเงียบเกิดขึ้นครู่หนึ่ง นักเรียนชายถามด้วยน้ำเสียงเบาๆ

[ ...คาจูคุง พี่ชายของเธอสำคัญขนาดนั้นเลยเหรอ? ]

[ ใช่ค่ะ คาจูจะไม่คบกับใครจนกว่าท่านพี่จะมีความสุข ]

ดวงตากลมโตของเธอเต็มไปด้วยความมุ่งมั่น เด็กชายเห็นดังนั้นก็พยักหน้า

[ ฉันเข้าใจความรู้สึกของเธอแล้ว… ขอโทษที่จู่ๆ ก็เรียกเธอมา ]

[ คาจูซาบซึ้งในความรู้สึกของประธานนะคะ ฉันจะเก็บสิ่งที่เกิดขึ้นวันนี้ไว้ในใจ ขอให้ประธานช่วยชี้แนะคาจูเช่นเคยด้วยนะคะ ]

เด็กชายได้แต่ยิ้มขมขื่นกับความอ่อนโยนของคาจู

[ ..ถ้าเธอพูดแบบนี้จะรู้ได้ไงว่าใครเป็นรุ่นพี่กันแน่เนี่ย ? สักวันถ้าฉันชนะพี่ชายเธอได้ ฉันขอสารภาพอีกครั้งได้มั้ย ? ]

การไม่ยอมรับความพ่ายแพ้ นี่มันน่าเศร้าพอสมควรเลยนะ ?

แววตาของคาจูแวววาวเมื่อได้ยินคำพูดของเด็กชายเต็มไปด้วยความเสียดาย

[ ...ไม่ได้หรอกค่ะ มันเป็นไปไม่ได้ ]

[ หา? ไม่ นี่- ]

คาจูเดินเข้าไปหาเด็กชายที่ดูตกใจ

[ ตั้งแต่อดีตไปจนถึงอนาคต จะไม่มีใครที่ดีไปกว่าท่านพี่แล้วค่ะ ! เสน่ห์ของท่านพี่มันเป็นเรื่องจริงแท้ที่ไม่มีใครเทียบได้ ไม่ใช่แค่เสน่ห์ภายนอก แต่รวมถึงแสงแห่งจิตวิญญาณของท่านพี่- ]

นักเรียนหญิงคนหนึ่งโผล่มากระชากแขนคาจูไว้ก่อนที่เธอจะพูดต่อ

[ พอได้แล้ว นุคุจัง! ไปกันเถอะ! ]

[ เอ๊ะ กอนจัง? ทำไมดึงคาจูไปล่ะ? ]

อาซามิ กอนโด หรือ กอนจัง ใช้แรงทั้งหมดที่มีลากคาจูออกมา

กอนจังถอนหายใจด้วยความโล่งอกหลังพาคาจูมาที่ที่ไม่มีใครอยู่

[ นุคุจังน่ะ พอเริ่มพูดแล้วหยุดไม่ค่อยได้เลยนะ ]

[ แต่ว่า…]

[ ไม่มีแต่ ]

กอนจังเคาะหัวคาจูเบาๆ

[ นี่คนที่ 8 ของปีนี้แล้วใช่มั้ย? เธอไม่เคยปฏิเสธดีๆ เลยนะ ]

[ แบบนั้นมันแย่ก็สิ คาจูมีท่านพี่อยู่นะ ]

คาจูเกาหัวแล้วทำหน้าดื้อดึง

[ จะมีทั้งแฟนทั้งพี่ชายก็ได้ใช่มั้ยล่ะ? ไม่ต้องโสดไปตลอดก็ได้นะ ]

[ ไม่ใช่แค่จะมีใครก็ได้นะ คาจูดูง่ายขนาดนั้นเลยเหรอ? ]

คาจูยืดอกแบนๆของเธอ กอนจังขยับไหล่ แล้วพูด “อาระ”

[ ว่าแต่ นุคุจังอยากคบกับคนแบบไหนล่ะ? ]

คาจูใช้ปลายนิ้วแตะที่คาง เธอเอียงคออย่างน่ารัก

[ อืม… ถึงคนคนนั้นจะไม่ยอดเยี่ยมเท่าท่านพี่ แต่ขอแค่จริงใจก็พอ ]

[ ใช่ๆๆๆๆๆๆ ]

[ เขาต้องอ่อนโยนกับคาจู ให้ความสำคัญกับคาจู ถ้าคนซื่อๆมีปัญหา เขาจะไม่ทิ้งไว้ เขาต้องดูน่าไว้วางใจเหมือท่านพี่ คาจูจะช่วยปลุกถ้าเขาตื่นสายหรือไปโรงเรียนสาย เขาชอบค่อยๆแอบเข้าไปในผ้าห่มคนเดียวตอนเที่ยงคืนและหลับเหมือนเด็กน้อย เขากลัวความเหงา เขาชอบกินเค้กมันฝรั่งขาว เขาควรจะเกิดวันที่ 25 ธันวาคม

กรุ๊ปเลือด A แล้วถ้าเขาแก่กว่าคาจู 2 ปีล่ะก็- คาจูพร้อมจะมอบกายเนื้อให้ได้ทุกเมื่อ.... ]

[ อืมม… ]

คาจูไม่ทันสังเกตคำตอบที่ไม่เต็มใจของกอนจัง เธอมองไปบนท้องฟ้าด้วยดวงตาที่เปล่งประกาย

[ ไม่รู้ว่าเขาอยู่ที่ไหนกันแน่นะ? คิดว่าเขาน่าจะอยู่ใกล้ๆฉันแบบคาดไม่ถึงแน่ เธอว่าไงล่ะ กอนจัง? ]

[ คนแบบนั้น ใครจะเป็นได้อีกนอกจาก ‘ท่านพี่’ ของนุคุจังล่ะ? ]

[ ทำยังไงดีนะ? …ถ้าเราได้เจอกันก็คงดี… ]
