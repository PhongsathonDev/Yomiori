เล่ม 6 บทที่ 3-3

เช้าวันต่อมา ผมยืนอยู่บนลู่วิ่งของโรงเรียนมัธยมปลายซึวะบุกิในชุดวอร์มกีฬา

ผมดูนาฬิกา ตอนนี้เป็นเวลา 6 โมงครึ่ง นักเรียนหญิงคนหนึ่งเดินมาหาผมอย่างกระตือรือร้น ขณะที่ผมพยายามกลั้นหาว

[ ได้ยินจากบาโซริคุงมาแล้ว ฉันช่วยนายได้นะ ! ]

คนที่ยืนอยู่ตรงหน้าผมคือประธานนักเรียนโรงเรียนมัธยมปลายซึวะบุกิ โฮโคบารุ ฮิบาริ

…ผมก็เดาๆไว้ก่อนแล้วแหละ

เทียร่าซังกับซากุไรคุงก็มาด้วยในฐานะผู้ดูแล

[ เอ่อ...ฝากตัวด้วยนะครับ ]

ประธานวางมือลงบนไหล่ผมหลังจากที่ผมโค้งให้อย่างเก้ๆ กังๆ

[ ก่อนอื่น ฉันอยากรู้ความสามารถของนายตอนนี้ ลองวอร์มอัพแล้ววิ่งหนึ่งรอบสิ ]

[ ครับ เข้าใจแล้ว ]

หลังจากฝึกมาหลายวัน ผมน่าจะวิ่งได้เร็วขึ้นบ้าง

ผมวิ่งสุดกำลังหลังจากยืดกล้ามเนื้อเสร็จ

[ ว-เวลา...เท่าไหร่ครับ? ]

...ทำไมวิ่งช้าลง ?

ประธานเอียงคอแล้วกอดอก

[ อืม...ไม่ใช่ว่าก่อนเริ่มฝึกได้ 16.5 วินาทีเหรอ? ]

[ ก็เพราะโค้ชห่วย……. ]

[ โอเค ยืนตรงไว้อย่างนั้นแหละ ]

ประธานเดินเข้ามาใกล้ๆแล้วเริ่มแตะตัวผมทันที

[ เฮ้ เดี๋ยวก่อน!? ]

[ อย่าเกร็ง ผ่อนคลาย ]

ด้วยสีหน้าจริงจัง ประธานสัมผัสกล้ามเนื้อหน้าท้องและหลังของผม

[ อุวะ เดี๋ยวสิ มันจั๊กจี้นะ—เฮ้ อย่าแตะต้นขาด้านในสิ ฮิย๊า!? ]

[ เป็นผู้ชายใช่มั้ย อดทนไว้หน่อย ? ]

ก็เพราะเป็นผู้ชายไง ผมกัดฟันอดทน ขณะที่เทียร่าซังมองผมด้วยสายตาจริงจังจนขนลุก และยังค่อยๆ เข้ามาใกล้อีกด้วย

ประธานหยุดตรวจร่างกายตอนที่ผมเริ่มท่องบทสวดลึกๆในใจ

[ อืม เข้าใจโครงสร้างร่างกายของนายแล้ว ]

...เข้าใจแล้วเหรอ

[ โครงสร้างร่างกายของนายค่อนข้างบอบบาง มวลกล้ามเนื้อก็ไม่พอ ]

เทียร่าซังกลืนน้ำลายอย่างประหม่า

[ เอ่อ งั้นหมายความว่าผมต้องฝึกวิ่งแบบที่เหมาะกับร่างกายตัวเองเหรอ? ]

ประธานส่ายหน้า

[ ไม่ใช่ นายยังไม่มีกำลังกล้ามเนื้อที่จำเป็นสำหรับการฝึกด้วยซ้ำ ]

เอ๋? หมายความว่าผมไม่ได้รับอนุญาตให้ฝึกเหรอ?

[ แต่ผมต้องทำอะไรสักอย่างเพื่อเตรียมตัวสำหรับการแข่งขันสิ้นเดือนนี้นะ ]

[ เพราะงั้น ช่วง 10 วันแรก เราจะเน้นปรับกล้ามเนื้อและความอึดโดยรวมก่อน การฝึกวิ่งจะเริ่มในสัปดาห์สุดท้าย ]

[ มันจะพอเหรอครับ? ]

[ ไม่รู้ บอกไม่ได้ แต่ฉันจะทำแบบนั้น ]

เธอกล่าวด้วยความหนักแน่น มองผมตรงๆ

...แม้ว่าเทียร่าซังจะเป็นคนขอร้องให้เธอมาช่วยผม แต่เธอก็ไม่ได้อะไรจากการฝึกเลยแท้ๆ แต่ยังมาให้ความช่วยเหลือแบบนี้

ผมสบตาเธอและโค้งลงต่ำ

[ ครับ รบกวนด้วยครับ ]

[ เพราะเป็นคำขอของบาโซริคุงนี่นา ฝากไว้ที่ฉันได้เลย ]

เทียร่าซังมองเราอยู่ใกล้ๆ ทำให้ผมรู้สึกกระอักกระอ่วน

[ อีกอย่างนะ ท่าวิ่งของนายดูแปลกๆไปหน่อย ข้อเท้าขวาเจ็บเหรอ? ]

[ ข้อเท้าขวาผมรู้สึกไม่ค่อยดี อาจจะเป็นอาการกล้ามเนื้อเจ็บมั้งครับ? ]

[ ถ้าเป็นข้อเท้า อาจเป็นการเคล็ดเล็กน้อย จะบอกโคนุกิเซนเซให้ ]

โอเค ผมไม่อยากไปห้องพยาบาลหรอก แต่ดูเหมือนจะไม่มีทางเลือกแล้ว

ประธานนั่งลงกับพื้น ยืดขาออกแล้วตบพื้นข้างๆ ตัว

[ วันนี้ฉันจะสอนการฝึกกล้ามเนื้อที่ไม่ทำให้ข้อต่อเจ็บ มานั่งข้างฉันสิ ]

[ อ่า ครับ ]

ผมทำตามคำสั่งเธออย่างว่าง่าย ขณะที่เทียร่าซังดูเหมือนจะถ่ายวิดีโอเราด้วยสมาร์ทโฟนของเธอ เดินวนไปมาพร้อมสีหน้าจริงจังที่ชวนให้กลัว...

บทเรียนของประธานจบลงตอนเกือบ 7 โมงครึ่ง

[ ว่าแต่ ข้อเท้าของนายเจ็บมากแค่ไหน? ]

[ ไม่เป็นไรครับถ้าไม่วิ่ง แค่เจ็บนิดหน่อยเวลาเดิน ]

[ อืม งั้นเรามาแลกเปลี่ยนช่องทางติดต่อกันเถอะ ]

ประธานหยิบโทรศัพท์ออกมา

[ ตั้งค่าความเจ็บปวดที่เธอรู้สึกตอนนี้เป็น 10 แล้วอัพเดตฉันทุกวัน ]

[ ใช้ LINE ดีมั้ยครับ? ]

เทียร่าซังเดินเข้ามาและกระแอมเบาๆ ขณะที่ผมกับประธานกำลังแลก LINE กัน

[ ...นุคุมิซึซัง ใช้ LINE ใช่มั้ย? ]

[ เฮ้ย!? ]

นี่ครั้งที่สามแล้วนะ ถ้าเทียร่าซังไม่ได้ขัดข้องทางเทคนิค….อ่า คงเป็นแบบนั้นแหละ...

[ งั้นบาโซริซัง แลก LINE กันหน่อยมั้ย? ]

[ เอ๋? อ่า ได้ค่ะ! ]

..ไม่เข้าใจเธอเลยจริงๆ

ผมยื่น QR โค้ดให้ และเทียร่าซังก็ยกกล้องขึ้นสแกน

[ ว่าแต่ วันนี้ดูสุขภาพดีจังนะ ]

[ ปกติฉันดูอ่อนแอขนาดนั้นเลยเหรอ? ]

[ อื้อ เพราะพักนี้เธอเลือดกำเดาไหลบ่อย— ]

เทียร่าซังเชิดอกขึ้นก่อนที่ผมจะพูดจบ

[ ไม่ต้องห่วงค่ะ ฉันเริ่มดื่ม *Orengedokuto* แล้วล่ะ ]

[ Orengedoku...? นั่นอะไรน่ะ? ]

[ เป็นยาจีนค่ะ ฉันเอาชนะเลือดกำเดาไหลได้ด้วยพลังของยาจีนเลยนะ! ]

เข้าใจละ ยาจีนดูน่าทึ่งมาก หวังว่ามันจะช่วยขับพิษในหัวเธอได้ด้วยนะ

◇

หลังจากแยกกับสามประธานนักเรียน ผมเดินผ่านการซ้อมเบสบอลยามเช้าไปยังมุมหนึ่งของสนามโรงเรียน

ได้เวลาเปลี่ยนชุดแล้วกลับไปเรียน ผมคิดในใจด้วยความเหนื่อยล้าสุดๆ แล้วทันใดนั้น—

[ พยายามสุดตัวเลยนะ ดูดีเชียว ]

ยานามิเดินมาจากด้านหน้าพร้อมกล้วยในมือ

[ เธอแอบดูอยู่เหรอ? น่าจะพูดอะไรหน่อยสิ ]

[ ฉันก็คิดจะพูดนะ แต่แบบว่า... ]

ยานามิชี้ไปทางต้นไม้ที่ริมสนามด้วยกล้วยที่ถูกกัดไปครึ่งหนึ่ง

หลังก้านต้นไม้ มีโคมาริกำลังแอบมองเราอยู่

[ เธอทำอะไรอยู่น่ะ? ]

[ คงเขินเพราะเจอคนแปลกหน้าเยอะล่ะมั้ง ]

ก็สมเหตุสมผลดีนะ พวกประธานนักเรียนนี่ก็มีบุคลิกแปลกๆ กันทั้งนั้น

ผมลากขาอันเหนื่อยล้าของตัวเองเดินไปยังต้นไม้ที่โคมาริแอบอยู่

[ มีอะไรเหรอ โคมาริ? ]

โคมาริโผล่หัวออกมาครึ่งหนึ่งจากหลังต้นไม้ จ้องมาที่ผมด้วยสายตาแน่วแน่

[ น-นายจะให้พวกเขาโค้ชเหรอ? ]

[ ใช่ พวกเขาบอกว่าจะคอยดูแลการฝึกทุกวัน ]

[ ............ ]

เธอเงียบไปอีกครั้ง

[ เอ่อ...มีอะไรหรือเปล่า? ]

[ อา นั่นไง นุคุมิซึคุงแกล้งโคมาริจังอีกแล้ว ]

ยานามิพูดจาไร้สาระไปเรื่อย พร้อมกับแกว่งเปลือกกล้วยไปมา

[ ยานามิซัง เธอก็เห็นใช่มั้ย? ผมยังไม่ได้ทำอะไรเลยนะ ]

โคมาริยื่นมือออกมาอย่างกล้าๆ กลัวๆ พร้อมกับขวดเครื่องดื่ม

[ ...ฉ-ฉันทำเครื่องดื่มมาให้ ]

[ ขอบคุณนะ กำลังหิวน้ำพอดี— ]

แต่โคมาริกลับไม่สนใจผมแล้วส่งขวดเครื่องดื่มให้ยานามิแทน

[ ขอบคุณนะ โคมาริจัง ]

[ หา? นั่นมันควรจะเป็นของผมไม่ใช่เหรอ? ]

โคมาริเงยหน้ามองผมด้วยความประหม่าและพูดเบาๆ

[ ...น-นายมันขี้โกง ]

เธอทิ้งคำพูดแปลกๆ ไว้ก่อนจะวิ่งหนีไป อะไรกันน่ะ?

[ เครื่องดื่มนี่อร่อยจังนะ กลิ่นแอปเปิ้ลไซเดอร์ช่วยเรื่องฟื้นตัวได้ดีเลย ]

[ งั้นมันควรจะเป็นของผมมั้ย? ยานามิซัง เธอจะดื่มทำไม? ]

ยานามิยักไหล่ขณะดูดน้ำจากหลอด

[ แต่นุคุมิซึคุง ถ้าฉันขอ นายก็จะให้ฉันใช่มั้ยล่ะ? ]

[ ก็ใช่ แต่ว่า— ]

[ ฉันคิดไว้อยู่แล้วล่ะ ]

...หมายความว่าไง ยานามิซัง?

ยานามิดูดเครื่องดื่มอีกอึกใหญ่ ก่อนจะยื่นขวดที่เหลือครึ่งหนึ่งมาให้ผม

[ นี่ เหลือไว้ให้นายครึ่งนึง ]

รู้สึกเหมือนโดนเก็บส่วยจากเจ้าขุนมูลนายเลย ผมยอมจำนนกับสถานการณ์นี้แล้วหยิบหลอดขึ้นมา—

…ทำไมมันถึงมีกลิ่นกล้วย?

ผมเช็ดหลอดด้วยผ้าเปียกอย่างระมัดระวังก่อนจะดื่ม

เครื่องดื่มมีรสชาติสดชื่นผสมกันระหว่างเค็ม หวาน และเปรี้ยวที่ซึมซาบไปทั่วร่างกาย

แต่กลิ่นกล้วยที่เหลืออยู่ก็ยัง... อึย...

เย็นวันนั้น คาจูเดินเข้ามาในห้องของผมอย่างเป็นธรรมชาติ ขณะที่ผมกำลังยืดเส้นยืดสายตามตารางการฝึกที่ประธานสอนมา

เธอนั่งลงเงียบๆ อยู่ตรงหน้าผม ผมยังคงทำกิจกรรมของตัวเองโดยไม่พูดอะไร

[ ใช่ รู้สึกว่าช่วงนี้ร่างกายไม่ค่อยกระฉับกระเฉงเท่าไหร่ มีอะไรเหรอ? ]

[ สุดสัปดาห์นี้ก็วันไวท์เดย์แล้วนะคะ คาจูเตรียมของให้ท่านพี่ไว้ด้วย ]

ถึงเวลานั้นแล้วเหรอเนี่ย? ผมเพิ่งได้ช็อกโกแลตตามมารยาทจากอาซากุโมะซังในวันวาเลนไทน์ แต่ถ้าไม่ให้อะไรกลับไป ยานามิก็คงจะบ่นยกใหญ่แน่

[ ช่วงนี้คาจูสนใจขนมยุโรปแบบดั้งเดิมค่ะ มี Dragées, Pignolata , แล้วก็ครัมเบิ้ลเค้ก ฝากแบ่งให้ทุกคนด้วยนะคะ ]

[ ...ห๊ะ? มันคืออะไรน่ะ? ]

คาจูส่งกล่องอีกกล่องให้ แต่ผมยังงๆอยู่

[ อันนี้คือ Pitta Nchiusa ค่ะ ฝากให้คนที่พิเศษสำหรับท่านพี่นะคะ ]

แต่จังหวะก็ดีเหมือนกัน ผมต้องให้อะไรบางอย่างกับอาซากุโมะซังเป็นการส่วนตัวอยู่พอดี งั้นเอาอันนี้ให้เธอละกัน

[ งั้นขอรับไว้ด้วยความยินดี ขอบคุณที่ช่วยนะ ]

เวลาผ่านไปหนึ่งเดือนแล้วตั้งแต่วันวาเลนไทน์ มีอะไรเกิดขึ้นมากมาย

ทั้งการต้อนรับสมาชิกใหม่ของชมรมวรรณกรรม รุ่นพี่ที่ย้ายออกไป และเรื่องวุ่นวายอีกหลายอย่างที่โดนการแข่งขันกับยากิชิโอะกลบไปหมด ผมก็ยังรู้สึกแปลกๆ อยู่ดีที่ตัวเองต้องมาเกี่ยวข้องกับเรื่องพวกนี้

[ ท่านพี่ ขอโทษที่รบกวนระหว่างฝึกนะคะ คาจูช่วยอะไรได้มั้ย? ]
