เมื่อเดินจากห้องชมวิวออกไปยังดาดฟ้าชั้นบนสุด สายลมที่เจือไปด้วยน้ำค้างยามค่ำคืนก็พัดเข้าปะทะร่างกาย

ยากิชิโอะส่งเสียงร้องดีใจพลางใช้มือกดผมม้าที่ปลิวไสวเพราะสายลม

[ โห ลมเย็นสบายจังเลย! ]

ท่าทีร่าเริงนั้นราวกับความเศร้าหมองเมื่อครู่เป็นเพียงเรื่องโกหก

แม้ดาดฟ้าจะไม่ได้สูงกว่าห้องชมวิวมากนัก แต่ก็อบอวลไปด้วยกลิ่นอายของท้องฟ้าและยามค่ำคืน

ผมพยายามข่มความรู้สึกตื่นเต้นเอาไว้ลึกๆ ขณะทอดสายตามองวิวกลางคืนผ่านรั้วกั้น

ทิวทัศน์เดียวกับเมื่อกี้ พอไม่มีกระจกขวางกั้นก็ให้ความรู้สึกที่ต่างออกไป

──ในแสงไฟแต่ละดวงมีผู้คนอาศัยอยู่ และมีความหมายซ่อนอยู่

แม้ว่ามองจากฝั่งนู้น พวกเราคงถูกกลืนหายไปกับแสงไฟประดับจนมองไม่เห็นก็ตาม

ถึงจะมองไม่เห็น แต่ที่ตรงนี้ก็มีเด็กสาวม.ปลายธรรมดาๆ คนหนึ่งกำลังกลัดกลุ้มเรื่องอนาคต

และมีผมที่ยังมองไม่เห็นอนาคตจนถึงขั้นต้องมานั่งกลุ้มอยู่ด้วย

ผมส่งยิ้มตอบยากิชิโอะที่กำลังร่าเริง พลางปล่อยตัวปล่อยใจไปกับความรู้สึกที่สายลมยามค่ำคืนพัดพามา

......จู่ๆ ผมก็หยุดเดินอยู่หน้าแผ่นหินเล็กๆ แผ่นหนึ่ง

บนนั้นเขียนไว้ว่า 『ดินแดนศักดิ์สิทธิ์ของคู่รัก』 และที่รั้วด้านหลังก็มีแผ่นการ์ดข้อความรูปหัวใจแขวนเรียงรายอยู่มากมาย

พอลองอ่านดูด้วยความอยากรู้อยากเห็น ก็พบว่ามีชื่อคู่รักและข้อความเขียนเอาไว้

มีแต่พวกหวานแหววกันทั้งนั้น โชคดีจริงๆ ที่ไม่ได้พายานามิมาที่นี่......

ก็นะ ปกติชายหญิงที่ไม่ได้คบกันเขาคงไม่มาดูวิวกลางคืนบนหอคอยส่งสัญญาณโทรทัศน์หรอก ขืนไปใส่ใจเรื่องแบบนี้คงเป็นเรื่องไร้สาระเปล่าๆ

หลังจากจบความคิดที่ออกจะสมเพชตัวเอง ผมก็มองหายากิชิโอะ แล้วก็เห็นเธอกำลังทำลับๆ ล่อๆ อยู่ตรงหน้าตะแกรงรั้วที่ห่างออกไปนิดหน่อย

......? ยัยนั่นเองก็โดนข้อความสวีทหวานของคู่รักเล่นงานเอาเหมือนกันหรือเปล่านะ

[ ยากิชิโอะ มีอะไรน่าสนใจงั้นเหรอ ]

[ ! มะ ไม่มีอะไรรร อากาศเริ่มเย็นแล้ว เราลงไปข้างล่างกันเถอะ ]

งั้นเหรอ ผมว่าห้องชมวิวที่เปิดแอร์น่าจะเย็นกว่าที่นี่ซะอีกนะ

[ ก่อนหน้านั้นขอยืมสมาร์ทโฟนหน่อยได้ไหม พอดีอยากถ่ายรูปวิวกลางคืนน่ะ ]

[ อื้อ ได้สิ──เดี๋ยวสิ แล้วนายจะเดินมาทางนี้ทำไมเนี่ย?! ]

พอผมจะเดินไปทางที่ยากิชิโอะทำลับๆ ล่อๆ เมื่อกี้ เธอกลับพยายามบล็อกผมไว้อย่างสุดชีวิตซะงั้น

[ ทำไมงั้นเหรอ......ก็ว่าจะไปถ่ายวิวกลางคืนจากตรงนู้นไง ]

[ ถ้าอย่างนั้น ลงไปถ่ายที่ห้องชมวิวข้างล่างเห็นชัดกว่านะ! เอ้า ลงไปกันเถอะ! ]

[ แต่ถ้าอยู่ข้างล่างมันจะสะท้อนกระจกนี่นา── ]

[ ค่าๆ นุกคุง ไปกันได้แล้ววว ]

ยากิชิโอะดันหลังผมอย่างแรง เอ๊ะ......ทำไมถึงพยายามกันผมให้ออกห่างจากรั้วนั่นขนาดนี้เนี่ย

ด้วยความที่ไม่เข้าใจเหตุผล ผมก็เลยถูกดันให้ลงบันไดที่เชื่อมไปยังห้องชมวิวไปทั้งอย่างนั้น

◇

เมื่อลงจากรถบัส ผมก็ใช้เท้าเช็กสัมผัสของพื้นดิน

──ทั้งที่แค่ตั้งใจจะมาไปร้านสะดวกซื้อแท้ๆ แต่กลับกลายเป็นว่าได้มาดูวิวกลางคืนกับยากิชิโอะสองต่อสองไปซะได้

ความรู้สึกหวิวๆ ราวกับอยู่ในความฝันยังคงไม่จางหายไป

[ ทุกคนจะเป็นห่วงกันหรือเปล่านะ ]

[ บอกไปเรียบร้อยแล้วล่ะ ไม่เป็นไรหรอก บอกว่าจะออกมาเดินเล่นกับนุกคุงไง ]

แต่สำหรับการเดินเล่นแล้ว มันไม่นานไปหน่อยเหรอ

ตอนนี้เลย 3 ทุ่มมาตั้งเยอะแล้ว ขืนกลับไปมียานามิกับโคมาริบ่นหูชาแน่......

ความกังวลของผมถูกปัดเป่าทิ้งไป ยากิชิโอะเริ่มเดินกระโดดโลดเต้นไปบนขอบฟุตบาทอย่างอารมณ์ดี

[ ยากิชิโอะ มันอันตรายนะ อย่าไปเดินตรงนั้นสิ ]

[ นุกคุงเนี่ย ขี้กังวลจังน้าー ]

ถึงจะพูดแบบนั้น ยากิชิโอะก็ยอมลงจากขอบฟุตบาทมาเดินขนาบข้างผม

ขณะที่เดินตามถนนยามค่ำคืนมุ่งหน้าไปยังแมนชั่นของรุ่นพี่สึกิโนะกิ ผมก็นึกย้อนถึงช่วงเวลาเมื่อครู่

การเปิดเผยความในใจให้ใครสักคนฟังในสถานที่ที่ต่างไปจากเดิม

ยากิชิโอะคงต้องการช่วงเวลาแบบนั้นล่ะมั้ง

แต่มีเรื่องหนึ่งที่ผมไม่เข้าใจเลยก็คือ──

[ นุกคุง เป็นอะไรเหรอ? ]

ผมหยุดเดินแล้วจ้องมองเข้าไปในดวงตาของยากิชิโอะ

[ ยากิชิโอะ ทำไมถึงพาผมออกมาด้วยล่ะ? ]

[ ก็บอกไปแล้วไง ว่าหมู่นี้เราไม่ค่อยได้คุยกันสองต่อเลย ]

[ มันก็ใช่อยู่หรอก...... ]

ยากิชิโอะเดินอ้อมมาดักหน้าผม พร้อมกับเผยรอยยิ้มร่าเริงตามปกติ

[ นุกคุงเป็นประธานชมรม ไหนจะต้องคอยดูแลยานะจัง โคมาริจัง แล้วตอนนี้ก็ต้องดูแลทามะจังอีกใช่ไหมล่ะ? เพราะงั้นเลยอยากให้นุกคุงได้── ]

คราวนี้ยากิชิโอะกลับเป็นฝ่ายพูดไม่ออก

[ ให้ผม......ทำไมเหรอ? ]

[ ──ไม่รู้สิ ]

ยากิชิโอะหัวเราะแก้เขิน แล้วใช้นิ้วจิ้มจมูกผมก่อนจะหันหลังกลับ

──ระหว่างผมกับยากิชิโอะ มีความรู้สึกอะไรบางอย่างอยู่จริงๆ

แต่ถึงอย่างนั้น ผมก็ไม่ได้หลงตัวเองขนาดคิดว่ายัยนี่กำลังตกหลุมรักผมหรอก

สำหรับยากิชิโอะแล้ว ผมเป็นแค่เพื่อนที่แปลกประหลาดนิดหน่อย

เพราะงั้นล่ะมั้ง ถึงได้ถูกเลือกให้มาเป็นเพื่อนร่วมทางในค่ำคืนแปลกๆ แบบนี้

ยากิชิโอะก้าวเดินอย่างเงียบงัน พลางพึมพำออกมาราวกับเสียงกระซิบ

[ นุกคุงน่ะ มีโคมาริจังกับยานะจังอยู่แล้วนี่น้าー ]

โคมาริกับยานามิ? ทำไมชื่อสองคนนั้นถึงมาโผล่ตรงนี้ได้ล่ะ......?

ก่อนที่ผมจะตัดสินใจถามกลับไป เสียงสมาร์ทโฟนของยากิชิโอะก็ดังขึ้น

ยากิชิโอะมองหน้าจอแล้วยิ้มแหยๆ ก่อนจะยกมันขึ้นแนบหู

[ ค่าๆ ว่าไงจ๊ะยานะจัง ]

หวา ในที่สุดยานามิก็โทรมาจนได้

ดูจากท่าทียากิชิโอะที่พูดไปหัวเราะไป อารมณ์ของยานามิก็น่าจะดีอยู่──ไม่สิ ฟังจากเสียงยานามิที่ลอดออกมาจากสมาร์ทโฟนแล้ว คงไม่ใช่อย่างนั้นแน่

ยานามิกับโคมาริเนี่ย พอผมทำตัวสนิทสนมกับยากิชิโอะทีไรเป็นต้องโกรธทุกที เข้าใจอยู่หรอกว่าเป็นห่วงยากิชิโอะ แต่ผมไม่มีทางไปจีบหรอกน่า......

งานเทศกาลสึวาบุกิปีที่แล้ว ก็มีผู้ชายที่เข้าใจผิดเรื่องระยะห่างของยากิชิโอะจนหน้าแตกหมอไม่รับเย็บไปคนนึง ผมไม่อยากจะซ้ำรอยหมอนั่นหรอกนะ

[ ก็บอกแล้วง๊ายยย ว่าแค่ขอยืมนุกคุงมาแป๊บเดียวเอง ]

เสียงคุยโทรศัพท์ของยากิชิโอะดังขึ้น

......ยานามิกับยากิชิโอะ คุยเรื่องอะไรกันอยู่นะ

ระหว่างที่ผมกำลังเงี่ยหูฟังด้วยความลุ้นระทึก ผมก็สังเกตเห็น

ยากิชิโอะจ้องเขม็งมาที่ผมทั้งๆ ที่ยังแนบสมาร์ทโฟนไว้ที่หู

เอ๊ะ......อะไรล่ะเนี่ย......? ยากิชิโอะมองผมด้วยท่าทางแบบนั้นแล้วพูดขึ้นว่า

[ ────นอกใจไงล่ะ ]

ยากิชิโอะทิ้งท้ายไว้แค่นั้นก่อนจะตัดสายไป

......หา? นอกใจ? นี่ไปคุยอะไรกับยานามิมาเนี่ย?

ยากิชิโอะมองผมที่กำลังสับสนแล้วหัวเราะคิกคัก

[ นุกคุง ดึกแล้วกลับกันเถอะ ]

[ เอ๊ะ? อ่า นั่นสินะ ]

จู่ๆ ยากิชิโอะก็ฮัมเพลงไปพลาง เดินนำไปตามทางกลับแมนชั่นที่พวกยานามิรออยู่

──นอกใจ เป็นคำที่ชวนให้ว้าวุ่นจนผมเผลอใจเต้นตึกตักอย่างบอกไม่ถูก

ขืนกลับไปมียานามิบ่นหูชาแหงๆ หรือว่าตรงไปบ้านรุ่นพี่ทามากิที่จะไปค้างคืนนี้เลยดีไหมนะ......

ระหว่างที่เดินไปใจลอยไป ในที่สุดก็มาถึงหน้าแมนชั่นของรุ่นพี่สึคิโนะกิ

ผมเรียกยากิชิโอะที่ทำท่าจะเดินเข้าไปในตึกทั้งอย่างนั้นเอาไว้

[ ยากิชิโอะ ไม่แวะร้านสะดวกซื้อแล้วเหรอ? ]

[ อื้อ มันดึกแล้วล่ะนะ ]

......เอ๊ะ ไม่ใช่ว่าต้องซื้อแปรงสีฟันหรอกเหรอ

ผมเดินตามยากิชิโอะเข้าไปในโถงทางเข้า พลางลอบมองท่าทีของเธอด้วยหางตา

หรือว่าตั้งแต่ตอนที่ชวนไปร้านสะดวกซื้อ ทั้งหมดนั่นเป็นแผนของยากิชิโอะมาตั้งแต่แรกแล้ว......?

[ เป็นอะไรเหรอ นุกคุง ]

[ อา เปล่า ไม่มีอะไร ]

......ไม่สิ เลิกคิดดีกว่า

ต่อหน้ารอยยิ้มของยากิชิโอะ ขืนไปใส่ใจเรื่องพรรค์นั้น──ก็คงเป็นเรื่องไร้สาระเปล่าๆ
