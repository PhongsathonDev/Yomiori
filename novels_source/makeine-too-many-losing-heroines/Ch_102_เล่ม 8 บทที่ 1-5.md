เล่ม 8 บทที่ 1-5

[ นี่มันอะไรกันคะ?! พวกคุณทำอะไรกันเนี่ย ]

เทียร่าซังจ้องเขม็งมาที่ผมขณะคนกาแฟด้วยช้อน

[ แล้วคนที่เรียกฉันมา พอพอใจก็กลับไปแล้วเนี่ย หมายความว่ายังไงคะ?! ]

[ ถึงพูดแบบนั้นก็เถอะ... ]

ใช่แล้ว...เพราะ ชิกิยะซังกลับไปแล้วผมเลยกลายเป็นคนเดียวที่ต้องรับมือกับความโกรธของเทียร่าซัง ทั้งที่ไม่ได้ทำอะไรผิดเลยแท้ๆ

[ นุคุมิซึซังก็ไม่ยอมห้าม แล้วทำไมถึงเล่นมือถือสบายใจเฉิบอยู่ได้คะ ]

[ ก็กะจะถ่ายวิดีโอ──ไม่ใช่สิ...คือรุ่นพี่ชิกิยะกับเทียร่าซังก็เป็นผู้ใหญ่แล้ว น่าจะไม่มีปัญหาอะไรถ้าอยู่กันตามลำพัง เลยไม่อยากรบกวนน่ะ ]

[ ไม่ใช่แบบนั้นสักหน่อย! แล้วก็อย่าเรียกฉันด้วยชื่อจริงสิคะ ！ ]

เทียร่าซังที่กำลังโกรธปุดๆ ดื่มกาแฟที่ใส่นมกับน้ำตาลไปสามช้อนในรวดเดียว

ผ่านไปครู่หนึ่ง ดูเหมือนเธอจะสงบลงได้จากคาเฟอีนกับน้ำตาล เธอวางถ้วยกาแฟลงบนโต๊ะอย่างมีเสียง แล้วกระแอมเบาๆ

[ ว่าแต่...เรื่องที่จะคุยกับฉันคือเรื่องอะไรเหรอคะ? ]

...หือ？เรื่องอะไรอีกล่ะ？

[ ไม่รู้เลยนะว่า บาโซริซัง จะมาด้วย ]

[ แต่ฉันได้ยินจากรุ่นพี่ชิกิยะว่าให้มาที่นี่ ]

อะไรนะ...หมายความว่าชิกิยะซังใช้ผมเป็นข้ออ้างเพื่อเรียกเทียร่าซังมาอย่างนั้นเหรอ？

ขณะที่กำลังสับสน เสียงกระจกแตกก็ดังขึ้นแหลมบาดหู

[ เสียงอะไรน่ะ？]

[ อ้อ รุ่นพี่ชิกิยะโทรมาน่ะ ]

พอดูหน้าจอมือถือ ก็มีข้อความเด้งขึ้นมาทันที

──ของขวัญตอบแทนคริสต์มาส

...โดนเข้าแล้ว

ผมเงยหน้ามองท้องฟ้าโดยไม่รู้ตัว คืนนั้นในวันคริสต์มาสอีฟปีที่แล้ว ผมก็เคยใช้ไฟประดับเป็นข้ออ้างเพื่อพาชิกิยะซังมาเจอกับรุ่นพี่สึคิโนกิ

พูดง่ายๆ นี่คือ การแก้แค้น ของเขาสินะ

[ นุคุมิซึซัง อย่ามัวแต่คิดเองเออเองค่ะ เกิดอะไรขึ้นเหรอ？]

[ เอ่อ...คือรุ่นพี่ชิกิยะอาจจะเคืองผมนิดหน่อย แล้วนี่เหมือนว่า...แก้แค้นมั้ง…. ]

[ เคืองเหรอคะ? ไปทำอะไรให้เขาไม่พอใจเหรอ？]

ก็...หลายอย่างเลยแหละ ผมหลบสายตาแล้วแกล้งทำเป็นยกถ้วยกาแฟที่ว่างเปล่าขึ้นจิบ

แล้วก็ครุ่นคิดถึงเหตุผลที่รุ่นพี่ชิกิยะจับเราสองคนมาเจอกันแบบนี้

ผมเริ่มพูดขึ้นมา

[ เอ่อ...เรื่องการเลือกตั้งสภานักเรียนน่ะ ]

[ อ๋อ ค่ะ ]

ผมหยุดสั้นๆ เพื่อดูท่าทีของเธอ

เทียร่าซังนั่งตัวตรง ตั้งใจฟังคำพูดต่อจากผม

──ผมกำลังจะอธิบายที่ผมปฏิเสธคำขอของชิกิยะซัง แต่ว่าก็หยุดไว้

[ ผมเป็นประธานชมรมวรรณกรรม และก็ไม่ได้สนใจเรื่องสภานักเรียนเลย การเป็นผู้สนับสนุนมันก็เหมือนการแกล้งทำเป็นสนใจ ทั้งที่จริงๆ แล้วไม่คิดจะมีส่วนร่วม และที่สำคัญคือ── ]

ผมพยายามหัวเราะแบบประชดตัวเอง แต่กลับกลายเป็นสีหน้าฝืนๆ

[ ผมไม่ถนัดการพูดต่อหน้าผู้คน ]

เทียร่าซังเงียบฟังผมอย่างตั้งใจ ก่อนจะถอนหายใจแรง

[ ...เข้าใจแล้วค่ะ ฉันจะไม่บังคับแล้ว ]

หือ...เธอยอมแพ้ง่ายขนาดนี้เลยเหรอ？

ขณะที่กำลังรู้สึกประหลาดใจ เทียร่าซังก็วางมือถือไว้บนโต๊ะอย่างไม่ตั้งใจ

หน้าจอที่สว่างขึ้นทันทีแสดงภาพ──ไม่สิ ไม่ใช่ภาพสาวสวยโดยตรง แต่เป็นของสะสมจากตัวละครสาวสวยต่างหาก ทำไมเทียร่าซังถึงมีอะไรแบบนี้...？

ผทเผลอมองซ้ำ แล้วก็ลุกขึ้นจากเก้าอี้แทบจะทันที

[ หะ? นั่นจิกะเปียวจาก< แก๊งสาวเส้นยาแดงผ่าแปด>ที่อยู่ในป้ายโปรโมตหน้าร้าน ไม่ใช่เหรอ?! ทำไมบาโซริซังถึงมีได้ล่ะ? ]

[ พอดีญาติของฉันทำธุรกิจร้านค้า แล้วมักจะเอาพร็อพสำหรับโปรโมตสินค้า──หรืออะไรประมาณนั้นมาให้บ่อยๆ เพราะคิดว่าฉันยังเด็ก คงชอบพวกอนิเมะกับมังงะน่ะค่ะ ]

เทียร่าซังพูดอย่างเรียบเฉย แล้วเลื่อนมือถือมาให้ผมดูชัดๆ

[ ฉันไม่ค่อยเข้าใจอะไรแบบนี้เท่าไหร่ค่ะ ถ้ามีคนที่ชอบก็อยากแบ่งให้ ]

[ งะ...งั้นเหรอ！ ]

ผมเอนตัวพรวดไปข้างหน้าแต่ก็รีบยืดหลังกลับมานั่งดีๆ

[ อ๋อ...งั้นก็ขอให้เจอคนที่อยากได้ล่ะกันนะ ]

[ แปลกจัง ฉันนึกว่านุคุมิซึซังอยากได้ เพราะเห็นมีพวงกุญแจที่คล้ายๆ กันห้อยอยู่ ]

[ เหรอ？ตัวละครแนวนี้ก็มีเยอะน่ะ ]

ผมรีบเลื่อนกระเป๋าให้พ้นสายตาเธอ

คล้ายๆ น่ะเหรอ──ไม่ใช่เลย ตัวที่อยู่บนกระเป๋าผมน่ะของจริงเลยต่างหาก

แสดงว่าเธอรู้อยู่แล้วว่าผมชอบตัวนี้ และจงใจหยิบขึ้นมาเพื่อดูปฏิกิริยาของผม เผลอตกหลุมเธอง่ายๆแล้ว

…………

………………แต่ถึงอย่างนั้น ก็ฟังเธอพูดอีกนิดก็ไม่เสียหายมั้ง…

ขณะฉันแอบเหลือบมองมือถือของเธอ เทียร่าซังก็หัวเราะเบาๆ

[ ถ้าฉันยกให้ จะยอมเป็นผู้สนับสนุนมั้ย── ]

[ อืม !]

[ ล้อเล่นหรอกค่ะ ถ้ามีคนอยากได้ ฉันก็ยกให้อยู่แล้ว ]

[ เอ๊ะ ได้จริงๆ เหรอ？ ]

ทันทีที่ผมพูดประโยคนั้นออกไป──ก็รู้ตัวว่าผมแพ้แล้ว

เทียร่าซังยิ้มอย่างมีเลศนัยที่มุมปาก

[ ไม่เป็นไรค่ะ แต่พอดีฉันก็เริ่มรู้สึกผูกพันกับมันนิดหน่อย ถ้านายจะตอบแทนในขอบเขตที่ไม่ลำบากเกินไปก็จะดีไม่น้อย ]

ให้ตายสิ...รู้ว่าเธอต้องมาไม้นี้แน่

แล้วเธอก็พูดต่ออย่างสบายๆ

[ ช่วยติวฉันอีกครั้งได้มั้ยคะ？]

…หือ แค่นี้เองเหรอ

ผมที่ยังงุนงงอยู่ เทียร่าซังก็ทำหน้าเหมือนรู้สึกผิดเล็กน้อย

[ ผลสอบครั้งก่อน...ออกมาไม่ค่อยดีเลย ]

[ ช่วงนี้เกรดผมก็เริ่มตกเหมือนกัน ถ้าไม่ถือสาก็โอเค ]

[ ค่ะ วิธีสอนของนุคุมิซึซังเข้าใจง่ายมากเลย ]

ฟังแบบนี้แล้วก็รู้สึกดีขึ้นมาหน่อย

แต่...เรื่องการเลือกตั้งสภานักเรียน เธอยอมง่ายเกินไปหรือเปล่านะ？

ขณะที่ผมกำลังครุ่นคิด เทียร่าซังก็ถามแบบหลบๆสายตา

[ เสียงเรียกเข้าจากรุ่นพี่ ชิกิยะเมื่อกี้...ตั้งไว้ต่างจากคนอื่นเหรอคะ？เสียงเหมือนกระจกแตกเลย ]

[ อื้ม จะได้รู้ว่าใครโทรมาโดยไม่ต้องหยิบดูไง ตั้งแบบนี้ก็สะดวกดีนะ ]

อย่างเช่นเวลาคุณครูโคนุกิส่งข้อความมา ผมก็จะทำเป็นไม่เห็นได้อย่างง่ายดาย

จากนั้นเทียร่าซังก็หยิบมือถือขึ้นมากดอะไรบางอย่าง

──ติ๋ง

เสียงเรียกเข้าดังจากมือถือผม

พอดูหน้าจอก็เห็นว่าเป็นข้อความว่างเปล่าจากเทียร่าซัง

[ อะไรเนี่ย？]

ขณะที่กำลังงง เทียร่าซังก็เก็บมือถือเข้ากระเป๋าพร้อมทำหน้าเบื่อๆ

[ เสียงของฉันยังเป็นค่าเริ่มต้นอยู่สินะ ]

[ ก็...ใช่นะ ]

อะไรกัน อยู่ดีๆ ก็อารมณ์ไม่ดีขึ้นมาเฉยๆ เลย

เทียร่าซังปัดกระโปรงแล้วลุกขึ้นยืน

[ งั้นพรุ่งนี้วันเสาร์ ทำตัวให้ว่างช่วงบ่ายๆด้วยนะคะ ]

[ พรุ่งนี้เลยเหรอ？กะทันหันไปหน่อยมั้ย ? ]

[ อ้าว หรือมีนัดอะไรเหรอคะ？]

...ก็ไม่มีหรอก

ผมส่ายหน้าเบาๆ แล้วเทียร่าซังก็ยิ้มบางๆ ก่อนจะหันหลังเดินจากไป

◇

คืนนั้น ผมจัดเรียงหนังสือเรียนคณิตศาสตร์ลงบนโต๊ะอ่านหนังสือ แล้วกอดอกมองมันจากด้านบน

พรุ่งนี้จะเอาเล่มไหนไปเรียนดีนะ ถ้าเอาไปหมดมันก็ดูจริงจังเกินไปหน่อย ไม่เท่เลย แต่ถ้าเอาไปน้อยเกินก็คงหมดเรื่องคุยกันเร็วแน่

หนังสือเรียนหลักกับสมุดโน้ตน่ะถือเป็นของตาย ส่วนหนังสือเสริมกับแบบฝึกหัดก็เลือกแค่เล่มเด็ด ๆ เล่มเดียวพอ...

พอใส่ลงกระเป๋าก็ดูไม่หนาเกิน กำลังดี ต่อไปก็ตรวจเช็คชุดที่จะใส่

ผมวางชุดไว้บนพื้น เป็นเชิ้ตแขนสั้นแบบมีปก กับกางเกงชิโนผ้าบาง ทุกชิ้นเป็นผ้าพื้นไม่มีลายทั้งนั้น

ช่วงนี้ดวงซวยบังเอิญลายหมดอายุชีวิตไปหลายชุดแล้ว ก็เลยไม่มีตัวเลือกอื่นนอกจากเสื้อผ้าพื้น ๆ

[โอเค เรียบร้อย──]

[ ท่านพี่ พรุ่งนี้จะออกไปข้างนอกเหรอคะ? ]

คนที่ยืนอยู่ข้างหลังผมไม่รู้ตั้งแต่เมื่อไหร่ก็คือ น้องสาวของผม คาจู

[ อืม กะว่าจะไปแถวสถานีนิดหน่อยน่ะ ]

[ อ๋อ ไปอ่านหนังสือที่ห้องสมุดสินะคะ ]

คาจูพูดพลางเหลือบมองกระเป๋า

พรุ่งนี้ผมนัดกับเทียร่าซังไว้หน้าร้านหนังสือเซบุงคังแถวสถานี แล้วจะไปสถานที่จัดกลุ่มติวด้วยกัน

ไม่ได้มีอะไรลับ ๆ ล่อ ๆ หรอก แต่ถ้าให้คาจูรู้เข้า ก็น่ารำคาญแหง ๆ ใช่ น่ารำคาญชัวร์

[ เอ่อ ก็นะ แค่จะไปซื้อของนิดหน่อยน่ะ ]

[ ……ไปติวหนังสือกับใครบางคนสินะคะ ]

คาจูพึมพำเบา ๆ

[ ห้ะ เปล่าสักหน่อย ]

[หรือว่าเป็นผู้หญิงเหรอคะ ?! อย่าบอกนะว่าติวกันที่บ้านของอีกฝ่าย…..แบบเดทอ่านหนังสือ! ]

[ ไม่ ๆ ไม่ใช่แบบนั้นเลย! แค่เพื่อน──ใช่ เพื่อนผู้ชายน่ะ ไปอ่านหนังสือด้วยกัน ]

ผมรีบแก้ต่างด้วยคำโกหกด้นสด คาจูส่ายหน้าเบา ๆ พร้อมกับแววตาเปล่งประกาย

[ ซากุไรซังพรุ่งนี้ต้องไปช่วยเก็บกะหล่ำปลีที่บ้านญาตินี่คะ อายาโนะซังก็มีเรียนพิเศษ แล้วพี่ชายก็ไม่มีเพื่อนผู้ชายคนอื่นแล้วนะคะ ]

คาจู พอพูดถึงเรื่องเพื่อนทีไรนี่ไม่ยอมปล่อยเลยจริง ๆ

[ ก็ใช่ เพื่อนผู้ชายผมก็มีแค่สองคนนั้นแหละ แต่เธอรู้ตารางของสองคนนั้นได้ยังไง? ]

[ วันก่อนบาโซริซังมาบ้าน หนูเลยถามเรื่องความสัมพันธ์ของพี่ชายกับเพื่อน ๆ ค่ะ สรุปว่าท่านพี่จะไปติวกับผู้หญิงแน่นอน! อย่าบอกนะว่าเป็นประธานนักเรียน หรือไม่ก็ชิกิยะซัง? หรือว่า──]

[ จ้าๆ ไม่ใช่แบบนั้นเลยนะ ได้เวลาเด็กมัธยมต้นเข้านอนแล้วนะ ]

[ หืมมม คาจูเป็นผู้ใหญ่แล้วนะคะ! ]

ผมเมินเสียงประท้วง แล้วค่อย ๆ ดันไหล่ของคาจูให้ออกไปจากห้อง
