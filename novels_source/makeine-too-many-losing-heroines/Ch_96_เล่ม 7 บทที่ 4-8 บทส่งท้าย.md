เล่ม 7 บทที่ 4-8 บทส่งท้าย

< บทส่งท้าย: ชิราทามะ ริโกะ ห้อง 1-F >

ห้าวันผ่านไปตั้งแต่วันนั้น เมื่อย้อนกลับไปคิด แทบไม่น่าเชื่อเลยว่าเราบุ่มบ่ามกันขนาดไหน

ผมมักพยายามเก็บตัวให้เงียบที่สุดเพื่อหลีกเลี่ยงปัญหาในชีวิตโรงเรียน

แต่ดูสิ ตอนนี้ผมกลับมาติดอยู่ในเรื่องวุ่นวายตั้งแต่ต้นปีการศึกษาที่สองของผม—

คิดแบบนั้นแล้ว ผมก็จอดจักรยานไว้ข้างหน้าบ้าน

—พักกิจกรรมชมรมชั่วคราวสองสัปดาห์

นั่นคือบทลงโทษที่ชมรมวรรณกรรมได้รับ

นึกว่าเรารอดมาได้โดยไม่ถูกจับได้ แต่ดันลืมเรื่องโคมาริไปสนิท

โคมาริบุกเข้าไปในสถานที่จัดงานแต่งงานเพื่อช่วยพวกเราหนี ซึ่งแน่นอนว่าทำให้เกิดความวุ่นวายไม่น้อย

พนักงานสถานที่คิดว่าเป็นเซอร์ไพรส์ที่ชิราทามะซังจัดขึ้น เลยปล่อยผ่านไป แต่ครูจากโรงเรียนซึวะบุกิที่อยู่ในงานกลับไม่ใจดีขนาดนั้น

ส่วนเรื่องการ "พักกิจกรรมชั่วคราว" จะเป็นยังไงนั้น พวกเราไม่มีใครรู้เลย

[ กลับมาแล้ว~ ]

ผมถอนหายใจพลางเปิดประตูบ้าน เห็นรองเท้าหลายคู่เรียงรายอยู่ที่ทางเข้า

ผมลากเท้าเดินไปเปิดประตูห้องนั่งเล่น

[ กลับมาช้านะ นุคุมิซึคุง ]

[ น-นึกถึงสิ่งที่นายได้ทำไว้ซะ ]

...สมาชิกชมรมวรรณกรรมทุกคนมารวมตัวกันที่โต๊ะกลางห้องนั่งเล่น

เราใช้ห้องชมรมไม่ได้เพราะถูกพักกิจกรรม แต่ทำไมบ้านผมถึงกลายเป็นที่รวมตัวใหม่ล่ะ?

ชิราทามะซังรีบเดินเข้ามาหยิบกระเป๋าจากมือผมไป

[ ยินดีต้อนรับกลับค่ะ ประธาน วันนี้ทุกคนจัดงานต้อนรับฉันล่ะ ]

[ เหรอ งั้น… อ๊ะ ผมถอดเสื้อนอกเองได้นะ ]

[ ไม่ต้องเกรงใจค่ะ เดี๋ยวฉันแขวนให้เอง ]

และใช่ ชิราทามะ ริโกะ เข้าชมรมวรรณกรรมอย่างเป็นทางการแล้ว

หลังจากร่วมมือกันทำภารกิจสำเร็จ พวกเราก็สนิทกันมากขึ้น

[ ดูเหมือนสายลมของรุ่นพี่จะพัดมานะ! ความเร็วลมเกิน 5 เมตรต่อวินาที! ]

[ ฉ-ฉันกำลังจะปลิวแล้ว ]

ยานามิกับโคมาริแซวผมจากด้านข้าง

เอาเป็นว่า การล้อเลียนนี้คือสัญญาณว่าความสัมพันธ์ของเราดีขึ้น

นั่นเป็นเหตุผลที่ผมไม่ถือสาโคมาริที่อ่านมังงะที่ผมซ่อนไว้หลังชั้นหนังสือ หรือยานามิที่กินพุดดิ้งของผมโดยไม่ขอ นี่คือสัญลักษณ์ของความสนิทสนมของพวกเราแน่นอน

[ อ๊ะ นุคคุงกลับมาแล้วเหรอ! ยินดีต้อนรับกลับนะ! ]

ยากิชิโอะเดินเข้ามาในห้องนั่งเล่นพร้อมเช็ดผมด้วยผ้าขนหนู ดูเหมือนระยะทางจากโรงเรียนมาถึงบ้านผมจะพอดีกับการวอร์มอัพของเธอ ช่วงนี้เลยแวะมาบ่อยขึ้น

ก็ไม่ได้ว่าอะไรหรอก แต่ผมจะดีใจมากถ้าเธอไม่อาบน้ำที่บ้านผม มันรู้สึกแปลกๆ

ชิราทามะซังส่งแก้วชามอลต์ให้เธอ

[ นี่ค่ะ ยากิชิโอะซัง ]

[ ขอบคุณนะ ทามะจัง! ]

ยากิชิโอะดื่มชาหมดแก้วในรวดเดียวก่อนจะมานั่งที่โต๊ะกินข้าวกับยานามิและคนอื่นๆ

รู้สึกแปลกๆ เล็กน้อย ผมนั่งลงที่โซฟา และกลิ่นหวานๆ ก็ลอยมาจากด้านหลัง

[ ชีสเค้กเสร็จแล้วค่ะ ทุกคน! ]

คาจูเดินออกมาจากห้องครัวพร้อมถือชีสเค้กทั้งก้อน

ขณะที่ได้ยินเสียงเชียร์ของยานามิ ผมก้มมองโทรศัพท์และเห็นข้อความจากโคนุกิเซ็นเซ

...ดูเหมือนว่าจะเกี่ยวกับการพักกิจกรรม เซ็นเซได้ช่วยงานเบื้องหลังมากมายเพื่อพวกเรา

จากสถานการณ์ที่เกิดขึ้น มันคงไม่แปลกถ้าชมรมถูกยุบไปเลย แต่ดูเหมือนเราจะโชคดีที่มีคนในงานแต่งจากทั้งสองโรงเรียนที่รู้จักโคนุกิเซ็นเซ

ผมไม่ได้ถามรายละเอียดเพิ่มเติม เพราะกลัวรู้ความจริง

[ ต้องขอบคุณเซ็นเซดีๆทีหลังสินะ… ]

อย่างไรก็ตาม ข้อความจากเซ็นเซมีข้อเสนอเกี่ยวกับการเยี่ยมบ้านอยู่

ก็สมเหตุสมผลดี ในฐานะอาจารย์ที่ปรึกษา เซ็นเซคงเป็นห่วงว่าเราจัดการกับการพักกิจกรรมยังไง

เอาล่ะ ผมจะปฏิเสธการเยี่ยมบ้านอย่างสุภาพ แล้วไปกินชีสเค้ก

ขณะที่กำลังพิมพ์ข้อความตอบกลับ การแจ้งเตือนอีเมลใหม่ก็เด้งขึ้นมาบนหน้าจอ

...หือ? จากชิราทามะซังเหรอ

อีเมลนั้นแนบไฟล์มาด้วย ดูจากหัวเรื่องแล้วน่าจะเป็นนิยาย

[ นุคุมิซึคุง รีบมาเร็ว ไม่งั้นเค้กหมดนะ! ]

[ แป๊บนึง เดี๋ยวไป พวกเธอกินกันก่อนได้เลย ]

ผมตอบยานามิแล้วคลิกเปิดไฟล์ของชิราทามะซัง

◇◇◇

รายงานชมรมวรรณกรรม

< มือปราบแห่งเรือนราตรี > โดย ชิราทามะ ริโกะ

จากหอคอยสุจิคาอิที่ตั้งอยู่ชานปราสาทเอโดะ หากมุ่งหน้าลงใต้ตามถนนยัตสึโคจิ สุดท้ายคุณจะพบกับตลาดปลาที่นิฮงบาชิ

ในห้องเล็ก ๆ ของเรือนแถวริมถนน ชายคนหนึ่งกำลังใช้แปรงเคลือบกาวที่ผสมระหว่างรากเฟิร์นกับน้ำยาดองลูกพลับลงบนซี่โครงร่มกระดาษ

เมื่อกาวถูกทาอย่างสม่ำเสมอ ชายคนนั้นกลั้นหายใจและค่อย ๆ แนบกระดาษที่ทาน้ำมันไว้กับโครงร่มอย่างระมัดระวัง

เขาจ้องมองกระดาษอย่างตั้งใจ ก่อนจะพยักหน้าด้วยความพอใจเล็กน้อย และเอื้อมมือไปหยิบแปรงอีกครั้ง

ทันใดนั้นเอง เสียงระฆังดังขึ้น ขณะที่ท้องฟ้าเริ่มมืดลง

เวลาหกโมงเย็น ระฆังของอิชิมาจิดังขึ้น

น้ำมันราคาแพงขึ้นมากในช่วงนี้ หากทำผิดพลาดในแสงสลัว ๆ คงแย่แน่ เขาจึงวางแปรงลง

[ ยุโนะสุเกะซัง เข้าไปแล้วนะคะ ]

ยังไม่ทันที่คำพูดจะจบ ประตูเลื่อนก็เปิดออกโดยเด็กสาวตัวเล็กคนหนึ่งที่มัดผมขึ้น

เธอดูมีอายุราว 15 หรือ 16 ปี ริมฝีปากที่ได้รูปของเธอมุ่ยเล็กน้อยขณะก้าวเข้ามาบนพื้นดินหน้าห้อง

[ มาได้จังหวะพอดีเลย โอรินจัง ฉันถังแตกแล้วล่ะ ]

สีหน้าของโอรินไม่เปลี่ยนแปลงเมื่อเธอก้าวขึ้นไปยังพื้นที่เสื่อทาทามิและนั่งลง

เธอเริ่มตรวจสอบร่มที่วางพิงกำแพงอยู่ทีละคัน เปิดดูทีละอัน

[ โอเค สามคันพอดี ]

เธอพูดพลางห่อร่มด้วยผ้าและวางเหรียญเงินหนึ่งเหรียญแทนที่

[ ไม่ขี้เหนียวไปหน่อยเหรอ? ฉันมีหนี้กองเต็มไปหมดเลยนะ ]

[ คุณเบิกเงินล่วงหน้าไป ฉันหักยอดนั้นออกไปแล้วค่ะ ]

คำตอบของโอรินเย็นชา แต่เมื่อเห็นสีหน้าของยุโนะสุเกะ เธอก็คล้ายจะอ่อนลงเล็กน้อย

เธอหยิบเหรียญอีกเหรียญหนึ่งจากถุงผ้าไหมออกมาวางบนเสื่อทาทามิเงียบ ๆ

[ แค่ครั้งนี้เท่านั้นนะ ]

[ ขอบใจมาก ในที่สุดฉันก็จะได้ซื้อข้าวสักที ]

ยุโนะสุเกะพูดพลางเก็บเงินใส่แขนเสื้อก่อนจะมองหน้าโอรินด้วยความเป็นห่วง

[ มีอะไรหรือเปล่า โอรินจัง? ]

[ คุณสัญญาว่าจะสอนคณิตศาสตร์ให้ จำไม่ได้แล้วเหรอคะ? ]

โอรินพูดด้วยน้ำเสียงน้อยใจ ยุโนะสุเกะเกาแก้มอย่างขวยเขิน

[ …ฉันคิดว่าคงไม่ควรไปที่ชิราทายะอีก ]

[ ทำไมล่ะ? ถ้าเป็นเรื่องของพี่สาวล่ะก็— ]

โอรินเริ่มพูดแต่ก็กลั้นคำพูดไว้ก่อนจะก้มหน้าลง

...ยุโนะสุเกะเคยเกือบได้เป็นลูกเขยของชิราทายะ

ชิราทายะคือร้านขายร่มและรองเท้าไม้ที่เทะรุเทะรุ และสำหรับยุโนะสุเกะ บุตรชายคนที่สี่ของตระกูลซามูไรซันชูที่ยากจนและไร้มรดก มันคือโอกาสที่ดีเกินกว่าจะปฏิเสธได้

โอรินไม่เคยสงสัยว่ายุโนะสุเกะจะกลายเป็นพี่เขยของเธอเลย จนกระทั่งมิโนะ พี่สาวของเธอเสียชีวิต

[ ไม่มีที่สำหรับคนอย่างฉันในร้านใหญ่ ๆ อย่างชิราทายะ ข้อตกลงก่อนหน้านี้มันดีเกินกว่าที่จะเป็นจริงได้ ]

[ ร้านใหญ่เป็นแค่ชื่อเท่านั้นแหละ เราก็แค่ประคองตัวเองด้วยการขายร่มให้กับร้านใหญ่จริง ๆ เพื่ออยู่รอด ]

โอรินพูดด้วยน้ำเสียงที่ดูเป็นผู้ใหญ่มากขึ้น ขณะกอดร่มที่ห่อไว้แน่นกับอก

[ …มีข่าวเรื่องการแต่งงานของฉันกับคนที่สามของบ้านซาคากิยะ ]

ยุโนะสุเกะถึงกับกลั้นหายใจ เขาอายุมากกว่าโอรินถึงสิบห้าปี และยังมองเธอเป็นเพียงเด็กน้อย

แต่ตอนนี้เธอกำลังจะถึงวัยแต่งงานแล้ว—

[ งั้นเหรอ ขอให้ไปได้ด้วยดีนะ ]

ซาคากิยะคือร้านขายกิโมโนชื่อดังในนิฮงบาชิ

พักหลังนี้พวกเขาทำกำไรได้ดีจากการเป็นร้านคู่ค้าของโชกุน ทำให้เป็นคู่ครองที่เหมาะสมในทุกแง่มุม

เมื่อได้ยินคำตอบที่ไม่ใส่ใจของยุโนะสุเกะ โอรินก็ลุกขึ้นยืนอย่างเงียบ ๆ

[ …วัสดุชุดต่อไปจะส่งมาพรุ่งนี้ อย่าช้าล่ะ ]

เธอออกจากห้องไป โดยไม่พูดอะไรอีก ทิ้งยุโนะสุเกะให้นั่งจ้องประตูโชจิที่แง้มไว้อยู่เพียงลำพัง

ในใจของเขา มิโนะยังคงเหมือนเดิมไม่มีเปลี่ยนแปลงจากเมื่อสามปีก่อน

และสำหรับยุโนะสุเกะ เวลาก็หยุดลงที่จุดนั้นเช่นกัน

[ โอรินจังจะแต่งงานเหรอ? ]

ชายหนุ่มคนหนึ่งก้าวเข้ามาในห้องพลางพูด

เขาวางตู้ยาสูบใบเล็กที่แบกไว้บนหลังลง และดึงคิเซรุจากกระเป๋าเสื้ออกมา

[ นุคุสุเกะ นายแอบฟังอยู่เหรอ? นายนี่นิสัยเสียจริง ๆ ]

[ จะไม่ให้ได้ยินได้ยังไงล่ะ ในเรือนแถวห่วย ๆ แบบนี้ ]

พ่อค้าขายยาสูบนามว่านุคุสุเกะจุดยาสูบและพ่นควันออกมาอย่างพอใจ

[ คนที่สามของซาคากิยะน่ะชื่อเสียงไม่ค่อยดีเลยนะ เป็นพวกเจ้าปัญหามานานแล้ว ]

[ เหรอ? ]

ยุโนะสุเกะตอบแบบไม่ใส่ใจขณะเริ่มเก็บเครื่องมือทำร่มของเขา

[ ครอบครัวพยายามปรับนิสัยเขาโดยส่งไปเรียนฟันดาบ แต่ดันกลายเป็นว่าเขาไปคบหากับพวกที่แย่กว่าเดิมอีก เจ้านายร้านชิราทายะนี่เลือกคนได้แย่จริง ๆ ]

มือของยุโนะสุเกะหยุดเคลื่อนไหวทันที นุคุสุเกะยักไหล่และยื่นมือออกมา

[ ถ้าช่วยเพื่อนเก่า ฉันลดราคาให้นะ ถ้าอยากให้ฉันสืบเรื่องนี้ ]

[ จะเก็บเงินจากคนจนเหรอ? ]
