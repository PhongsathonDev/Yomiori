เล่ม 6 บทที่ 1-1

ห้องชมรมวรรณกรรมของโรงเรียนซึวะบุกิตั้งอยู่ที่ขอบอาคารฝั่งตะวันตก

ผมกับยานามิเดินไปตามทางเดินที่มุ่งหน้าไปยังห้องชมรม พร้อมกับถือถุงช็อปปิ้งกันมาด้วย

[ มาเช็คกันอีกที วันนี้เราจะไม่พูดถึงเรื่องสอบเลย พูดแต่เรื่องสนุกๆแค่นั้นพอ ]

[ ไม่ต้องห่วง เชื่อมือคลังเรื่องสนุก ๆ ของฉันได้เลย ]

โอเค ผมฝากเธอไว้แล้วกัน ไม่ใช่ว่าผมไว้ใจเธอหรอกนะ

เมื่อมาถึงห้องชมรม พวกเราก็สูดหายใจลึก ๆ ก่อนจะเปิดประตูเข้าไป

[ พวกเรากลับมาแล้วนะ... ]

ในห้องมีแค่โคมาริคนเดียว กำลังยืนอยู่บนเก้าอี้ ติดตั้งของตกแต่งอยู่

[ พ-พวกเธอมาช้านะ ช่วยเตรียมของให้เสร็จทีสิ ]

[ แล้ว รุ่นพี่สึกิโนะคิยังไม่มาเหรอ? ]

โคมาริส่งของตกแต่งยาว ๆ ให้ผมหลังจากลงจากเก้าอี้อย่างไม่มั่นคง

มันทำมาจากกระดาษพับแบบบาง ๆ เชื่อมต่อกันเป็นวงกลมและต่อเข้าด้วยกัน

ยานามิเข้ามาดูจากด้านข้าง

[ เหมือนของตกแต่งวันเกิดเลยนะเนี่ย ]

[ ช-ใช่ มันช่วยสร้างบรรยากาศให้ดีขึ้น ]

โคมาริตอบพร้อมรอยยิ้มแบบขี้อาย แต่ผมส่ายหัว

[ โคมาริ จะปลอบใจรุ่นพี่สึกิโนะคิมันก็ดีอยู่หรอก แต่แบบนี้มันดูมากไปนิดนะ ]

[ ใช่ ควรจะใช้กระดาษสีขาวดำแทนซะมากกว่า ]

ผมก็ไม่คิดว่ามันเป็นความคิดที่ดีหรอกนะ

[ อ-เอ๊ะ? ต-แต่ว่ารุ่นพี่จะ... ]

แล้วก็มีเสียงฝีเท้าที่สดใสดังมาจากทางเดิน

โดยสัญชาตญาณ พวกเราหันไปมองที่ประตู และเสียงฝีเท้าก็หยุดลงตรงหน้าห้องชมรมของเรา

หลังจากหยุดนิ่งครู่หนึ่ง ประตูก็เปิดออกอย่างมีชีวิตชีวา

[ ไม่ได้เจอกันนานเลยนะ! ทุกคนเป็นยังไงกันบ้าง? ]

คนที่ปรากฏตัวมาพร้อมรอยยิ้มเจิดจ้าคืออดีตรองประธานชมรมวรรณกรรม สึกิโนะคิ โคโตะ ผมทวินเทลคู่ของเธอดูบางลงเล็กน้อยเมื่อเทียบกับครั้งล่าสุดที่เจอ และดวงตาสองชั้นของเธอที่มีขนตายาวดูเป็นผู้ใหญ่มากขึ้นเมื่อไม่มีแว่น

[ เปลี่ยนไปใช้คอนแทคเลนส์แล้วเหรอครับ? ]

[ อ้าว สังเกตเห็นด้วยเหรอ? ]

รุ่นพี่สึกิโนะคิยิ้มเจ้าเล่ห์

เป็นการเปลี่ยนแปลงครั้งใหญ่ก่อนจบการศึกษาที่กล้าหาญดีนะ

รุ่นพี่สึกิโนะคิก้าวไปข้างหน้าอย่างสง่างาม—แล้วก็ชนกับโต๊ะเข้าอย่างจัง

[ ...เจ็บจัง ดูเหมือนถ้าไม่มีแว่นฉันจะมองไม่ค่อยเห็นน่ะ ]

รุ่นพี่สึกิโนะคิหาที่นั่งและนั่งลง ก่อนจะหยิบแว่นตาออกมาจากกระเป๋าและใส่มันกลับเข้าไป ทำไมเธอถึงทำท่าเหมือนไม่ต้องใช้แว่นก็ไม่รู้

[ ขอบคุณพวกเธอที่ไปซื้อของมาให้ แล้วมันราคาเท่าไหร่ล่ะ? ]

ยานามิรีบยื่นไทยากิให้เธอในขณะที่รุ่นพี่สึกิโนะคิค้นหากระเป๋าของเธอ

[ รุ่นพี่สึกิโนะคิ! ชีวิตมีขึ้นมีลงนะคะ แต่ได้โปรดเข้มแข็งไว้ด้วยค่ะ! ]

[ หืม? ไม่แน่ใจว่าหมายถึงอะไรนะ แต่ก็ขอบใจนะ เดี๋ยวนะ มีใครกัดไทยากินี่แล้วหรือยัง? ]

ผมยื่นแก้วน้ำโคล่าให้รุ่นพี่ตามที่ยานามิเริ่มไว้

[ มันก็ไม่ใช่เรื่องใหญ่เลยนะ ก็แค่ปีเดียวเอง เหมือนกลับมาจากการทำภารกิจแหละ เป็นการเพิ่มประสบการณ์ให้กับตัวเองด้วย ]

ยานามิพยักหน้าอย่างกระตือรือร้น

[ ใช่ๆ! พ่อของฉันเคยเกเรเมื่อตอนหนุ่ม ๆ แต่ตอนนี้เขาก็ไปได้ดีเลยล่ะ! เพราะงั้นรุ่นพี่ก็ต้องโอเคแน่ ๆ! ]

ขณะที่เคี้ยวไทยากิอยู่ รุ่นพี่สึกิโนะคิเอียงคอด้วยความสงสัย

...เดี๋ยวนะ นี่ไม่ใช่ปฏิกิริยาที่ผมคาดไว้ หรือว่าเราพูดอะไรแทงใจดำไป?

[ เข้าใจแล้ว ผมว่าโคมาริก็คงพูดอะไรที่ให้กำลังใจแต่ออกแนวขาดความรับผิดชอบสินะ ]

ผมหันไปหาโคมาริด้วยความสิ้นหวัง แต่เธอก็ส่ายหน้า

[ ร-รุ่นพี่...สอบติดมหาวิทยาลัยแล้วนะ... ]

[ [ เอ๊? ] ]

ผมกับยานามิมองรุ่นพี่สึกิโนะคิด้วยความงุนงง เธอยกแก้วขึ้นอย่างภาคภูมิใจ

[ ฉัน สึกิโนะคิ โคโตะ ในที่สุดก็สอบเข้ามหาวิทยาลัยได้แล้ว ! ]

ยานามิกระแอมเบา ๆ หลังจากเงียบไปสักครู่

[ ...ฉันเชื่อในตัวรุ่นพี่ตั้งแต่แรกเลยนะ ! ไม่เหมือนนุคุมิซึคุงหรอก ]

เธอเป็นคนเริ่มพูดว่ารุ่นพี่สอบไม่ติดนะรู้มั้ย?

แย่ล่ะ ถ้าปล่อยไว้แบบนี้ ผมจะกลายเป็นตัวร้ายคนเดียวแน่ ๆ

[ รุ่นพี่! มหาวิทยาลัยที่ติดนี่ที่ไหนเหรอ? ]

[ เอ๋ เดี๋ยว- สรุปที่ไหนนะ ? ]

ขณะที่ผมพยายามเปลี่ยนเรื่องสุดชีวิต รุ่นพี่สึกิโนะคิก็เอียงคอและเริ่มกดโทรศัพท์

...เดี๋ยวก่อน นี่เธอสอบติดจริงๆ ใช่มั้ย? บรรยากาศในห้องชมรมเริ่มเงียบสงัด

[ อ้อ เจอแล้ว ดูสิ ที่หน้าล็อกอินบอกว่า ‘สอบผ่าน’ ใช่มั้ย? ]

พวกเราสามคนโน้มตัวไปดูที่หน้าจอโทรศัพท์ของเธอที่เธอยื่นออกมา

[ ...อ้อ มันคือคณะบริหารธุรกิจที่เมไอน่ะ ]

[ เมไอ? อ่า ฉันจะเข้าไปเรียนที่นั่นตั้งแต่เดือนเมษานั้นแหละ]

[ อื้ม เรียนที่นี่เถอะ เพราะไม่น่าติดที่อื่นแล้ว ]

ด้วยการยืนยันผลการสอบ รุ่นพี่สึกิโนะคิก็เริ่มฉลองอย่างเต็มที่

วันนี้เป็นวันปล่อยตัวตามสบาย ยานามิเปิดถุงมันฝรั่งทอดไปทีละถุงโดยไม่มีใครว่าอะไร

[ นี่ ยานามิซัง กินมันฝรั่งรสซอสถั่วเหลืองหมดแล้วเหรอ? ]

[ ยังเหลืออีกถุงนึงอยู่—อ๊ะ เดี๋ยวนะ ฉันกินมันไปตอนกลับมาจากซุปเปอร์มาเก็ต ]

ตอนไหนเนี่ย? ผมยังไม่ได้กินสักชิ้นเลย

ยานามิวางมันฝรั่งสามรสซ้อนกันเพื่อจะกินทีเดียว แล้วถามรุ่นพี่สึกิโนะคิ

[ รุ่นพี่ จะย้ายออกไปอยู่หอพักตอนเดือนเมษาหรอคะ? ]

[ ก็มีแผนไว้อย่างนั้นนะ พรุ่งนี้ฉันนัดนายหน้าไว้แล้ว ]

รุ่นพี่สึกิโนะคิตอบด้วยรอยยิ้มเหงา ๆ

มหาวิทยาลัยเมไอที่นาโกย่าและเมืองโทโยฮาชิในจังหวัดไอจินั้นอยู่คนละฟากฝั่งกัน บางคนเดินทางไปเรียนแต่ผมมั่นใจว่าเธอคงจะโดดเรียนบ้างแน่ๆ มีแฟนอยู่ใกล้ๆ อาจจะช่วยได้หน่อย แต่-

[ ว่าแต่ รุ่นพี่ทามากิเตรียมสอบเป็นยังไงบ้าง ]

ทามากิ ชินทาโร่ อดีตประธานชมรมและเป็นแฟนของรุ่นพี่สึกิโนะคิ

เขาตั้งเป้าที่มหาวิทยาลัยของรัฐที่นาโกย่า โดยไม่ได้สมัครที่สำรองอื่น ๆ เลย

[ พรุ่งนี้จะเข้าสอบรอบที่สอง ตอนนี้เขากำลังทุ่มสุดตัวเลย ]

เธอตอบด้วยท่าทางสบาย ๆ พลางหยิบมันฝรั่งเข้าปาก

ถึงแม้จะพูดแบบนั้น แต่แววตาของเธอก็แฝงความกังวลอยู่เล็กน้อย

[ รุ่นพี่ท-ทามากิต้องทำได้แน่ ]

โคมาริพึมพำเหมือนกับพูดกับตัวเอง พร้อมทั้งกำถ้วยชาอู่หลงแน่น

[ ใช่แล้ว ประธานต้องทำได้แน่ ]

ยานามิเข้ามาขัดจังหวะแล้วลูบหัวโคมาริ ผมเป็นประธานคนปัจจุบันแล้วนะ

รุ่นพี่สึกิโนะคิหัวเราะแล้วเปิดถุงช็อคโกแลตถุงใหญ่

[ ดูเหมือนฉันจะทำให้ทุกคนกังวลนะ เอาล่ะ มากินขนมที่ซื้อมาให้หมดดีกว่า! ]

[ จ-จะกินหมดได้จริงๆ เหรอ- ]

โคมาริยังพูดไม่ทันจบก็หันไปมองยานามิที่เทมันฝรั่งทอดเข้าปากจนหมด

[ หืม? โคมาริจัง เธออยากลองกินแบบนี้บ้างมั้ย? เดี๋ยวฉันเปิดถุงใหม่ให้ ]

[ อุเอะ!? ม-ไม่เป็นไร- ]

[ มันฝรั่งทอดน่ะต้องกินพร้อมกับการกลืนน้ำลายถึงจะอร่อย นี่ เงยหน้าขึ้นแล้วอ้าปากซิ! ]

โคมาริที่ไม่สามารถปฏิเสธได้ต้องกลืนมันฝรั่งทอดเข้าไป ดูเหมือนกับการทรมานรูปแบบใหม่

รุ่นพี่สึกิโนะคิมองภาพนั้นด้วยสายตาอ่อนโยนพลางเคี้ยวมิตาราชิดังโงะ

ผมวางถ้วยชาลงตรงหน้าเธอ

[ ผมชงชาอุ่น ๆ ไว้แล้วนะครับ ไว้ตรงนี้ละกัน ]

[ อุ ใจดีจริง ๆ ]

[ วันนี้รุ่นพี่เป็นเจ้ามือที่สปอนเซอร์พวกเราไว้ ก็ให้พวกเราได้ดูแลบ้างสิครับ ]

รุ่นพี่สึกิโนะคิจิบชาร้อนพลางหันมามองผมข้าง ๆ

[ งานเลี้ยงต้อนรับนักเรียนใหม่เป็นยังไงบ้างล่ะ เตรียมอะไรไว้บ้างหรือยัง? ]

[ ยังไม่ได้เริ่มเลยครับ พอเห็นรุ่นพี่มาที่ห้องชมรมแบบนี้ มันเลยไม่รู้สึกเลยว่าจะขึ้นปีสองแล้ว ]

ผมตอบอย่างตรงไปตรงมารุ่นพี่สึกิโนะคิหัวเราะอย่างร่าเริง

[ ฉันเองก็ยังไม่รู้สึกเลยว่าจะเรียนจบแล้ว ]

เธอหมุนไม้เสียบดังโงะในมือเล่น

[ บางทีอาจจะเริ่มรู้สึกเอาตอนเช้าวันถัดจากพิธีจบการศึกษาตอนที่ฉันนึกขึ้นได้ว่าไม่ต้องมาเรียนที่โรงเรียนมัธยมอีกแล้ว นั่นแหละถึงจะรู้ว่าต้องย้ายไปที่ใหม่ ]

...อีกแค่สัปดาห์เดียวก็จะถึงวันจบการศึกษาแล้ว

สิ่งที่เคยคิดว่าอยู่อีกไกล ตอนนี้อยู่แค่เอื้อม

[ แต่อาจจะเข้ามาห้องชมรมเรื่อย ๆ จนถึงนาทีสุดท้ายก็ได้นะ เพราะยังมีเวลาว่างก่อนจะย้ายออกไปมหาวิทยาลัยน่ะ ]

[ นั่นก็ดีแล้วครับ ]

พวกเรานั่งเงียบกันอย่างสบายใจในขณะที่ยานามิและโคมาริก็ยังคงสร้างเสียงดังวุ่นวายอยู่

และขณะที่พวกเรากำลังซาบซึ้งกับช่วงเวลานี้-

[ ยินดีด้วยนะคะ รุ่นพี่! ]

ประตูเปิดออก และยากิชิโอะกระโดดเข้ามา

[ อ้าว ยากิชิโอะจัง เธอก็มาด้วยเหรอ ไม่เจอกันนานเลยนะ ]

[ ใช่ค่ะ ไม่ได้เจอกันนานเลย ฉันเป็นห่วงรุ่นพี่มากเพราะนุคคุงบอกว่ารุ่นพี่ต้องสอบไม่ติดแน่ ๆ ]

[ โฮะโฮ นุคุมิซึคุงพูดอย่างนั้นเหรอ? ]

ผมพูดแบบนั้นเหรอ? รู้สึกเหมือนเคยพูดไปนิด ๆ แฮะ

ผมรีบลุกขึ้นไปชงชาเพิ่ม

ขณะที่ผมรินน้ำร้อนลงในกาน้ำชา ยากิชิโอะก็มายืนข้าง ๆ พร้อมกับถือไทยากิอยู่ในมือ

[ ช่วยชงให้ฉันด้วยได้มั้ย? ]

[ ได้สิ แต่เราก็ซื้อชาอู่หลงกับโคล่ามาเหมือนกันนะ ]

[ อืม ไม่ค่อยอยากทำให้ร่างกายเย็นลงเท่าไหร่น่ะ ]

ยากิชิโอะดูลังเลมากกว่าปกติ นี่ถือว่าเป็นเรื่องหายาก

เธอก็ชำเลืองมองไปที่ยานามิและคนอื่น ๆ ด้วย

[ ผทชงให้เอง เธอนั่งลงเถอะ ]

[ …นี่ วันอาทิตย์นี้นายว่างมั้ย? ]
