เล่ม 6 บทที่ 2-5

คืนนั้นผมนั่งอยู่ในห้อง ขีดเขียนด้วยดินสอกดลงบนสมุดโน้ต

ปีการศึกษานี้เหลือเวลาแค่หนึ่งเดือน ก็ถึงเวลาที่ต้องเริ่มวางแผนกิจกรรมต้อนรับสมาชิกใหม่ของชมรมวรรณกรรมแล้ว

การทำโปสเตอร์และใบปลิว การจัดทำวารสารชมรม และสิ่งที่ยากที่สุดคือการแนะนำชมรมในงานปฐมนิเทศนักเรียนใหม่

แค่จินตนาการว่าโคมาริกับผมต้องขึ้นเวทีในโรงยิมเพื่อแนะนำชมรมก็เหมือนกับลางร้ายล่วงหน้าแล้ว

ถึงเราจะมียานามิที่ดูดีเป็นตัวดึงดูดสายตา แต่นักเรียนใหม่ที่สนใจ

ชมรมวรรณกรรมก็คงจะเป็นพวกเก็บตัวซะส่วนใหญ่ การเอาคนสวยโดดเด่นมาเป็นจุดเด่น อาจทำให้พวกเขารู้สึกกลัวจนไม่กล้าเข้ามา

[ …ก็ดูเป็นไอเดียที่ดี ]

ขณะที่ผมจดไอเดียนั้นลงในสมุดสายตาก็เหลือบไปเห็นพลาสเตอร์ที่พันอยู่รอบนิ้วชี้

โคมาริบอกให้ผมเปลี่ยนมัน แต่ผมก็ปล่อยไว้อย่างนั้นโดยไม่รู้ว่าทำไม

[ จะเปลี่ยนหลังอาบน้ำก็แล้วกัน แล้ว เธอเข้ามาในห้องตั้งแต่เมื่อไหร่? ]

[ คาจูอยู่มาสักพักแล้วค่ะ ….แต่ว่า การถักนี่มันยากจังเลยนะคะ ]

สิ่งที่เหมือนกระเป๋าใบเล็กๆ ห้อยอยู่ตรงปลายไหมพรม สงสัยว่าเธอกำลังทำอะไรอยู่

[ ถึงจะเริ่มถักตอนนี้ แต่คงเสร็จตอนหน้าร้อนแล้วมั้ง? ]

[ โบราณเขาว่าไว้ว่ากว่าจะตั้งท้องก็ต้องรอจนครบ 10 เดือนใช่มั้ยคะ? คาจูเลยคิดว่าควรเริ่มเตรียมตัวทีละนิด ]

[ คาจู… อย่าบอกนะว่า!? ]

ผมลุกขึ้นเร็วเสียจนเก้าอี้ล้ม แต่คาจูก็แค่ยิ้มแหย่เล่นกับความตกใจของผม

[ ไม่ใช่แบบนั้นสักหน่อยค่ะ ท่านพี่ไม่ทันคิดเลยใช่มั้ยคะ ? คาจูเตรียมไว้ให้ท่านพี่ต่างหาก ไม่ใช่อขงหนูหรอก ]

อ๋อ… เป็นของผมสินะ ผมถอนหายใจอย่างโล่งอกก่อนจะยกเก้าอี้กลับตั้งเหมือนเดิม

[ แล้วมันเกี่ยวอะไรกับพี่เหรอ? ]

มือของคาจูหยุดถักขณะที่เธอหันมามองผมด้วยสายตาจริงจัง

[ ท่านพี่ไม่ต้องปิดบังหรอกค่ะ คาจูเห็นชัดๆ ว่าท่านพี่สร้างความสัมพันธ์แน่นแฟ้นกับยากิชิโอะซังแล้วใช่มั้ยคะ? ]

[ ไม่เลย มันไม่ใช่แบบนั้นสักนิด ]

[ คาจูเห็นเต็มสองตานะคะ ท่ามกลางสายลมทะเล พวกพี่จับมือกันแล้วก็กอดกัน ฉากนั้นมันเหมือนภาพวาดทางศาสนาเลยค่ะ น้ำตาคาจูไหลออกมาโดยไม่รู้ตัวเลย ]

เดี๋ยวนะ คาจูอยู่ที่นั่นด้วยเหรอ? พอเข้าใจแล้วว่าทำไมเธอถึงเข้าใจผิด เพราะเธอไม่รู้สถานการณ์

[ เปล่า นั่นแค่ถูกช่วยตอนเกือบล้ม…]

[ แล้วการช่วยใครสักคนต้องจับมือเหมือนคนรักด้วยเหรอคะ? ]

[ ถุงเท้าค่ะ ตอนนี้ใกล้จะเสร็จแล้วหนึ่งข้าง ]

ความคิดที่ไปไกลลิ่วของคาจูไม่ใช่เรื่องใหม่ แต่ครั้งนี้ดูจะเข้าใจผิดไปไกลมาก

[ นี่เธอฟังที่พี่พูดบ้างมั้ย ? อย่างที่พี่บอกเมื่อกี้ ยากิชิโอะกับพี่ไม่ได้มีความสัมพันธ์แบบนั้น- ]

[ เรียกหม่าม๊าคาจูเป็นไงคะ! ถ้าลูกของท่านพี่เรียกคาจูแบบนั้น แล้วถ้าบอกว่าคาจูคือหม่าม๊ามันจะไม่เกินจริงเลยค่ะ ! ]

มันเกินจริงไปเยอะแล้วหนู

[ และถ้าไปไกลกว่านั้น ก็เหมือนกับว่าท่านพี่กับคาจูแต่งงานกันแล้ว! ]

[ ไม่เลยค่ะ ]

ผมถอนหายใจเงียบๆ ขณะที่สัมผัสถึงความอบอุ่นจากแผ่นหลังของเธอ

[ พึ่งเปลี่ยนมาใช้สมาร์ทโฟนน่ะ อยู่ในสภานักเรียนแล้วไม่มีมันลำบากชะมัด ]
