เล่ม 8 บทที่ 1-1

ช่วงนี้พระอาทิตย์ตกช้าลงมาก

แสงแดดยามเย็นที่ส่องเข้ามาในห้องชมรม ลูบไล้อย่างแผ่วเบาไปยังใบหน้าของ เทียร่าซังที่กำลังนั่งอยู่บนเก้าอี้ ท่ามกลางสาว ๆ ชมรมวรรณกรรม

[ เชิญค่ะ รุ่นพี่ บาโซริ น้ำชาค่ะ ]

[ อ๊ะ ขอบใจนะ ]

คนที่ยื่นถ้วยชาที่มีไอน้ำลอยขึ้นมาให้ด้วยรอยยิ้มสดใสคือ ชิราทามะ ริโกะ นักเรียนปีหนึ่ง

เธอยิ้มแย้มอย่างไม่มีที่ติ แล้วยืนเงียบ ๆ อยู่ด้านหลังของเทียร่า ราวกับคอยเฝ้าดูเธออยู่

ขณะที่เทียร่าดูไม่ค่อยสงบใจนัก ยานามิ ก็ยื่นกล่องคุกกี้ให้

[ บาโซริจัง อยากกินมั้ย? ]

[ อะ…ค่ะ ขอบคุณค่ะ ]

พอรับคุกกี้มาด้วยความโล่งใจ สีหน้าของเทียร่าก็ค่อย ๆ เปลี่ยนเป็นความสับสน

[ เอ่อ…ถ้าจ้องกันขนาดนี้ ฉันรู้สึกไม่สบายใจเลยค่ะ… ]

จะให้เทียร่ารู้สึกไม่สับสนก็คงยาก

เพราะ ยานามิ โน้มตัวเข้ามามองมือของเทียร่าแบบไม่ละสายตา

ผมถอนหายใจเบา ๆ พลางเคาะเก้าอี้

[ ยานามิซัง กลับไปนั่งที่ดี ๆ เถอะ ]

[ นุคุมิซึคุง นายกำลังคิดว่าฉันให้ขนมคนอื่นแล้วเสียดายใช่มั้ย? ]

ใช่ คิดอยู่

ยานามิยักไหล่เบา ๆแล้วนั่งลงบนเก้าอี้ดัง ตึง

[ ฟังให้ดีนะ นุคุมิซึคุง คุกกี้นี้หนึ่งชิ้นมี 70 กิโลแคลอรี่ ]

[ อืม? ]

[ ถ้าฉันไม่กินแล้วให้บาโซริจังกินแทน—นายเข้าใจความหมายมั้ย? ตอบเลย โคมาริจัง! ]

[ เอ๊ะ?! ฉะ...ฉันเหรอ? ]

โคมาริ ที่นั่งมุมห้องกำลังจ้องมือถือ รีบเงยหน้าขึ้นอย่างตกใจ

[ เอ่อ…แบบว่า ยานามิจะอ้วน น้อยลงนิดนึง? ]

[ ...ไม่ใช่จ้ะ ต่อไป นุคุมิซึคุง ]

อ้อ แบบเวียนตอบสินะ

[ ขอคำใบ้หน่อยได้มั้ย ]

[ ก็ได้ ๆ ถ้าฉันไม่กินคุกกี้แต่อยากกิน แล้วให้คนอื่นกินแทน ฉันจะได้รับแคลอรี่เท่าไหร่? ]

ก็ไม่ได้กิน…ก็ต้อง…

[ 0 แคล? ]

[ ผิดแล้ว แคลอรี่ที่ฉันควรจะได้รับมันย้ายไปอยู่กับบาโซริจังแล้ว—สรุปคือ ฉันติดลบไป 70 แคลยังไงล่ะ! ]

[ ไม่มีทางเป็นแบบนั้นหรอก… ]

ถึงผมจะคัดค้านอย่างเต็มที่ ยานามิก็ยังคงอธิบายทฤษฎีประหลาดของเธอต่อไปอย่างมั่นใจ

[ ถ้าบาโซริจังกินคุกกี้ 110 ชิ้น น้ำหนักฉันก็จะลดลง 1 กิโลพอดีเลยไง เชิญเลยๆ ]

[ หนึ่งชิ้นก็พอ─อะ ค่ะ ขอบคุณค่ะ ]

เธอรับคุกกี้ชิ้นที่สองมาอย่างเลี่ยงไม่ได้ เทียร่าก็หันมาทางผม

[ เอ่อ คือ…ทำไมฉันถึงมานั่งกินคุกกี้อยู่ในห้องชมรมวรรณกรรมแบบนี้เหรอคะ? ]

[ เพราะห้องสมุดปิดแล้ว แล้วครูบรรณารักษ์ก็จะมา เลยคิดว่ามาคุยตรงนี้น่าจะไม่มีใครเห็น ]

[ แต่ที่นี่ดูมีคนเยอะกว่าชัด ๆ เลยไม่ใช่เหรอคะ? ]

อืม…ก็จริง

แต่ยังไงก็เถอะ พวกยานามิพวกนี้ก็เหมือนวิญญาณประจำห้องชมรมไปแล้ว คิดมากก็ไร้ประโยชน์

[ ถึงจะมีคนเยอะ แต่เรื่องที่เราคุยกันจะมีแค่พวกในชมรมได้ยิน—ประมาณนั้นแหละ สบายใจได้ ]

[ ฉันจะสบายใจได้ยังไงกันคะ…? ]

[ เชิญค่ะ รุ่นพี่ น้ำชาอีกถ้วยค่ะ ]

[ เอ๊ะ? ]

กริ๊ก เสียงถ้วยชาวางลงเบา ๆ ชิราทามะวางถ้วยที่สองลงตรงหน้าของเทียร่า

เทียร่ามองถ้วยน้ำชาทั้งสองใบก่อนจะเอ่ยขึ้น

[ ชิราทามะซังใช่มั้ยคะ เมื่อกี้ก็... ]

[ เชิญค่ะ ดื่มก่อนจะเย็นนะคะ ]

[ อ่ะ ค่ะ… ]

ซู๊ด… เสียงเทียร่าซดชาเบา ๆ

แล้วก็มี ยานามิ จ้องคุกกี้ของเทียร่าไม่วางตา ใช่เลย นี่แหละบรรยากาศประจำชมรมวรรณกรรม

[ ว่าแต่บาโซริจัง มีเรื่องอยากคุยกับผมไม่ใช่เหรอ? ]

[ จะคุยในสถานการณ์แบบนี้เลยเหรอคะ? ]

แน่นอน ต้องคุยตอนนี้แหละ

เทียร่าตัดสินใจเด็ดขาด อัดคุกกี้เข้าปาก แล้ววางกระดาษแผ่นหนึ่งลงบนโต๊ะ

[ จะเล่าให้หมดคงนาน เอาเป็นว่า…ฉันอยากขอยืมชื่อของนุคุมิซึซัง ]

[ ให้เขียนชื่อลงตรงนี้ใช่มั้ย? ]

ผมหยิบปากกาขึ้นมา แต่...

[ ประธานคะ!! ]

ชิราทามะรีบร้องห้ามอย่างตกใจ

[ มีอะไรผิดปกติเหรอ? ]

[ ค่ะ ห้ามเซ็นชื่อโดยไม่อ่านเอกสารก่อนเด็ดขาดนะคะ ]

[ มีสตินิดนึงเถอะ นุคุมิซึคุง นายรู้มั้ยว่าเมื่อก่อนพ่อฉันเคยประทับตราไปโดยไม่ดู แล้วเกิดเรื่องใหญ่ขนาดไหน ]

ยานามิหยิบกระดาษขึ้นมาดู แล้วกะพริบตาปริบ ๆ ด้วยความสงสัย

[ เอกสารใบสมัครรับเลือกตั้งสภานักเรียนเหรอ…แล้วเกี่ยวอะไรกับนุคุมิซึคุงล่ะ? ]

[ ฉันคิดว่าทุกคนคงทราบอยู่แล้วว่าหลังจบกีฬาสีเดือนหน้า วาระของสภานักเรียนจะสิ้นสุดลง ]

แน่นอน ผมไม่รู้เลยสักนิด

เทียร่านั่งหลังตรง แล้วมองผมอย่างจริงจัง

[ ฉันจะลงสมัครเป็นประธานสภานักเรียนคนถัดไป…เลยอยากให้นุคุมิซึซังเป็น ผู้สนับสนุนให้ค่ะ ]

[ ผู้สนับสนุนเหรอ? ผมน่ะนะ? ]

แม้ผมจะย้อนถามแบบงง ๆ เทียร่าก็พยักหน้าอย่างจริงจัง

[ ค่ะ…ถ้าเป็นไปได้ ก็อยากขอให้ช่วยพูด สุนทรพจน์สนับสนุน ด้วย ]

…สุนทรพจน์สนับสนุน—ก็คือสิ่งที่ต้องพูดหน้าทุกคนในโรงยิมวันลงคะแนนนั่นแหละ

พูดต่อหน้าทั้งโรงเรียนเหรอ ผมเนี่ยนะ…อ่าาาา…

[ …ไม่ไหวครับ ]

ผมคว้าใบสมัครลงสมัครเลือกตั้งจากมือยานามิ แล้ววางไว้ตรงหน้าของเทียร่า

[ ขอโทษนะ แต่ช่วยไปหาคนอื่นเถอะ ]

[ นุคุมิซึซัง ช่วยฟังฉันหน่อยได้มั้ยคะ?]

เทียร่าพยายามจะยื้อไว้ แต่เรื่องนี้ผมยอมไม่ได้จริง ๆ

[ เอาน่า นุคุมิซึคุง ลองฟังดูก่อนก็ได้ ]

ยานามิพูดพลางยื่นคุกกี้ชิ้นที่สามให้

เทียร่ารับไว้ด้วยความลังเล ยานามิจึงยิ้มให้อย่างอ่อนโยน

[ ถ้าอย่างนั้น ถ้าเกิดว่า บาโซริซังชนะการเลือกตั้ง นายก็จะเข้าร่วมสภานักเรียนด้วยเหรอ? ]

[ ค่ะ เพราะตำแหน่งเจ้าหน้าที่จะได้รับการแต่งตั้งโดยประธาน ถ้าเป็นไปได้ก็อยากให้นุคุมิซึซังรับตำแหน่งรองประธานน่ะค่ะ ]

[ ทำไมต้องเป็นนุคุมิซึคุงล่ะ? ยังมีคนที่ดีกว่านี้ตั้งเยอะนะ ]

ยานามิก็ยังปากเสียตามเคย

เทียร่ากลับพยักหน้ารับด้วยท่าทีจริงจัง ทั้งที่ก่อนหน้านี้ดูเหมือนจะมาขอร้องผมแท้ ๆ

[ ตอนนี้ประธานกับรองประธานของสภานักเรียนเป็นผู้หญิงทั้งคู่ คุณครูเลยอยากให้รอบหน้ามีผู้ชายสักคน ก็ เลย.. . ]

[ แล้วทำไมไม่เลือกซากุไรคุงล่ะ? ]

ยานามิ เธอควรหยุดพูดได้แล้วนะ

[ ดูเหมือนว่าซากุไรคุงไม่อยากทำงานในสภานักเรียนต่อ และฉันก็ไม่สนิทกับผู้ชายคนอื่นเลย…]

เทียร่าหลบสายตาด้วยท่าทางอึดอัด

เข้าใจล่ะ ถ้าจะตัดใจจากเรื่องนี้ล่ะก็ผมชำนาญดี

ผมเรียกสติแล้วแทรกเข้าไปในบทสนทนา

[ ต้องถึงขนาดเน้นว่าเป็นผู้ชายเลยเหรอ? ตอนนี้ก็มีแต่ผู้หญิงแต่ก็ไม่มีปัญหานี่ ถ้าอธิบายดี ๆ ครูก็น่าจะเข้าใจนะ ]

[ เพราะว่าสภานักเรียนเป็นตัวแทนของนักเรียน เราเลยอยากให้เปิดรับฟังความคิดเห็นจากทุกกลุ่มให้มากที่สุด ถ้ามีแต่เพศเดียวกัน นักเรียนอาจไม่กล้าปรึกษาน่ะค่ะ ]

ก็จริง ปัจจุบันซากุไรคุงเป็นผู้ชายคนเดียวในสภานักเรียน แถมยังเป็นคนดีด้วย ผู้ชายจำเป็นจริง ๆ

[ ตอนฉันจะเป็นรองประธาน ก็มีปัญหาเหมือนกันค่ะ ตอนทำงานก็ต้องได้รับความเข้าใจจากทั้งครูและคนรอบข้าง ในฐานะตัวแทนนักเรียนชายของโรงเรียนทสึวะบุกิ ช่วยฉันหน่อยได้มั้ยคะ?]

เข้าใจเหตุผลแล้ว แต่การที่ผมจะเป็นตัวแทนของนักเรียนชายนี่มัน…

ขณะผมกำลังคิดหาทางปฏิเสธ ยานามิก็พูดขึ้น

[ ฉันเข้าใจที่บาโซริซังพูดนะ แต่ยังไงนุคุมิซึคุงก็เป็นประธานชมรมวรรณกรรม พวกเราก็ลำบากเหมือนกัน ]

นี่เป็นครั้งแรกที่ยานามิพูดอะไรดูมีเหตุผล แถมยังเข้าข้างผมด้วย ต้องตามน้ำไปแล้วล่ะ

[ ใช่ ๆ เพราะผมมีหน้าที่ในชมรม ยังไงก็ยากล่ะนะ ]

[ ถ้าจะให้นุคุมิซึเข้าร่วมสภานักเรียน ก็ต้องมีผลประโยชน์ให้ชมรมวรรณกรรมด้วยสิ ]

ยานามิยิ้มเจ้าเล่ห์

แย่ล่ะ ผมตามน้ำผิดจังหวะแล้ว

[ ผลประโยชน์เหรอคะ ? ]

เทียร่าที่ได้ยินคำพูดไม่คาดคิดถึงกับเบิกตากว้าง

ยานามิเอนตัวเข้าไปหาเธอ

[ ใช่ ผลประโยชน์ ก็อย่างเช่น พอเข้าร่วมสภานักเรียนแล้วจะสามารถใช้จ่ายงบประมาณตามใจ หรือมีสิทธิพิเศษกินฟรีที่โรงอาหาร อะไรแบบนั้น ]

[ อืม… สิทธิพิเศษอะไรแบบนั้นก็… เรื่องงบประมาณชมรมก็ใช่ค่ะ ทางสภานักเรียนเป็นคนร่างขึ้นมาก็จริง แต่ก็ต้องได้รับการอนุมัติจากคุณครู──]

[ ร่างงบชมรมได้เหรอ?! งั้นนุคุมิซึ นายต้องเข้าร่วมแล้วล่ะ! ]

นี่ขายเพื่อนเร็วเกินไปมั้ย?

[ ไม่ไหวหรอก ยานามิซังก็คิดแบบนั้นใช่มั้ย? ]

[ แต่ว่านะ… ถ้ามีตู้เย็นกับไมโครเวฟในห้องชมรม ก็น่าจะดีนะ หรือถ้ามีโต๊ะแต่งหน้าด้วยก็แจ๋วเลย ]

ไม่เกี่ยวอะไรกับชมรมเลยสักนิด

ขณะนั้น ชิราทามะที่อยู่ข้างหลังเทียร่าซังก็พนมมือขึ้นพร้อมแววตาเป็นประกาย

[ โต๊ะแต่งหน้า… ดีเลยค่ะ! รุ่นพี่โคมาริก็อยากได้ใช่มั้ยคะ? ]

[ เอ๊ะ… โต๊ะ…? ]

โคมาริที่โดนถามกะทันหันสะดุ้งจากมุมห้องชมรม

[ เขาหมายถึงโต๊ะแต่งหน้าน่ะ ใช้เงินชมรมซื้อไม่ได้หรอก ]

[ เรื่องนั้นก็จริงค่ะ… แต่ถ้าเป็นตู้เย็นล่ะก็ อาจจะเอาของที่อยู่ในห้องสภานักเรียนมาให้ได้นะคะ ]

[ งั้นก็ตกลงตามนั้นล่ะนะ นุคุมิซึ ฝากด้วยนะ! ]

[ ยังไม่ตกลงสักหน่อย ผมไม่คิดจะเข้าหรอกนะ ]

ผมปฏิเสธชัดเจน ยานามิก็ส่งสายตาท้าทายกลับมา

[ งั้นก็โหวตกันเลยมั้ย ? ชิราทามะจังล่ะว่าไง? ]

ชิราทามะเอานิ้วชี้ทั้งสองแตะที่ขมับ แล้วยิ้มหวานพลางเอียงคอน่ารัก

[ ก็… ประธานชมรมเป็นรองประธานสภานักเรียนด้วย ก็ดูเท่ดีนะคะ]

[ อ๋อ… ได้อวดด้วยเหรอ… แต่ก็…]

[ เสียงของสมาชิกชมรมสำคัญนะ เราต้องฟังความเห็นของโคมาริด้วย ]

[ ปะ...ไปตายซะ]

ยานามิพยักหน้า

[ อืม สองต่อหนึ่ง ฝ่ายเห็นด้วยมากกว่าแล้วล่ะ ]

[ ผมไม่มีสิทธิ์โหวตเหรอ? ]

[ แน่นอนสิ ก็เป็นเรื่องที่เกี่ยวข้องกับตัวเองนี่นา งั้นบาโซริซัง เรื่องนี้ก็ตกลงแล้วนะ ]

เทียร่าที่เงียบฟังอยู่ตลอด ก็เหมือนจะได้สติกลับมา เธอตั้งท่าขึ้นตรง

[ อะ ค่ะ! ถ้าอย่างนั้นช่วยเซ็นชื่อตรงนี้ด้วยค่ะ นุคุมิซึซัง── ]

[ เอ๊ะ… อะไรเหรอคะ? ]

[ ฉันขอใช้สิทธิ์งดออกเสียงค่ะ งั้นผลโหวตก็เป็นหนึ่งต่อหนึ่งนะคะ ]
