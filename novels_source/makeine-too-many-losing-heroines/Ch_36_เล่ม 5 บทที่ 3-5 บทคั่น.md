บทคั่น: ระหว่างมิตรภาพและยามราตรี

ชมรมปลูกต้นไม้ โรงเรียนมัธยมต้นโมโมโซโนะ

พระอาทิตย์กำลังลาลับขอบฟ้า เรือนกระจกหลังเล็กสว่างไสวด้วยแสงจากหลอดไฟฟลูออเรสเซนต์เก่า ๆ

เด็กสาวที่ยืนอยู่หน้าไม้สนในกระถางคือ อาซามิ กอนโดะ จากห้อง 2-1

เธอยืนอยู่ตรงนั้น พร้อมกับกรรไกรในมือ

[ ...นุคุจัง ที่นี่ห้ามคนนอกเข้านะ รู้ใช่ไหม? ]

เธอพึมพำเบา ๆ โดยไม่ละสายตาจากกิ่งไม้

คนที่เดินเข้ามาในเรือนกระจกคือ คาจุ นุคุมิซึ ผมดำยาวของเธอพลิ้วไหวเบา ๆ ขณะยิ้มอย่างอ่อนโยน

[ ฉันมาในฐานะสภานักเรียนต่างหาก กอนจัง นี่รายงานประจำเดือนของสภาจ้ะ ]

กอนจังถอนหายใจยาว ราวกับจะปล่อยลมหายใจทั้งหมดออกมา ก่อนจะวางกรรไกรไว้ข้างกระถาง

[ ขอบใจนะ แต่วันนี้มาช้าจังเลย ]

[ อืม ไม่คิดว่าการเป็นรองประธานจะเหนื่อยขนาดนี้ แต่ฉันอยากให้งานเลี้ยงอำลารุ่นพี่ออกมาดีที่สุด ]

คาจุยื่นรายงานให้พลางมองต้นไม้บนโต๊ะ

ไม้สนเล็ก ๆ เหยียดกิ่งก้านออกมาราวกับแขนเล็ก ๆ

[ กอนจังชอบพืชกระถางจริง ๆ เลยนะ ]

[ ทาคามัตสึเซนเซย์เกษียณไปเมื่อปีที่แล้วใช่ไหม? ท่านเป็นที่ปรึกษาชมรมเรา ต้นนี้คือสิ่งที่เขาทิ้งไว้ให้ ]

กอนจังหยิบกรรไกรขึ้นมาอีกครั้ง แล้วจ้องไปที่กิ่งไม้

หลังจากจ้องอยู่ครู่หนึ่ง คะจุตัดสินใจพูดขึ้นมา

[ ขอฉันพูดอะไรหน่อยได้ไหม? ]

[ ..อะไรเหรอ? ]

เธอรวบรวมความกล้าอีกครั้ง

[ ฉันหมายถึงเรื่องทาจิบานะคุงน่ะ กอนจัง เธอสองคนสนิทกันมาตั้งแต่เด็กใช่ไหม? ]

[ เราเคยเข้าร่วมกลุ่มงานเด็กด้วยกันน่ะ เหมือนเป็นทั้งครอบครัวและเพื่อนไปพร้อมกัน ความสัมพันธ์แปลกดีเนอะ ]

รอยยิ้มหวนนึกถึงอดีตผุดขึ้นบนใบหน้าของกอนจังเพียงชั่วครู่

แต่ในวินาทีถัดมา เธอกลับแสดงสีหน้าเรียบเฉย

[ ...กอนจังเป็นเพื่อนที่สำคัญที่สุดของคาจุเลยนะ เพราะงั้นพอได้ยินความรู้สึกของทาจิบานะคุง ฉันก็รู้สึกตกใจ สิ่งแรกที่อยากทำก็คือมาคุยกับกอนจังก่อน ]

คะจุรอฟังคำตอบของเธอ

เวลาผ่านไปเท่าไรไม่รู้ คาจุก็เอ่ยขึ้นอีกครั้ง

[ กอนจัง เราสองคนจะเดินไปข้างหน้าด้วยกันได้จริง ๆ เหรอ? ]

ฉับ! เสียงกรรไกรในมือของกอนจังตัดผ่านอากาศ

[ เพราะเป็นแบบนั้น—เลยต้องลองดูไงล่ะ ]

คาจุนั่งตัวตรงขึ้น เมื่อเห็นแววตาเด็ดเดี่ยวของเพื่อนสนิท

[ มะรืนนี้ก็วันที่ 14 แล้ว—ฉันคิดว่าเขาต้องสารภาพแน่นอน ]

[ ...ไม่ว่าจะเป็นฉันหรือซาโตชิ ก็ไม่มีอะไรเปลี่ยนหรอก ]

หลังจากได้ยินคำพูดนั้น คาจุก็พยักหน้าเงียบ ๆ
