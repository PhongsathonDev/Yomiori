บทที่14-1 สายลมที่แปรปรวน

ผมก้าวลงจากรถไฟชินคันเซ็นมาเหยียบชานชาลา แล้วแหงนหน้ามองท้องฟ้าสีครามในยามว่างเว้นจากฤดูฝนผ่านสายไฟเหนือหัว

ยี่สิบกว่านาทีจากสถานีโทโยฮาชิ พวกเราสี่คนซึ่งเป็นนักเรียนชั้นปีสอง ชมรมวรรณกรรม โรงเรียนมัธยมปลายซึวาบุกิ ก็มาอยู่ที่สถานีนาโกย่า

พวกเรามาเยี่ยมรุ่นพี่สึคิโนกิกับรุ่นพี่ทามากิที่เข้าเรียนต่อมหาวิทยาลัยในนาโกย่าตั้งแต่ช่วงฤดูใบไม้ผลิ โดยมีกำหนดการพักค้างคืน 1 คืน 2 วัน

[ อ๊า อยู่นิ่งๆ แล้วปวดไหล่ชะมัดเลย ทางออกอยู่ทางไหนเนี่ย ]

ยากิชิโอะบิดขี้เกียจพลางหันมองรอบๆ

[ เดินตามกระแสคนไปก็คงได้แหละมั้ง ทุกคนอยู่กันครบไหม? ]

โคมาริโผล่หน้าออกมาขณะหลบอยู่หลังยากิชิโอะ

[ ฉะ ฉันอยู่นี่ ยานามิไปไหนแล้วล่ะ? ]

[ ยานามิซังอยู่ตรงนั้นไง── ]

อ้าว ไม่เห็นมีเลย อย่าบอกนะว่านั่งเลยป้ายน่ะ

ถ้าเป็นงั้นก็คงต้องปล่อยให้ยานามิกินทาโกะยากิอยู่ที่โอซาก้าคนเดียวแล้วล่ะ

พอผมกวาดสายตามองไปรอบๆ ชานชาลา ก็เจอแผ่นหลังของยานามิยืนอยู่หน้าร้านคิชิเมนแบบยืนกิน

[ อยู่นี่เอง รีบไปที่ช่องตรวจตั๋วกันเถอะ ]

ยานามิหันกลับมาอย่างช้าๆ แล้วชูเศษกระดาษใบเล็กๆ ให้ดูด้วยใบหน้ารู้สึกผิด

[ ……เผลอซื้อคูปองอาหารไปแล้วอะ ]

งั้นเหรอ ซื้อไปแล้วสินะ……

ไม่รู้ว่าสังเกตเห็นสีหน้าเอือมระอาของพวกเราทั้งสามคนหรือเปล่า ยานามิถึงได้โบกไม้โบกมือปฏิเสธพัลวัน

[ ก็แหม ถ้านึกถึงนาโกย่าก็ต้องคิชิเมนไม่ใช่เหรอ?! แล้วพอลงจากชินคันเซ็นปุ๊บ ร้านก็อยู่ตรงหน้าเลยนะ?! มันก็ต้องซื้อคูปองสิ ]

[ นอกจากยานามิซังก็ไม่มีใครซื้อเลยนะ ]

เมื่อเจอผมตบมุกกลับไปอย่างใจเย็น ยานามิก็แบมือออก

[ ขอเวลา 5 นาที…… ไม่สิ 3 นาที! เดี๋ยวรีบกินแล้วมาเลย! ]

เธอทิ้งท้ายไว้แค่นั้นแล้วก็เดินเข้าไปในร้านแบบยืนกิน

ยานามิเดินริมฝีปากมันแผล็บออกมา──หลังจากเข้าไปในร้านได้ 2 นาที 50 วินาที

เมื่อเห็นยานามิทำหน้าทำตาภูมิใจ พวกเราก็เลยปรบมือให้ไปพลางๆก่อน

◇

บริเวณหน้าห้างสรรพสินค้าที่ตั้งอยู่ติดกับสถานีรถไฟเมเทตสึ มีจุดนัดพบที่ใหญ่ที่สุดในนาโกย่าอยู่

──ตุ๊กตานานะจัง

มันคือหุ่นโชว์เสื้อผ้าขนาดยักษ์ที่สูงกว่า 6 เมตร ซึ่งความโดดเด่นของมันทำให้คนที่เคยเห็นครั้งหนึ่งแล้วไม่มีวันลืม

ยานามิอ้าปากค้าง แหงนหน้ามองนานะจัง

[ไม่ได้เห็นมาตั้งนาน แต่ก็ใหญ่อย่างที่คิดไว้เลยแฮะ ]

[ เห็นเขาว่าเจ้านี่หนักตั้ง 600โลเลยนะ ]

[โห เท่ากับตัวฉัน 20 คนเลยสินะเนี่ย ]

โห ยานามิ 20 คนเหรอ 600 หาร 20 ก็──

[ ……ไคิดยังไงมันก็เวอร์เกินไปหน่อยไหม? ไม่รู้สึกผิดต่อมโนธรรมบ้างเหรอ? ]

[ ก็ไม่นะ ในความรู้สึกฉันมันก็ประมาณนั้นแหละ ]

ในขณะที่พวกเรากำลังสนทนาเรื่องไร้สาระกันอยู่ ยากิชิโอะที่อยู่ข้างๆ ก็ดูนาฬิกา

[ เลยเวลานัดกับพวกคุณพี่แล้วนี่นา ]

ถึงจะเลยเวลานัดมา 5 นาทีแล้ว แต่อีกฝ่ายคือรุ่นพี่ทสึกิโนกิ ก็คงประมาณนี้แหละ

ขณะที่กำลังแหงนมองเรือนร่างสีขาวของตุ๊กตานานะจัง โคมาริก็เริ่มโบกมือไปมาอย่างแรง

[ ระ รุ่นพี่! ทางนี้ค่ะ! ]

[ โอ้ โทษทีๆ มาสายไปหน่อยน่ะ ]

คนที่ปรากฏตัวพร้อมกับรอยยิ้มสบายๆ คือศิษย์เก่าชมรมวรรณกรรมสึคิโนกิ โคโตะ

ผมปรายตามองรุ่นพี่ที่แท็กมือข้างเดียวกับโคมาริซึ่งวิ่งเข้าไปหา พลางมองหาศิษย์เก่าอีกคน

[ อ้าว รุ่นพี่ทามากิไม่มาเหรอครับ ]

พวกสมาชิกผู้หญิงจะไปพักที่บ้านรุ่นพี่ทสึคิโนกิ ส่วนผมจะไปพักที่บ้านรุ่นพี่ทามากิ ถ้าไม่มีเขาละก็ ผมอาจจะต้องนั่งรถไฟเที่ยวสุดท้ายกลับคนเดียวก็ได้นะ……

รุ่นพี่สึคิโนกิยิ้มแย้มพลางลูบหัวโคมาริอย่างเอ็นดู

[ เห็นบอกว่ารายงานยังไม่เสร็จ เลยจะตามมาสมทบทีหลังน่ะ แหม เด็กมหาลัยนี่ก็ยุ่งกว่าที่คิดนะเนี่ย ]

[ รุ่นพี่ได้เข้าเรียนบ้างไหมครับเนี่ย? ]

ผมนึกสงสารความลำบากของแฟนเธอ พลางมองดูยานามิและยากิชิโอะที่กำลังถ่ายรูปกับตุ๊กตานานะจัง

──เมืองที่ใหญ่ที่สุดในจังหวัดไอจิ นาโกย่า

พอเป็นเมืองนี้ แม้แต่หุ่นโชว์ขนาดยักษ์ปริศนาก็กลายเป็นสถานที่ท่องเที่ยวได้

ผมคิดว่าเสน่ห์ของเมืองโทโยฮาชิก็ไม่ได้แพ้กันหรอก แต่ความจริงที่ว่ารถไฟชินคันเซ็นขบวนโนโซมิไม่จอดนี่มันช่างหนักหนาเสียจริง

[ หลังจากนี้ทุกคนอยากไปย่านการค้าโอซุกันสินะ ถ้างั้นไปขึ้นรถไฟใต้ดินกันเถอะ ]

เมื่อรุ่นพี่สึคิโนกิดื่มด่ำกับโคมาริจนพอใจแล้ว เธอก็เอ่ยปากชวนทุกคน

รถไฟใต้ดิน ระบบขนส่งมวลชนที่อนุญาตให้มีเฉพาะในเมืองใหญ่เท่านั้น แต่ที่โทโยฮาชิก็มีรถรางอยู่นะ……

ผมแอบจุดไฟแห่งความรู้สึกอยากแข่งขันขึ้นมาในใจ ขณะที่เดินตามทางไปสู่สถานีรถไฟใต้ดิน

◇

พวกเราเปลี่ยนสายรถไฟใต้ดินที่ฟุชิมิ แล้วไปลงที่สถานีคามิมาเอซึ

จากที่นี่ไปจนถึงโอสึคันนง มีย่านการค้าหลายสายพาดผ่าน และบริเวณนั้นทั้งแถบก็เป็นสถานที่ท่องเที่ยวด้วย

ประเดิมด้วยการเดินมาถึงทางเข้าถนนบันโชจิ ทันใดนั้นยานามิก็ถอนหายใจเฮือกใหญ่

[ ให้ตายสิ อยากให้เพลาๆ ลงบ้างจริงๆ…… ]

[ เอ่อ เรื่องอะไรเหรอ? ]

เมื่อผมถามตามมารยาท ยานามิก็เอานิ้วแตะหน้าผากที่ก้มลงเล็กน้อย แล้วส่ายหน้าอย่างเหนื่อยหน่าย

[ ดูสิ นุกุมิซึคุง ตรงทางเข้าน่ะ──มีอยู่ใช่ไหมล่ะ? ]

[ อืม ก็มีร้านข้าวปั้นย่างกับร้านเกาลัดหวานอยู่นะ ]

[ อุตส่าห์กำลังเตรียมตัวรับหน้าร้อนแท้ๆ มาทำแบบนี้ฉันก็แย่สิ ]

ยานามิเสยผมพลางเดินผ่านหน้าร้านไป

[ อ๋อ ที่แท้ยานามิซังก็อ้── เอ้ย กำลังไดเอทอยู่นี่เอง ]

[ ……เมื่อกี้ช่วงแรกเหมือนพูดค้างไว้หรือเปล่า? ]

[ ไม่ได้พูดอะไรนี่ครับ ]

แต่ช่วงหลังๆ มานี้ยานามิมักจะใส่ชุดไปรเวทที่พรางหุ่นบ่อยๆ ก็คงจะเป็นอย่างนั้นแหละมั้ง……

ขณะที่กำลังทนรับแรงกดดันจากยานามิ ยากิชิโอะก็กวักมือเรียกมาจากไกลๆ

[ ทางนั้นมีของที่ยานะจังน่าจะชอบด้วยแหละ! ไก่อบทั้งตัว เห็นว่าเป็นของขึ้นชื่อของโอสึเลยนะ! ]

[ อะไรเนี่ย เดินกินได้ด้วยหรือเปล่า! ]

ไก่อบทั้งตัวเป็นของขึ้นชื่อเมืองโอสึ……? ไม่ค่อยเข้าใจเท่าไหร่หรอก แต่ก็เป็นนาโกย่านี่นะ คงจะเป็นงั้นแหละ

ยอมรับได้ทุกอย่างและไม่คิดมาก นั่นแหละคือนาโกย่า

[ ยะ ยากิชิโอะ อย่าวิ่งพล่านสิ…… ]

โคมาริที่เดินโซเซวิ่งตามหลังทั้งสองคนที่วิ่งนำไป

ขณะที่ผมมองภาพนั้นอย่างขบขัน รุ่นพี่สึคิโนกิก็เดินมาขนาบข้างพร้อมกับถือชาขวดในมือ

[ เป็นไงบ้าง บ้านเกิดแห่งที่สองของฉัน ]

[ ตอนแรกผมคิดว่าจะรู้สึกวุ่นวายคล้ายๆ โอซาก้า แต่ก็ต่างกันนิดหน่อยนะครับ ]

[ โฮ่ ทำไมถึงคิดงั้นล่ะ? ]

รุ่นพี่สึคิโนกิถามด้วยน้ำเสียงที่ดูสนุกสนาน

[ ทำไมถึงมีขายเคบับบ้างล่ะ ร้านอาหารบราซิลบ้างล่ะ มันดูไม่ค่อยเป็นไปในทิศทางเดียวกันเลย ]

ผมมองกวาดไปตามถนน

[ โอโคโนมิยากิตรงนั้นก็เขียนว่าสไตล์นาโกย่า แต่ก็ไม่รู้ว่ามันคืออะไรกันแน่ ดูมันจับฉ่ายยังไงก็ไม่รู้── ]

ผมหมุนสมองอย่างเต็มกำลังเพื่อหาคำพูดที่เหมาะสม

[ ……มันมีความเป็นนาโกย่ามากๆ เลยสินะครับ ]

ยอมแพ้แล้ว นาโกย่านี่ไม่เข้าใจเลยจริงๆ

[ เห็นด้วยเลยล่ะ ฉันเองก็เพิ่งมาอยู่ได้ไม่นาน จะพูดอะไรใหญ่โตก็ไม่ได้หรอก แต่ว่านะ มันมีพลังและความน่าเชื่อถือแบบแปลกๆ แฝงอยู่น่ะ ]

ผมเผลอปรายตามองไปทางเมดคาเฟ่ที่เดินผ่านมา

คุณเมดของร้านนี้เซ็ตติ้งว่าเป็นหุ่นยนต์เมดจากอนาคตเหรอเนี่ย……หืมม……

[ พอลองมาอยู่ดู นาโกย่าก็เป็นที่ที่ดีนะ นุคุมิซึคุงล่ะ อีกสองปีข้างหน้าเอาไหม? ]

[ ฮะฮะ นาโกย่าเหรอครับ ]

พอผมตอบส่งๆ เพราะมัวแต่สนใจคุณเมด รุ่นพี่ก็ทำหน้าจริงจังขึ้นมากะทันหัน

[ ปีหน้าก็จะอยู่ปี 3 แล้วนี่นา ต้องเริ่มคิดเรื่องเรียนต่อตั้งแต่ตอนนี้แล้วล่ะ ]

ถึงจะไม่ค่อยอยากเชื่อคำพูดของคนคนนี้เท่าไหร่ แต่มันก็จริงอย่างที่พูด

ถ้าคิดถึงเรื่องเรียนเพื่อสอบเข้า ก็จำเป็นต้องกำหนดแนวทางไว้ตั้งแต่ตอนอยู่ปี 2 นี่แหละ

[ นั่นสินะครับ พ่อแม่ก็บอกไว้ว่าถ้าเรียนจบแล้วให้ออกจากบ้านไปน่ะ ]

[ เห เริ่มคุยเรื่องแบบนั้นกันแล้วเหรอ ]

[ ครับ บอกให้เตรียมใจว่าจะไม่กลับมาบ้านเกิด แล้วไปให้ไกลที่สุดเท่าที่จะทำได้น่ะ ]

พอได้ยินดังนั้น แว่นตาของรุ่นพี่สึคิโนกิก็สว่างวาบขึ้นมา

[ โฮ่ มังงะ BL แนวหมู่บ้านที่มีประเพณีประหลาดที่ฉันเพิ่งอ่านไปเมื่อวันก่อนก็เปิดเรื่องมาแบบนี้เลยนะ พ่อแม่พยายามจะให้ชายหนุ่มตัวเอกหนีออกไปจากหมู่บ้านน่ะ ]

[ แล้วตัวเอกจะเป็นยังไงต่อล่ะครับ ]

[ ก็โดนจับได้แล้วก็ไปมีเรื่องอย่างว่ากับผู้ใหญ่บ้านสุดหล่อน่ะสิ สนใจไหม? ]

[ ไม่ครับ แล้วจะหยิบสมาร์ตโฟนออกมาทำไมครับ? อย่าเปิดแอปขึ้นมาเลยนะครับ ]

คนคนนี้ เป็นนักศึกษามหาลัยแล้วก็ไม่เปลี่ยนไปเลย แถมยังหนักข้อขึ้นกว่าเดิมอีก……

การทนรับการล่วงละเมิดทางเพศจากศิษย์เก่าก็เป็นงานของประธานชมรมเหมือนกัน ขณะที่ผมทำใจให้ว่างเปล่าเพื่อรับมือ ยากิชิโอะก็วิ่งกลับมาอีกครั้ง

[ อ้าว โคมาริจังไม่ได้อยู่ที่นี่เหรอ? ]

[ ไม่อยู่นะ เมื่อกี้ก็วิ่งตามยากิชิโอะไปไม่ใช่เหรอ ]

[ ก็เผลอแป๊บเดียวก็หายไปไหนแล้วก็ไม่รู้อะ แถวนี้ไม่มีเลยเหรอ ]

ยากิชิโอะชะโงกหน้าดูใต้รถเข็นหน้าร้านด้วยท่าทีร้อนรน
