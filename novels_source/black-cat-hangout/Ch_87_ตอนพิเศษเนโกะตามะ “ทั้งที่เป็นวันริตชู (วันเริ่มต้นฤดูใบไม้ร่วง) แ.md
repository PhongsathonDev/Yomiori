Ch.87 — ตอนพิเศษเนโกะตามะ “ทั้งที่เป็นวันริตชู (วันเริ่มต้นฤดูใบไม้ร่วง) แท้ๆ แต่กลับร้อนเกินไปแล้ว”

By อาสึมิ

Published: 2026-09-15T05:00:00Z

Source: https://www.nekopost.net/novel/17903/87

ฮินะ : “ร้อนจังเลยน้า~”

มิซึกิ : “ร้อนจังเลยนะคะ......”

ทาคุมิ : “ร้อนจริงๆ ด้วยครับ......”

ฮินะ : “เห็นว่าวันนี้คือวันริตชู (วันเริ่มต้นฤดูใบไม้ร่วง) ล่ะมั้ง......?”

มิซึกิ : “ตามปฏิทินแล้วก็เป็นแบบนั้นแหละค่ะ”

ทาคุมิ : “เดี๋ยวๆ ทำไมถึงเป็นแบบนั้นไปได้ล่ะครับ ตอนนี้มันกลางฤดูร้อนชัดๆ เลยไม่ใช่เหรอครับ?”

ฮินะ : “เนอะ~ ไม่เห็นจะมีความเป็นฤดูใบไม้ร่วงตรงไหนเลยสักนิดเนอะ”

มิซึกิ : “เห็นว่าเพราะช่วงกลางวันจะร้อน แต่พอตอนเย็นเริ่มมีลมเย็นๆ พัดมาให้รู้สึกถึงฤดูใบไม้ร่วงน่ะค่ะ เพราะงั้นตามปฏิทินตั้งแต่วันนี้เลยนับเป็นฤดูใบไม้ร่วง แต่ว่า......”

ทาคุมิ : “อยู่ท่ามกลางฤดูร้อนขนาดนี้ จู่ๆ มาบอกว่า 'ตั้งแต่วันนี้คือฤดูใบไม้ร่วงแล้ว' พูดตามตรงผมก็ทำตัวไม่ถูกเหมือนกันนะครับ ตอนเย็นก็ยังร้อนเป็นปกติอยู่เลย”

ฮินะ : “ไม่มีทางคิดว่าเป็นฤดูใบไม้ร่วงได้หรอก เรื่องนี้ฉันขอยืนยันเสียงแข็งเลย!”

มิซึกิ : “อย่างวันนี้อุณหภูมิสูงสุดตั้ง 37 องศาเซลเซียสแน่ะค่ะ ถ้าไม่มีเครื่องปรับอากาศ ชีวิตประจำวันคงลำบากแย่”

ทาคุมิ : “สัญลักษณ์ประจำฤดูร้อนอย่างการแข่งขันเบสบอลโคชิเอ็งเองก็เพิ่งเปิดฉากไปเมื่อวานซืนนี่เองนะครับ”

ฮินะ : “จะว่าไป แค่คุยกันอยู่แบบนี้ก็ร้อนแล้วน้า~”

มิซึกิ : “ร้อนจังเลยนะคะ......”

ทาคุมิ : “ร้อนจริงๆ นั่นแหละครับ......”

ฮินะ : “ไม่ว่าจะคิดยังไง ตอนนี้ก็คือฤดูร้อนชัดๆ เนอะ......”

มิซึกิ : “ปฏิเสธไม่ได้เลยล่ะค่ะ......”

ทาคุมิ : “ไม่ว่าใครมองยังไง ตอนนี้ก็คือฤดูร้อน ไม่ใช่ฤดูใบไม้ร่วงหรอกนะครับ......”

ฮินะ : “ร้อนจังเลยน้า~......”

มิซึกิ : “ร้อนจังเลยนะคะ......”

ทาคุมิ : “ร้อนจริงๆ ด้วยนะครับ......”

พอมาถึงบ้านผมจนได้ ผมก็รีบเปิดเครื่องปรับอากาศในห้องนั่งเล่น กดปุ่มลมแรงและปรับลดอุณหภูมิลงต่ำสุดรัวๆ ทันทีครับ
