# Ch.4 — คุณโคคาเงะผู้ขี้วิตก

“ถ้าอย่างนั้น ลูกแมวตัวนี้... ให้ผมรับไปเลี้ยงได้ไหม?”

“เอ๊ะ? คุณนากาโนะ... รับไปเลี้ยงได้เหรอคะ?”

คุณโคคาเงะเบิกตากว้างพลางมองมาทางผม

“ผมเองก็รู้สึกปวดใจเหมือนกันถ้าต้องปล่อยมันไว้แบบนี้ แถมยังคิดว่านี่อาจเป็นโชคชะตาก็ได้นะ”

“แต่จะตัดสินใจตามใจชอบแบบนั้นจะดีเหรอคะ? ต้องได้รับการยินยอมจากทางครอบครัวก่อนนะคะ แล้วก็ห้ามฝืนตัวเองเด็ดขาดเลยนะคะ”

“ถ้าเรื่องนั้นล่ะก็สบายใจได้เลย เพราะผมอาศัยอยู่คนเดียวน่ะ”

“อาศัยอยู่คนเดียว... เหรอคะ?”

คุณโคคาเงะเอียงคอเล็กน้อยอย่างน่ารัก

“เรื่องจริงเลยล่ะ”

“เอ่อ คือว่า... หรือว่าคุณพ่อคุณแม่ของคุณนากาโนะจะ...”

คุณโคคาเงะทำสีหน้าเหมือนรู้ตัวว่าพูดอะไรที่ไม่ควรออกไป แล้วรีบเอามืออุดปาก ก่อนสีหน้าจะเปลี่ยนเป็นเศร้าโศก ราวกับเพิ่งเห็นวีทูบเบอร์คนโปรดประกาศจบการศึกษาแบบไม่มีปี่มีขลุ่ย

สายตาของเธอเริ่มมองเลิ่กลั่กไปทางโน้นทีทางนี้ทีอย่างลนลาน

โอ้โห ปฏิกิริยาแบบนี้...

สมกับเป็นคุณโคคาเงะผู้จิตใจดีถึงขนาดซื้ออาหารมาให้ลูกแมวถูกทิ้งจริงๆ

เธอต้องจินตนาการไปไกลว่าผมสูญเสียคุณพ่อคุณแม่ไปแล้วอะไรทำนองนั้นแน่เลย

“อาฮะฮะ คุณโคคาเงะน่าจะเข้าใจผิดแล้วล่ะ คุณพ่อคุณแม่ของผมยังสบายดีอยู่นะ”

“...ทั้งอย่างนั้น แต่อาศัยอยู่คนเดียวเหรอคะ? ทั้งที่เป็นแค่นักเรียนมัธยมปลายเนี่ยนะ?”

“จริงๆ แล้วบ้านที่ผมอยู่นี้ เดิมทีเป็นบ้านของคุณย่าน่ะ”

“บ้านของคุณย่าของคุณนากาโนะ... ถ้าอย่างนั้นก็...”

คุณโคคาเงะทำสีหน้าเศร้าหมองลงไปอีกครั้ง

เป็นเด็กผู้หญิงที่อ่อนไหวและใจดีจริงๆ เลยน้า

“บอกไว้ก่อนนะว่าคุณย่าของผมก็ยังมีชีวิตอยู่เหมือนกัน นอกจากเรื่องขาและเอวที่เริ่มอ่อนแรงลงตามวัยแล้ว ที่เหลือท่านก็แข็งแรงดีสุดๆ วันนี้ผมเองก็เพิ่งแวะไปเยี่ยมคุณย่าที่บ้านพักคนชรา แล้วกำลังเดินกลับบ้านนี่ไง”

“อย่างนั้นเองเหรอคะ... ฟู่ ค่อยยังชั่วหน่อย...”

คุณโคคาเงะถอนหายใจยาวด้วยความโล่งอก

แต่สีหน้าสงสัยของเธอยังไม่หายไปไหนเลย

คงเพราะยังไม่ค่อยเข้าใจสถานการณ์ของผมสินะ

ก็ไม่ใช่เรื่องต้องปิดบังอะไรด้วย ไหนๆ ก็ไหนๆ แล้ว เล่าเหตุผลที่ต้องอยู่คนเดียวให้ฟังเลยแล้วกัน

“ตั้งแต่เดือนกุมภาพันธ์ปีนี้ คุณย่าย้ายเข้าไปอยู่ในบ้านพักคนชราน่ะ แต่ท่านบอกว่าบ้านที่เคยอยู่มาหลายสิบปีและเต็มไปด้วยความทรงจำของคุณตาที่เสียไปแล้ว ไม่อยากขายมันทิ้งตราบใดที่ท่านยังมีชีวิตอยู่น่ะสิ”

“เข้าใจความรู้สึกนั้นเลยค่ะ แค่รู้ว่ามีสิ่งสำคัญอยู่ตรงนั้น มันก็กลายเป็นที่พึ่งทางใจได้แล้ว...”

คุณโคคาเงะพยักหน้าหงึกๆ อย่างเข้าใจเป็นอย่างดี

มีเรื่องอะไรที่ทำให้เธอเข้าถึงความรู้สึกนี้ได้ขนาดนั้นกันนะ?

“แต่ก็นั่นแหละ เขาว่ากันว่าบ้านถ้าไม่มีใครอยู่อาศัยเลย มันจะทรุดโทรมไวมาก”

“เรื่องนั้นเข้าใจเลยค่ะ แค่ไปเที่ยวไม่ได้ทำความสะอาดแป๊บเดียว ฝุ่นก็จับเต็มไปหมดอย่างรวดเร็วเลยค่ะ”

“นั่นสิเนอะ แล้วพอดีกับที่ผมสอบติดมัธยมปลายฮาคุเรียวได ซึ่งสามารถเดินไปเรียนจากบ้านคุณย่าได้พอดี ผมก็เลยได้รับอนุญาตให้อาศัยอยู่คนเดียว แลกกับการคอยดูแลบ้านให้คุณย่าน่ะ”

“มีเหตุผลแบบนี้นี่เองนะคะ”

คุณโคคาเงะพยักหน้ารับอย่างจริงจังเหมือนเข้าใจเรื่องราวทั้งหมดแล้ว

พออธิบายแล้วมันก็ไม่ได้มีอะไรซับซ้อนหรอก แต่ถ้าไม่อธิบายเลยคงไม่มีทางรู้ได้แน่ๆ

“เพราะงั้นแหละ เรื่องครอบครัวเลยไม่มีปัญหาหรอก ถึงยังไงเดี๋ยวค่อยโทรบอกคุณย่าทีหลังก็ได้ เพราะคุณย่าเองก็ชอบแมวเหมือนกัน แถมเมื่อก่อนเคยเก็บแมวโดนทิ้งมาเลี้ยงด้วย คงไม่ว่าอะไรหรอก... แถมยังเป็นแมวดำที่เหมือนกับเจ้าตัวนี้เปี๊ยบเลยด้วย”

จนกระทั่งเจ้าแมวดำตัวนั้นหมดอายุขัยไปตามวัยเมื่อสองปีก่อน ผมเองก็คอยลูบหัวและป้อนอาหารให้มันทุกครั้งที่มาบ้านคุณย่าเหมือนกัน

แต่ถ้าพูดอีกมุมหนึ่ง ผมเคยทำแค่นั้นเอง ก็เลยไม่ได้มีความรู้หรือทักษะการเลี้ยงแมวติดตัวเท่าไหร่เนี่ยสิ

แถมคุณย่าก็เป็นคนมีน้ำใจและให้ความสำคัญกับคนอื่นมาก

ท่านมักจะพร่ำสอนอยู่เสมอว่าให้รักษาความสัมพันธ์และสายสัมพันธ์กับผู้คนเอาไว้ให้ดี

พูดตรงๆ ขนาดวันนี้ตอนไปเยี่ยมที่บ้านพักคนชรา ผมก็เพิ่งโดนท่านเทศน์เรื่องนี้มาสดๆ ร้อนๆ เลย

ลูกแมวที่ผมบังเอิญเจอระหว่างทางกลับบ้านหลังไปหาคุณย่าผู้เปี่ยมไปด้วยน้ำใจแบบนั้น มันต้องมีสายสัมพันธ์ร่วมกันยิ่งกว่าอะไรทั้งหมดแน่ๆ ไม่ใช่หรือไง
