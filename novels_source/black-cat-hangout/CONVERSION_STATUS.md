# สถานะการแปลงเรื่องแมวดำ

ตรวจต้นฉบับที่มีในคลังถึงตอน 87 ตามคำขอให้แปลงเฉพาะตอนที่ทำได้ และเว้นพร้อมกำกับตอนที่เหลือ

## ตอนที่เพิ่มในการแปลงรอบนี้

- ตอน 61–74: 14 ตอน
- ตอนพิเศษ 77: 1 ตอน
- ตอนพิเศษ 85–87: 3 ตอน
- รวมเพิ่ม 18 ตอน โดยคงข้อความต้นฉบับครบถ้วนและระบุผู้พูดทุกบล็อกบทสนทนา
- เมื่อรวมข้อมูลเดิมตอน 0–60 จะมี 79 รายการอ่าน (รวมตอน 0 ที่เป็นภาพประกอบ)

## ตอนที่เว้นไว้

เว้น **ทั้งตอน** ไม่ตัดบางย่อหน้าออกแล้วเผยแพร่เป็นตอนสมบูรณ์ เพราะต้องรักษาหลักไม่ตัดทอนต้นฉบับ ตอนที่เว้นไม่มี JSON หรือตอนเปล่าในสารบัญ จึงไม่มีลิงก์อ่านที่พาไปเจอ 404 และไม่เปลี่ยนเลขตอนเพื่อปิดช่องว่าง

เหตุผลคือบางช่วงมีเนื้อหาเชิงเพศที่พาดพิงร่างกายหรือการสัมผัสตัวละครวัยมัธยม ไม่ได้เป็นการจัดเรตทั้งเรื่องว่าเป็นนิยาย 18+

ชื่อและการซ้ำบางส่วนของตอนพิเศษคงตามต้นฉบับ รวมถึงชื่อ “ภาคจบ” ของตอน 80 ที่มาก่อนตอน 81–82

## ข้อมูลและคำสั่งตรวจสอบ

- รายการสถานะแบบ JSON: `reader-web/src/data/novels/black-cat-hangout/conversion-status.json` และสำเนาใน `reader-mobile/src/data/novels/black-cat-hangout/`
- ตัวแปลงระบุผู้พูดจากการอ่านบริบท ไม่ใช้การเดาสลับผู้พูดอัตโนมัติ
- แปลงซ้ำเฉพาะช่วงที่ตรวจรอบนี้: `node reader-web/scripts/convert-blackcat-chapters.mjs --from 61 --to 87`
- ตรวจข้อความแบบเท่ากันทุกตัวอักษรต่อย่อหน้า ผู้พูด รายการที่เว้น และความตรงกันระหว่างเว็บ/มือถือ: `node --test reader-web/scripts/blackcat-conversion.test.mjs`
- รายการอ่านของมือถือรวมจากไฟล์ที่มีจริง ไม่ใช้เลขตอนสูงสุดสร้างรายการต่อเนื่อง จึงไม่เติมตอนที่เว้นกลับเข้ามา

## ผลการตรวจสอบก่อนส่งมอบ

- การตรวจข้อมูลใหม่: ผ่าน 21 tests รวมเทียบข้อความทุกย่อหน้าแบบเท่ากันทุกตัวอักษร ไม่ใช่เพียงเทียบความยาว
- Mobile: typecheck และ lint ผ่าน; ชุดทดสอบทั้งหมดผ่าน 107 tests รวมกรณี offline และ manifest เก่าที่ต้องรวมตอนใหม่โดยไม่เติมตอนที่เว้น
- Web: production build ผ่าน; manifest/CDN ที่สร้างมี 79 รายการและไม่มีไฟล์ตอนที่เว้น
- Lint ของไฟล์สคริปต์ที่แก้ผ่าน แต่ lint รวมเว็บยังติดข้อผิดพลาดเดิมเรื่อง React Hooks 4 จุดใน `reader-web/src/components/QuickFixModal.tsx` ซึ่งไม่อยู่ในขอบเขตการแปลงและไม่ได้แก้ไข
