# Ch.33.5 — แนะนำตัวละครหลัก และการเปลี่ยนแปลง (หลังจบเรื่องราวในเมืองแห่งทะเลทราย (ตอน 33))

Ch.33.5 — แนะนำตัวละครหลัก และการเปลี่ยนแปลง (หลังจบเรื่องราวในเมืองแห่งทะเลทราย (ตอน 33))

แนะนำตัวละครหลัก และการเปลี่ยนแปลง (หลังจบเรื่องราวในเมืองแห่งทะเลทราย (ตอน 33))

〈พี่ชายที่พึ่งพาได้ ผู้ชื่นชอบการแย่งชิง〉 ชินจิ

ตัวเอกของเรื่อง นักเวทผู้ทำสัญญากับภูตบุปผาเฟรรี่

+ สวิตช์ความปรารถนาทางเพศของเขาจะเปิดก็ต่อเมื่อเป็นการแย่งชิงมาเท่านั้น

+ ชอบเมดเป็นพิเศษ

〈นักดาบหนุ่มบ้านนอกผู้ซื่อสัตย์〉 อัลวิน

หัวหน้าปาร์ตี้ 〈หมาป่าทะยาน〉 อายุ 16 ปี

ผมสั้นสีดำ

ใช้อาวุธดาบสองมือ ชอบชุดเกราะเบา ถนัดการเคลื่อนไหวที่รวดเร็วและการโจมตีที่กล้าหาญ

ใบหน้าหล่อเหลา

นิสัยค่อนข้างสบาย ๆ ในทางที่ดี

รักมีริสคนรักของเขามาก

ชอบงานเลี้ยง ไม่เคยเจ้าชู้หรือเล่นการพนัน

+ เป็นศิษย์ของเอมิลี่

〈สาวน้อยนักบวชผู้ใจดี〉 มีริส

ผู้รักษาประจำปาร์ตี้〈หมาป่าทะยาน〉อายุ 16 ปี

ผมสีทองยาวสลวยถึงเอว

ใช้ไม้เท้าเป็นอาวุธ

นักบวชหญิงในชุดคลุมสีน้ำเงิน ใบหน้าน่ารัก แม้จะตัวเล็ก แต่มีหน้าอกและสะโพกใหญ่ มีรูปร่างที่ดึงดูดผู้ชาย

นิสัยสงบเสงี่ยมและถ่อมตัว พึ่งพาอัลวินคนรัก รักเรนกะเหมือนพี่สาว

+ ตอนนี้เธอถูกอวัยวะเพศของชินจิที่เป็น “คู่นอน” สลักความสุขไว้ในร่างกาย

+ เธอชอบการกระแทกส่วนลึกในช่องคลอด (แม้จะยังไม่รู้ตัว) ซึ่งอัลวินไม่สามารถเข้าถึงได้

+ เธอได้ตกอยู่ในความสัมพันธ์แบบ “คู่นอน“ กับชินจิแล้ว

〈เรนเจอร์สาวผู้ชอบดูแล〉เรนกะ  <เปลี่ยนเป็น> 〈เรนเจอร์สาวผู้ปรนนิบัติ〉เรนกะ

หน่วยลาดตระเวนและพลธนูประจำปาร์ตี้〈หมาป่าทะยาน〉อายุ 17 ปี

ผมสีแดงยาวปานกลาง

ใช้อาวุธธนูและมีดสั้น

เรนเจอร์ในชุดสีเขียว ใบหน้าสวยงามและดูดีมาก รูปร่างสมส่วน หน้าอกค่อนข้างใหญ่

นิสัยมีความรับผิดชอบสูงและชอบเอาชนะ อาจเป็นเพราะอายุมากกว่าอัลวินและมีริส 1 ปี จึงพยายามปกป้องทั้งสองราวกับพี่สาว

ดูเหมือนจะมีความรู้สึกแบบเพศตรงข้ามต่ออัลวินด้วย การที่เธอไม่ซื่อตรงและมักจะโต้เถียงกันก็เป็นอีกด้านหนึ่งของความรู้สึกนั้น ซึ่งอัลวินไม่รู้เรื่องนี้เลย

...เดิมทีควรจะเป็นเช่นนั้น

+ ตอนนี้ติดใจการมีเซ็กส์กับชินจิไปโดยสิ้นเชิง เริ่มรู้สึกยินดีกับการได้ปรนนิบัติ มีความรู้สึกว่าความรักที่มีต่ออัลวินเป็นความรักแบบครอบครัวเหมือนน้องชาย ส่วนความรักแบบเพศตรงข้าม เธอรู้ตัวว่าชอบชินจิ แต่ยังไม่ได้พูดออกมา

+ ชอบการมีเซ็กส์ในท่า แนบชิดตัวติดกันในท่าหันหน้าเข้าหากันมากที่สุด

〈ลูกสาวคนเดียวของโรงแรมผู้ร่าเริง〉ชาร์ลอตต้า

ดาวเด่นประจำโรงแรม〈โพรงตัวตุ่นผู้ซ่อนเร้น〉

ผมสีน้ำตาลอ่อน ใบหน้าน่ารัก และหน้าอกค่อนข้างใหญ่

มีคนรักชื่อมอร์ส

〈ภรรยา〉นานากะ

อดีตสมาชิกปาร์ตี้ของชินจิ

ผมสีม่วงรวบเป็นหางม้า แม้หน้าอกจะเล็ก แต่มีช่วงล่างที่อวบอิ่มน่าดึงดูดใจ เหมาะสำหรับการตั้งครรภ์และคลอดบุตร

สามีชื่อฮารุโตะ ลูกสาวชื่อฮานะ

〈นักรบสาวอัจฉริยะผู้งดงาม〉เอมิลี่

อดีตสมาชิกปาร์ตี้ของชินจิ

ผมสีทองยาวถึงไหล่ ใบหน้าน่ารักมาก ตัวเล็กและมีรูปร่างเหมือนเด็ก

มีความรู้สึกดีๆ ต่อชินจิ

แข็งแกร่งมาก

+ เป็นอาจารย์ของอัลวินและเริ่มฝึกซ้อมร่วมกัน

〈นักบวชหญิงผู้มีบาดแผลในใจ〉อากาเนะ  <เปลี่ยนเป็น> 〈นักบวชหญิงผู้ลามก〉อากาเนะ

อดีตนักผจญภัยจากบ้านเกิดเดียวกันกับพวกอัลวิน

นักบวชหญิงผมสีแดงเข้ม

ปาร์ตี้ที่เธอเคยสังกัดถูกทำลาย และเธอเป็นคนเดียวที่รอดชีวิตมาได้ด้วยความช่วยเหลือจาก〈หมาป่าทะยาน〉

ออกจากบ้านเกิดและมาเป็นนักบวชหญิงในเมืองแห่งทะเลทราย

+ ซ่อนหน้าอกที่ใหญ่โตด้วยผ้าคาดหน้าอก

+ ไม่เพียงแต่อาการกลัวผู้ชายจะทุเลาลงโดยชินจิ เธอยังถูกสอนให้รู้ถึงความสุขของการมีเซ็กส์ และติดใจการมีเซ็กส์กับชินจิ

+ รู้สึกพึ่งพิงชินจิ
