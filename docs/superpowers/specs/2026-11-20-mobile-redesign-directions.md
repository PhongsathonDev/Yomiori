# ทิศทางดีไซน์มือถือ 6 แบบ — Design Lab

วันที่: 20 พฤศจิกายน 2026
สถานะ: รอเลือกทิศทาง (รอบแรก 3 แบบ + มินิมอล 3 แบบ; ยังไม่เปลี่ยนแอปจริง)
ขอบเขต: `reader-mobile` ชั้นหนังสือ รายละเอียดนิยาย และหน้าอ่าน

## ทำไมต้องมีรอบนี้

เจ้าของโปรเจกต์ยังไม่พอใจหน้าตาแอปปัจจุบัน จึงต้องการเห็นทางเลือกใหม่ที่ต่างกันจริง ๆ ต่อเนื่องกันสองรอบ: รอบแรก 3 แบบ และรอบมินิมอลอีก 3 แบบ
รอบนี้จึงเป็น design exploration/spike ไม่ใช่การเปลี่ยนแบรนด์หรือ conversion ของเนื้อหา
ข้อมูลนิยาย ปก แท็ก และเรื่องย่อใช้ของจริง เพื่อให้ตัดสินจากหน้าจอที่ใกล้การใช้งานจริง
ส่วนข้อความตัวอย่างในหน้าอ่านเป็นข้อความกลาง ๆ ที่เขียนขึ้นสำหรับดูตัวอักษร ไม่ใช่เนื้อหาตอนจริง

## รอบที่ 2 — มินิมอล 3 แบบ

รอบนี้เพิ่มหลังจากรอบแรกยังไม่ถูกใจ โดยทั้งสามแบบลดการ์ด เงา และสีจัดลง แต่ใช้วิธีจัดวางและน้ำหนักตัวอักษรต่างกัน

### 4. โปร่ง / Ma — มินิมอล เงียบ เว้นที่ว่าง

- อารมณ์: กระดาษขาวอุ่น งานสิ่งพิมพ์ญี่ปุ่นที่เหลือเพียงพื้นที่ว่างกับตัวอักษร
- สี: ขาวอุ่น `#F7F6F1`, หมึก `#1D1D1A`, เขียวมอส `#6E7A66`; โหมดมืดเกือบดำ
- ตัวอักษร: Prompt Light สำหรับหัวเรื่องและชื่อหนังสือ, Sarabun สำหรับเนื้อหา
- โครง: ชั้นหนังสือเป็น **รายการแนวตั้ง** ปกเล็ก ตัวอักษรเบา เส้นคั่น 1px และไม่มี card; หน้าอ่านใช้พื้นที่ว่างเยอะมาก
- จุดจำ: ความเงียบและสัดส่วน whitespace ไม่มีตรา ไม่มีเงา ไม่มีป้าย
- แลกกับ: อาจดูจืดหรือเปลืองพื้นที่บนแท็บเล็ต และการนำทางต้องพึ่งตัวอักษรเป็นหลัก

### 5. กริด / Swiss — มินิมอล ตาราง ตัวอักษร

- อารมณ์: International Typographic Style / นิตยสารออกแบบ หัวเรื่องใหญ่ ตารางชัด
- สี: ขาว `#FFFFFF`, ดำ `#0A0A0A`, น้ำเงินไฟฟ้า `#1F4BFF`; โหมดมืดดำสนิท
- ตัวอักษร: Prompt SemiBold สำหรับหัวเรื่อง, Sarabun สำหรับตารางและเนื้อหา
- โครง: ชั้นหนังสือเป็น **ตารางรายการ** มีหัวคอลัมน์ เรื่อง/ผู้เขียน/อ่านแล้ว; hero อ่านต่อเป็นคู่ปกกับข้อความ; รายละเอียดมีตาราง metadata
- จุดจำ: เส้นหนัก 2px, มุมเหลี่ยมทั้งหมด, ตัวอักษรใหญ่, accent น้ำเงินใช้เฉพาะ action
- แลกกับ: ดูเป็นเครื่องมือ/นิตยสารมากกว่าแอปอ่านนิยาย และตัวอักษรใหญ่กินพื้นที่บนมือถือ

### 6. นุ่ม / Calm — มินิมอล นุ่ม สงบ

- อารมณ์: แอปพักผ่อนตอนกลางคืน สีเขียวเซจ เงานุ่ม มุมโค้ง
- สี: หินอุ่น `#F2F1EC`, ขาว `#FFFFFF`, เซจ `#7C8F7A`; โหมดมืดเขียวเข้ม
- ตัวอักษร: Prompt Light สำหรับหัวเรื่อง, Sarabun สำหรับเนื้อหา
- โครง: การ์ดอ่านต่อและปกแบบ rounded 18–22, ช่องค้นหาเป็น pill, หน้ารายละเอียดจัดกลาง, dock อ่านลอยเป็น pill
- จุดจำ: เงานุ่มมาก, สีเซจ, การ์ดขอบมน, จังหวะห่างสบาย
- แลกกับ: ใกล้เคียงกับภาษา UI ทั่วไปที่สุดในชุดนี้; ต้องระวังไม่ให้กลายเป็น card kit ซ้ำ ๆ

## รอบแรก — 3 แบบที่ลองแล้ว

### 1. วะชิ / Washi — กระดาษ หมึก ตราประทับ

- อารมณ์: วารสารวรรณกรรมญี่ปุ่น เงียบ มีระยะหายใจ ไม่เร่งให้กด
- สี: กระดาษอุ่น `#F2ECDF`, หมึก `#211D17`, ชาด `#A63A2B`; โหมดมืดเป็นกระดาษดำอุ่น
- ตัวอักษร: Noto Serif Thai สำหรับหัวเรื่อง/ชื่อหนังสือ, Sarabun สำหรับข้อมูลประกอบ
- โครง: หัวเรื่องแบบ editorial, แถบอ่านต่อเป็นคู่ปกกับข้อความ, เส้นคั่นบาง, ปกวางบนพื้นกระดาษแทนการ์ด, สารบัญเป็นดัชนีมีเลขบท
- จุดจำ: ตราประทับ `読` และเส้นหมึกบาง
- ปรับล่าสุดตาม feedback: ชั้นหนังสือใช้การ์ดขอบมนมีกรอบ, มีช่องค้นหา, แท็กเป็น pill, รายละเอียด/สารบัญ/ช่องอ่านมีกรอบและมุมมนขึ้น โดยยังคงกระดาษ หมึก และตราประทับ
- แลกกับ: ใช้พื้นที่มากและให้ความรู้สึกอนุรักษ์นิยม ถ้าอยากได้แอปที่ดูทันสมัยกว่านี้จะไม่ตอบโจทย์

### 2. ซีน / Zine — มังงะ ป็อป กราฟิกหนัก

- อารมณ์: นิตยสารมังงะ/ซีน ดิบ เสียงดัง กดแล้วสนุก
- สี: ครีม `#FFF3DC`, ดำ `#111111`, แดง `#FF4A2A`, เขียวมะนาว `#D7FF3F`; โหมดมืดดำสนิทกับเงาแดง
- ตัวอักษร: Kanit หนักสำหรับหัวเรื่อง, Sarabun สำหรับเนื้อหา
- โครง: wordmark ใหญ่, การ์ดอ่านต่อขอบดำหนา + เงาแข็ง, ช่องค้นหาแบบแผง, แท็กเป็นสติกเกอร์, ปกหนังสือมีการ์ดขอบหนา
- จุดจำ: เงาแข็งแบบ offset, เทปกระดาษ, สติกเกอร์เอียงเล็กน้อย
- แลกกับ: รายละเอียดเยอะและพลังงานสูง อาจล้าตาเวลาอ่านนาน ๆ จึงต้องคุมจำนวนสติกเกอร์/เงาในหน้าจริง

### 3. ราตรี / Nocturne — ภาพยนตร์ กลางคืน ทองคำ

- อารมณ์: ห้องสมุดกลางคืน/โปสเตอร์ภาพยนตร์ หรู แต่ยังอ่านสบาย
- สี: midnight `#070A11`, ผิว `#0F1520`, ครีม `#F4EFE4`, ทอง `#D9A441`; โหมดสว่างเป็นฟ้าเทาอ่อน
- ตัวอักษร: Noto Serif Thai สำหรับชื่อเรื่อง, Prompt สำหรับ UI และเนื้ออ่าน
- โครง: hero แบบโปสเตอร์ที่มีปกจริงวางคู่ข้อความ, พื้นหลังปกจาง ๆ, การ์ดโปสเตอร์ในชั้นหนังสือ, ปกรายการตอนแบบเรียบ, dock อ่านที่มีเส้นทอง
- จุดจำ: เงาของปกที่จางอยู่ในฉากหลัง, เส้นทอง, ตัวอักษร serif บนพื้นมืด
- แลกกับ: โทนมืด/หรูอาจดูจริงจังเกินไป และต้องระวังคอนทราสต์ของข้อความรองในโหมดสว่าง

## สิ่งที่สร้างในรอบนี้

- `src/screens/DesignLabScreen.tsx` — ตัวสลับ 6 คอนเซปต์, 3 หน้าจอ, โหมดสว่าง/มืด
- `src/design-lab/` — token/palette, ข้อมูลตัวอย่าง, และหน้าชั้นหนังสือ/รายละเอียด/อ่านของแต่ละคอนเซปต์
- เพิ่มฟอนต์ `@expo-google-fonts/noto-serif-thai` และน้ำหนัก Kanit/Prompt ที่ใช้
- ทางเข้า: ปุ่ม palette ในชั้นหนังสือ (เฉพาะ `__DEV__`) และเปิด Design Lab เป็นหน้าแรกเฉพาะ development build
- ไม่แตะข้อมูลตอน, ตัวแปลง, manifest หรือหน้าแอปจริง; ปุ่ม X ใน lab กลับไปแอปเดิมได้

## วิธีดู

```bash
cd reader-mobile
npx expo start --localhost
```

เปิด Expo Go แล้วโหลดโปรเจกต์ จากนั้นสลับคอนเซปต์/หน้าจอที่แถบด้านบน และสลับสว่าง-มืดด้วยปุ่มพระจันทร์
ในหน้ารายละเอียดสามารถแตะปก/รายการตอนเพื่อไปหน้าอ่าน และกดลูกศรกลับเพื่อกลับชั้นหนังสือ

## Validation

- Typecheck: `npm run typecheck` ผ่าน (เพิ่ม `--stack-size=8192` ให้ `tsc` เพราะ Termux/Android stack เริ่มต้นตื้นเกินไป; บนเครื่องอื่นยังใช้ `tsc` ตัวเดียวกัน)
- Lint: `npm run lint` ผ่าน
- Tests: `npm test` ผ่าน 12 suites / 174 tests (รวม smoke test ของ Design Lab ทั้ง 6 คอนเซปต์)
- Android export: `npx expo export --platform android --output-dir dist/android --max-workers 2 --no-bytecode` ผ่าน (3024 modules; 36 assets)
  - ไม่ได้ตรวจ Hermes bytecode เพราะ Hermes compiler ของ Expo ไม่รองรับ host เป็น Android/Termux (`Unsupported host platform for Hermes compiler: android`)
- Device: Samsung SM-X820 (Galaxy Tab S10+), Expo Go 58.0.5, landscape 2800x1752 @ 320 dpi
  - ตรวจด้วยตาแล้ว: 3 คอนเซปต์รอบแรก × ชั้นหนังสือ/รายละเอียด/อ่าน × โหมดสว่าง/มืด; แตะปก/แท็บ/บท และปุ่มสลับโหมดได้
  - รอบมินิมอล: ผ่าน automated render/smoke test ของทั้ง 6 คอนเซปต์; ยังไม่ได้เก็บ screenshot/ตรวจสายตาบนอุปกรณ์รอบนี้เพราะ adb หลุดระหว่างทำ
  - ยังไม่ได้ทำตาม Reader contract เต็มชุด (offline, resume, TalkBack, APK install) เพราะรอบนี้ไม่ได้แก้ behavior การอ่าน; ต้องทำในรอบ implement คอนเซปต์ที่เลือก

## ขั้นต่อไปหลังเลือก

1. ยืนยันคอนเซปต์ที่เลือกจาก 6 แบบ (หรือผสม เช่น Ma shelf + Calm reader)
2. แปลง token ของคอนเซปต์นั้นเป็น design system จริงของ `reader-mobile` แทน palette ชั่วคราว
3. ปรับ `BookshelfScreen`, `NovelDetailScreen`, `ReaderScreen` และ component ที่เกี่ยวข้อง
4. ตรวจ typecheck/lint/ทดสอบบนเครื่อง แล้วลบ Design Lab หรือเก็บไว้หลัง dev flag
5. ตรวจ dark/light, safe area, touch target 48dp, และคอนทราสต์ก่อนส่ง
